## 一、两条片型的流程总览（G0–G6 公共骨架）

骨架统一按 `AGENTS.md` §三 的 G0–G6 走，两条片型只是每关的具体方法不同：

| 关 | 真人短剧（§二） | 小说漫剧（§三） |
|---|---|---|
| **G0 立项 + 风格** | 用大纲公式定类型/主题/主角/冲突/爽点/时长（§2.1）；视觉基线、色彩脚本与风格锁按 `导演视觉圣经.md` | 步骤 1 定人设与美术基调，产出一段**画风基底词**（Style Anchor），全篇生图复用（§3.1） |
| **G1 剧本** | 大纲公式 → 剧本生成提示词 → 标准格式剧本，结尾停"黑屏。"（§2.1–§2.2） | 步骤 1 文本解析与人设拆解 → 步骤 2 漫剧多格分镜剧本（§3.1） |
| **G2 视觉资产** | 人物双参考板 / 场景总览与所需机位板 / 道具身份细节合板（§2.4–§2.6） | 立绘与关键帧共用同一人设表（角色外貌、常驻服饰、核心道具）+ 画风锚点；资产三库带版本跨集复用（§3.1、§4.1） |
| **G3 分镜 + 首帧** | 真实剪辑镜头与生成段弹性映射，按需首帧；提示词只翻译已锁定导演意图（§2.3、§2.7） | 4–8 格漫剧分镜表 → 关键帧按需出图（§3.1 步骤 2–3） |
| **G4 逐镜生成** | 图生视频公式：主体动作 + 动作顺序 + 表情视线 + 镜头运动 + 环境动态（§2.8） | 首帧图驱动 + 动态与镜头提示词，单次批量至多 3 条（§3.1 步骤 5） |
| **G5 音频** | 按分镜表配音配乐（§2.10 第 9 步） | 台词 TTS 原样还原 + 拟音/氛围音乐（§3.1 步骤 4） |
| **G6 成片交付** | 剪辑成片与交付按 `06-后期与发布/成片与字幕.md` | 同左；音频按 §4.8 分轨交付 |

**公共纪律（两片型同源，§二 / §三 不再重复）**：

- **资产先锁定再拆镜**：预拆镜只用于估计资产需求，不在 G2 前冻结最终分镜；角色/场景/道具冻结后才进 G3 最终分镜与逐镜关键帧（细则见 `AGENTS.md` §三）。
- **分步落地，不盲目烧算力**：角色形象与分镜未经确认/自检前，不进入耗算力的批量生成；用户开启阶段审核时在对应步骤等待确认，全权委托时由 Agent 自检并记录后继续（`AGENTS.md` §一.4）。真人短剧的确认点是资产验收（§2.4–§2.6），漫剧的确认点是步骤 1 人设与美术基调、步骤 2 分镜方案（§3.1）。
- **一致性靠图像条件，不靠文字碰运气**：参考板/立绘必须作为**图像条件**接进生成链（身份锚硬闸 + 一致性前置目检闸，见 `AGENTS.md` §三）。
- **失败回退统一走** `AGENTS.md` §五 回退链，两片型不各写一套重抽预算；工程化补充见 §四。

## 二、真人短剧全流程

> 适用：AI短剧 / AI漫剧 / AI动画 / AI广告 / AI微电影
> 原教程用过的工具链只作来源背景，不构成选型要求；生产实现查项目《能力登记.md》。
> 本版公式已与原始示例逐条核对，可直接复制使用
> 制作流程原为「剧本 Script → 分镜脚本 Storyboard → 人物设定 Character Design → 资产生成 Asset Generation → 视频创作 Video Creation → 剪辑成片」，已并入 §一 的 G0–G6 对照，本节只保留真人短剧特有的公式与执行顺序。

### 2.1 短剧剧本大纲公式（图03/04）

```
【短剧类型】：现代言情 / 古装逆袭 / 悬疑反转 / 家庭伦理 / 玄幻漫剧 / 古装甜宠...
【故事主题】：一句话说明这个故事主要讲什么。
【主角设定】：主角是谁？身份、性格、当前处境、目标是什么？
【核心冲突】：主角遇到了什么问题？谁在阻碍主角？
【核心爽点/反转】：这一集最想让观众爽在哪里？反转点是什么？
【故事时长】：例如 1分30秒 / 2分钟 / 3分钟
```

**示例（古装甜宠）**：
- 类型：古装甜宠 / 轻喜剧
- 主题：贪吃灵动的少女误闯王府偷吃点心，意外撞上冷面王爷，被迫留下成为"专属试菜员"的甜宠故事
- 主角：苏小棠——古灵精怪、胆子大、贪吃又机灵
- 冲突：上元节翻墙误入王府禁地，撞上王爷萧寒，被暗卫误认为刺客
- 爽点：不是被抓去审问，而是被王爷强势留下；"偷吃罪名"变成"专属试菜员身份"

### 2.2 剧本生成提示词（图05，整段复制可用）

```
# Role
你是一位精通爆款短剧创作的资深编剧，擅长将扁平的大纲转化为画面感极强、节奏紧凑、反转不断的专业短剧剧本。

# Goal
用户会为你提供【短剧类型】、【故事主题】、【主角设定】、【核心冲突】、【核心爽点/反转】和【故事时长】。你需要严格按照下方指定的【标准剧本格式】和【写作原则】，将其拓展为单集短剧剧本。

# Writing Principles（核心写作原则）
1. 视觉化呈现：这是教程原文的短剧默认写法；本体系现行规则允许必要的内心活动/旁白，但必须明确标注并由画面或声音设计承接。所有人物情绪、心理活动必须通过"可拍摄的动作、眼神、微表情或内心 OS"来展现。
2. 节奏紧凑：根据用户要求的时长（通常 1.5-3 分钟），单集一般控制在 3-4 个场景内。开篇 5 秒必须有视觉抓手，结尾必须卡在核心爽点或反转的"钩子"上。
3. 动作与对白：对白要精炼、口语化，严禁长篇大论。在对白前必须用括号注明人物的【神态/语气/小动作】。
4. 转场规范：场景之间切换时，需使用"转场至："、"与此同时："、"切回："等明确的转场提示词。

# Standard Script Template（必须严格遵循的剧本格式）

《【AI 根据主题拟定一个吸睛的剧名】》
专业短剧剧本格式 | 由分镜脚本整理
类型：【填入用户提供的类型】
篇幅：短剧单集（对应时长：【填入用户提供的时长】）
主要人物：【根据大纲提炼出核心出场人物及姓名】

第一场【内景/外景】|【具体地点】|【时间：日/夜】
人物：【本场出场的人物姓名】
【描写本场的环境、氛围、灯光，字数在 50-100 字左右，拉开故事序幕】
【描写人物进入画面后的具体动作、细节。】
【人物名字】
【括号内写神态、动作或内心 OS】
【台词内容】

（如果有多个场景，依此类推，场景间用转场词衔接。最后一场结尾必须以"黑屏。"结束）

# Workflow
1. 解析用户提供的大纲要素。
2. 按照【标准剧本格式】输出单集剧本。
3. 确保结尾停在最精彩的反转或悬念处（即用户提供的核心爽点）。
```

### 2.3 分镜脚本生成提示词（图06，整段复制可用）

```
# Role
你是一位资深电影导演兼顶尖 AI 分镜设计师，擅长将文字剧本转化为适合短剧现场拍摄或 AI 视频生成（如 Kling, seedance2.0 等）的高质量专业分镜脚本。

# Core Rules
1. 弹性拆镜：教程原文的 1:1 单镜映射不是现行规则。真实剪辑镜头与生成段可以一对多或多对一；只有观看重点、主体、情绪、动作阶段、空间方向、道具状态或声音理解变化时才切镜，服务同一结果的连续动作可以合镜。
2. 短剧景别规范：这是教程原文的局部叙事偏好；本体系允许用大远景/全景先交代空间，具体按导演视觉圣经与 G3 分镜判断。以中景、近景、面部特写、道具特写为主，建立局部空间感，聚焦人物神态。
3. 可落地运镜：严禁炫技，多用固定、轻微推/拉、横移浅景深、越肩、极速前推急停（撞击感）等。
4. 视听配合：
   - 音效（SFX）：精准具体（如衣服摩擦、木门吱呀、清脆金属声、咀嚼声）。
   - BGM：随情绪段落明确提示起承转合（如：垫乐起、甜宠推进、戛然而止）。
   - 对白：短小、高情绪张力，符合短剧节奏。

# Output Format
请严格按照以下 Markdown 表格格式输出：

| 镜号 | 景别 | 运镜 | 画面内容（动作/神态细节） | 参考对白 / 音效 / BGM |
| :--- | :--- | :--- | :--- | :--- |

# Process Workflow
1. 拆解：理清剧本主线与情绪转折点。
2. 细化：严格按规则将剧本拆分为独立的单一镜号。
3. 对齐：为每镜填充景别、运镜、画面细节与精准音效 BGM。
4. 输出：渲染为 Markdown 表格。

# Example
| 镜号 | 景别 | 运镜 | 画面内容 | 参考对白 / 音效 / BGM |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 全景 / 背影 | 固定，轻微推进 | 上元节夜景，花灯如昼，高墙森严。 | BGM：悬疑垫乐起；音效：夜风、石阶轻脚步。 |
| 2 | 近景 / 特写 | 固定，极轻缓推 | 苏小棠趴在墙头，古灵精怪的大眼睛四处张望。 | 音效：轻呼吸；BGM 压低。 |
| 3 | 胸口近景 | 极速前推，撞击急停 | 苏小棠往前走，头狠狠撞上了王爷的胸膛。 | 音效：沉闷撞击"咚"；BGM 戛然而止。 |
```

> 本节保留外部教程示例供溯源；真实剪辑镜头与生成段的划分以 `02-分镜与镜头/分镜工作流.md`「进阶补充三」的弹性拆镜为准，不再执行 1:1 单镜映射铁律。

### 2.4 人物资产公式（双参考板交付，单图按需制作）

**当前交付规则**：身份造型板（左侧正面半身定妆、右侧正/侧/背全身三视图）+ 同一身份派生的日常表情九宫格，两板共同冻结、统一版本。原教程图13的独立三图组合保留为方法来源，**不再作为必须三张交付的要求**；一次性剪影/远景路人按需减量。

**当前生产顺序**：先确认角色身份与服装 → 制作身份造型板 → 从同一身份派生日常表情九宫格 → 两板同身份核对、小样与统一版本冻结。默认交付布局、九种日常表情、完整提示词和验收要求统一见 `03-角色与视觉资产/角色资产参考板.md`。

下列 2.4.1–2.4.6 的原教程单图公式保留用于制作源图、局部修正或必要补图，不要求独立交付定妆、三视图、肖像三张。可分图核对后拼成两板，源图保留；镜头按需选择整板或裁图并登记父板版本/区域，非每镜两张全上。仅首帧模式先做正式场景首帧，不直接将合板作为剧情首帧。

#### 2.4.2 人物三视图提示词公式（图08）

```

视图规格：生成一张完整的人物三视图资产图，在同一画面中同时展示角色的标准正面全身、标准90度侧面全身和标准背面全身。

输出要求：写实真人短剧人物资产图，高清细节，适合作为后续分镜设计、角色一致性控制和视频创作参考。
```

```
输出要求：写实真人短剧人物肖像资产图，高清细节，适合作为后续近景、特写镜头和角色一致性控制参考。
```


### 2.5 场景资产公式

#### 2.5.1 场景资产的定义（图14）

G2 按剧本与预拆镜准备空间总览及所需机位，G3 最终分镜再核对覆盖；不要求先冻结最终分镜才做资产。详细规则见 `03-角色与视觉资产/场景与道具资产.md`。提前把短剧里面会用到的场景按需制作好（含案例：上元节街市 / 府邸后墙 / 后厨）

#### 2.5.2 场景资产基础信息六要素（图15）

```
时代背景 / 地点 / 空间结构 / 核心陈设 / 时间 / 画面灯光 / 整体氛围
```

#### 2.5.3 场景提示词公式（图16，按空间与机位适配）

### 2.10 使用说明（真人短剧执行顺序）

1. **大纲**：用【短剧剧本大纲公式】确定类型/主题/主角/冲突/爽点/时长
2. **剧本**：把大纲喂给【剧本生成提示词】→ 得到标准格式剧本（结尾"黑屏。"）
3. **预拆镜**：由剧本估计机位、景别、站位与资产需求，形成草案，不在 G2 前冻结最终分镜
4. **角色资产**：按【身份基准】→【身份造型板】→【同身份日常表情九宫格】制作并逐区域检查；单图公式可用于源图/补图。两板共同冻结、统一版本，实际整板/裁图输入通过小样后再批量。
5. **场景资产**：按预拆镜制作【空间总览 + 所需机位参考板】，复杂走位补规划示意；核对固定空间、机位投影及光源，不强制九格。
6. **道具资产**：制作【身份细节合板】，按需补实际角色交互尺度图和剧情状态图，设计版本/状态分开；选择当前状态后进入首帧。
7. **最终分镜与关键帧**：G2 资产确认后核对最终分镜覆盖，再用【资产约束+画面描述+构图机位】三段式逐镜生成；补充同基准机位可登记检查，改布局/身份按解冻规则处理
8. **图生视频**：用【主体动作+动作顺序+表情视线+镜头运动+环境动态】公式生成视频片段
9. **配音剪辑**：按分镜表配音配乐、剪辑成片（配音语速180-220字/分，1分钟15-25个镜头）

## 三、小说漫剧全流程

专业的小说漫剧总导演与多媒体制作人工作方式：把用户输入的小说正文或故事片段，系统化拆解为漫剧分镜，并协同调用已登记能力完成角色立绘/关键帧生图、台词配音与分镜动态视频生成。

> 总流程骨架（G0–G6 对应）见 §一；本节保留漫剧特有的五步方法与边界纪律。
> 原文中的 `generate_image` / `generate_audio` / `generate_video` 是原流程的实现名（含 `items`、`operation: "speech"` / `"generate"`、`first_frame_image_url` 等字段）；本体系按项目《能力登记.md》选择当前实现并做对应预检，下列步骤只保留能力与批量上限，实现字段以能力登记为准。

### 3.1 阶段详解（步骤 1–5）

采用**分步协同推进**流程：步骤 1 与步骤 2 是确认点——用户开启阶段审核时在此等待确认，全权委托时由 Agent 自检并记录后继续；未经确认/自检不得直接批量消耗算力生成最终视频。

```
[步骤 1: 文本解析与人设拆解] ➔ [确认人设与美术基调]
  ➔ [步骤 2: 漫剧多格分镜剧本] ➔ [确认分镜方案]
  ➔ [步骤 3: 关键帧出图]
  ➔ [步骤 4: 角色台词配音]
  ➔ [步骤 5: 图生视频与动效合成]
```

#### 步骤 1：文本解析与人设定调

1. **提取核心要素**：
   - 故事冲突与高潮点。
   - 出场角色（外貌特征、服饰、体态、性格特征、代表性色彩）。
   - 核心场景与世界观定位。
2. **确定视觉画风**：
   - 根据小说类型自动推荐最匹配的美术风格（如：修仙玄幻推荐国风厚涂漫，科幻悬疑推荐赛博朋克漫，都市言情推荐韩漫精修条漫风），并提供 1 段画风基底词（Style Prompt Anchor），供后续生图复用以保持全篇画风统一。
3. **输出《漫剧人设与设定表》**供审阅确认：
   - 角色名称、视觉定位、常驻服饰、核心道具。
   - 推荐画风与色彩基调。
   - 用户开启阶段审核时在此等待修改意见，确认无误后进入步骤 2；全权委托时 Agent 自检记录后继续。

---

#### 步骤 2：漫剧分镜剧本设计

将文本转化为 4-8 个极具张力的漫剧分镜（镜头数量可随小说段落长短合理增减），每个分镜按以下结构规范呈现：

| 镜号 | 景别与运镜 | 画面主体与动作设计 | 构图与光影氛围 | 台词/旁白 | 拟音/BGM情绪 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 01 | 特写 / 慢推镜头 | 少年主角紧咬下唇，额角流下汗珠 | 侧逆光，强调阴郁与紧张 | 旁白：“那是他第一次直面命运的审判。” | 紧促心跳声，低沉大提琴 |

输出分镜表后确认分镜节奏与画面安排（用户开启阶段审核时征询意见："以上分镜节奏与画面安排是否满意？若无问题，我们将开始生成分镜关键帧画面与角色配音"；全权委托时 Agent 自检后继续）。

---

#### 步骤 3：分镜关键帧生成

1. **一致性约束**：
   - 严格在每张分镜生图提示词中携带步骤 1 确定的画风锚点词（Style Anchor）与统一角色外貌描述。
   - 画面应具备漫画感（如分镜框感、手绘质感、动态张力）。
2. **批量并发调用**：
   - 按当前实现的批量参数并发生成；**单次批量上限 5 张**，分镜多于 5 张时分批请求。
   - 默认横屏 16:9 统一画幅（竖屏 9:16 为备选，按用户指定或上下文题材匹配）。

---

#### 步骤 4：台词与音效生成

1. **文字转语音 (TTS)**：
   - 针对有对白或旁白的分镜，走当前实现的对白/TTS 路径。
   - 传入原样台词文本（严禁对台词进行提示词扩写，原汁原味还原台词）。
   - 批量多段台词按实现的批量参数并发调用。
2. **环境音效与氛围音乐 (SFX/BGM)**：
   - 当需要特殊拟音（如：刀剑碰撞声、雷鸣电闪、心跳声）时，描述声音的类型、节奏与质感再生成。

---

#### 步骤 5：图生视频动态化

1. **首帧图驱动**：
   - 新场次第一镜用步骤 3 的关键帧。同场下一镜改用上一镜审核过的末帧，或由该末帧修好的静帧。禁止每镜都用一张重新采样的关键帧当起点。
2. **动态与镜头提示词**：
   - 提示词重点描述镜头运动（慢推、环绕、平摇、急速拉远）与主体微动作（长发飘动、眼神转动、法术光效聚拢、嘴唇微动）。
   - 避免提示词破坏原始图像的人物结构，保持连贯性。
3. **调用规范**：
   - 单次批量至多 3 条，且只限于不同场次。同场下一条必须使用上一条审核过的末帧，不得并发重采样。时长按分镜的刀来剪，生成段全长不等于成片镜头时长。协议见 `AGENTS.md`「成片生成裁决」。
4. **兜底**：整段视频反复翻车（动作崩坏/身份漂移）时按 §4.2 降级为静态关键帧 + KenBurns 动态化。

---

### 3.2 边界与质量把控

1. **避免算力浪费**：在角色形象或分镜未经确认前，不盲目调用视频生成；分步落地，逐步把控。
2. **角色一致性保障**：在同一集的多个镜头中，角色核心特征（如发型、发色、瞳色、标志性服装、武器）在 prompt 中保持固定词组命名。
3. **故障与回退**：若特定分镜生图不符合预期，允许指定单个镜号进行局部微调重绘，而无需推翻整套分镜；重抽预算与回退顺序见 `AGENTS.md` §五 与 §4.2。

## 四、工程化生产机制（两片型通用）

> 本节管"多集连做、批量交付时不乱套"。单集试片可忽略；一旦开连载，建议逐条落实。来源为 2025–2026 年多个开源端到端管线与漫剧管线的共性实践；两条片型同源，§二 / §三 不重复写。

### 4.0 生产模式分级

| 模式 | 适用 | 默认自主检查节奏 | 首集验证 |
|---|---|---|---|
| 精品单集 | 单集 3–8 分钟、重质不重量 | 每阶段自检，关键镜头逐镜检查；用户开启审核时可按阶段递交 | 可选 |
| 量产连载 | 日更或几十到几百集 | 首集全流程自检，后续每 5–10 集里程碑复检；用户开启审核时递交对应批次 | 必做，作为放量内部闸 |

量产中间集按冻结资产与分镜规则执行并记《执行清单》。质量下滑先暂停放量并做质量归因；精品模式提速先评估冻结范围是否支持。任何模式都不放松身份锚、连续交接、真实证据、平台语法、提示词契约、声音路线和能力登记。

### 4.1 资产锁定先于生成、跨集复用（反"抽卡式"）

开源工业化管线的共同结论：**先把角色/场景/道具资产锁死冻结，再进关键帧与视频生成**，生成期不返工改资产。对应本 SOP：§2.4–§2.6 的资产检验规则（图09/12/17）是硬闸口，没过检的资产不许流入 §2.7 的逐镜关键帧。靠提示词碰运气 = 无限重抽 = 成本黑洞。

跨集复用（漫剧管线做法，真人片型同样适用）：文本解析时同步产出**角色库 / 场景库 / 道具库**三张表，每个资产带版本号。跨集复用同一资产，改人设 = 升版本号 + 只重跑受影响镜头，不要每集重新生成全部角色。

### 4.2 断点续跑与失败回退

- 每个生成步骤默认**最多 2 次质量重抽**；限流、排队超时等瞬态错误可额外进行 **1 次技术重试**。质量重抽 2 次仍败就跳过打标并进入回退链（`AGENTS.md` §五），最后统一处理，不让单镜卡死整集。
- 降级顺序：单镜质量重抽 ≤2 次仍不达标 → 换备选模型/实现 → 再不行用 **KenBurns 兜底**（静态关键帧 + 推拉摇移变焦动态化）→ 记录待人工处理，不阻塞整集。漫剧的回忆、独白、过渡段落用 KenBurns 反而更有"漫画感"，也省算力；保底永远要有，不跟模型死磕。
- **2026-10-23《尸变》样片实测**：当时 8GB 显存本机跑漫剧，KenBurns 是该样片唯一跑通的量产路线；这是项目实测记录，不是所有片型的永久结论。立项时必须在《能力登记.md》声明生产路线及数字运动占比：`静帧+数字轻推` 承担主体叙事会触发 ROUTE-01，不能把 FAIL 改称通过，也不能把插入镜伪装成生成运动。若选择该路线，就把它作为明确的路线取舍与交付限制记录，另做真实回放验收；若项目要求 ROUTE-01 通过，则必须增加真实生成动作并倒推算力预算。
- 已有产物**智能跳过**：重跑流水线时只补缺口，不覆盖已通过检验的旧资产。
- 每集结束把整集工程打包归档（分镜表/资产图/提示词/成片），可整体搬家、可回溯。

### 4.3 长任务队列化

视频生成是长任务（单镜数十秒到数分钟）。不同场次可以排队并行，失败单任务重试不阻塞其他场次。同场视频必须等上一镜末帧审核通过再生成下一镜，规则见 `AGENTS.md`「成片生成裁决」。不要为了队列把同场每一镜重新采样。

### 4.4 算力成本台账

逐镜记录所用模型与单次花费，一集一汇总。作用：发现"哪个环节烧钱最多"（通常是视频重抽），用数据决定是改提示词还是改流程；超预算的集数在立项时就能预警。

### 4.5 多供应商 fallback（应急专用）

图/视频/文本三类模型独立配置，单一供应商限流或故障时切换。**注意**：切换供应商 = 画风断裂风险，仅限同类别素材应急使用，主角戏不中途换。

### 4.6 画布工作流管理长剧

整季项目用"画布视图"管全局（每镜一个节点、流水线竖排、整组重跑），单集用"列表视图"抠细节。画布视图已被多个开源管线验证为长剧管理的最佳形态。

### 4.7 关键帧批量一致性

关键帧量大时，可用共享注意力类工具（StoryDiffusion/ConsiStory 思路）批量出同风格同身份帧，详见 `03-角色与视觉资产/角色一致性.md` §七 模型层身份保持能力；批量不超过 4-6 帧，超长序列分批衔接。

### 4.8 音频分轨交付

音频**分轨交付**（配音/音效/BGM 各自独立文件），不要只交混好的单轨——`06-后期与发布/成片与字幕.md` 需要分轨做音量层级与卡点微调。

### 4.9 本地部署选项（数据不出本机）

Wan 2.x、HunyuanVideo、LTX-Video 等开源视频模型可在本地跑通"剧本→分镜→视频"闭环：素材与剧本不出本机、零 API 费。代价是画质与可控性目前仍低于商用 API——推荐用于草稿预览、敏感题材和断网场景，正片量产仍走商用模型。
