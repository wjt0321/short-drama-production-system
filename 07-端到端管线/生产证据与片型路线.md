# Agent简明制作流程

本文件替代上一版生产证据硬门禁。无需production.json、哈希、签核证据或固定片型注册。不要把准备文件当成制作本身。

**制作落点**：先按 `AGENTS.md` 第六节创建或定位 `00-视频项目/《片名》/`，所有本片输出（含前置验证小样）进入该项目，不写入体系根目录。

**关卡定义唯一权威在 `AGENTS.md` §三（B7，2026-10-12）**：本文件不复述 G0–G6、不另立关卡，只做执行层的方法细则与导演判断清单。

1. **判断要做什么。** 从用户目的判断是剧情、展示、生活复刻、广告、音乐影像或其他形式，不限类别。用几句话写清观众看什么、画风与时长。用户委托时Agent自己决定，不逐项追问。即使用户未提光照、构图或风险，也必须启动下文“主动导演判断与前置风险预检”，先识别可能决定成败的要求，再承诺制作路线。
2. **先形成导演判断，再创作。** Agent 先从剧本目标、受众、情绪曲线、导演视觉圣经和当前资产中推导风格、构图、导演视角、光线与提示词方案，再用风格探针验证并锁定基线。用户提供的参考或项目已有素材只作为可选输入；体系不默认读取外部参考库，也不把外部样片当作风格模板。每项借鉴都记录“参考文件/出处 + 借鉴点 + 不适用处”，不得整段复制提示词或照搬成图。联网、下载、付费和外发按授权；按内容组织镜头，不固定三幕、数量或等长时长。
3. **按顺序制作。** 正式产物仍按角色/场景与关键图、视频、声音、剪辑推进；高风险能力的最小样片或试听应前置，不受正式交付顺序限制。关键依赖未验证或已知不适配时，先按下文停止受影响的批量投入并告知，不能先做完整片再验证难点。参考资产保持一致。读当前需要的专项文档即可，不全库加载。单机不支持并发时串行排队。
4. **检查并修当前问题。** 图检查结构与一致性；视频检查动作、人物和衔接；音频检查听感；剪辑后看整体。发现明显问题就修当前镜头或其直接原因，不重新审核整套文件。修改后检查变化部分与必要衔接。
5. **收口。** 能继续修就继续，不把已知不合格片子交成终版。轻微不影响理解的瑕疵不无限追求完美；同一路线两次仍失败，改变动作、构图或实现办法，避免循环抽卡。确实无法完成时说明具体限制与已完成部分。

## 主动导演判断与前置风险预检

本节是导演判断、方法适配和前置预警的唯一细则；全权委托、阶段审核、项目续跑均适用。不是新增审批关卡或哈希门禁，也不要求用户懂术语、手工找资料或逐项点名。从外部吸收的经验（开源运动合同、开源管线、研究档）只作为**按需方法库**：按当前问题检索查阅、验证后使用，不构成新增前置门禁，不默认加载。记录判断结果、简短理由和实际验证依据即可，不记录冗长推理过程。

### 1. 从需求主动推导，不等用户点名

- 接到“做一部某题材短片”，先提炼观众应看到的内容、硬性效果、可调整项和已有授权边界。推导需要的导演判断及高风险能力，不只按用户有没有说“灯光/运镜”来触发文档。
- **方法检索与能力适配分开**：先按下表查当前场景需要的方法，再查项目能力登记验证能否实现。不得按手头工具反向改题材，也不能只用模型常识替代查阅已有方法。
- 以情节目的、场景条件、人物关系、动作/声音需求检索相关章节，通常比较少量候选再选；不要一次通读整库，也不把题材词直接固定映射成某种灯光或构图。
- 每个适用判断留下“内容目的 → 方法出处/具体条目 → 采用理由 → 写入哪项产物”。同场景可复用基准，逐镜只记录差异；不适用写原因，不能空白跳过。固定机位、自然光、单色或静态呈现同样是有效选择，不为显得专业强加复杂效果。

### 2. 风险发现与试样必须早于依赖性投入

**需求进入时就识别风险；一旦发现关键不确定性立即告知，不等试样耗尽预算才说。** 三个时点只逐步补细节，不要求一次完成整片分镜：

1. **立项/剧本方向确定前**：找出会决定方案成立的能力与授权，例如指定真人音色、多人接触、长镜连续性、动态光照、特定画幅交付。先判断可用条件，不用“工具支持”承诺该场景一定成功。
2. **资产/分镜锁定和批量生成前**：用临时或已有合法素材，优先测试后果最严重、最不确定的关键组合，再扩到正式资产。探针不是正式资产冻结，也不能充当最终首帧。无需等整套角色图完成后才发现动作路线走不通。
3. **改变关键条件或续跑时**：检查样片是否覆盖当前实现/版本、输入资产、人数、机位、光照、时长、声音与输出条件；条件变化重验受影响部分，不无故重做全片。

最小验证不是一律“出两张图”：

- 风格与静态光照可先试关键帧；转身、反打或移动光源要看对应动作/相邻机位中的光影一致性。
- 多人互动要试真正的同框接触与遮挡；单人肖像通过不能代表双人动作通过。
- 一镜到底跨技术段要试代表性接缝与动作连续性；单段顺滑不等于跨段成功。
- 露口对白要试实际语种、台词长度、表演与口型；配音应计时并试听，不能等全片视频做完才发现说不完。
- 新交付链先做短片段装配/导出与回放，检查画幅、裁切、字幕/声音是否能落地。

测试前写清**要验证什么、通过/失败的可观察标准、覆盖条件、预计成本/耗时、投入上限和停止条件**。估计与实测分开；无法确认费用或没有必要授权时先问，不用“先试一下”绕过授权。沿用 `AGENTS.md` 的重抽预算，换实现也不能重置项目总投入上限或开启无限测试。

只验证高风险项；已有可比样片确实覆盖当前条件时可复用并说明依据。低规格探针未覆盖的最终细节仍为待验证，不能把草稿成功扩大成全片承诺。目录存在、选卡成功、提示词已写、接口能调用和校验器通过，都不是画面/声音可行性证据。实际回放不可用时明确缺口，不能把未看的试样标为通过。

### 3. 可行性状态与生产状态分开

| 可行性状态 | 意义 | 允许推进的范围 |
|---|---|---|
| 已验证 | 有实际查看/试听或可复用的可比结果，且满足该项标准 | 仅推进样片覆盖条件内的相关生产，批量仍要质检 |
| 待验证 | 未测试、缺少条件或证据不覆盖当前要求 | 可在授权上限内做最小验证；不得扩大依赖它的投入 |
| 不适配 | 已知不支持、样片失败或代价无法满足要求 | 停止受影响生产，说明已知失败范围，进入候选/回退处理 |
| 不适用 | 本项目没有该项需求并说明理由 | 不强行增加复杂效果，不用该状态掩盖用户硬性要求 |

此状态只描述某个要求在某组条件下的结果，不是替换镜头生产状态（生产状态的取值唯一权威 = 项目《执行清单.md》机器白名单）。“不适配”只针对已知路线，不能说成所有工具都绝对做不到。

### 4. 第一时间预警，按影响范围停止投入

出现以下任一情况，**先在当前对话告知并更新项目状态，再继续任何新增的受影响投入**：核心要求已知做不到；关键条件待验证且无法在当前授权下验证；当前风险会推翻角色/分镜或已完成素材；实际成本/工期可能越界；素材授权或输出链存在阻塞。执行中后来发现的新风险同样立即处理，不能等阶段审核或成片交付。

预警用用户能判断的效果描述，至少包含：

- **哪里不确定/做不到**：对应场景或镜号、原要求和实际限制；区分已失败与尚未验证。
- **依据与后果**：已看过的样片/试听/失败记录，或缺失的验证条件；继续做会浪费哪些资产与工序。
- **已停止什么、还能做什么**：列出受影响的镜头与下游，不影响该风险、不会因此报废的工作才可继续。涉及冻结项按 `AGENTS.md` 解冻处理。
- **候选与下一步**：给 2–4 个真实可行或可验证的候选，说明效果损失、新增费用/时间、风险、可逆性和推荐项。不足两个可行候选时如实说只有一条或暂不可行，不凑数、不保证未验证方案。

普通参数修正或已授权的等效替换，告知后可自主试样并记录；改变用户核心效果（例如一镜到底改多镜、正脸对白改旁白）、方向、预算、交期或素材外发授权，需要用户决断，不能以“全权委托”为由静默降级。用户知悉风险不等于验证通过。

**恢复条件**：关键要求在当前条件下已验证，或用户已接受明确的替代要求且替代路线也有足够验证依据；记录变更与剩余风险后再放开相关生产。不能靠把状态改成“完成”或口头接受风险来绕过验证。

### 5. 落到已有产物，不新增手续

- 风格提案记录场景级导演选择、光照基准及关键可行性；分镜记录构图/运镜/照明继承、选择理由和风险关联。
- 测试条件、结果文件、投入及覆盖范围记入项目能力登记；项目状态摘要只保留当前风险、停止范围和下一步。
- 执行清单“备注”指向风险编号或已有记录。使用镜头简表的项目把选择与风险写入“当前问题与处理”，不再复制一套表。
- 每次给用户的阶段结果或进度摘要简短说明采用的导演思路、已验证范围和未解决风险；无关键风险写“当前未发现”，不宣称零风险或未来绝不失败。

## 导演证据包（技术通过 ≠ 作品通过）

> 这一节建立"通过 = 通过"的双轨标准。技术检查全部绿不代表作品成立；技术检查不绿不代表作品不成立。**两轨独立成证，互不替代**。

### 一、技术通过 ≠ 作品通过

- **技术通过**指机器闸与质检表能自动检查的指标——画幅 / 分辨率 / 帧率 / 编码 / 码率 / 黑帧 / 白闪 / 字幕 / 命名 / 完整回放 / 时长方差 / 静帧·冻结占比 / 模式错配 / 合同式反模式 等。
- **作品通过**指观众看完一遍能复述主线、被关键场景打动、记住 1–2 个镜头。技术全绿但作品失败是常见失败形态（某早期样片 v01 就是这种：技术绿，但被识别为"PPT感"）。
- **机器闸不作的作品判断**：动作节拍是否成立 / 摄影机起讫是否合理 / 转场接力是否顺畅 / 环境异步是否到位 / 叙事逻辑是否清晰 / 情感是否传达 / 留白是否有意。这些由**导演证据包**承载。

### 二、导演证据包是什么

导演证据包是项目内一组**可观察、可对照、可移交**的产物，让"作品通过"这个主观判断有依据、能复盘、能交接。证据包不是审批，不是哈希，不是关卡，而是**对照表 + 截图 / 视频片段 + 文字结论**。

| 证据项 | 用途 | 归属 |
|---|---|---|
| **代表镜实拍 / 草稿** | 验证高风险镜头（物理 / 对白 / 多目标 / 长插曲）的可实现性 | `04-镜头/代表镜实拍/` |
| **animatic 低清动态草稿** | 验证节奏 / 切点 / 转场接力 / 长短刀成节拍 | `04-镜头/animatic/` |
| **关键场景对照表** | 同一场景不同镜头的色彩 / 光线 / 轴线对照（防漂移） | `06-成片/导演证据/` |
| **关键场景回放片段** | 1–2 个最能体现作品意图的镜头原片（带时间码） | `06-成片/导演证据/` |
| **失败记录** | 重抽日志、试错结论、模型上限标注 | `04-镜头/重抽日志.md` + `06-成片/导演证据/` |
| **导演笔记** | 每场戏意图 / 关键选择 / 与原剧本的取舍 | `06-成片/导演证据/导演笔记.md` |

### 三、作品判断怎么落地（A/B 评分与观众抽样的处置，2026-10-12）

旧版这里有「A/B 评分每镜必填」和「观众复述抽样 ≥3 人」两道硬闸——**已删**。原因：单人 Agent 场景没有真人观众可抽，也没有校验器查评分是否真填，纯装饰性硬闸，反而稀释真检查。

替代机制（都是机器闸或已有产物，不新增表格）：

- **动作节拍 / 摄影机起讫 / 转场接力 / 环境异步** → 生成前运动设计闸七项（`02-分镜与镜头/分镜工作流.md`）+ 逐秒五要素 / 锚点链 / hook 密度闸（G3 交稿五检）；
- **首帧构图 / 末帧衔接 / 无坏帧** → 项目合规闸 + 逐镜自检；
- **"作品成不成立"** → 导演笔记（为什么这样拍、想让观众看到什么）+ 粗剪完整回放；Agent 自问「观众能说出什么」并写进复盘（见 `06-成片/导演笔记.md` 配套）。

**有真人观众时**（朋友、社群、试映）才追加复述抽样："这片讲什么 / 印象最深哪个镜头 / 哪一处假"——三项记录进导演笔记，不建专门表格。

### 四、技术通过 → 作品通过的跃迁点

技术闸全部绿灯后，仍要做以下三件事才算"作品成立"：

1. **代表镜回放 + 文字说明**：把作品意图最浓的 1–2 镜写一段导演笔记（不是技术说明，是"为什么这样拍、想让观众看到什么"）。
2. **关键场景对照**：把同场戏的所有镜头并排看，确认色相统一、轴线一致、接力成立。
3. **粗剪完整回放**：头到尾完整看一遍，确认叙事清晰、无累赘、无跳跃；Agent 用一句话回答"观众看完能说出什么"，答不出回分镜补刀，不靠旁白遮。
4. **种子还在不在**：对照 G0「具体物件或话语」，在 `06-成片/导演证据/导演笔记.md` 写下它还在不在画面里、意思变过没有、在哪一镜看见。答「不在」，或答不出来，状态保持「技术已通过，作品未验证」，不进交付。`python tools/check_seed_survival.py <项目目录>` 核这几行有没有写实。

未完成这四件事的成片，状态写"技术已通过，作品未验证"，不进交付。

## 前后逻辑小检查（试行）

- 正式安排镜头前，用一句话说清整片的组织线索：观众跟随谁、什么事、什么物件或什么意象变化。不能只用“唯美、繁华、震撼”代替内容；不强制所有作品都有剧情或主角。
- 看过参考后，选择服务这条线索的结构，不把独立作品中的漂亮镜头直接拼盘。每次切镜说清“为什么下一镜在这里出现”：动作结果、视线、空间揭示、声音承接或明确的意象/情绪变化均可。人物、地点、道具或时间跳变时给观众必要提示，不强求所有镜头无缝连续。
- 视频生成前，按成片顺序看首帧拼版，检查组织线索和相邻关系；生成后先连成粗剪，检查实际动作结果与前后关系，再做精修。静帧检查不代替运动检查。不用旁白、配乐或叠化掩盖缺失的动作和逻辑；转场按观看关系选择，不因景别变化自动要求叠化。
- 有问题只调整相关镜头与衔接，不推倒全片、不新建审批文件。上述检查由Agent自主完成，效果留待实际作品验证。

## 时长、切点与连续呈现

先决定叙事段落如何呈现，再决定镜头何时结束与观看多久，最后按工具能力拆生成段。叙事段落、拍摄镜头、AI生成段不是同一个单位。

- 按台词实际语速与停顿、动作过程和结果、信息辨认时间、情绪变化估时；不按总秒数除以镜头数，不为不平均而刻意长短交错。时长是初估，配音与粗剪后校准；超时优先调整内容，不等比例压缩全部镜头。
- 在已有画面描述中说明“连续呈现还是切镜、在哪里结束、为什么在这里结束”。观看重点、反应、信息揭示或节奏变化可以构成切点；没有理由不自动切，不把默认硬切当导演决策。
- 需要一镜到底时，工具分段只是技术实现，不能自动变成成片切点。跨段核对人物身份、位置、视线、运动方向、道具状态、光线和机位/运动；衔接依据要实际检查，不盲目直接使用模型尾帧。
- 连续镜头接不上时，修衔接或调整构图、动作与实现办法；确需改成多镜头，应重新给出合理切点，不用叠化遮盖断裂，也不把分段拼接宣称为成功的一镜到底。工具生成了较长素材，剪辑可以只取有效部分；重要段落需要较长时间，不因工具单次时长而压扁内容。
