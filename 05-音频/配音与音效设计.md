# 配音与音效设计

本 skill 覆盖配音侧三层：**用什么声音说**（§2 选音色、§8 平台专属音色定制）→ **说什么、说多长、什么响声、怎么和画面对上**（§1、§3、§4 配音文案与 SFX 层，是主体）→ **整场戏铺什么情绪**（BGM 层走同目录 `背景音乐生成.md`）。

工具无关：本 skill 的规则在任意配音工具、任意音效生成工具、任意剪辑软件下都成立。具体平台的操作差异按平台文档处理。

## 0. 音频前移（2026-10-12，A7）

> 旧流程 G4 出视频、G5 才配声音——音频是事后 fitting，视频生成时不知道声音是什么。
> 新流程把音频设计前移到 G3：分镜阶段就把每镜的声音设计完，G4 按声音生成、G5 只做执行与混音。
> 佐证：一部获奖 AI 短片的片尾字幕列配音、作曲、声音设计、拟音、录音五个岗位——优秀作品的音频是设计出来的，不是补上去的。

- **G3 每镜填「音频与对白轨」**（分镜表子块）：旁白（文本+时间范围）/ 对白（台词+说话人+语气+时间范围）/ 音效（按时间锚定）/ 表演备注。
- **逐秒第 4 要素同源**：逐秒指令表的「音频线索」列就是该轨的秒级展开；有意静默写 `silent`，不留空。
- **嘴部开合标记**：人物说话的每秒标 `mouth-open: 说话人`；离屏旁白标 `narrator-mouth-closed: true`（画面人物嘴必须闭，否则观众出戏）。
- **BGM 一条连续轨，不逐镜生成**；对白与重要音效处 duck。逐镜只在分镜备注标"此处 duck / 此处留白"。
- **H3 原生双声道音频要用上**：G4 生成时提示词带声音设计（环境声/物声按音频轨写进 `overall_soundscape` 等已登记契约字段），原生轨可作拟音参考或底噪；成品线判定见项目《能力登记.md》。
- G5 的职责从"想声音"变成"按已设计的轨执行 + 混音 + 对表核对"：配音逐镜对照「音频与对白轨」时间范围，偏差 >0.3s 回查。

## 1. 配音文案准备

### 1.1 台词语速基准

以中文普通话、常规情绪为基准：

| 台词类型 | 语速基准 | 换算 |
|---|---|---|
| 常规对白 | 180-220 字/分钟 | 约 3 秒说 10 字，1 秒 3-3.7 字 |
| 旁白 / 内心独白 | 160-190 字/分钟 | 留出画面呼吸空间 |
| 争吵、急促、连续追问 | 220-260 字/分钟 | 情绪上头，但吐字仍需清楚 |
| 悬念铺垫、临终遗言式慢句 | 150-180 字/分钟 | 关键句前后各留 0.3-0.5 秒停顿 |

**速算口诀**：180-220 字/分钟 ≈ 每 1 秒 3-4 字。写台词时直接按这个比例算，不要按阅读速度（阅读速度是配音的 2 倍以上，按阅读速度写必然超长）。

### 1.2 台词量与镜头配比

横屏短片（默认）镜头密度按片型与段落，12–30 个/分钟（详见 成片与字幕）；竖屏短剧 15–25 个/分钟，即：

> 口径说明：15-25 个/分钟指成片剪辑切换点；分镜稿的叙事镜头为单集 8-20 个（见 `02-分镜与镜头/分镜工作流.md` §13.7.2），两者口径不同，不矛盾。

- 平均单镜头时长 **2.4-4 秒**；
- 对应每个镜头承载的口型台词约 **7-15 字**；
- 快切镜头（1-1.5 秒）只配 3-5 字，或干脆不配台词、只用画外音；
- 长镜头（5-6 秒）可到 15-20 字，再多就该拆镜头。

写作阶段的红线：**先按镜头容量写台词，不要写完台词再硬塞镜头**。超容量的台词后面只能靠删字、变速或改画外音补救。

### 1.3 口型台词 vs 画外音 / 旁白

| 类型 | 定义 | 约束 | 标注方式 |
|---|---|---|---|
| 口型台词 | 镜头内能看到说话人的嘴 | 受镜头时长硬约束，占用不超过镜头时长的 **90%**；生成画面时人物必须带说话动作 | 分镜表内直接写在「台词」列 |
| 画外音（OS） | 说话人在画面内但背对／侧面／模糊，或声音来自画面外 | 无口型约束，可跨镜连续；画面必须给情绪落点（听的人的反应镜头） | 标注 `OS`，并注明跨哪几个镜头、总时长 |
| 旁白（VO） | 叙述者不在故事空间内，用于交代前情与时间跳跃 | 速度偏慢，句间留白；不与口型冲突 | 标注 `VO`，整集用量**默认上限 20%**（仅对白驱动型片型；适用边界见本节末「20% 上限的适用范围」） |

规则：

- 同一镜头里，口型台词与画外音不要同时出现两路以上人声，观众分不清谁在说。
- 一句长台词如果超过镜头容量，优先**降级为画外音**，而不是删信息——把镜头切到听者的反应上，声音继续走。
- 旁白是「必要之恶」：能用画面交代的不写旁白，短剧观众对解释性旁白的耐受度极低。

**20% 上限的适用范围**：20% 是**对白驱动型短剧的默认上限**。意境/解说型、无对白片型**不适用**本上限——这类片型的旁白是主叙事载体，应在 G0 立项时把目标占比写进风格提案，并在 `06-成片/复盘一页.md` 指标区记一行「旁白实测占比 = X%」回填实测值。上限的作用是逼出「能用画面就不写旁白」，不是给诗性片型定量。（实测参考：某 120s 无对白片旁白 74% 被判过密，用户知情接受值 57.1%，新目标 40–50%。）

### 1.4 长台词按语义断句

配音合成与后期对齐都要求台词被切成合理片段：

1. **单条片段 ≤ 30 字**（约 8-10 秒）。超过就断，别指望一次生成读出长段。
2. **在句号、问号、感叹号、分号处断**；必须在逗号处断时，要保证两侧各自是完整意群。
3. **不要在虚词后断**：的、了、把、被、和、就、也——断了会听出明显的机械停顿。
4. **不要在人名与称谓中间断**，也不要在「数字 + 单位」中间断。
5. 片段统一用音频ID编号（A001、A002……，与项目《音频生产清单》和剪辑装配单同一编号体系；清单 schema 与填法唯一权威 = `模板/短剧项目模板/05-音频/音频生产清单.md`），便于对齐与单独重录。
6. 片段之间预留 **100-200 毫秒**静音，剪辑时再按需压缩；不要切到零间隔，会有爆音感。

断句示例：

```
原文：你以为我今天来是要跟你道歉的吗我告诉你我今天是来拿回属于我的东西的
断句：
  A001  你以为我今天来是要跟你道歉的吗   （口型台词，镜头 S03，约 3.5 秒）
  A002  我告诉你，我今天是来拿回属于我的东西的（OS，转镜头 S04-S05，约 5 秒）
```

## 2. 配音流程

**第一步 · 能力路由与选音色**：先按 `AGENTS.md` §二 能力路由查项目《能力登记.md》，在已验证实现里选 TTS/配音方案——本地开源（`声音实现适配参考.md` §8）或云端平台预设/专属音色（本文件 §8，仅明确需要平台专属时）由权衡决定，**不预设本地/云端先后**。参考音必须合法取得，授权字段见 `声音实现适配参考.md` §0（source/license/voice_clone_scope/commercial_use/research_only；可下载≠可克隆/可商用）。绝大多数平台预设音色池有几百个，先搜再判断，预设能满足就不定制——定制是付费且异步的动作。

**第二步 · 试听文本**：挑能体现音色特点的句子，不要用「你好，这是一段测试」。

| 角色类型 | 试听文本方向 | 例子 |
|---|---|---|
| 反派 / 阴狠 | 带 threat 感的短句 | 你真以为，你还有资格跟我谈条件？ |
| 悬疑旁白 | 夜戏氛围独白 | 那天夜里，我最后一次听见她的声音 |
| 爽剧女主 | 情绪爬升的一句 | 从今天起，谁也别想再替我做决定 |
| 长辈 / 威严 | 慢速、断句清楚的训话 | 这个家里，什么时候轮到你说话了 |
| 少年 / 活泼 | 语速偏快的日常句 | 哥，你可算回来了，我等你好久了 |

试听确认三件事：**性别年龄对不对、气质对不对、语速是不是你要的**。三项都对才批量生成，不要生成完才听。

**第三步 · 分角色批量生成**：

- 按角色分组，一次把该角色本集全部台词排成队连续生成，用同一音色、同一参数。
- 不要逐句切音色、逐句调参数——参数漂移会让同一角色在不同镜头里像两个人。
- 一次生成失败的片段单独重试，不要把整批重新生成（既费额度又会让音色出现细微差异）。

**第四步 · 命名规范**（与 `AGENTS.md` 统一：镜号 `S01/S02…`，音频ID `A001/FX001/BGM001…`）：

`镜号-角色.扩展名`，例如：

```
S03-林晓.mp3        口型台词
S04-林晓_OS.mp3     画外音
S12-旁白.mp3        旁白（或按清单用 A001.mp3 纯ID命名，二选一全片统一）
S03-王总_v2.mp3     重录版本（保留旧版便于对比，不要直接覆盖）
```

- 镜号 `S01`（两位数补零，保证按文件名排序即等于播放顺序）。
- 角色名用剧本里的正式名称，不要用「男1」「女2」这类临时称呼。
- 一个文件只放一条片段，不合并；合并后的文件无法单独重录。

## 3. 音效设计方法论

### 3.1 SFX 四分类

| 类别 | 作用 | 出现时机 | 音量参考 | 缺了会怎样 |
|---|---|---|---|---|
| 环境音 Ambience | 建立空间真实感，告诉观众「这是哪儿」 | 每场戏开头 0.5-1 秒内起来，全程垫底 | -30 ~ -24 dB | 画面像贴纸，没有现场感 |
| 动作音效 Foley/SFX | 强化动作的力度与打击感 | 动作接触瞬间，可提前 1-3 帧 | -18 ~ -12 dB | 打斗像默片，爽点不「爽」 |
| 转场音 Transition | 缝合镜头、给节奏打标点 | 镜头切换处，前后各 0.2-0.5 秒 | -20 ~ -14 dB | 镜头切换生硬、节奏散 |
| 情绪氛围音 Atmos/Tension | 放大心理压迫或提前铺垫 | 情绪转折**前** 1-2 秒起，持续到转折发生 | -28 ~ -20 dB | 反转来得突然，观众没被「预判」到 |

四类的关系：环境音是地基（全场一直在），动作音效是重音（点状），转场音是标点（线状短促），氛围音是暗流（转折专用）。**同一时刻不要四类全开**，人声出现时至少让出中频。**导演指定了静默窗口（见 `背景音乐生成.md`「静默设计」）时，静默优先**：该窗口内氛围音与 BGM 全部让位，不用氛围音铺垫去填静默。

### 3.2 音效 prompt 写法

**公式：具体声源 + 空间环境 + 动态变化（+ 排除词）**

- **具体声源**：写清是什么物体、什么材质、以什么力度发出声音。写物体不写情绪——「紧张的声音」这种描述生成结果不可控，生成工具要的是物理描述。
- **空间环境**：室内小房间 / 空旷大厅 / 户外旷野 / 狭窄楼道 / 车内 / 水下闷响。空间决定了混响与远近感。
- **动态变化**：sudden（骤起）/ rising（渐强）/ fading in（淡入）/ distant approaching（由远及近）/ sharp attack with fast decay（快起快落）/ sustained（持续）。
- **排除词**：`no music, no dialogue`——BGM 与人声由别的层负责，混进音效里会盖台词。

对比：

| 写法 | 结果 |
|---|---|
| 打斗声 | ❌ 模糊，生成结果每次都不一样 |
| heavy fist impact on wooden table, indoor room reverb, sharp attack with fast decay, no music | ✅ 一次到位，可复现 |

**复用建议**：把常用音效建成本集/本剧的**音效资产库**（同类剧集反复使用同一批音效，比每次重新生成更统一，也更省成本）。命名同样遵循 `类别-场景-序号`，例如 `foley-punch-impact-01`。

### 3.3 常见场景音效词表（英文关键词）

**打斗 / 动作类**

- `heavy fist impact on flesh, tight dry thud, no reverb`
- `bone crack, close perspective, sudden sharp snap`
- `sword clash metallic ring, sustained shimmer with fast decay`
- `whoosh of fast punch swinging past camera`
- `body slam on concrete, heavy low frequency impact`
- `glass shatter, small shards scattering on floor`
- `cloth tear, quick ripping close to mic`
- `footsteps running on gravel, fast irregular, outdoor`

**古风 / 宅斗类**

- `guzheng single pluck, string ringing with long decay`
- `bamboo flute breathy note, distant courtyard reverb`
- `sword unsheathe, metal scraping against scabbard`
- `wooden door creak, old hinges, slow opening`
- `horse hooves on stone road, rhythmic, approaching`
- `wind through bamboo forest, layered rustling leaves`
- `paper fan snap open, quick crisp flick`
- `teacup placed hard on wooden table, single clink`

**都市 / 现代类**

- `office keyboard typing, fast rhythmic, close perspective`
- `elevator ding, clean metallic bell, small room reverb`
- `phone notification buzz on glass table, brief`
- `car door slam shut, outdoor street ambience behind`
- `city traffic ambience, distant horns and tire hiss on wet road`
- `coffee machine steamer hiss, kitchen background`
- `high heel footsteps on marble floor, sharp, echoing hallway`
- `subway rumble passing underground, low frequency swell`

**悬疑 / 惊悚类**

- `low unsettling drone, slow pulsing, sub bass`
- `single piano note struck, long reverb tail, empty room`
- `heartbeat slow thumping, close to chest, building`
- `clock ticking in silent room, dry and isolated`
- `sudden metallic creak overhead, no music`
- `indistinct whispering voices, very low mix, unsettling`
- `electrical hum from old fluorescent light, constant`
- `close breath near microphone, uneven, tense`

## 4. 音画同步 SOP

**核心原则：先定配音时长，再剪画面。** 配音是硬约束（台词不能凭空变长变短），画面是软约束（可以掐头去尾、变速、增删空镜）。反过来做必然大规模返工。

流程：

1. **排配音时间轴**：把所有配音片段按镜号排序，累加时长，加上片段间静音与镜间留白，得到一版「有精确时长的音轨表」。
2. **按时间轴剪画面**：每个镜头按音轨表给出的时长去裁，画面以「台词说完即切」为准。
3. **逐镜比对偏差**，偏差率 = | 画面时长 − 配音时长 | ÷ 配音时长。
4. **按下面分档处理**，不要所有偏差都靠重录解决。

| 偏差 | 判断 | 处理方式 |
|---|---|---|
| ≤ 15% | 正常范围 | **微调画面**：5-10% 变速（变速不变调优先）；掐头去尾或补 0.3 秒空镜；提前/延后切换点；不动台词 |
| 15% - 35% | 需要动台词 | **改台词断句**：拆分或合并片段；删虚词、删重复信息、删客套话；把口型台词降级为画外音跨镜处理；必要时补一句短过渡句 |
| ≥ 35% | 结构性问题 | **重录或重剪**：优先重写台词（台词长度与镜头容量根本不匹配）；其次把这段改为画外音压在其他镜头上；最后才考虑重剪画面/重新生成镜头 |

**字幕与配音对齐**：

- 字幕出现比人声**早 0.1-0.2 秒**，消失比人声**晚 0.2-0.5 秒**——跟得太紧会显得字幕「追」着人说话。
- 字幕换行位置与配音断句位置一致；一条字幕不超过 15 字（与 成片与字幕 的字幕规范统一）。
- 画外音跨镜头时，字幕跟随声音而不是跟随画面。
- 对齐检查方法：逐条播放，听「字先到还是声先到」；批量检查可把字幕时间轴与人声音轨叠加看波形起始点。

## 5. 交付物模板：音效与转场建议书

本 skill 的最终产出是一张交给剪辑执行的表。**五列固定，不得缺列**：

| 镜号 | 画面剧情摘要 | 转场方式 | 环境音 / BGM 情绪 | 关键 SFX（英文 prompt） |
|---|---|---|---|---|
| S001 | 女主独自站在雨夜街口，回头看向车灯 | 硬切进 | 雨夜街道环境音 + BGM 神秘幽暗 | `rain on asphalt, steady heavy, close perspective, no music` |
| S002 | 黑色轿车缓缓停在身后，车窗下降 | 声音先入（车声先起 0.3 秒） | 同上 | `car tire rolling on wet road, slow approach, then power window motor hum` |
| S003 | 男主递出文件，女主手抖着接过 | 硬切 | 雨声减弱 + BGM 转紧张悬疑 | `paper sheets shifting, close to mic, slight tremble, no music` |
| S004 | 特写：文件上「亲子鉴定」四个字 | 推镜 + 转场音 | 环境音抽空 + BGM 停顿一拍 | `deep low boom impact with long reverb, sudden` |
| S005 | 女主抬头，眼眶通红，咬唇不语 | 叠化（呼吸感留白） | 环境音回位 + BGM 温暖治愈起 | `single piano note, long reverb tail, empty room` |
| S006 | 男主转身走向车，背影拉远 | 淡出到黑 | BGM 收尾 + 环境音延续 | `footsteps on wet pavement walking away, gradually fading out` |

列填写要求：

- **转场方式**统一取值：硬切 / 淡入淡出 / 叠化 / 划像 / 推拉 / 闪白 / 甩镜 / 声音先入 / 无转场（同场景连续）。
- **环境音 / BGM 情绪**列写成「环境音 + BGM 情绪」两段，环境音描述空间，BGM 情绪取自 背景音乐生成 的情绪取值。
- **关键 SFX（英文 prompt）**：每镜最多 1-2 个关键音效，只写该镜最需要的那一个，不要堆砌；按 3.2 的公式写全三要素。
- 整表逐镜连续，不得跳号；没有音效的镜头也要保留行，SFX 列写「—」，防止后期漏镜。

## 6. 检查清单

配音文案：

- [ ] 全部台词按 180-220 字/分钟核算过总时长，未超过单集目标时长。
- [ ] 每条口型台词的字数与所在镜头时长匹配，占用不超过镜头时长的 90%。
- [ ] 每条 TTS 片段 ≤ 30 字，断句处两侧语义完整，无虚词后断句。
- [ ] 口型台词 / 画外音 OS / 旁白 VO 已分类标注，跨镜画外音标明跨镜范围。
- [ ] 旁白总量：**对白驱动型**片型不超过本集总时长的 20%（默认上限）；**意境/解说型与无对白片型**改按 G0 风格提案登记的目标占比判，并在 `06-成片/复盘一页.md` 回填「旁白实测占比 = X%」（口径见 §1.3「20% 上限的适用范围」）。

配音执行：

- [ ] 已先搜预设音色，确认无法满足才走定制。
- [ ] 每个角色的试听文本能体现其特点，三项（年龄性别 / 气质 / 语速）已确认。
- [ ] 同一角色全片使用同一音色与同一组参数，无中途漂移。
- [ ] 文件命名符合 `镜号-角色`（或全片统一用音频ID），重录版本带 `_v2` 后缀且未覆盖旧版。
- [ ] 生成失败的片段是否单独重试而非整批重跑。

音效与同步：

- [ ] 每场戏开头都有环境音，且同一场景内空间感一致（不出现室内声突然变旷野）。
- [ ] 所有关键动作都有动作音效，且贴合接触帧（不是慢半拍）。
- [ ] 情绪转折前 1-2 秒有氛围音铺垫，转场处有转场音。
- [ ] 音效 prompt 均包含「声源 + 空间 + 动态」三要素，并带 `no music, no dialogue`。
- [ ] 音效不与人声抢中频，人声出现时音效让位。
- [ ] 逐镜偏差已核算，≤15% 微调画面 / 15-35% 改断句 / ≥35% 重录或重剪，无遗留超标项。

- [ ] 全片音量层级正确：人声最高、SFX 居中、BGM 垫底、氛围音最弱。
- [ ] 「音效与转场建议书」五列齐全、逐镜连续、无跳号。

## 7. 口型与声音生成的能力选择

先明确台词、情绪、说话人、音色与同步要求，再在项目能力登记中比较原生音画生成、独立配音加口型适配或画外音方案。按实际效果、授权、耗时与成本选择，不规定某品牌先用或本地/在线优先。

- 先出代表性试听与对白镜头样片，再批量；具体参考音长度、语种、参数和运行入口按所选实现核验（通用参考音规格与授权见 `声音实现适配参考.md` §0）。
- 具体 lip-sync 工具选型见 `声音实现适配参考.md` §7；口型适配检查侧脸、遮挡、阴影、牙齿与表情；同段质感应连贯，不只看嘴巴是否动。
- 参考声音与人物素材须获得相应用途授权，授权字段与红线见 `声音实现适配参考.md` §0；公开可听、可提取不等于允许克隆。
- 频谱和时长检查只辅助诊断，最终仍要实际试听及音画回放，不能仅凭谐波断言“真人声”。
- 具体实现名、参数、选型经验和旧案例由《能力登记.md》指向声音适配资料；通用台词表、音频清单和项目 ID 不因更换实现而重建。

## 8. 平台专属音色定制（可选实现，仅选定该平台时）

> 本节原为独立文件《专属音色定制》（2026-10-12 并入，同主题不再单独加载）。它只描述**该云端平台内部**的工具（`design_voice` / `clone_voice` / `list_voices`）；体系不绑定任何云端音色平台——是否走定制、走哪个平台，按 `AGENTS.md` §二 能力路由与项目《能力登记.md》决定；本地开源替代见 `声音实现适配参考.md` §8，通用参考音规格与授权见其 §0。

帮用户在该平台内拿到一个可反复使用的专属音色。两条路：**用文字描述设计一个**，或**用一段人声样本克隆一个**。

### 8.1 先判断走哪条路

| 用户诉求 | 走哪条 | 工具 |
|---|---|---|
| 「我想要一个低沉的悬疑男声」——只有想象没有样本 | 描述设计 | `design_voice` |
| 「用我自己的声音」「用这段录音的音色」——有具体人声样本 | 样本克隆 | `clone_voice` |
| 「随便找个好听的女声」——不需要专属 | **不定制**，去预设音色里挑 | `list_voices` |

第三种最常见也最容易做错：**先用 `list_voices` 搜一遍预设**（几百个，带 `q` 搜索），预设能满足就不要花钱定制。

### 8.2 硬规则（违反会让用户白花钱）

1. **音色创建绝不走音频合成工具**。`generate_audio` 对音色创建类模型有代码层硬闸会直接拒绝；即使绕过去，那条链路的结果里只有一个音频地址，**音色本身会被丢弃、不入库**——钱扣了，音色没了。音色创建的唯一入口就是 `design_voice` / `clone_voice`。
2. **这是一次性付费动作**。调用 `design_voice` 或 `clone_voice` 之前，**必须先明确告诉用户会产生音色费用，并拿到用户明确同意**（付费属 `AGENTS.md` §一.4 必须停下问用户的类别）。用户没明确说「可以/开始/确认」就不要调。
3. **设计音色是异步的**。`design_voice` 返回的是 `status: processing` 加一个 `voice_key`，不是成品。约 1 到 2 分钟后用 `list_voices` 查，新音色出现在清单里才算完成。**这段等待期间绝不要重复提交——重复提交等于重复扣费。**
4. **同样本克隆会去重**。`clone_voice` 对同一段样本会命中去重直接返回已有音色并标记复用，此时**本次没有收费**。如实告诉用户「这段样本之前克隆过，直接复用了，本次未收费」，不要包装成一次新克隆。
5. **专属音色只配同家族的语音模型**。音色绑定创建它的厂商，跨家族的语音模型用不了它（会被拒或静默兜底成别的声音）。合成时如果用户选的模型不同家族，如实说明并建议改用预设音色。
6. **授权是前提**：参考人声必须按 `声音实现适配参考.md` §0 取得相应用途授权；公开可听、可提取不等于允许克隆。

### 8.3 样本规格（该平台上传约束，克隆前必须核对）

> 以下时长、体积、来源要求**只属于本平台的样本上传协议**，不是体系通用参考音规格；通用规格与授权字段见 `声音实现适配参考.md` §0。

- 格式：mp3 / m4a / wav
- 时长：10 秒 到 5 分钟
- 体积：小于 20MB
- 来源：**必须是已上传到本平台的音频**，给出可公网访问的 http(s) 地址
- 质量要求（不满足就先让用户重录，克隆出来才不糊）：单人说话、无背景音乐、无混响、无多人重叠、语速自然、情绪平稳

### 8.4 音色描述词写法（设计音色时用，这段决定成品像不像）

**描述维度**：[性别与年龄段] + [音高与音色质感] + [语速节奏] + [气息特征] + [情绪底色] + [使用场景] + [类比参照]

- 性别年龄：青年男声 / 中年男声 / 少年音 / 青年女声 / 知性女声 / 少女音 / 老者
- 音高音色：低沉浑厚 / 中低磁性 / 清亮通透 / 略带沙哑 / 温润柔和 / 尖细活泼
- 语速节奏：语速偏慢字句分明 / 中速平稳 / 偏快利落 / 忽快忽慢有起伏
- 气息特征：气声较重 / 胸腔共鸣强 / 鼻音轻微 / 干净无杂气
- 情绪底色：克制冷静 / 温暖亲切 / 疏离神秘 / 热情外放 / 慵懒随性

**写法要求**：连成一段自然的中文描述，4 到 500 字，**至少覆盖 3 个维度**。只写「好听的男声」这种没有维度的描述，出来的音色是随机的。试听文本的挑句原则与三项判项（性别年龄 / 气质 / 语速）见 §2 第二步，不在这里重复。

### 8.5 工具调用流程与参数

界面不提供这些参数的表单，由你在对话里问齐。

**设计音色**：确认用户同意付费 → `design_voice`（`name` 1-50 字 / `prompt` 音色描述 4-500 字 / `preview_text` 试听文本 4-300 字 / `language`，四项都要给全）→ 告知用户需等待 1-2 分钟 → 用 `list_voices` 查是否出现 → 拿到 `voice_key` 交给用户。

**克隆音色**：核对样本规格 → 确认用户同意付费 → `clone_voice`（`name` / `sample_url` / 可选 `preview_text` / `language`）→ 结果若标记为复用则如实说明本次未收费 → 拿到 `voice_key` 交给用户。

**拿到之后**：`voice_key` 就是合成时 `generate_audio` 的 `parameters.voice` 取值。**不要把 `voice_id`（uuid 形态）传给合成工具**，那是我方资产主键，不发厂商。

**参数取值**

| 参数 | 说明 | 取值 |
|---|---|---|
| 音色名称 | 便于用户日后识别 | 1-50 字 |
| 音色描述（设计必填） | 按 §8.4 的维度写（取值口径见该节） | 4-500 字，至少覆盖 3 个维度 |
| 样本音频（克隆必填） | 已上传到平台的人声，符合 §8.3 样本规格 | http(s) URL |
| 试听文本 | 设计必填；克隆可选，给了能听得更准 | 4-300 字 |
| 语言 | 两者可选 | 中文普通话 / 英文 / 日语 / 其它 |

**输出格式**：先说明你判断走哪条路以及为什么；设计音色时把写好的描述词与试听文本先给用户过目；**明确提示会产生一次性音色费用并等用户确认**；确认后再调用工具。拿到结果后把 `voice_key` 和后续怎么用告诉用户。
