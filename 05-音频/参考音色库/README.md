# 参考音色库（历史研究样本）

> **体系定位**：这里保存 SOP 侧的历史研究样本与许可记录，不再作为首选范例。当前主参考音由使用者自备（例如选用 TTS 实现自带的示例参考音目录）；实际位置以项目《能力登记.md》为准。
> **AISHELL-3 权威清单是子目录的 `manifest.json`**（该子目录为研究许可样本，**不随本包提供**）；临时文件不作权威。

## 这是什么

- `AISHELL-3_研究样本/`：8 条 AISHELL-3 单句 WAV（8 个不同说话人，各 1 条，5.6–8.3 秒，44.1kHz 单声道 PCM）。**该目录为 research_only 许可样本，不随本包提供**；下面的字段与授权说明只用于说明口径。
- 状态：历史技术验证样本，不再作为首选范例；新版首选为 WenetSpeech4TTS 2024 官方 Demo reference speaker。
- 两类参考音都仅用于本地研究与试听比较，不是商业成品音色库。

## 版本库边界

- 本地二进制 **不入版本库**（`.gitignore` 排除 `参考音色库/**/*.wav|mp3|flac`）；
  本文档随包提供；`manifest.json` 与 WAV 属研究样本，不在本包内。
- 换机器/换盘后按 `manifest.json` 的 `sha256` 校验本地 wav 是否齐备，缺失需重新按来源采集。

## manifest.json 字段

| 字段 | 含义 |
|---|---|
| `speaker_id` / `utterance_id` | AISHELL-3 说话人/语句编号（同一说话人可多句，本库每说话人 1 句） |
| `text` | 中文转写文本（试听时可对照咬字清晰度） |
| `file` | 本地 wav 文件名（与本目录同名文件一一对应） |
| `duration_s` / `sample_rate` / `channels` / `codec` | 时长 / 采样率 / 声道 / 编码 |
| `rms_dbfs` / `peak` / `clipping_ratio` / `active_ratio` | 响度与活动率质检指标 |
| `f0_median_hz` | 基频中位数（只用于技术核对，**不代表也不应推断性别年龄**） |
| `qc_pass` | 采集质检是否通过（8/8 通过） |
| `bytes` / `sha256` / `source_member` | 文件完整性校验与原始归档路径 |
| `source` / `license` | 来源与许可（含页面附加条款原文） |
| `license_policy` / `voice_clone_scope` / `commercial_use` / `research_only` / `permission_required_for_other_use` | 授权判定字段，见下 |

## 授权边界（严格口径）

- 8 条全部 `voice_clone_scope: "research_only"`、`commercial_use: false`、`research_only: true`；已完成的 IndexTTS 复刻只属于本地技术验证，任何其他用途必须另取许可。
- AISHELL-3 在 OpenSLR 页面标 **Apache-2.0**，但 ModelScope 数据页正文写明
  **"学术研究免费、未经许可不得商业使用"**——两个来源冲突时按**最严格口径**执行：
  **禁止商用、禁止商用克隆**。任何项目要商用，须取得书面许可或换用明确可商用的参考音。
- 来源可下载 ≠ 可克隆 ≠ 可商用；授权字段登记要求见 `../声音实现适配参考.md` §0。

## 如何试听与选择

1. **项目级选择靠耳朵，不靠 metadata**：按 `../配音与音效设计.md` §2 的试听方法，
   用**能体现角色特点的试听文本**逐条合成对比，确认性别年龄气质语速三项；不写死、不推断性别年龄。
2. **技术验证结论**：IndexTTS-2.5 用本库 8 条参考音技术测试 **8/8 通过**（API 正确加载、合成出正常语音）；
   但这只是**技术可用**，人工听感是否贴角色仍需**每个项目重新试听选择**。
3. 同一角色全片固定同一段参考音，保证音色一致（`../声音实现适配参考.md` §8.1）。

## 边界与注意

- 本库只是**研究样本**；正式项目的参考音优先用：用户自录（授权最干净）、
  已授权素材、或实现自带可商用预设。
- 商用项目的参考音授权必须登记进项目《素材与授权台账.md》。
