## 0. 参考音规格与授权（唯一权威）

**通用本地零样本参考音建议**（各实现若有更严限制，以项目《能力登记.md》/适配层记录为准）：

- 时长 **5–30 秒**，取干净、有代表性的段落；
- **目标语种**与成片台词一致（念中文必须用中文参考音，语种错会"夹生"）；
- **单人干声**：无 BGM、无混响、无多人重叠、无明显底噪；
- **WAV 优先**（mp3 可作采集中间格式，正式参考音尽量无损/高码率）。

**授权字段**（每个参考音/参考音色必须在项目《素材与授权台账.md》登记）：

| 字段 | 含义 |
|---|---|
| `source` | 来源（自录 / 数据集 / 已授权素材 / 平台预设） |
| `license` | 许可名与版本（如 Apache-2.0），含页面附加条款原文 |
| `voice_clone_scope` | 允许范围：`none` / `research_only` / `commercial` / `permission_required` |
| `commercial_use` | 是否允许商用 |
| `research_only` | 是否仅限本地研究与技术验证 |
| `permission_required_for_other_use` | 超出已登记范围是否必须另取书面许可 |

**红线：来源可下载 ≠ 可克隆、≠ 可商用。** 公开可听、可提取不等于授权克隆；按最严格口径执行。

**本机主参考样本**：IndexTTS 仓库 `examples/wenetspeech4tts_官方参考音/` 共 8 条，来自 WenetSpeech4TTS 2024 官方 Demo，使用中文声学标签命名并通过 IndexTTS-2.5 技术测试 8/8；权威清单为其 `音色清单.json`。WenetSpeech 官方数据页限定非商业用途且原音频版权仍归原权利人，因此统一按 `research_only` 使用，禁止直接用于商业成片。

**历史验证样本**：`05-音频/参考音色库/AISHELL-3_研究样本/` 保留 8 条旧研究样本及 manifest，用于复现实验，不再作为首选范例。其 OpenSLR/ModelScope 许可说明存在附加限制，同样按 `research_only` 执行。

**音频前移的适配口径（2026-10-12，A7）**：声音设计在 G3 完成（分镜表「音频与对白轨」+ 逐秒音频线索），本参考只影响 G5 执行选型。两条硬约束：

- **生成期优先用模型自带对白能力**（H3 等，见 §7 分工原则）——A7 后这不再是"补录"而是按已设计轨执行；台词、语气、时间范围以 G3 音频与对白轨为准，不以生成时临时发挥为准。
- **BGM 一条连续轨**：任何"逐镜生成 BGM 再拼"的方案都不进本表（对标件 qc-checklist STEP 8 同款禁令）；选 BGM 实现时确认它支持整轨生成 + 按时间 duck。

## 7. 口型同步（lip-sync）工具选型

> 分工原则：**生成期优先用模型自带对白能力**（H3、可灵原生支持台词与口型，原视频实现对照见 `04-视频生成/适配登记/Seedance语法与三家对照.md` §1.1）；只有"先生成了无声画面、后期才配台词"时才用本节工具补口型。

### 7.1 开源口型同步选型表

| 工具 | 出品/原理 | 画质 | 速度 | 适用场景 | 硬件门槛 |
|---|---|---|---|---|---|
| **MuseTalk 1.5** | 腾讯音乐，VAE 潜空间单步修复嘴部 | 中高（面部区域 256×256） | 实时级，30fps+ | **生产首选**：批量给成片补口型 | 常规 N 卡 |
| **LatentSync 1.6** | 字节，512×512 潜空间扩散 | 三类中最好 | 慢（扩散多步） | 高画质特写、近景对话镜头 | 推理约 18GB 显存 |
| **Wav2Lip** | 经典基线，像素空间重绘嘴部 | 嘴部偏糊 | 快 | 应急、草稿、遮幅小的镜头 | 普通 GPU 即可 |
| **VideoReTalking** | 面部提取→嘴部重绘→融合回播 | 保持原画质好 | 中 | 成熟稳定方案，画质敏感的中景 | 常规 N 卡 |
| **SadTalker** | 3DMM 系数驱动，单张图+音频出说话头 | 中 | 中 | 只有定妆照、没有表演素材的对话镜头 | 常规 N 卡 |
| **LivePortrait** | 快手开源，表情系数迁移 | 高（吃源图质量） | 慢 | 高质量特写、表情复刻 | 常规 N 卡 |

### 7.2 使用纪律

1. **输入材料决定上限**：正脸、无遮挡、光线均匀、分辨率越高越好；大侧脸/手部遮挡/强阴影必翻车。素材不达标时改走画外音，不要硬上 lip-sync。
2. **MuseTalk 嘴张不开**时调 `bbox_shift` 参数（正值加大张嘴幅度）；`use_float16` 可提速约三成。
3. **同一段表演只跑一个工具**，多个 lip-sync 结果混剪会让嘴部质感跳变。
4. **真人剧底线不变**：lip-sync 只用于 AI 生成的角色或已获授权的素材，真人换脸/对口型的合规边界见 §0 授权红线，以及 `配音与音效设计.md` §8 授权前提。
5. 不想自己搭环境可用整合面板 **AigcPanel**（modstart-lib/aigcpanel，MIT），MuseTalk/Wav2Lip/LatentSync 与 CosyVoice/Fish-Speech 一键整合。

## 8. 开源/免费 TTS 速查（本地替代方案）

> 与 `配音与音效设计.md` §8 的关系：那一节管"平台专属音色的完整流程与付费硬规则"，本节是**免费/本地开源替代清单**——预算敏感或要离线时走这里；克隆授权与通用参考音规格见 §0，平台侧的样本去重属其上传协议、不在此重复。

| 工具 | 出品 | 特点 | 适合 |
|---|---|---|---|
| **CosyVoice 2** | 阿里 FunAudioLLM | 自然度高，支持指令式语气控制 | 主力本地配音 |
| **Fish-Speech** | fishaudio | 中文多语言好，克隆门槛低 | 角色音色快速克隆 |
| **Spark-TTS** | SparkAudio | 轻量，零样本克隆 | 低配机器 |
| **GPT-SoVITS** | RVC-Boss 社区 | 生态大、教程多，少样本克隆 | 社区方案兜底 |
| **IndexTTS-2.5** | B 站 IndexTeam | 情绪与音色解耦（8 个情绪维度独立控制）、语速可调（0.5–2.0 倍）、中文韵律强 | 情绪戏台词、需精细控制语气的角色 |
| **edge-tts** | 微软接口 | 免费、无克隆、音色多 | 旁白草稿、预览配音 |

**选用路由**：不预设本地/云端先后。按 `AGENTS.md` §二 能力路由（镜头需求 → 项目《能力登记.md》候选 → 质量/成功率/速度/成本/隐私权衡 → 已验证实现）选定 TTS 实现；本机 IndexTTS-2.5 是**已验证实现之一，不是全局强绑**。预算或离线受限时优先考虑本表本地开源方案；无论选哪个，永远先出 10 秒试听再批量生成。参考音规格与授权见 §0。

### 8.1 本地零样本人声复刻（indexTTS 推荐用法）

零样本克隆的核心是：**参考音决定音色、语种和情绪**。所以要"复刻"你真正想要的声音，而不是用 examples 自带的示例音色：

1. **先按 §0 准备已授权参考音**（通用建议 5–30 秒，目标语种、单人干声、无 BGM / 混响）：
   - 来源优先：用户自录并授权、明确允许相应用途的数据集/素材、或实现自带且许可覆盖当前用途的预设。
   - 对标片只用于研究声音设计，不得默认提取人物声音做复刻；念中文必须使用中文参考音。
2. **不要直接拿 examples 里的 voice_01–12 当成品音色**——它们是演示用，音色 / 情绪未必合适（容易显刻意、出戏）。
3. **同角色固定同一段参考音**，保证全片音色一致；情绪靠选带相应情绪的参考音传递。
4. 每句出 2–3 个候选再挑；合成后看频谱确认是真人声（有谐波、有音节），不是电流音。
5. 正确 API（v2.5 入口）：`from indextts.infer_v2_5 import IndexTTS2`；`tts.infer(spk_audio_prompt=参考音, text=台词, output_path=..., lang="zh")`，加载时不得有 missing keys。
