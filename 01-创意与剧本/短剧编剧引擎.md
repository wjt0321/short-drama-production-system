# 短剧编剧引擎

## 写能看见的剧本（跨形式通用补充）

下面的短剧钩子、反派和商业模板仅用于适合它们的作品，不强制给生活观察、展示或诗性影像加冲突。用户全权委托时自主写作和继续，专项任务只完成用户要求的环节。

每个段落写清当前处境、发生的事、人物如何行动/回应、结果和下一段的联系。动作按先后顺序写，并区分持续状态与一次性变化；涉及互动时交代注意力、视线、站位、遮挡、接触和受力。用具体动作、声音、可辨认的表情和空间关系承载信息；“他失落/她释然/盛世震撼”只是意图，不是完成的画面。重要转变必须有铺垫与表现过程，人物跨地点和道具换状态需有可理解的交代或明确省略。

需要对白时写原句、说话对象、语气与必要停顿，以及听者的反应；不让人人解释剧情，不强制每段都说话。内心活动选择少量外显行为，内心旁白明确标注，不能让旁白声称人物完成了画面没发生的行动。先读出台词并结合动作估时，再交分镜安排切点，不等长分段。

细节只保留服务人物、内容或视觉组织的部分。把可复用外貌与地点设定交资产稿；剧本重在这一场发生什么，不用长篇服装描写挤掉行动。写好剧本不能被下游压缩成只有情绪标签的梗概。

## 1. 定位与边界

你的职责是：把"想拍一个短剧"推进到"有人物、有钩子、有节奏、有合规保障的分集大纲与单集剧本"。

你处于短剧生产链路的最上游：

想法 / 素材 → 本 Skill 做选题与编剧 → 02 阶段做单集分镜 → 03 阶段做视觉资产 → 04 阶段生视频成片

本 Skill 负责：

- 选题定位：题材、平台形态、目标受众、免费或付费模式。
- 故事内核：一句话故事、主角欲望与阻碍、核心人物关系。
- 钩子设计：前 3 秒钩子、集首钩子、集尾钩子。
- 节奏设计：单集节奏链、多集节奏曲线、付费卡点位置。
- 冲突结构：冲突类型与反派层级递进。
- 台词规则：口语化、信息密度、台词与动作的配合。
- 合规审查：交付前按红线清单自查并给出修改建议。
- 交付物：分集大纲、单集剧本、人物关系表。

本 Skill 不负责：

- 分镜、景别、镜头顺序与台词落点（交给 02 阶段 `分镜工作流.md` §十三）。
- 生图 / 生视频提示词、模型参数、运镜参数语法。
- 剪辑、配乐、配音方案。
- 替用户决定平台投放策略与商务条款。

交付物是"能开拍的文字剧本"，不是分镜稿，也不是提示词。完成大纲与剧本后停止，不要继续替下游补镜头设计。

## 2. 方法论来源

本 Skill 综合了以下几类公开方法论，均为思路借鉴与重组，不是原文转载：

- **GitHub `0xsline/short-drama`**：钩子设计理论（每集必须留下未完成状态）、网文式节奏曲线（小高潮密铺、大高潮间隔投放）、四层反派递进（对手由贴身小人逐层升维到幕后真凶）、以及成片前的广电合规自查思路。
- **GitHub `Victor-F-M-A-R/skywork-skill-short-drama-writer`**：把编剧任务切成六类可独立调用的能力——故事撰写（write）、人物（character）、情节（plot）、台词（dialogue）、钩子（hook）、商业化（monetize）。本 Skill 的章节划分沿用了这一"能力可拆分"的组织方式，便于单点返工。
- **剧蛙短剧前三集 SOP**：钩子 → 小爽 → 大爆 → 卡点的前三集结构。前三集决定留存与付费转化，必须单独按这套 SOP 打磨，不能和后段平均用力。
- **ArcLoop 前 3 秒钩子四型**：视觉证据型、关系冲突型、危险动作型、反常信息型。用来把"开场要抓人"这句空话落成可执行的四条具体路径。

使用时按任务取用对应章节即可，不必每个项目都走完全部流程；但**剧情节奏、钩子、合规三项不可跳过**。

## 3. 第一步：选题定位

动手写故事之前，先把下面五个问题问清楚。用户没给答案时，给出你的建议方案让他确认，不要让他填空。

### 3.1 五个定位问题

1. **题材**：从题材清单里选一个主类型 + 一个辅类型（如"复仇逆袭 + 家庭伦理"）。
2. **平台形态**：默认横屏（16:9）、单集 1–3 分钟；竖屏短剧（9:16）或图文漫剧形态要单独说明差异。
3. **目标受众**：性别、年龄段、看剧动机（爽感宣泄 / 情感代偿 / 悬疑解谜 / 家庭共鸣）。受众决定爽点类型。
4. **模式**：免费引流剧（靠量走广告分成）还是付费卡点剧（前若干集免费，卡点后付费）。
5. **集数与体量**：总集数、单集时长、更新节奏。没指定时给一个保守建议（如 20–60 集 × 每集 1.5 分钟）。

### 3.2 题材清单

| 题材 | 核心爽点 | 常见主角 | 最大风险 |
|---|---|---|---|
| 复仇逆袭 | 压迫→反击→身份揭露→权力反转 | 被冤屈者、隐藏身份者、重生者 | 以暴制暴、私刑报复，需走合法追责路线 |
| 甜宠 | 误会→试探→保护→确认关系 | 强势一方与柔软一方 | 拖沓、无冲突、只撒糖不推进 |
| 悬疑 / 读心 | 观众比人物多知道一点，或旧信息被重新理解 | 掌握秘密者、读心者、追查者 | 靠旁白解释线索，线索不前置 |
| 家庭伦理 | 利益、亲情、身份、尊严的现实冲突 | 被排挤的家庭成员、隐忍者 | 全员站着吵架，缺动作与证据 |
| 喜剧 | 目标错位、误判、升级、结果反差 | 自视甚高者、老实人被误导 | 用大段解释讲笑点，不用画面反差 |
| 玄幻修仙 | 弱者觉醒→越级碾压→身份升维 | 废柴、觉醒血脉者、重生修士 | 世界观铺陈过长，前 3 秒不给冲突 |

选题材的两条硬规则：

- **一个项目只主打一个爽点类型**，其余类型只做调味。多主线并行会让每集的信息密度被摊薄。
- **优先选能用画面表达的题材方向**。以"内心挣扎"为唯一卖点的方向，在竖屏短剧里转化率低。

### 3.3 免费模式与付费卡点模式

- **免费引流剧**：重心在每集结尾都留钩子，靠连续留存换播放量。钩子密度要高，单集可以更短，允许强切分。
- **付费卡点剧**：重心在卡点位置与卡点强度。常见做法是前 3–10 集免费建立人物与情绪债，第一个大卡点落在"关键信息将要揭晓"的瞬间。
- 无论哪种模式，**卡点必须落在事情未完成的瞬间**：观众想知道结果，但结果没给。落在"事情已经结束"之后的卡点无效。
- 卡点常见位置：身份即将被揭露、证据即将被公开、反击即将成功、误会即将解开、对手即将失势、主角即将说出关键决定。

## 4. 第二步：故事内核与人物关系

### 4.1 一句话故事

用一句话写清"谁，因为什么，要做什么，被什么挡住"。模板：

> 一个（身份/处境）的（主角），在被（具体压迫事件）之后，为了（明确目标），必须（关键行动），但（最强阻碍）让他/她（代价）。

- 不超过 60 字，必须包含具体的压迫事件，不能只写"受尽欺辱"。
- 写完自检：这句话里有没有一个能立刻拍出来的动作？如果没有，说明故事内核还是概念而不是情节。
- 这个故事内核是整部剧的锚。后续所有集数都要能回答"这一集让主角离目标更近还是更远"。

### 4.2 主角的欲望与阻碍

| 项 | 要求 | 反例 |
|---|---|---|
| 欲望 | 具体、可被画面衡量 | "想被认可"（不可拍）→ "要拿回母亲的房产证"（可拍） |
| 阻碍 | 有实体对手，不是抽象命运 | "命运不公" → "继母与她的弟弟持续侵占家产" |
| 代价 | 每次抗争都要付出东西 | 每次都赢且无损失（没有张力） |
| 能力来源 | 主角的强必须可解释 | 突然无敌（观众不服） |

主角可以强，但**强的来源要在前几集给出**：隐藏身份、多年积累的证据、专业能力、他人欠下的人情。爽点来自观众知道"为什么这个反击成立"。

### 4.3 核心人物关系

至少明确五类角色，并写成关系表：

- **主角**：观众代入对象，欲望与阻碍明确。
- **直接对手（第一层反派）**：与主角同场景、同阶层，制造日常压迫。
- **情感线角色**：推动关系变化，不是纯工具人，要有自己的诉求。
- **盟友 / 见证者**：承担信息传递与旁观视角，避免主角自言自语。
- **更高层对手**：见第 7 节的四层反派递进。

关系表建议字段：人物名 / 身份定位 / 与主角关系 / 想要什么 / 阻碍谁 / 本剧结局走向。上游已有固定人物卡时优先沿用，不要重新设计。

## 5. 第三步：钩子设计

### 5.1 前 3 秒钩子四型（无厘头/恐怖片型另有第五型）

开场不要环境、不要起床、不要旁白介绍背景。前 3 秒必须从下列四型里选一种落地：

| 类型 | 做法 | 示例方向 |
|---|---|---|
| 视觉证据型 | 开场先给出一个物件或画面，观众立刻明白关系出了事 | 桌上摊开的离婚协议、手机里刺眼的聊天记录、抽屉里的第二本结婚证 |
| 关系冲突型 | 开场就在一句带立场的话或一个当众冲突里 | 婚礼上被当众否认身份、饭桌上被要求签字放弃继承 |
| 危险动作型 | 开场是一个正在发生的、结果未定的动作 | 有人把主角推向楼梯、车正冲向站在路边的人 |
| 反常信息型 | 开场给出观众一眼看不懂但强烈想知道原因的场面 | 主角在葬礼上微笑、全家人都对着空椅子说话 |

- 四型可以叠加，但**第一镜只承载一个信息**。
- 不要用"先给两秒城市空镜再进正戏"的方式，那两秒决定观众划走。
- 如果环境信息很重要，让它和冲突同时出现，而不是提前单独交代。
- **第五型「异常状态型」**（第一帧就是异常状态）只用于无厘头与恐怖片型，展开见 `02-分镜与镜头/分镜类型特则.md` §2.1；本节的四型/第五型是**开场承诺怎么给**，与分镜表 `hook` 列的十选一（每镜叙事回报类型，唯一权威 `02-分镜与镜头/分镜工作流.md` 第 3 条）是两套轴，不能互相顶替填写。


### 5.2 集首钩子

每一集（不只是第一集）的开头都要重新抓人。集首钩子的常见做法：

- 承接上一集卡点，**先给后果的第一帧**，再补过程。
- 直接用一句冲突性台词开场，人物关系在第一句里就带上压力。
- 用"上一集结尾的同一动作换视角重演"，让观众获得新信息。

### 5.3 集尾钩子（必须未完成）

集尾是短剧最重要的一格。判断标准只有一条：**这一集结束时，有没有一件事明确地"没做完"。**

有效的集尾：

- 新身份刚被发现，但还没被当众确认。
- 秘密只揭开一半，另一半指向谁还不知道。
- 某人听到了不该听到的话，但对方还没察觉。
- 证据刚被拿出来，还没打开。
- 关键人物突然出现，还没开口。
- 角色做出无法撤回的选择，结果未揭晓。
- 观众知道真相，但角色还不知道（信息差卡点）。

无效的集尾（不要用）：

- 大家散场、主角回家、情绪自然平复。
- 旁白总结本集发生了什么。
- "事情终于结束了"式的收束。
- 反转已经完整揭晓并给出解释，没有留下任何悬而未决的东西。

钩子最好同时包含一个画面和一句能卡住情绪的台词；能靠画面本身完成卡点就不要再加台词解释。

### 5.4 前三集 SOP：钩子—小爽—大爆—卡点

前三集单独治理，不要与后段平均用力：

1. **第一集：钩子。** 完成四型之一的开场，建立主角处境与最大压迫者，结尾落在第一个未完成状态。
2. **第二集：小爽。** 尽快给第一次小反击与正向反馈，让观众确认"这剧会爽"。小爽要小、要早、要具体（一次当众打脸、一次证据初现）。
3. **第三集：大爆。** 放出第一个强情绪回报，让关系或权力发生可见变化，同时把新问题一起抛出。
4. **卡点。** 第三集或紧随其后的集尾必须是全剧第一个强卡点，付费剧的付费点通常落在这里或之后一格。

## 6. 第四步：节奏曲线

### 6.1 单集节奏链

完整一集默认走这条链，但不要机械套模板，可依题材调整重点：

**抓人 → 冲突 → 升级 → 蓄积 → 关键信息 → 反转 → 新问题 → 戛然而止**

- **抓人**：前 3 秒给出观看理由（见 5.1）。
- **冲突**：明确谁和谁因为什么对上，冲突要在前半段就出现。
- **升级**：压力加码，对手掌握更多筹码或主角付出代价。
- **蓄积**：情绪积累段，用一个短停顿、一个动作或一次沉默把情绪压到位。
- **关键信息**：本集最重要的新信息出现，且要前置过线索。
- **反转**：关系、权力或认知发生变化，反转必须有前置条件。
- **新问题**：反转之后立刻抛出新的未解决问题，避免情绪落平。
- **戛然而止**：在本集最后留出未完成状态（见 5.3）。

### 6.2 多集节奏曲线

借鉴网文节奏的做法，把"小爽"和"大爆"分层投放：

- **小爽密铺**：约每 1–2 集给一次小的正向反馈，维持观看惯性。
- **大爆间隔**：约每 5–10 集给一次结构性反转（身份揭露、权力洗牌、关系破裂），间隔太长会流失。
- **压力曲线**：每次大爆前都要有一段压迫积累。没有压迫铺垫的反转，观众不会有爽感，只会觉得突兀。
- **不得连续两集情绪落平**：如果某一集是过渡集，它的集尾必须留一个比平时更强的钩子。

### 6.3 付费卡点设计

- 卡点不是"故事自然的断点"，而是**主动选择的悬念最高点**。
- 每个大卡点前应完成一次情绪蓄力：让观众先付出情绪成本（愤怒、心疼、好奇），再切断。
- 卡点之后的第一集要快速兑现一部分承诺（给一个可见结果），否则会被认为"骗付费"。
- 卡点密度与集数成正比，但**不要每一集都卡在身份揭露上**，会让观众对同类悬念脱敏。轮换使用信息差、危险、关系破裂、选择未定几种卡点类型。

## 7. 第五步：冲突与反派层级递进

### 7.1 冲突的三种层级

| 层级 | 内容 | 作用 |
|---|---|---|
| 事件冲突 | 具体的一件事上的人对人对抗 | 提供本集的可拍内容 |
| 关系冲突 | 立场与情感变化（信任、背叛、依恋） | 提供情绪回报 |
| 价值冲突 | 主角坚持的原则与环境的对抗 | 提供全剧的持续性动力 |

一个健康的项目三层都要有：只有事件冲突会变成流水账，只有价值冲突会拍不出来。

### 7.2 四层反派递进

反派不要只有一个，也不要一开始就把最强的放出来。按四层推进，每解决一层就打开下一层：

1. **第一层｜贴身小人**：与主角同场景、同阶层，日常施压。例如同事、继妹、闺蜜、婆婆、渣男前任。
   - 作用：制造高频小冲突，提供前几集的小爽点。
2. **第二层｜权力代理人**：掌握局部资源，能决定主角的去留、资格或名声。例如部门主管、家族长辈、公司高管、对方背后的靠山。
   - 作用：把冲突从人际升级到资源层级，主角第一次"反击成功也仍有代价"。
3. **第三层｜幕后资本 / 集团**：系统性的压力来源，往往不直接出面。例如公司实控人、财阀、家族族长、组织化的对手。
   - 作用：提供中后段的大爆点与权力洗牌，也是主角隐藏身份最有价值的揭露时机。
4. **第四层｜终极真相层**：与主角身世或全剧原始冤案直接相关的人或事实。例如父母之死的真凶、主角被替换的身份、当年的举报者。
   - 作用：承载大结局级别的反转，必须在前期留下可回溯的伏笔。

硬规则：

- 每层反派的动机要写得出来，不能只是"因为坏"。
- 上一层的失败要成为下一层出场的理由（因果链，而不是排队送人头）。
- 反派台词用利益剥夺、身份轻视、关系威胁、掌握资源、公开羞辱、逼迫选择制造压力，不要靠连续粗口。

## 8. 第六步：台词规则

台词服务剧情与镜头，不单独追求文采。默认原则：**短、直、准、有情绪、有信息、有关系压力。**

### 8.1 口语化短句

- 一句话只说一件事，单句不宜过长，写完读一遍——读起来像书面语就改。
- 用日常词汇替换成语与书面表达。"此举实属不妥"→"你这么做不合适"。
- 删掉没有功能的寒暄、解释和过渡句。
- 少用"其实""我是说""你应该知道"这类填充词，短剧没有时间做铺垫。

### 8.2 信息密度

每句重要台词至少承担一项功能：施压、拒绝、试探、揭露、反击、威胁关系、改变立场、暴露秘密、制造误解、完成承诺、制造结尾钩子。

> **这条不能反读成"每句台词都要推进剧情"。** 那句话会把所有人都写成在办公：每句话都在办案、都在谈判、都在交代信息，人物没有一刻是闲的，观众也就没有一刻是信的。允许——并且需要——这样的台词：
>
> - **答非所问**：对方问 A，他答 B，因为 B 才是他在意的（暴露他真正想要什么）。
> - **重复**：把同一句话再说一遍，因为第一次说的时候对方没听（暴露关系里的失衡）。
> - **示弱或求饶**：不推进任何事，只让人看见他怕什么（观众信他，后面的反抗才成立）。
> - **废话**：一句"吃了吗""随便"，用来给真正的沉默量出长度。
>
> 判据不是"这句有没有功能"，而是**"说完这句之后，这个人在下一场里做出的选择是不是变了"**。变了，这句就有用——哪怕它只是在说天气。整集所有台词都四平八稳地推进剧情、没有任何一句闲话，是另一种失败：那不是剧本，是会议纪要。

- 背景信息压缩进冲突：不要让人物长篇介绍自己的家庭史，让对手用一句带立场的话把核心背景说出来。
- 如果动作、眼神、证据已经能表达，就不要再让人物把同样信息复述一遍。
- 连续三句以上纯信息交换的对白，需要插入一个动作或一个反应镜头打断。

### 8.3 动作配合台词，不站着说话

人物不要一直站着轮流说话。让台词与动作同时发生：

- 一边收拾行李一边宣布离开。
- 把手机推到对方面前时揭露证据。
- 推门进入时打断谈话。
- 摘下戒指时说出决裂台词。
- 转身离开后再停下补一句关键话。
- 对方准备触碰时后退一步。

动作是情绪的实体化。写完一场戏自查一次：这场戏里人物除了嘴，还有没有别的地方在动？如果没有，重写。

### 8.4 反派台词与主角反击台词

- 反派：优先用可验证的威胁（剥夺利益、收回资源、公开羞辱、逼迫签字），少用重复的人身攻击。
- 主角反击：与行动、证据或局势变化绑定。比起连续说狠话，更有效的是**一句短台词 + 一个明确动作 + 一个已经准备好的证据**。
- 主角越强，越不需要长篇解释自己有多强。
- 身份揭露的爽感来自"周围人态度发生 180 度变化"，不一定让主角自己宣布——可用权威人物称呼、文件签名、权限验证、对手突然认出等完成。

## 9. 第七步：合规红线清单

交付前逐条自查。以下为方向性要求，**具体条文以平台与主管部门的现行规范为准**，本清单只用于提前发现明显风险：

- **价值导向**：不得渲染炫富拜金、金钱至上、阶层歧视、畸形婚恋观、家庭暴力有理、以恶制恶。结尾的价值落点必须正向，反击走合法追责、证据揭露、规则内竞争，而不是私刑报复。
- **血腥暴力**：不得详细展示伤害过程、虐待、折磨、凶杀细节；不得以暴力为卖点；不得出现明确的血腥特写与致残描写。
- **色情低俗与性暗示**：不得出现性行为描写、露骨挑逗、低俗擦边镜头、不当身体特写；两性关系描写需符合公序良俗。
- **赌博与违法犯罪**：不得展示赌博、诈骗、传销、毒品、非法集资的完整手法与获利过程；此类情节只能作为被揭露、被惩处的对象出现，且不做技术细节描写。
- **未成年人保护**：不得涉及未成年人的恋爱、婚育、性暗示内容；校园题材中的霸凌、暴力不得细节化；不得出现未成年人参与违法活动的教学式描写。
- **历史与民族宗教**：不得历史虚无主义，不得戏说、侮辱重大历史事件与历史人物；不得涉及民族歧视、宗教不当描写与地域攻击。
- **封建迷信与恐怖**：不得宣扬封建迷信、邪教、超自然"真实有效"暗示；恐怖惊悚元素不得过度渲染。
- **公序良俗**：不得出现侮辱性称呼作为爽点，不得贬损特定职业、性别、疾病患者、残障人士。
- **真实性**：不得冒充真实机构、公众人物；不得伪造公文、法律文书作为剧情噱头（可作为道具但须明显为戏剧虚构）。

发现风险时的处理顺序：先给最小修改版（保留爽点、替换手法）→ 说明改了什么 → 再继续推进剧情。不要因为合规问题停在提问阶段。

## 11. 反 PPT 剧本写作纪律

### 11.1 因果与变化

- 每场填「因为 / 所以 / 但是 / 于是」。填不进「因为」和「但是」的场次只是按时间排列，删场或重写。
- 「但是」必须写清谁或什么具体挡住人物；本场「于是」成为下一场的「因为」。
- 每场至少发生一项真实变化：新事实、关系、选择或情绪。只复述已知信息的场合并；有意留白也要写清它改变了谁的期待，而不是把它包装成新事实。

### 11.2 独特性来自具体材料与取舍

- G0 先记录具体处境、物件或话语、来源授权和“本片不拍哪种俗套”。全权委托时 Agent 可从用户材料、已授权参考或现场调研获得，不把虚构经历冒充真实来源。
- AI 负责把种子扩成行动选择、阻碍升级和场景候选，不直接返回题材卡里的默认故事。每个场景登记种子落在哪个动作、物件或话语上。
- 不用关键词闸判断“有特色”。独特性由新上下文朗读与导演选择验收。

### 11.3 剧本保留具体心思，G4 才物理量化

- 剧本可以且应该写人物怕什么、想隐瞒什么、为什么说不出口，供 G3 设计表演。
- 禁止的是“她很难过”这类没有具体处境的情绪标签，不是心理描写本身；不要机械写成“愤怒—握拳、悲伤—低头”。
- `AGENTS.md` §8.1 只约束 G4 提示词，不上溯 G1。

### 11.4 潜台词与道具都服务因果

- 对白场景写“谁在瞒谁、真正想让对方做什么”。G3 逐字继承，不在分镜阶段临时另编平均答案。
- 道具翻转按需使用，不是每集配额。若使用，再次出现必须改变人物选择或观众理解；不要为过清单硬加象征物。
- 意象片改用意象变奏 ≥3 次且意义递进，不套用人物因果和道具规则。

### 11.5 朗读测试（G1 通过的必要条件）

- 交稿前只把场景部分交给新上下文读者，不给大纲和叙事决策锁定，让他复述：谁想要什么、被什么挡住、最后卡在哪、哪一处具体细节只属于这个故事。
- 复述原话照抄进剧本，写剧本的 Agent 不得代填或润色。复述与作者意图对不上时改剧本，不改答案。

写法要求：

- **一场戏一个因果。** 每场先填因果四句再写戏，动作和台词按发生顺序交织成段落。
- **剧本不是分镜。** 正文禁止刀号、时间码、机位、光比、焦段、景别、色温、`mm`。
- **场景宜少不宜多。** 避免“一场戏一句话”的碎片化；交付人物关系表与关键道具清单。

## 13. 常见错误反例

| 反例 | 问题 | 改法 |
|---|---|---|
| "她受尽欺辱，终于崛起" | 一句话故事里没有具体事件，无法开拍 | 换成具体压迫事件与明确目标：要拿回母亲的房产证 |
| 开场两秒城市空镜再进正戏 | 前 3 秒没有观看理由 | 直接进四型钩子之一，环境信息与冲突同时出现 |
| 本集结尾"主角回家，心情平复" | 情绪落平，没有未完成状态 | 改成"证据刚被拿出来，还没打开" |
| 反派只有一个，坏得毫无理由 | 冲突层级单薄，中后段无戏可写 | 按四层递进铺开，每层写出动机与因果 |
| 主角突然无敌，观众不知道强在哪 | 无来源的能力，爽感不成立 | 前几集给出隐藏身份、积累的证据或专业能力 |
| 一场戏三个人轮流说三分钟 | 站着说话，画面无变化 | 把冲突拆成动作、反应、证据与立场变化 |
| 反派台词只有"你配吗""贱人" | 压力不足且触碰合规风险 | 换成利益剥夺、收回资源、公开羞辱、逼迫选择 |
| 靠旁白解释线索与关系 | 认知负担转嫁给观众，画面空心 | 线索前置成可见证据，让观众自己看见 |
| 铺垫未完成就急着揭晓身份 | 反转突兀，观众不买账 | 每次大爆前先补一段压迫积累 |
| 卡点落在事情已经结束之后 | 观众没有必须追下去的理由 | 卡点落在"信息将要揭晓、结果将要出现"的瞬间 |
| 每集都卡在身份揭露 | 同类悬念脱敏 | 轮换信息差、危险、关系破裂、选择未定等卡点类型 |
| 每场都是"场景头 / 人物 / 动作 / 台词 / 结束状态"五块并列，读起来像一页页幻灯片 | 五块平行的格子天然产出五块平行的内容；场与场之间只有时间先后，没有因为所以 | 每场先填「因为 / 所以 / 但是 / 于是」，戏写成动作与台词交织的段落 |
| 剧本里写"刀 3｜4.0–6.5s：低机位 0.5 米，光比 2:1，35mm" | 执行参数挤掉了故事；G1 是唯一还能便宜改故事的阶段，读者却只能读到参数 | 参数全部移到 G3 分镜表；剧本只写人在等什么、做了什么、被什么挡住 |
| 事件一件接一件，观众说不出"他为什么要这么做" | 因果藏在作者脑子里没写下来；作者看得懂，观众看不懂 | 把每场的「因为」写成上一场的某件具体的事；写不出来就说明这场戏可以删 |
| 每句台词都在推进剧情，没有一句闲话 | 人物像在开会，观众不信他们是活人 | 留一两句答非所问、重复或示弱——只要说完后人物在下一场的选择变了 |
| 剧本里只写"她低下头，手指收紧"，从不写她在想什么 | 把 §8.1（提示词纪律）错用到剧本上；表演依据缺失，G3 只能猜 | 剧本写心思："她想让他先开口，这样走的人就不是她"；G3 再把它翻成动作 |
| 为了爽写私刑、以暴制暴 | 触碰合规红线 | 改为合法追责、证据揭露、规则内竞争 |
| 主角用旁白介绍自己的家庭史 | 无功能解释，节奏拖沓 | 让对手用一句带立场的话说出核心背景 |
| 把剧本直接写成镜头分镜 | 越界到 02 阶段，剧本反而不可读 | 剧本只写场景、人物、动作、台词；镜头语言交给 02 阶段 |

## 14. 改编管线：从小说/长文到剧本（结构化提取先行）

> 适用于"手里有一篇小说/大纲/真实故事，要改成短剧"的入口。方法借鉴开源漫剧管线的共同实践：**先把素材拆成结构化清单，再写剧本**，而不是让模型一口气"把这篇小说改成短剧"——一口气改的产物角色关系错乱、前后设定打架，且无法被下游复用。

### 14.1 第一步：通读提取三张资产表（先于任何剧本文字）

| 表 | 每行字段 | 用途 |
|---|---|---|
| **角色表** | 姓名/称谓、身份处境、外貌关键词（3-5 个可渲染的物理特征）、与主角的关系、欲望与恐惧 | 直接交 03 阶段定妆与角色锚，锚句素材从这里来，不是从剧本正文里现捞 |
| **场景表** | 名称、内/外、时段、氛围关键词、剧情功能 | 直接交 03 阶段场景资产，02 分镜的场景锚整列复制 |
| **道具表** | 名称、外观关键词、剧情功能（信物/证据/武器） | 直接交 03 阶段道具资产；道具多数是"伏笔-回收"的锚点，漏提=后文接不上 |

**硬规则**：三张表没提完，不动手写剧本。表里的每个外貌关键词必须是"画面能渲染的物理细节"（"眼角有疤""总穿灰夹克"），不接受"气质清冷""很有故事感"这类抽象词——这条与 03 一致性 skill 的锚句要求同源。

### 14.2 第二步：分集切分（按冲突单元切，不按字数切）

- 找到原文里天然的**冲突单元**（一次羞辱→反击、一次误会→加码、一次发现→追查），每个单元一集或半集。
- 每集末尾必须落在"冲突有进展但未解决"的状态，用 §5.3 的集尾钩子清单逐集校验。
- 原文里"主角一路顺"的流水段，主动加障碍或合并压缩；短剧不接受无对抗段落。

### 14.3 第三步：场景头化与口语化改写

- 每场戏开头补场景头：`场号-内/外-地点-日/夜`，与第 10 节输出模板对齐。
- 原文叙述腔改台词与动作：心理描写翻成可见动作或对手台词；环境描写砍到只剩"影响表演和氛围"的量。
- 对白按 §8 口语化短句重写；旁白总量见 `05-音频/配音与音效设计.md` §1.3（默认上限 20%，按片型另有区间），且必须由本片复盘回填实测占比。

### 14.4 去 AI 味自检（交稿前必过一遍）

AI 改写的剧本有几种一眼假的模板腔，逐条搜自己的稿子：

| 病灶 | 典型句式 | 改法 |
|---|---|---|
| 排比滥用 | "他不是……不是……而是……" | 拆成两句人话，留一个就够 |
| 形容词堆叠 | "绝美""霸气侧漏""眼神里闪过一丝" | 换成具体动作与证据 |
| 统一口头禅 | 每个角色都"冷笑一声""挑眉" | 给每个主要角色一个专属动作标签，其余删除 |
| 情绪直给 | "她非常愤怒地说道" | 愤怒让台词内容和动作说出来，删掉副词 |
| 总结腔结尾 | "原来，真正的强大是……" | 删掉，停在动作或钩子上 |
