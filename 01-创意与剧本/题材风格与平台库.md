# 题材风格与平台库

## 1. 使用说明

本文件是**动笔前的选题决策库**，不是创作方法论。推荐配合 `短剧编剧引擎.md` 按四步走：

```
第一步：选形态（§2）——这部片子是 AI 真人剧、漫剧、特效片还是口播？
第二步：选题材（§3）——翻题材卡片，确定爽点、受众、变现模式
第三步：选平台（§6）——目标平台决定时长、画幅、节奏、合规红线
第四步：定钩子（§4）——从 5 类钩子里挑本集的开场与结尾钩
```

选定后带着「形态 + 题材 + 平台 + 钩子」四个结论进入 `短剧编剧引擎.md` 的第一步（选题定位），视听风格则从 §5 导演技巧速查库里挑 2-3 个主技法写进剧本视觉基调。

**两条铁律**：

1. **一部片只服务一个平台的主战场**。跨平台分发是后期裁剪的事（见 `06-后期与发布/成片与字幕.md` 的导出规格），选题阶段必须明确主战场，否则节奏和画幅都会拧巴。
2. **题材决定 80% 的提示词基调**。甜宠的柔光暖调和悬疑的冷硬阴影从第一帧就分叉，不要试图写"什么都能搭"的中性风格。

## 2. AI 短片 8 大形态

形态决定整条流水线的走法（哪条端到端管线、哪些 skill 是主力）。

| 形态 | 定义 | 制作难点 | 提示词侧重 | 所需能力 |
|---|---|---|---|---|
| **AI 真人短剧** | AI 数字演员按真人短剧逻辑出演 | 角色一致性、微表情、唇形同步、多机位连贯 | 角色锚定图 + 主体参考 + 服装/光线/动作/景别四要素 | 主体参考、身份保持、表演与音画同步 |
| **AI 漫剧/动态漫** | 漫画风格连续画面，介于动画与短剧之间 | 画风一致性、分镜转场、台词同步 | **全局风格参数先行**（如"3D 电影级写实 CG 动画，东方玄幻风格"），再写分镜 | 画风约束、图生视频与跨段一致性 |
| **3D 电影级 CG 漫剧** | 3D 写实 CG/次世代游戏过场质感的漫剧，当前 AI 漫剧头部主流形态之一 | 渲染风格域一致、材质锚、3D 角色三视图 | 风格锚句最前（渲染域+光照+材质+镜头光学），材质可渲染化 | 3D 资产 + 图生视频链，专项见 `03-角色与视觉资产/角色一致性.md` §九 3D 漫剧分支 |
| **AI 特效大片/概念片** | 5-60 秒视觉奇观，弱叙事 | 物理一致性、材质细节、运镜复杂度 | 电影级运镜 + 物理细节（材质/光线/反射）+ 首尾帧引导 | 物理运动、材质呈现与首尾状态约束 |
| **AI 文旅/风景片** | 城市景区宣传、风光空镜 | 写实质感、长镜头流畅度 | 光线时段（黄金/蓝调时刻）+ 天气 + 航拍推拉摇 | 通用视频模型 |
| **AI 广告/TVC** | 品牌定制 15s-3min 短片 | 品牌调性、产品卖点视觉化、多镜头角色锁定 | 品牌色卡 + 产品特写关键词 + Logo 保护约束 | 首尾状态与产品参考约束 |
| **AI MV** | 歌曲视觉化，节奏卡点 | 节拍对位、运镜变化密度 | 节拍卡点描述 + 风格统一 + 高频运镜切换 | 节拍对齐、素材生成与剪辑装配 |
| **口播数字人** | 数字分身讲解/带货 | 唇形同步、表情自然、动作不僵 | 锁定中近景 + 短句台词 + 最小头部动作 + 字幕安全区 | 经授权的人物呈现、口型与表情控制 |
| **混剪/解说** | 现有素材重组 + AI 配音解说 | 版权、节奏、信息密度 | 解说稿生成 + 情绪匹配 + BGM 卡点 | 剪辑工具 + TTS |

**形态与体系管线对应**：真人短剧 → `07-端到端管线/片型全流程.md`「真人短剧」节；漫剧 → 同文「小说漫剧」节；特效/文旅/广告/MV → 跳过 01 编剧的剧本层，直接从 `02-分镜与镜头/` 起步；口播 → 只需 `04-视频生成` + `05-音频` 两段。

## 3. 题材卡片库（10 大热门题材）

每张卡片可直接作为 `短剧编剧引擎.md` 选题定位的输入。

### 3.1 玄幻战神（男频顶流）
- **核心爽点**：隐藏身份 → 被辱 → 亮身份/神装 → 全场跪服（扮猪吃虎）
- **目标受众**：18-45 岁男性，下沉市场为主
- **典型钩子**：身份曝光前最后一秒卡点；反派刚要动手；信物发光
- **变现模式**：IAP 付费卡点（第 10/30/60 集）；AI 漫剧也可跑 IAA
- **推荐视听**：环绕运镜英雄亮相 + 升格慢动作 + 侧光半脸阴影 + 能量粒子
- **提示词基调**：东方玄幻武侠风格，铠甲金属反光，法术能量主光源，大场面低机位仰拍
- **体系配套**：`03-角色与视觉资产/题材取材与角色卡.md` §六 中式神怪角色设计 + `04-视频生成/动作镜方法.md` §一 玄幻打斗一镜到底

### 3.2 逆袭重生（双频通吃）
- **核心爽点**：被踩到底 → 反杀崛起；前世被虐 → 今世加倍奉还
- **目标受众**：全龄段；逆袭偏男频、复仇偏女频
- **典型钩子**：反派动手前一刻；真相即将大白；隐藏大佬身份曝光
- **变现模式**：IAP 三段卡点（10/30/60 集）
- **推荐视听**：冷暖色调对比（压抑期冷色/爆发期暖光）+ 俯拍上帝视角 + "压-爆"剪辑节奏
- **提示词基调**：前期低饱和去饱和压抑，觉醒节点强光暖色，色彩反差即叙事

### 3.3 甜宠闪婚（女频长青）
- **核心爽点**：身份差反转、"被宠溺"、霸道男主只对我好
- **目标受众**：18-35 岁女性，一二线城市
- **典型钩子**：误会未解开；身份将曝光；契约到期；第三者插足
- **变现模式**：小程序 IAP 主战场
- **推荐视听**：柔光高调 + 暖色调 + 特写眼神 + 升格回眸
- **提示词基调**：柔光高调摄影，暖色橙调，浅景深虚化背景，眼神特写慢镜头

### 3.4 萌宝亲子
- **核心爽点**：萌娃神助攻、神童打脸反派、团宠日常
- **目标受众**：25-40 岁女性、宝妈群体
- **典型钩子**：萌娃暴露身份；萌娃神回复；身世揭秘
- **变现模式**：女频 IAP
- **推荐视听**：童趣配色高饱和 + 超广角仰拍萌娃 + 表情大特写
- **提示词基调**：明亮高饱和色彩，Q 版比例元素混搭，仰拍视角，表情特写
- **合规提示**：涉及未成年人角色，注意 `短剧编剧引擎.md` 合规章节的未成年人红线

### 3.5 豪门霸总（出海主力）
- **核心爽点**：身份差反转、被宠上天、真假千金
- **目标受众**：18-40 岁女性；出海欧美主力人群
- **典型钩子**：契约到期；身份将曝光；第三者搅局
- **变现模式**：海外 IAP 主力题材（ReelShort 起家赛道）
- **推荐视听**：西装夜景 + 暖光高端酒店 + 升格回眸 + 红酒豪车符号
- **提示词基调**：都市夜景暖光，高端室内布景，西装革履材质细节，克制表情特写

### 3.6 复仇打脸
- **核心爽点**：手撕渣男、复仇千金、当场揭穿
- **目标受众**：全龄段女性为主
- **典型钩子**：证据即将亮出；仇人就在眼前；身份反杀前一秒
- **变现模式**：全平台 IAP/IAA 均可
- **推荐视听**：对称构图对峙 + 反应镜头停留 + 硬切节奏
- **提示词基调**：对峙构图，压迫感近景，情绪爆发定格，反应镜头特写

### 3.7 悬疑规则怪谈
- **核心爽点**：智识优越感、抽丝剥茧、反转不断
- **目标受众**：18-30 岁，男女通吃略偏男频
- **典型钩子**：监控盲区；新角色动机不明；关键证据刚被发现
- **变现模式**：IAA 免费为主；互动剧"充钱改命"分支付费
- **推荐视听**：冷色调 + 底光/侧光阴影 + 手持晃动 + 希区柯克变焦 + Dutch Angle
- **提示词基调**：冷色低照度，阴影切割画面，手持纪实质感，慢推逼近关键物

### 3.8 玄幻异能末世（AI 漫剧黄金赛道）
- **核心爽点**：世界观新奇、战力体系炫、升级节奏爽
- **目标受众**：18-30 岁男性，Z 世代二次元
- **典型钩子**：异象刚出现；怪物将破封印；主角觉醒前一刻
- **变现模式**：AI 漫剧 IAA 为主，IAP 续作
- **推荐视听**：大场面航拍 + 特效粒子 + 3D CG 质感
- **提示词基调**：3D 电影级写实 CG 动画，次世代游戏过场质感，真实材质物理，能量特效分层
- **为什么适合 AI**：实拍成本极高的题材恰是 AI 成本洼地，是 AI 漫剧的天然赛道

### 3.9 银发重启人生
- **核心爽点**：60 岁照样活出自我、闪婚老伴是豪门、子女不孝我有底气
- **目标受众**：50+ 用户（银发短剧用户约 4000 万级，红果集中度高，2026 年数据）
- **典型钩子**：隐藏身份曝光；儿女后悔；老伴亮明身家
- **变现模式**：IAA 免费为主，红果主战场
- **推荐视听**：怀旧色调 + 室内景为主 + 对称构图仪式感 + 字幕字号加大
- **提示词基调**：怀旧暖黄调，中老年写实人脸（保留皱纹与自然老化细节），日常室内光

### 3.10 家庭伦理
- **核心爽点**：婆媳矛盾爆发、重男轻女反转、亲情和解
- **目标受众**：30+ 女性、中老年，抖音/快手下沉市场
- **典型钩子**：矛盾当众爆发；偏心现场被抓包；身世秘密揭开
- **变现模式**：IAA 为主
- **推荐视听**：纪实手持 + 自然光室内 + 反应镜头密集
- **提示词基调**：生活纪实感，自然窗光，居家场景陈设写实，表情微特写

## 4. 钩子模板库（5 类钩子）

钩子分**开场钩**（前 3 秒）和**集尾钩**（卡点）两个位置，写法不同：开场钩要"已经出事"，集尾钩要"即将出事、必须下集"。

| 钩子类型 | 句式模板 | 开场实例 | 集尾实例 |
|---|---|---|---|
| **身份钩** | 「（所有人以为他是 A），其实他是 B」 | 全公司嘲笑的保洁员，走进了董事长专属电梯 | 他掏出那枚徽章的瞬间，全场跪了——而反派还没回头 |
| **动作钩** | 「动作已发起，结果悬而未落」 | 巴掌已经扬起，她却没有躲 | 刀尖抵到喉咙的前一帧，画面定格黑屏 |
| **悬念钩** | 「出现了不该出现的东西/信息」 | 监控里，死去的丈夫走进了家门 | 她翻开档案袋，第一页的照片让她浑身发抖 |
| **情感钩** | 「关系即将破裂或错位」 | 婚礼现场，新郎喊出了别人的名字 | "我们离婚吧"——而这时门铃响了 |
| **新人物钩** | 「一个改变力量格局的人登场」 | 破产签字现场，门外走进来一位老人 | 所有人都怕他，直到那个女人推门而入 |

**节奏铁律**：
- 前 3 秒必出钩，超过 3 秒没抓住 = 被划走
- 前 30 秒必出第一个爆点，之后每 30 秒悬念升级或反转
- 付费卡点黄金位在全剧 25%-35% 处；系列剧经典卡点为第 10、30、60 集

## 5. 导演技巧速查库

五个子库，每行可直接取英文关键词写进提示词。选技法的原则：**技法服务情绪**，先问"这个镜头要什么情绪"，再查表取词。

### 5.1 运镜（11 类）

| 技法 | 情绪/场景 | 英文关键词 |
|---|---|---|
| 推镜头 | 逼近真相、压迫感、聚焦情绪 | push in, dolly in, slow zoom in |
| 拉镜头 | 揭示环境、孤独、释然 | pull out, dolly out, zoom out |
| 摇镜头 | 跟随主体、横向信息量 | pan left/right |
| 移镜头 | 平行跟拍、平行叙事 | truck left/right, lateral tracking |
| 跟拍 | 紧张追逐、沉浸代入 | tracking shot, follow shot |
| 环绕拍摄 | 英雄亮相、气场全开 | orbit shot, 360 tracking, arc shot |
| 航拍/俯拍 | 上帝视角、命运渺小、宏大场景 | aerial shot, bird's-eye view, drone shot |
| 手持跟拍 | 纪实感、紧张、混乱 | handheld, shaky cam |
| 希区柯克变焦 | 眩晕、认知崩塌、悬疑揭示 | dolly zoom, vertigo effect |
| 升格慢动作 | 高光时刻、美学定格、情感放大 | slow motion, 120fps, cinematic slo-mo |
| 一镜到底 | 沉浸、炫技、连续时空 | one-take, single continuous shot, long take |

### 5.2 剪辑节奏（6 类）

| 技法 | 情绪/场景 | 英文关键词 |
|---|---|---|
| 快切卡点 | 紧张、燃向、MV | fast cuts, beat-synced cuts |
| 硬切/跳切 | 节奏感、突兀惊醒 | hard cut, jump cut, smash cut |
| 叠化/淡入淡出 | 时间流逝、情绪过渡 | cross dissolve, fade in/out |
| J-Cut/L-Cut | 声音先导、平滑转场 | J-cut, L-cut, audio bridge |
| 蒙太奇 | 信息浓缩、情绪叠加 | montage sequence, parallel editing |
| 定格 | 强调、反转前一刻 | freeze frame, hold on frame |

### 5.3 构图（8 类）

| 技法 | 情绪/场景 | 英文关键词 |
|---|---|---|
| 三分法 | 安全通用、叙事平衡 | rule of thirds composition |
| 对称构图 | 仪式感、压迫感 | symmetrical composition, centered frame |
| 框架构图 | 窥视、囚禁、聚焦 | frame within frame |
| 对角线构图 | 动感、张力、不安 | diagonal composition, Dutch angle |
| 汇聚线构图 | 纵深、命运感 | leading lines, converging lines |
| 镜像/倒影 | 双生、分裂、觉醒 | mirror reflection, water reflection |
| 仰拍 | 神化、威严 | low angle, worm's-eye view |
| 俯拍 | 渺小化、审判感 | high angle, top-down shot |

### 5.4 光影（8 类）

| 技法 | 情绪/场景 | 英文关键词 |
|---|---|---|
| 侧光 | 戏剧性、悬疑、两面性 | side lighting, Rembrandt lighting |
| 逆光 | 神圣、离别、剪影美 | backlighting, silhouette, rim light |
| 顶光 | 神性、审判、压迫 | top lighting, overhead light |
| 底光 | 恐怖、反派、惊悚 | underlighting, horror lighting |
| 黄金时刻 | 温暖、回忆、初恋 | golden hour, magic hour |
| 蓝调时刻 | 忧郁、孤独、科幻 | blue hour, cold blue light |
| 高对比硬光 | 黑色电影、赛博朋克 | hard light, high contrast chiaroscuro |
| 霓虹赛博光 | 都市夜景、未来感 | neon light, cyberpunk lighting |

### 5.5 色彩叙事（7 类）

| 技法 | 情绪/场景 | 英文关键词 |
|---|---|---|
| 暖色调 | 甜宠、温馨、回忆 | warm color palette |
| 冷色调 | 悬疑、孤独、虐恋 | cool color palette, desaturated blue |
| 高饱和 | 喜剧、萌宝、广告 | high saturation, vibrant colors |
| 去饱和/黑白 | 苦难、纪实、回忆杀 | desaturated, monochrome |
| 青橙对比 | 商业大片主流调 | teal and orange color grading |
| 赛博粉紫 | 玄幻、未来 | magenta neon, cyber pink |
| 色彩反转 | 人物成长弧、前后对立 | before/after palette shift |

## 6. 平台适配矩阵

> 画幅规则（C1，2026-10-12）：本表全是竖屏平台，**不等于全体系默认竖屏**——画幅由 G0 选定的目标平台决定；平台给了规格用平台规格，无平台信息时缺省横屏 16:9。

## 8. 2026 趋势提示（选题前读一遍）

1. **AI 仿真人剧爆发**：AI 仿真人剧在漫剧百强榜占比一年内从个位数跃升至约 38%（2026.1 数据），"伪人感"瓶颈正在被打破，真人剧路线值得重仓。
2. **3D 漫剧是头部主流形态**：公开榜单观察（2026 年），AI 漫剧头部榜单中 3D 形态占比显著，玄幻/穿越/大女主是高频标签；立项前按目标平台当期榜单验证，不依赖此处旧观察。
3. **互动短剧是下一风口**：观众选分支、选错触发 BE、充值回溯改命的模式付费转化显著，剧本层需支持多分支决策节点。
4. **出海 6 倍增长**：海外 AI 短剧市场 2025 约 1 亿美元 → 2026 预计 6.5 亿美元；题材正从女频甜宠扩展到男频玄幻/狼人/机甲，立项时可同步规划英文版。
5. **备案制 + 精品化**：漫剧需备案持证、单账号日上传设上限，倒逼"少而精"；平台分账政策向高质量 AI 内容倾斜，粗制跑量策略风险升高。
6. **用户需求转向**：从"强情绪释放"转向"被理解、情感共鸣"（巨量引擎 2026 趋势洞察），纯打脸爽剧边际递减，情感厚度成为新差异点。
7. **立项先拆爆款**：题材热度与成本模型请以公开榜单的当期数据为准，榜单高频词与成本区间每月都会变。
