# 剧本去 AI 味

模型写剧本时，容易把一场戏写成最稳妥的说明：用否定句制造深度，用情绪词代替动作，用总结句替观众做结论。单次出现可以是人话。同一场里挤在一起，读起来就不像这场戏里的人。

这层检查借鉴两类公开做法，只取对白和场戏用得上的部分，不把文章润色规则整份搬进来：

- 英文与中文的 humanizer 清单（上游包括 Wikipedia 的 Signs of AI writing）：看聚簇，不看孤词；改写时保住事实、语气和因果，不为了躲检测去加错字。
- 本机小说体系的风格词库：否定翻转、情绪贴牌、总结收尾、对白后面机械补一拍动作。那些规则服务长章正文。短剧只拿会伤一场戏的几条，不把长篇的章审流程带进来。

## 怎么改

- 改句子，不改这场戏的因为、所以、但是、于是。
- 不新增原文没有的证据、数字、关系和过去。
- 人物心里的具体打算可以留。删的是「她感到愤怒」「眼神里闪过一丝」这种贴牌。
- 不要把对白改成说明文，也不要整集自动重写。先改命中的那几句，再重跑检查。

## 机检

```powershell
python tools/check_script_ai_flavor.py <项目目录>
python tools/check_script_ai_flavor.py
python tools/check_script_ai_flavor.py --selftest
```

退出码 1 表示下面任一情况：同一场可见正文里的套话达到 3 处；「不是……而是 / 不是……是」在全稿出现 2 次及以上；出现总结式收尾。改表达后再跑。退出码 0 就是这一层通过，其中包含完全没有命中，也包括有提醒但没超线。有提醒时人可以改那一句，不要据此重写整集。

没有在制项目时打印未评估并退出 0。本检查不进常驻全闸，避免没写剧本时把体系自检打红。它也不证明稿子是人写的。

| 机器规则 | 看见什么 | 怎么改 |
|---|---|---|
| 否定翻转 | 不是钱，而是尊严 | 直接写他要的那一件 |
| 情绪贴牌 | 感到愤怒、冷笑一声、眼神里闪过一丝 | 改成这句话说完之后对方做什么 |
| 总结收尾 | 原来，真正的强大是 | 停在动作或还没做完的事上 |
| 时代腔和拔高 | 随着……的发展、不仅……更、彰显 | 写成这一场谁做了什么 |
| 讲义列举 | 首先……其次 | 改成有先后的动作 |
