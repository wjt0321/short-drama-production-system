# 短剧项目模板

本目录是单部片子的生产模板，不是实际工作项目。复制 `短剧项目模板/` 的内容到体系根目录下的 `00-视频项目/《片名》/`，再从 G0 开始执行；建项规则统一见 `AGENTS.md` 第六节，不在根目录直接建片名文件夹。

## 使用规则

1. 只复制模板，不覆盖已有项目。
2. 文件名中的 `S01`、`EP01`、`v2` 按实际项目替换。
3. 通过的产物不得覆盖；修改必须升版本并登记到《变更记录.md》。
4. 默认由 Agent 按 G0–G6 自检并更新《项目状态摘要.md》；只有用户开启阶段审核或实际参与裁决时，才填写审核包与《用户裁决日志.md》。
5. 角色、场景、道具在 G2 通过后冻结；分镜在 G3 通过后冻结。
6. 能力、成本、授权和失败记录不得写入密码、密钥或个人隐私。

## 推荐命名

```text
EP01-S01-v1.mp4
EP01-S01-v1-prompt.md
EP01-S01-v1-first-frame.png
EP01-S01-v1-last-frame.png
```

## 状态机

```text
未开始 → 生成中 → 待审 → 通过
                      ├→ 修改后重审
                      ├→ 回退链
                      └→ 终止
```
