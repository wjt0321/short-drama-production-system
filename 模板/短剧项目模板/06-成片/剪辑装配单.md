# G6 剪辑装配单

> 本表是可复现时间线的最小交接件。任何进入成片的画面、声音和字幕都必须能追溯到稳定 ID 与文件版本。
> **本文件是剪辑装配单的唯一权威**（表结构 + 填法 + 生成规则 + 自动生成步骤 + 审核闸门；SOP 侧 `06-后期与发布/剪辑装配单生成器.md` 只作指针，防两处漂移）。
> 用法：把本文件复制进项目 `06-成片/` 后，按 §四「生成规则」逐镜填；下游质检与门禁见 `06-后期与发布/成片与字幕.md`。

**装配单 = 一条时间线：每一行告诉剪辑工具"哪段素材、从哪秒到哪秒、放哪条轨道、配什么声音和字幕、怎么转场"。** Agent 按 §四–§五 自主生成、自检并登记，用户只审时间线；用户确认时间线后才允许渲染。

## 四、生成规则（Agent 照此执行）

### 规则 1 · 轨道映射

| 素材类型 | 轨道 | 说明 |
|---|---|---|
| 画面镜头（视频/图+KenBurns） | V1（主画面） | 每镜一行 |
| 覆盖镜头/插入画面（手机屏、证据特写） | V2（覆盖） | 叠加在主画面上，需标入出点 |
| 配音/旁白 | A1（对白轨） | 绑定 V1 对应镜号 |
| 音效与环境声 | A2（音效轨） | 绑定镜号 + 精确入点 |
| BGM | A3（音乐轨） | 跨多镜，标起始镜与结束镜 |
| 字幕 | S1（字幕轨） | 对齐台词入出点 |

### 规则 2 · 时间线入出点计算

- 以分镜表"时间线时码"为基准：第一镜入点 = 00:00:00.000；每镜出点 = 入点 + 本镜时长（分镜表"时长秒"× 1000ms）。
- 相邻镜入点 = 前镜出点（硬切）或 前镜出点 − 转场重叠（叠化 0.5s 等，见规则 3）。
- **素材源入出点**：素材文件本身可能比目标镜长，源出点 = 源入点 + 目标时长；素材不足时标"需补拍/补生成"，不静默拉长。
- **必须裁切**：源入点、源出点按这一刀的实际使用区间填。备注写 `素材全长 Ns`（有文件时以文件时长为准）。使用时长等于素材全长，表示这一刀没剪。可判定的 V1 行达到 4 行且超过一半没剪，G6 不通过。检查：`python tools/check_assembly_usage.py <项目目录>`。

### 规则 3 · 转场决策

| 相邻关系 | 默认转场 | 依据 |
|---|---|---|
| 同场景、动作连续 | 硬切 | 保持连续性 |
| 情绪断裂 / 时间跳跃 | 叠化（0.5–1s） | 分镜表"镜后状态"或"情绪变化"变化大 |
| 闪回 / 梦境 / 回忆 | 白闪或叠化 | 分镜表叙事标注 |
| 动作快节奏卡点 | 硬切对齐音乐重音 | BGM 节拍（音频清单备注） |
| 位置大跳（异空间） | 硬切 + 无转场 | 避免滥用转场 |

### 规则 4 · ID 关联

- 配音/音效/BGM/字幕**只写 ID，不写文件名**；装配工具按 ID 反查《音频生产清单》与字幕事件表。
- 一个剪辑镜头可挂多个音效 ID，但每个 ID 只能挂一个时间点（冲突时拆行）。

### 规则 5 · 状态机

每行"状态"列：**待装配 → 已装配 → 已确认 → 已渲染 → 回放通过**。Agent 每完成一步更新；用户确认时间线后才允许渲染。
（表头"装配状态"是整条时间线的阶段字段，取值：未开始 / 装配中 / 已确认 / 已渲染 / 回放通过——与行状态是同一套阶段的整体/逐行两种粒度，`项目状态摘要.md` 的"时间线状态"用后者。）

### 规则 6 · 光学统一层（全片常量，不是逐镜变量）

装配单必须带一段**全片统一的光学参数**，来源是视觉圣经选定的风格卡对应参数套
（见 `06-后期与发布/成片与字幕.md` §5.3）：

- 颗粒强度与尺寸、暗角强度、色温/色调分离、对比与高光滚降、锐度增减、
  光晕与色散、快门角、统一帧率 —— **八项一次性写死，装配时整条时间线统一施加**。
- **严禁逐镜各调一套**：单镜加颗粒不难看，36 镜各自加不同强度，观众立刻感到画面在抖。
- 场与场的区别交给色彩脚本和照明卡（视觉圣经第二、三节），**不交给光学层**。
- 缺少这一段 = 装配单不完整，不进入渲染。

## 五、自动生成步骤（Agent 动作）

1. **读齐五份输入**：分镜表、素材清单、音频清单、字幕事件表、光学参数套；缺任何一份先补齐，不猜。
2. **逐镜展开**：每镜一行 V1，按规则 2 算入出点，按规则 3 定转场。
3. **挂音频**：从音频清单把 Axxx/FXxxx/AMBxxx/BGMxxx 按绑定镜号挂到对应轨与时间点。
4. **挂字幕**：从字幕事件表按台词入出点挂到 S1。
5. **登记覆盖镜头**：有 V2 的镜号单独列行，标叠加区间。
6. **施加光学层**：按规则 6 把八项参数写到装配单的光学段，整条时间线统一施加（不是逐镜加）。
7. **产出装配单**：填入 `06-成片/剪辑装配单.md`，初始状态全"待装配"。
8. **交用户审核**：重点看时码是否连贯、转场是否合理、音频字幕是否对位、光学层是否全片一致；通过后才进入实际剪辑。

## 六、时间线门禁

- [ ] 所有剪辑镜头都能追溯到生成段和素材版本
- [ ] 配音、音效事件、BGM 和字幕分别使用稳定 ID，可反查文件与版本
- [ ] 画面、对白、音效、BGM、字幕的入出点无冲突
- [ ] 变速、转场、裁切与画幅处理已登记；V1 每行有源入点、源出点，备注写有 `素材全长 Ns`
- [ ] 可判定的画面行达到 4 行时，使用时长等于素材全长的不超过一半
- [ ] 成片 mp4 已导出时，叙事片帧差静止占比不超过 50%，连续静止不超过 5 镜（`python tools/check_assembly_usage.py <项目目录>`）
- [ ] 时间线已完整回放，未出现黑帧、闪帧、断声或字幕越界
- [ ] 渲染文件名、规格和校验结果已写入《成片质检表.md》

## 七、审核闸门

| 节点 | 谁审 | 通过标准 |
|---|---|---|
| 装配单本身 | 用户 | 时码连贯、转场合理、音频/字幕 ID 对位、无缺素材、光学参数套已填写 |
| 时间线回放 | 用户 | 无黑帧/闪帧/断声/字幕越界（对齐 `06-后期与发布/成片与字幕.md` §7 质检清单） |
| 渲染 | 用户 | 渲染规格与质检表一致，完整回放通过 |

> 注意：装配单是**可复现时间线的最小交接件**——所有进入成片的画面、声音、字幕必须能追溯到稳定 ID 与文件版本（对齐本文件 §六 门禁）。
