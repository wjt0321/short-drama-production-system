## 导演质量检查（区别于技术检查 —— 这部分是「片子好不好」）

> 闸 `check_project_conformance.py` 会反查 G4 提示词与 G6 装配单里
> 「静帧 + 数字轻推」「时长窄带」「合同式反模式」「演员调度 / 运动学合同缺失」等特征。
> 本节是**人工对账**，与机器闸互为补集。

- [ ] **静帧 + Ken Burns / 冻结占比 ≤ 10%**（按 `重抽与回退决策.md` §1.3）—— 主体叙事累计 ≥10% 必须停下告知，不进交付
- [ ] **动作密度与状态变化** —— G0/G3 已按片型声明目标；每个叙事镜头至少存在可观察的起始状态→过程→结果或反应。慢镜头、凝视与诗性停顿允许低密度，但必须有明确叙事意图；不得用固定数值替代导演判断
- [ ] **摄影机起讫四要素** —— 每镜的起点（距离/高度/朝向）→ 过程（运动方式/速度）→ 终点 → 焦点 都已写明并实际呈现
- [ ] **环境异步响应** —— 每镜至少 1 类显式异步（光线 / 粒子·液体 / 布料·机械 / 背景人物）；无异步 = 木偶化风险
- [ ] **转场接力** —— 每镜"接力声明"已写明（动作 / 视线 / 遮挡 / 形状 / 光线 / 声音 六选一或组合），下一镜首帧能接住
- [ ] **语义一致** —— 同场戏所有镜头的色温 / 光线方向 / 主光 / 服装 / 道具状态 / 轴线 一致；漂移镜已记录并标注原因
- [ ] 镜头与镜头之间**有动作起承**（不是「一眼画接一眼画」）
- [ ] **时长有长有短** —— 整片时长方差 std ≥ 0.20s（否则像 PPT）
- [ ] **生成段内的多刀 / 多镜规则** —— 设计为多刀/多镜的生成段，必须有 ≥2 个不同 Shot 编号 + `At 00:mm.mmm` 切点声明；单镜段允许只写 1 个 Shot，但必须明确「起点 → 过程 → 结果」（如运镜起点/过程/终点、缓推、dolly in、跟拍、环绕等摄影机运动动词）
- [ ] 刀型列填的都是 `短刀` / `常规` / `长刀` 三档之一（仍写 `普通` 等模板遗留值会被机器闸拦）
- [ ] 转场不是「全部硬切」也不是「无意义硬切」 —— 跨场用遮挡/匹配，反应组用跳切
- [ ] 提示词里**没有堆叠**「No / never / 不出现」类防错合同（出现即 PROMPT-CT WARN）
- [ ] 配音和音效有**场景声与动作声**（不是只有 BGM + 系统播报）
- [ ] 系统播报音色明确登记来源 —— **Microsoft Huihui Desktop 之类默认音色需说明**

### 演员调度与运动学合同（完整回放不可省 —— 首中末联系表不能替代）

> 这一节是**S03 A/B 测试**的硬约束：状态差 / 摄影机路径 / 焦点转移 / 转场接力都是必要条件，仅靠它们镜头仍会失败；补的是"在画面里到底怎么动"。研究依据见 `04-视频生成/平台提示词契约.md` §一.9、`02-分镜与镜头/分镜工作流.md` §生成前运动设计闸 第 8 项。
>
> **本节不是首中末联系表能替代的**——首末帧对得齐，不代表中间走对。含人 / 道具 / 接触 / 移动 / 转身 / 持物的镜必须做**完整回放**（从头到尾看完一遍）核对下列 9 项。

- [ ] **完整回放方向一致** —— 主体在画面里的移动方向与摄影机方向、与远景视差方向一致（人物面朝摄影机却不退 / 不滑步 / 远景与人物同向 = 失败）
- [ ] **步态 / 重心** —— 走 / 跑 / 推 / 骑 / 落座的镜，起步脚 / 承重脚 / 落脚方向可见；无滑步、无脚离地却平移
- [ ] **手 - 道具接触点 / 承重 / 解除** —— 拿 / 放 / 翻 / 按 / 擦 / 拍 / 持物移动的镜，手-道具接触在画面里**可见**（不是消失后再出现）；承重方式与道具重量匹配；解除时机合理
- [ ] **车轮 / 持物链式耦合** —— 推车 / 持物移动 / 翻书的镜，手把→踏步→身体→轮转→远景视差 五项方向一致（手推、踏步、车轮、远景任一项反向 = 失败）
- [ ] **轴线一致** —— 同场戏多角色对话 / 对峙的镜，角色左右关系始终一致；越轴时给转身 / 过肩 / 空间重建，不突然跳边
- [ ] **视线接力** —— 视线看向谁 / 哪个屏幕方向 / 何时回看 可读；不"全员同时看镜头"
- [ ] **朝向变化自然** —— 转身的镜，头→肩→髋 可分段观察（不是瞬间换姿态）
- [ ] **首帧与目标动作不冲突** —— 首帧若已是"完成态"（车已停下 / 椅子被坐住 / 门已关上），文字硬拧不会改变走样——必须改首帧 / 改 FLF2V / 改运动参考
- [ ] **正向机械替代负向合同** —— 转身 = 头→肩→髋；行走 = 脚落地 / 承重；拿物 = 手指闭合 / 接触 / 承重；**不写** `no / doesn't / never`（缺少可靠负向分支或低 CFG 的实现只复制关键词，不理解否定）
