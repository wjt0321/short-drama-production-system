# 短剧项目模板

复制本目录内容到体系根目录下的 `00-视频项目/《片名》/` 后开始，不在模板内制作。建项和输出路径统一遵循根目录 `AGENTS.md` 第六节；在项目状态摘要登记项目相对路径。

## 第一读取文件

1. `项目状态摘要.md`：恢复当前关卡、冻结资产、已通过决策和下一动作；
2. `执行清单.md`：查看逐镜生产状态；
3. 当前关卡审核包：只加载当前需要内容。

不要一次性读取整个项目。每次关卡通过、冻结/解冻、失败回退或中断前更新《项目状态摘要.md》。

## 审核与裁决

默认由 Agent 自检推进（产物自查、修当前问题后继续），**不要求每关用户裁决**。
只有用户明确开启阶段审核模式时，才逐关递交审核包，并把用户决定写入《用户裁决日志.md》；
Agent 自主选择与变更写《项目状态摘要.md》/《变更记录.md》。
