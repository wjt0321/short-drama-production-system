## 节奏链

> **每个「因为上一段」都必须写出上一段的哪件事。** 填法：读「发生什么」一列自上而下，每一行都要能接在上一行后面说"因为上一段的那件事，所以他才会这么做"。接不上、只能靠"然后"接上的行，是并列事件表，不是故事——整张表作废重写，不许在原表上补形容词。
>
> 判定（写完立刻做）：把「因为上一段」一列遮住，只看「发生什么」，如果读者能自由调换任意两行的顺序而不觉得别扭，这张表就是 PPT 目录。

| 段落 | 时间 | 因为上一段的什么 | 发生什么 | 他为此做了什么 | 但被什么挡住 | 于是变成 | 情绪 | 信息/反转 | 卡点 |
|---|---:|---|---|---|---|---|---|---|---|
| 冷开场 | | —（开场无前置） | | | | | | | |
| 建立处境 | | | | | | | | | |
| 小爽 | | | | | | | | | |
| 压迫升级 | | | | | | | | | |
| 大爆/反转 | | | | | | | | | |
| 结尾卡点 | | | | | | | | | |

> 段落名只是默认骨架（无厘头、悬疑、意象片的段落可以换），但「因为上一段 / 但被什么挡住 / 于是变成」三列不能删——删了就没有因果，只剩时间顺序。
