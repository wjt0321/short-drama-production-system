# G1 单集剧本

- 集数：EP__
- 版本：v1
- 剧本状态：草稿 / 待审 / 通过 / 冻结
- 片型：叙事 / 意象（有人物在追求什么的选「叙事」；无对白视听诗、纯意象片选「意象」——意象片不填「本场因果」与「道具翻转」，改填文末「意象变奏」）
- 立意语域：生活观察 / 寓言 / 诗性影像 / 其他（意象片必填，与 G0 一致）

> **剧本不是分镜。** 本文件正文禁止出现：刀号、时间码（如 `0–3.0s`）、机位、光比、焦段、景别、色温、`mm`。这些是 G3 的事；写进剧本，读者就只能看到参数，看不到故事。判定：一个没看过分镜的人能一口气读完，并说出这一集好看在哪。
>
> **剧本可以写心里话。** `AGENTS.md` §8.1「情绪词必须翻译成物理量」只管 G4 提示词，不管剧本。剧本里写"他怕被看穿""她其实想留下"是允许的，而且应该写——G3 分镜时再把它翻译成眉眼、视线和动作。

> 以下场级字段用于叙事片。意象片只写「戏」与文末「意象变奏」，不强行填写人物欲望、因果或潜台词。

## 意象变奏（仅片型＝意象）

> 意象片没有"谁想要什么"，它的连贯靠同一个意象反复出现、每次意思往前走一步。至少一个意象出现 ≥3 次，且每次「意味着」都不同；三次意思一样就是重复，不是变奏。

## 反 PPT 自检（G1 交稿前逐条过）

- [ ] 叙事片每场都有因果和至少一项真实变化，没有「然后」型或纯复述场；
- [ ] 叙事片的 G0 种子已落到动作、物件或话语；意象片不强行填写；

- [ ] 朗读测试已由新上下文读者完成，复述与作者意图一致；
