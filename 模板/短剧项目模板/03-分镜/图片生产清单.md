# G2–G3 图片生产清单

> 用法：把本文件复制进项目 `03-分镜/` 后填写。每行一张图；搓完更新状态；全部"通过"才进视频段。
> **本文件是图片清单的唯一权威**（列结构 + 填法 + 自动生成规则 + 执行层衔接 + 审核记录；SOP 侧 `02-分镜与镜头/图片生产清单.md` 只作指针，防两处漂移）。批量出图与筛选方法见 `02-分镜与镜头/分镜工作流.md` §十四。

**清单 = 一张表，每行一张图：告诉出图工具"画什么、画多大、参考谁、存成什么名"。** 拿到清单后逐行复制提示词出图，按文件名归档，审核通过后进视频段。

**A8 前提**：分镜的默认形态是**文本**，不是图。本清单只列**真正要出的图**——① G2 资产板（角色/场景/道具，冻结后经 Ref2VA 作图像条件接入）；② G3 按需首帧/尾帧（hero shot / 精确构图锁）。**不为"看起来更专业"给每镜配首帧**：逐镜强制首帧正是把身份漂移面从 1 张放大到镜数张的旧流程。

## 三、填法规则（Agent 自动生成时照此执行）

**先枚举后出图**：列全了才知道要出几张；每行有"引用锁"字段，出图时锁死参考；固定文件名让后续视频段能按名读取；状态列保证"没审核就往下走"不会发生。

1. **枚举资产图**：从 03 阶段资产卡读出角色双参考板与场景/道具需求，每张最终交付图各列一行；制作中间件与裁图另行标注用途。每个主要角色默认两行（身份造型板 + 日常表情九宫格，同一身份派生），额外角度/服装/材质/强表演/手持按镜头补图；每个反复使用/叙事场景一行空间总览 + 一行所需机位参考板；每个重要道具一行身份细节合板，交互/剧情状态按需另列。规则见 `03-角色与视觉资产/角色资产参考板.md`、`场景与道具资产.md`。
2. **枚举按需首帧（+ 需要的尾帧）**：遍历分镜表，只为本节开头 A8 两类镜列首帧行；提示词直接来自分镜表该镜的"景别/机位/构图/主体动作/场景/光影"列——**不要重新创作**，只是把分镜语言翻译成出图语言。引用锁 = 角色板 ID/版本及所需区域/E 编号 + 场景 ID/设计版本/CAM/时空状态 + 关键道具 ID/设计版本/当前状态；仅列本镜实际需要的项。按输入名额选择整板、单图或裁图并说明职责，不能将互斥状态同时当起始参考；名额不足先分阶段合成并核对正式关键帧。
3. **统一写提示词（八要素顺序）**：每张图先按下列顺序整理内容（不承诺模型权重等于书写顺序），必要要素不全就从 `02-分镜与镜头/影视视听语言速查.md` 对应小节补默认值：

```
①景别（离多远）→ ②机位/视角（从哪看）→ ③构图（怎么摆）
→ ④人物动作/表情/表演（在做什么）→ ⑤场景（在哪）
→ ⑥画面内动态（环境里什么在动）→ ⑦光影（怎么亮）→ ⑧色彩（什么调）→ ⑨质感/风格（什么质）
```

   规则：一镜一构图法则、一主一辅两色、光源必须具名；身份定妆图优先中性姿态与稳定特征，表情板/手持图/互动图按其用途写动作与情绪，不因此改动角色身份；首帧图提示词 = 资产身份（引用锁）+ 该镜的动作/情绪 + 场景 + 光影；保留可读的内容描述，只在所选实现确有要求时附适配语言或字段。
4. **给文件名与状态**：文件名对齐 `AGENTS.md` 产物规范——资产图 `02-资产/<类型>/<ID>_<用途>_v1.png`，首帧 `03-分镜/首帧/S<镜号>.png`。所有行初始状态 = **待搓**；逐张生成后标"已搓"，按授权模式检查并标"通过/打回"。
5. **输出与审核**：清单落在项目 `03-分镜/` 下。阶段审核模式先审清单本身（图齐不齐、提示词对不对味）；实际生成、命名、适配和回填由 Agent 完成，全权委托时 Agent 按授权自主检查推进。

## 四、执行层的衔接（能力与契约）

> 体系只描述**能力与契约**，不绑定任何具体出图工具或工作流。执行层对接由 Agent 按项目《能力登记.md》运行时落地，只登记在能力登记与执行层文档，不写入通用方法与模板规则。

- **出图能力**：需要"文生图/图生图能力，输入提示词 + 宽高比 + 输出文件名，产出图片文件"——具体实现查《能力登记.md》。
- **文件名契约**：清单"输出文件名"是体系侧契约，执行层必须原样使用（保证搓完的图能被后续视频段按名读取）。
- **尺寸适配**：首帧/尾帧满足对应视频输入规格；身份造型板与表情板按参考输入规格及实际缩放后可辨识度制作，不强制与成片同画幅。若需要裁切、留边或等比缩放，记录方案并检查构图、细节，不直接拉伸。

## 五、审核记录

| 节点 | 通过标准 |
|---|---|
| 清单本身 | 图齐、提示词对味、文件名与后续路径一致 |
| 单张图 | 无一眼假、符合该行提示词、与引用锁资产一致 |
| 全部图 | 角色/场景/道具全部冻结，按需首帧逐镜通过（对齐 G2/G3 关卡） |

- 清单审核：通过 / 修改（指出项） / 暂停
- 逐图审核：全部"通过"后才允许进视频段；打回的图走重抽（≤2 次）→ 回退链。
- 尺寸适配与裁切方案按 §四「执行层的衔接」的契约执行；不直接拉伸。
- 参考板小样：检查实际缩放后细节、多人/拼板误读和表情混用，记录在能力登记/角色卡；仅首帧模式先生成正式场景首帧，不把展示板直接作为首帧。
- 场景/道具按 `03-角色与视觉资产/场景与道具资产.md`：场景总览 + 所需机位板，道具身份细节板 + 按需交互/状态图。新增派生文件登记父设计版本、CAM/状态编号与修订，不混用互斥状态。
- 参考名额不足先分阶段做并检查同框关键帧；机位板/状态板默认不是剧情首帧，空间示意默认只用于规划核对。
