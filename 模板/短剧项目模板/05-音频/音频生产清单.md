# G5 音频生产清单

> 用法：把本文件复制进项目 `05-音频/` 后填写。每行一段声音；生成完更新状态；全部"通过"才进剪辑装配单。
> **本文件是音频清单的唯一权威**（列结构 + 填法 + 自动生成规则 + 审核记录；SOP 侧 `05-音频/音频生产清单.md` 只作指针，防两处漂移）。生成方法见 `05-音频/配音与音效设计.md`（配音文案、音效设计、音色定制）与 `05-音频/背景音乐生成.md`（BGM 情绪与曲风）。

**清单 = 一张表，每行一段声音：告诉生成工具"说什么、谁说的、什么情绪、多长、存成什么名"。** Agent 按清单逐行自主生成、自检（身份/情绪/底噪/时长）并完整试听；按文件名归档，通过后进剪辑装配单。用户开启阶段审核模式时才逐行等待裁决；付费、外发仍按 `AGENTS.md` §一.4 停下问。

## 四、填法规则（Agent 自动生成时照此执行）

先枚举后生成——台词段 + 音效事件 + BGM + 环境声全列出，理由是每一步都有对应的坑：列全了才知道要配几段；情绪与口型列锁死生成参数；固定文件名让装配单能直接引用；绑定镜号/入点保证声音与画面挂点一致；状态列让 Agent 自检后流转，不留"没检查就进成片"。

1. **从剧本台词生成配音行**：遍历剧本每句台词一行。说话人绑定该角色已选定的音色；情绪/口型从剧本情绪标注 + 分镜表该镜"表演"列提取，写"情绪 + 语速 + 重音"三要素；旁白/画外音单独标类型。
2. **从分镜表生成音效与环境声行**：遍历每镜的"台词/声音"列，关键动作出音效事件（每镜最多 1–2 个，避免堆砌），场景氛围出环境声行（安静场景也要一条打底；导演指定静默窗口的镜位不铺氛围音）；音效同时绑镜号与时间线入点。
3. **生成 BGM 行**：每幕一条主 BGM（绑定起止镜号），情绪峰值单独一条或标注"沿用主 BGM 变奏"；内容 = 风格 + 情绪 + 乐器 + 节奏 + 时长，规则按 `05-音频/背景音乐生成.md`。**BGM 是一条连续轨，不逐镜生成**。
4. **定文件名与状态**：文件名对齐 `AGENTS.md` 第六节——`音频/配音/<音频ID>.mp3`、`音频/音效/<音频ID>.wav`、`音频/BGM/<音频ID>.mp3`。**状态取值唯一权威 = 项目《执行清单.md》的机器白名单**（未开始 / 进行中 / 待审 / 通过 / 修改后重审 / 回退 / 失败归档），本文件不另列一套。"绑定镜号"列没有对应镜头的（如全剧环境声）可改填时间线入点。
5. **生成、自检与试听**：逐段生成后自检（身份/情绪/底噪/时长/口型时机），再做完整试听（全清单从头到尾 + 音画粗混），确认无误进剪辑装配单。

## 五、与剪辑装配单的衔接

- 清单的音频ID 沿用剪辑装配单 `配音ID / 音效事件ID / BGM ID / 字幕ID` 编号体系（Axxx / FXxxx / AMBxxx / BGMxxx）——**装配时按 ID 反查文件，不重新命名**。
- "绑定镜号 / 时间线入点"在装配单里原样搬入，保证声音与画面挂点一致。
- 多语言版：台词行按 `06-后期与发布/多语言版本管线.md` 增补目标语言列，产双语台词表后再生成。

## 六、检查与审核

默认（全权委托）：Agent 逐段自检 + 全清单完整试听，自行修当前问题，不在此阻塞。用户开启阶段审核模式时按下表阻塞；无论哪种模式，付费、外发仍按 `AGENTS.md` §一.4 停下问。打回段重生成 **≤2 次**，再不过走 `AGENTS.md` 失败回退链。

| 节点 | 默认 | 阶段审核模式 |
|---|---|---|
| 清单本身 | Agent 按剧本/分镜枚举并自检完整性 | 用户确认配音/音效/BGM 齐、情绪对、时长合理、ID 与装配单一致 |
| 单段声音 | Agent 自检身份/情绪/底噪/口型时机 | 用户逐段听 |
| 全部声音 | Agent 完整试听 + 音画粗混试听 | 用户分轨试听 + 音画粗混版试听通过（对齐 G5） |

审核记录：清单审核写 通过 / 修改（指出项） / 暂停；逐段试听全部"通过"后才允许进剪辑装配单。
