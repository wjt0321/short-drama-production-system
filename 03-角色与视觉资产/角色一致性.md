# 角色一致性

AI 生成没有记忆。同一句描述，两次生成的可能是两张相似但不相同的脸；镜头一多、场景一换、同框人数一涨，角色就开始"换人"。本 skill 给出一套与模型、工具无关的锚定方法，把角色的可复现性从"碰运气"变成"流程"。

---

## 一、问题定义：角色漂移的典型症状

先能认出漂移，才能治漂移。逐条对照已生成的镜头：

| 漂移类型 | 典型症状 |
| :--- | :--- |
| **面部漂移** | 脸型忽宽忽窄、眼距与中庭比例变化、年龄感忽大忽小、鼻梁与下颌线条改样；极端情况直接"换脸" |
| **发型漂移** | 长度变化、刘海有无、发色深浅偏移、卷曲度改变、发际线位置跳动 |
| **服装漂移** | 颜色色差、领型改变（立领变翻领）、纹样消失或繁复化、材质改样（棉变皮、哑光变亮面） |
| **配饰漂移** | 耳饰、项链、发簪、眼镜、武器时有时无，或造型改样 |
| **场景漂移** | 同一场景里家具、墙面、陈设位置改变；时间、天气、光线方向与上一镜矛盾 |
| **色调漂移** | 相邻镜头冷暖、反差、饱和度、颗粒感不一致，剪辑点上出现明显的"跳质感" |
| **人数漂移** | 多人同框时两张脸互相"融合"，配角张冠李戴，身高与体量关系错乱 |
| **视角漂移** | 机位与朝向无规律跳变，人物左右关系反转（越轴），空间关系说不通 |

**根因**：每次生成都是从当前这条提示词重新采样，模型看不到上一镜的结果。所以——

- 代词无效："他/她/它的"在模型眼里没有指向。
- 省略语无效："同上""保持一致""还是那个发型"不会被执行。
- 参考图只锁住它被真正读取的特征：给一张风景半身图，锁不住面部结构。
- 一句话概括的角色设定（"清冷御姐"）信息量太低，每次采样都会落在不同解上。

因此一致性靠三件事：**静态锚（有基准）、文本锚（每镜重贴）、资产引用锚（有资产表）。**

## 二、三层锚定机制

> **绑定层级升级（2026-10-12，A8）**：三层锚定的默认落点从「逐镜首帧」改为「卡级图像条件」——G2 冻结的角色卡/场景卡经 Ref2VA 类参考图节点（本机已验证 `MiniMaxH3ReferenceToVideo`，`<Picture N>` 引用，参考图上限 9）接入**每一次**生成；纯文生图 + 不同 seed 不承担跨镜身份一致性（原理性限制，见 `AGENTS.md` 身份锚硬闸）。G3 逐镜首帧降为按需（hero shot / 精确构图锁），分镜默认形态是文本。G2 冻结后的一致性前置目检闸（2–3 机位/表情人眼确认）保留，接在卡级条件之前。

### ① 静态锚：角色双参考板先行

需要持续保持身份的主要角色，批量生成前默认准备两张核心参考板。详细布局、九格表情、生成模板与投喂规则统一见 `角色资产参考板.md`，不再把定妆、肖像、三视图作为三张独立必交图。

| 角色资产 | 内容要求 | 解决什么 |
| :--- | :--- | :--- |
| **身份造型板** | 左侧清晰正面半身定妆，右侧同一角色、同套服装的正/侧/背全身三视图 | 面部识别、身形比例、发型和服装正背面基准 |
| **日常表情九宫格** | 从确认身份派生，统一头肩构图、妆造、机位与光线，只变九种日常表情 | 中性身份与表演范围的对应，不让表情变化成为换脸 |

使用纪律：

- 主要角色默认双板；一次性剪影、远景路人按需减量并记录原因。额外服装、材质、角度、强表演或互动按镜头补充。
- 可直接出板或分图检查后拼板；源图保留。两板先互相核对，再共同冻结、统一版本；确需改动时升级资产包并登记影响范围。
- 默认交付两张不等于每镜都上传两张：按镜头和已验证能力选择整板或裁图。裁图记录父板 ID/版本及视角/表情格号，高清源图同样登记来源。
- 实际缩放后检查细节，并用小样排除多人物误读、网格入镜与表情混用；仅支持首帧驱动时先生成正式场景首帧，不用展示板直接起片。

### ② 文本锚：复用稳定基准，当前状态单列

把已确认的身份与设计信息写成**冻结基准文本**，即“锚句”。复用以下三段时明确其适用版本与场次；时间、天气、灯光开关和道具状态另列为当前镜头变量，不全局冻结：

| 段落 | 应写内容 | 示例 |
| :--- | :--- | :--- |
| **角色锚** | 外貌 + 年龄 + 发型 + 服装 + 体态 | 25 岁女性，偏窄鹅蛋脸，眼距稍窄、细长丹凤眼，黑色及肩直发、中分无刘海，哑光深墨绿立领衬衫，身姿挺拔，个子高挑 |
| **场景锚** | 地点身份 + 固定空间/陈设关系 + 设计版本 | LOC01/v1，老式办公室，深色木质长桌靠窗墙，入口在对面墙 |
| **色调锚** | 色彩 + 反差 + 胶片感 | 冷青绿低饱和，中低反差，轻微胶片颗粒与柔和过渡 |

写作纪律（这部分比写得多漂亮更重要）：

1. **同一身份/设计版本及适用范围内复用稳定锚句**；工具支持时原样带入，不支持时按真实字段与长度等价适配。当前时空状态、道具状态及本机位投影单列，不把上一镜状态不加判断地复制到下一镜。
2. **不用代词**，不写"同上""延续上一镜""保持一致"这类相对表述。模型只认当前这条提示词里的字面描述。
3. **锚句放在提示词的固定位置**（建议开头第一段），既利于模型抓权重，也利于自查漏贴。
4. **身份/空间/物件设计基准确认后冻结**。改变恒定设计须按授权升级相关版本并标明受影响镜头，不覆写历史镜头的版本。已批准的日夜、天气、开关、持有状态等变化按状态编号与触发事件记录，不因此升级设计版本。
5. 锚句要写**可渲染的物理细节**，不写"清冷高级""气质出众"这类抽象判断词。

### ③ 资产引用锚：资产引用 ID 资产管理与参考图锁定

- **资产引用 ID 资产管理**：给每个角色、每套服装、每个场景、每种色调各起一个 资产引用 ID 名（如 `@linxia`、`@linxia_work_dress`、`@office_night`、`@grade_coldteal`），在提示词中引用 token，而不是每次重抄描述。
- **资产登记表**：token 名、锚句全文、角色双参考板路径、参考图路径、版本号集中记录在一张表里，全组共用同一份。项目资产 ID 保持稳定，实际上传编号和引用语法另在实现映射中记录，不用平台标签替代资产身份。
- **参考图分层锁定**：双参考板按区域分工：身份造型板提供脸、体型与服装，表情板只提供同一身份的表演范围；场景/动作补充参考不得反过来覆盖身份。
  - 面部参考：正脸或微侧，光线均匀、无遮挡、无夸张表情。
  - 发型参考：能看清长度、刘海、发际线与发色。
  - 服装参考：正面 + 背面，能看清领型、纹样、版型。
  - 材质参考：织纹、光泽、厚薄。这一层最容易被忽略，也最容易在换镜头后跑偏（棉布变亮面皮革是最常见的塌方点）。
- **身份固定、选择按镜头**：始终来自同一身份与服装基准，但按当前视角选择清楚且相关的参考；侧脸用侧脸、背影用背面，不强求所有镜头挂相同数量或顺序。多参考的对应关系按工具实际语法说明，互相矛盾的图不要同时送入。
- **版本可追溯**：稳定设计改动升级设计版本，派生机位/状态/裁图更新记录文件修订与父版本；同一身份与适用范围内不混用设计。各镜头引用其批准的版本和当前状态，不把剧情状态变化误当设计变更。

## 三、资产图实际准备（按需，不凑数量）

成套资产板（多视图/服装/材质/表情/手持）怎么排、提示词怎么写、远景崩脸怎么规避，见 `角色资产参考板.md`；本节只讲锚定纪律。

先按项目需要从seek等已登记参考来源确定美术方向，再选定本项目原创角色的身份基准。seek里的不同人物不能直接拼成同一角色的身份包。

- 身份图：清晰正面或微侧面、无遮挡、自然表情与均匀光线。中性身份图与戏中妆造分开；不要强制所有角色素颜。
- 服装图：全身正面和实际会拍到的侧/背面，能看清鞋、配饰、轮廓与材质。正/侧/背三视图并入身份造型板右侧，实际输入必要时裁为单视角，避免模型把展示视图当多人。
- 表演图：主要角色默认从同一基准派生日常表情九宫格；强烈哭笑、大侧脸或特殊口型按剧本另补，不替代九格。
- 互动图：多人对话、拥抱、递物等容易融合的镜头，先做实际站位和接触关系的同框关键图；不是把两张独立肖像堆进提示词就算完成。
- 派生纪律：优先参考编辑、局部修正或其他已支持的身份保持能力，别用独立文生图重新抽每个视角。把候选并排检查脸型、年龄、发型、服装、体型；不一致图不进入参考包。数量增加不等于信息增加。
- 进入视频前，人物身份、服装、背景光线在关键图中已经合理；视频重点描述动作，不要求视频模型同时重新设计脸、衣服和地点。只修有问题区域，修脸后核对身份及跨帧闪烁，不盲目美化换脸。

## 四、锚句词库与模板

### 1. 锚句取词库

| 锚段 | 建议写死的维度 | 常用描述词 |
| :--- | :--- | :--- |
| **角色锚** | 年龄、脸型、五官特征、发型、发色、服装、鞋、配饰、体态、身高量感 | 脸型：偏窄鹅蛋脸／方长脸／圆脸；五官：眼距稍窄、细长丹凤眼、原生浓平眉、鼻梁自然挺直；发型：黑色及肩直发、中分无刘海、低马尾；服装：哑光深墨绿立领衬衫、深灰直筒西裤；体态：身姿挺拔、肩线平直；量感：个子高挑、骨架细 |
| **场景锚** | 地点身份、固定空间特征、关键陈设位置、固定光源位置；时空状态另记 | 老式办公室，入口墙对面为窗墙，深色木质长桌靠窗，绿罩台灯放桌角；当前日夜、天气、灯亮灭与机位受光填变量区 |
| **色调锚** | 主色、辅色、饱和度、反差、颗粒与光学质感 | 冷青绿低饱和、暖橙作为点缀色、中低反差、暗部保留细节、轻微胶片颗粒、浅景深 |
| **负面锚**（可选） | 全片统一排除项 | 换脸、面孔融合、多余人脸、手指畸形、画风突变、突然高清锐化、水印 |

### 2. 单镜头提示词模板

> **适用范围**：本模板用于 **G3/G4 镜头提示词**（分镜 → 首帧 → 视频镜头）；G2 资产图提示词（身份造型板、九宫格、场景/道具参考板）按 `角色资产参考板.md` §4 / `场景与道具资产.md` §2.4 §3.4 **分路径选模板**——文生图用路径 A 完整版，参考编辑用精简版（头部写 `模式：图像编辑`，只写保持项 + 本次变量），依据 `04-视频生成/平台提示词契约.md` §2.4，2026-10-13 立。

```text
【稳定锚句·按版本与适用范围复用】
角色锚：{角色锚全文}
场景锚：{场景锚全文}
色调锚：{色调锚全文}
负面锚：{负面锚全文}

【本镜变量】
时空/道具状态：{状态编号、日夜天气、灯光开关、持有者/左右手/朝向/数量及变化依据}
机位投影与受光：{CAM与固定空间关系、当前画面左右、具名光源及主体受光}
景别：{远景 / 全景 / 中景 / 近景 / 特写}
机位与运动：{低机位仰拍 / 平视 / 过肩 / 缓推}
动作与情绪：{本镜唯一一个动作 + 一个情绪}
道具与互动：{本镜新出现的道具，以及它与角色的关系}
```

同一设计版本范围内只改本镜需要变化的变量，稳定基准不重设计。变量变化必须有剧情/机位依据；颜色脚本或照明状态改变时引用对应范围的已确认基准，不把旧场次的光色强行套到新场次。

### 3. 填写示例

```text
【稳定锚句·按版本与适用范围复用】
角色锚：25 岁东方女性，偏窄鹅蛋脸，眼距稍窄、细长丹凤眼、原生自然眉，黑色及肩直发、中分无刘海，哑光深墨绿立领衬衫，身姿挺拔，个子高挑。
场景锚：LOC01/v1，老式办公室，深色木质长桌靠带百叶窗的窗墙，入口在对面墙，绿罩台灯位于桌角。
色调锚：冷青绿低饱和，中低反差，暗部保留细节，轻微胶片颗粒，浅景深。
负面锚：换脸，面孔融合，多余人脸，手指畸形，画风突变，突然高清锐化，水印。

【本镜变量】
时空/道具状态：L1，夜晚小雨，桌角台灯亮；钢笔P0，人物右手持有，数量1，无状态变化。
机位投影与受光：CAM01由入口朝窗墙观察，主光为桌角台灯；画面左前侧受光，反打另按机位核对。
景别：中近景
机位与运动：平视机位，固定镜头
动作与情绪：低头翻看一份文件，随即抬眼看向画外，情绪克制
道具与互动：手中捏着一支钢笔
```

## 五、多人同框策略

| 同框人数 | 稳定性 | 处理方式 |
| :--- | :--- | :--- |
| **1 人** | 稳定 | 正常流程，锚句 + 角色卡即可 |
| **2 人** | 相对稳定 | 两个角色各自的角色锚都要写全，另加**空间关系锚**：谁在左谁在右、谁前谁后、谁的视线朝向谁；禁止用"两人""他们"概括 |
| **3 人** | 开始显著漂移 | 脸互换、配饰错位、身高体量失调高发。改为拆对生成：先出 A、B、C 三个单人镜头，再出 A+B、B+C 的双人镜头，需要时再拼三人或改用剪辑切换 |
| **4 人及以上** | 基本不可控 | 必须拆组分别生成，或做后期合成。不要指望一次生成全员合照 |

补充做法：

- **主角优先**：先出主角镜头并通过一致性检查，再让配角与主角同框，以主角为基准校正配角。
- **弱化非重点人脸**：群体镜头用背影、侧影、虚化、远景、过曝或遮挡处理，避免观众数到"怎么突然多了一张生脸"。
- **逐人写清朝向与视线**：每个人一条"位置 + 朝向 + 视线 + 与谁互动"，比一句"三人围坐交谈"稳定得多。
- **同框镜头单独建锚句**：双人、多人镜头的空间关系锚同样冻结、同样重贴。

## 六、中途核对与修复流程

不要等全片生成完再回看——那时返工成本最高。按批核对、分级修复：

### 1. 核对节奏

- 每生成 **3–5 个镜头**回看比对一次；
- 比对项固定为三组：面部（脸型、眼距、发型、发际线）、服装配饰（领型、颜色、纹样、配饰有无）、基调（冷暖、反差、颗粒、光线方位）。
- 每一批的比对基准始终是角色双参考板与已通过的镜头，而不是"上一镜看着还行"。

### 2. 分级修复

| 漂移程度 | 表现 | 处理 |
| :--- | :--- | :--- |
| **轻度** | 单点细节偏移（发色略浅、衬衫偏亮） | 加强锚句：把漂移部位写得更具体，补上负面锚，重生成该镜 |
| **中度** | 面部比例或服装版型已变，角色仍可辨认 | 换 hero frame 重新锚定：从已通过的镜头里挑一张最准确的作为新基准参考图，重出该镜及其后续镜头 |
| **重度** | 明显换脸、跨镜像两个人、多人同框串脸 | 停线，回到角色双参考板重做静态锚，本场景全部重出；不要逐镜打补丁 |

### 3. 修复纪律

- **一次只改一个变量**：锚句、参考图、模型参数不要同时动，否则无法判断是哪个起了作用。
- **不动锚句以外的部分**：重生成时只让变量区变化，避免顺手改出新问题。
- **记漂移日志**：哪个镜头漂了、漂的是什么、用了哪一级修复、是否通过。同一处反复漂移，说明锚句本身写得不够明确，要回去改锚句而不是反复重抽。
- **通过即冻结**：已通过一致性检查的镜头纳入 hero frame 池，不要回头重抽。

## 七、第四层：模型层身份保持能力（可选）

静态锚、文本锚、资产引用锚之外，可按项目需要选择参考约束、角色适配训练或批量身份保持等能力。先比较成本、可部署条件和角色复用规模，再登记所选实现，不默认在线或本地更优。

重点检查：参考是否把姿势/背景一起复制，训练是否改变服装或表演，批量结果是否趋同。资产身份、版本和评价方法独立于具体实现；实现级参数与历史案例由《能力登记.md》指向适配资料，不能反过来规定通用资产表。

前三层锚（静态锚/文本锚/资产引用锚）解决的是"同一套素材与描述被稳定引用"；当模型支持更强的身份保持机制时，还有第四层可用——**模型层锚**。本节梳理开源社区的三类方案及其适用边界，选型不当反而帮倒忙。

### 1. 参考图条件注入（IP-Adapter / InstantID / PhotoMaker 一脉）

**原理**：把角色参考图编码成特征向量注入扩散过程，免训练、即插即用。即梦/Seedance/可灵自带的"角色参考"功能本质也是这一路。

**优点**：成本低，任意角色即用即弃。
**已知风险——"过度复制"**：模型会把参考图的姿势、构图、背景一起复制过来，你只想锁脸，它连站姿和客厅都锁了。
**对策**：
- 参考图用**标准照**：正面、标准站姿、纯色背景、素色衣服——把"不想被复制的变量"从参考图里剔除，构图交给分镜首帧去控。
- 一角色一参考，不要把多人合影当参考图。

### 2. 训练式身份锚（DreamBooth / 角色 LoRA）

**原理**：用 10-20 张角色图微调出一个专属权重，之后任何提示词都能召唤出这个角色，一致性是三类里最强的。

**成本决策线**：
- **主角/贯穿全剧的高频角色（出场 ≥20 镜）**：值得训。一次性成本换 80 集的稳定。
- **配角/三四集就下线的角色**：不划算，静态锚+文本锚足够，训练成本赚不回来。

**工程注意**：LoRA 权重进资产库管理（命名/版本/对应角色卡），与 资产引用 ID 登记一一对应，防止"权重在手但不知道是谁"。

### 3. 共享注意力批量一致（StoryDiffusion / ConsiStory 一脉）

**原理**：免训练，让同批次生成的多张图在注意力层面共享角色特征，批量出"同一角色的不同分镜帧"。

**适用**：漫剧/动态漫的关键帧批量生成（一次出一整页分镜帧，风格身份天然统一）。
**已知风险——"多样性坍缩"**：共享过强时所有帧的姿势、表情、取景趋同，像复印。
**对策**：身份描述词逐帧原样重贴，动作/景别/构图描述逐帧放开变化；批量不宜超过 4-6 帧，超长序列分批并拿第一帧做跨批衔接。

### 4. 选型速查

| 场景 | 首选 | 备选 |
|---|---|---|
| 商用 API 出片（即梦/Seedance/可灵） | 官方角色参考功能（=参考图注入） | 首尾帧衔接 |
| 主角、长篇连载、本地部署 | 角色 LoRA（≥20 镜才训） | 参考图注入 |
| 漫剧关键帧批量出图 | 共享注意力类工具 | 参考图注入逐帧出 |
| 应急单镜修脸 | 参考图注入 + 提高面部权重 | 局部重绘 |

> 落地建议：优先用商用 API 的官方身份保持功能，开源方案作为本地部署与兜底。开源侧的可视化落地首推 ComfyUI（IP-Adapter/InstantID 均有成熟节点）。

## 八、身份合同与动作合同分层

角色迁移或复杂动作不能把“像谁”和“怎么动”混成一个要求：

- **身份合同**：脸部恒定特征、发型轮廓、身材比例、服装版本、标志物和禁止变化；
- **动作合同**：起始姿态、动作阶段、受力方向、速度、接触关系、结束姿态；
- **镜头合同**：景别、机位、轴线、主体位置和运动方向。

先冻结身份合同，再为每个生成段写动作合同。动作可以替换，身份字段不得随动作参考一起漂移。三视图用于验证正、侧、背不同机位仍是同一角色，不把三视图当三套造型。

身份与动作冲突时的候选顺序：A 降低动作复杂度；B 拆成多个动作阶段；C 改机位隐藏高风险部分；D 经用户同意后更换整体方案。

## 九、3D 漫剧分支：渲染风格锚与材质锚

> **形态说明**：3D 漫剧指"3D 电影级写实 CG / 次世代游戏过场质感"的动态漫剧，是 AI 漫剧中的主流高流量形态之一（2026 年公开榜单观察：头部 AI 漫剧榜单中 3D 形态占比显著）。本节只描述能力与约束，不绑定任何平台与工具。定位见 `01-创意与剧本/题材风格与平台库.md`（3D 漫剧形态在形态表与玄幻异能末世题材卡中的定位）。

### 1. 与普通漫剧的差异：多了一套"渲染锚"

§二的三层锚（静态锚/文本锚/资产引用锚）在 3D 漫剧中依然全部适用。3D 漫剧额外多两个必须冻结的维度，否则会出现"脸没变、但画面质感崩了"：

| 额外维度 | 问题表现 | 解决方式 |
|---|---|---|
| **材质锚** | 同一角色皮肤从哑光变油光、铠甲从金属变塑料、布料从厚重变轻薄 | 材质描述写死进角色锚，参考图单独锁材质 |
| **渲染风格锚** | 同一部剧有的镜头像游戏渲染、有的像皮克斯、有的像真人拍摄 | 全局风格参数先行，逐镜原样重贴 |

**铁律**：3D 漫剧开工前，先定全局渲染风格，再生成任何角色与镜头。风格漂移在 3D 形态里比 2D 更刺眼——因为 3D 的"假"与"真"之间有一道清晰的质感悬崖。

### 2. 全局渲染风格锚（先行一步）

#### 2.1 三步定风格

1. **选风格域**（二选一为主，不要混）：
   - 电影级写实 CG：次世代游戏过场质感、真实材质物理、PBR 光照、真实镜头光学（景深/色差/颗粒）
   - 风格化 3D：三维动画电影质感（皮克斯/梦工厂向）、夸张比例、明快色彩、卡通材质
2. **写风格锚句**：一段冻结文本，包含——渲染域 + 光照模型 + 材质基调 + 镜头光学 + 色调。
   - 示例（写实域）：「3D 电影级写实 CG 动画，次世代游戏过场质感，PBR 物理材质，真实皮肤次表面散射，全局光照为主光，电影级浅景深与轻微色差，暗部保留细节，低饱和冷色调」
3. **冻结并全片复用**：风格锚句像角色锚句一样逐镜原样重贴，只允许在同一风格域内做明度/氛围微调，不允许跨风格域。

#### 2.2 风格域冲突检测

- 写实域角色（真实皮肤材质）+ 卡通域场景（高饱和亮面）→ 同框即穿帮
- 检查点：角色、场景、道具、特效四个对象必须在同一风格域
- 若确需混搭（如写实角色进入幻觉场景），在分镜表里标注"风格切换点"，且切换必须有叙事理由

### 3. 3D 角色资产三视图与材质

#### 3.1 三视图的 3D 要求

`角色资产参考板.md` 身份造型板右侧的三视图（正/侧/背）在 3D 形态下必须额外满足：

| 视图 | 3D 专属检查点 |
|---|---|
| 正面 | 五官比例、头身比、脸型基准 |
| 侧面 | 鼻梁高度、下颌线、胸背厚度、发量体感 |
| 背面 | 发型后部轮廓、服装背部细节、配饰挂点 |

- 三视图必须**同一渲染风格、同一光照环境**（建议统一用中性棚拍光：正面主光 + 柔和补光），否则无法判断是"角色变了"还是"光变了"。
- 3D 角色建议加一张**四分之三侧视**，这是多数动作镜头的主视角，正面+侧面之间最容易漂移。
- 默认交付身份造型板与日常表情九宫格，沿用 `角色资产参考板.md`。九格含中性表情与日常情绪，同一渲染/光照基准；标志性强情绪、四分之三等额外机位按需补图，不强制独立多交一套。

#### 3.2 材质锚写法

材质描述必须进角色锚，且要写得可渲染：

| 部位 | 写实域示例 | 反例（不可渲染） |
|---|---|---|
| 皮肤 | 真实皮肤次表面散射，哑光，T 区轻微油光 | "皮肤很真实" |
| 布料 | 粗织棉麻，哑光，微褶皱 | "衣服有质感" |
| 金属 | 拉丝哑光金属，磨损划痕，环境反射 | "铠甲很酷" |
| 能量/特效 | 半透明发光粒子，冷蓝色，边缘羽化 | "很炫" |

#### 3.3 材质参考图分层

一张参考图只锁一件事（沿用 §二 ③ 的分层原则）：

- 皮肤材质图（特写，看肤质与光照响应）
- 布料材质图（看织纹、厚度、反光）
- 金属/特效材质图（看反射、发光、磨损）

### 4. 批量一致与生成纪律

#### 4.1 批量策略

- 3D 漫剧关键帧批量出图时，优先共享注意力类方案（见 §七 模型层身份保持能力），批量 4-6 帧为一批，超长序列分批并用首帧衔接。
- 单角色首次定稿：按授权预算探索候选，确认一个身份后派生双参考板并检查；不把不同候选脸混成一个身份包，不固定候选张数。通过相关镜头小样后再批量。

#### 4.2 生成纪律

1. **风格锚句 > 角色锚句 > 场景锚句**：3D 漫剧提示词中风格锚句放最前，权重最高。
2. 首帧必须来自人工过目过的 3D 资产图（沿用身份锚定铁律），末帧只能作衔接参考。
3. 每 3-5 镜回到 3D 资产重新锚定一次，防渲染漂移（风格域漂移与角色漂移分开检查）。
4. 动作参考与身份锚分离：动作可以换，风格域与角色资产字段不得随动作参考漂移（合同分层见 §八）。

#### 4.3 常见 3D 漂移症状

| 症状 | 优先怀疑 | 首选处理 |
|---|---|---|
| 同一角色有的像游戏渲染、有的像动画电影 | 风格锚句未全片重贴 | 修正风格锚句，重出漂移镜 |
| 皮肤从哑光变油光/塑料感 | 材质锚缺失或参考图没锁皮肤 | 补材质锚 + 皮肤材质参考图 |
| 脸没变但"看着不像同一部片" | 光照/色调跨镜不一致 | 回 G0 照明卡，统一光照方向与色温 |
| 同一角色胖瘦忽变 | 三视图比例未冻结 | 回三视图重定头身比基准 |

## 十、交付前一致性检查清单

**静态锚**

- [ ] 每个主要角色都有定稿的身份造型板与日常表情九宫格，且各区域为同一身份/妆造？
- [ ] 两板已共同冻结、统一版本，本批次裁图/源图与父板版本对应？

**文本锚**

- [ ] 各镜头复用适用版本/场次的角色、场景、色调基准，当前状态与机位投影单列且有变化依据？
- [ ] 全文没有代词指代角色，没有"同上""延续上一镜""保持一致"这类表述？
- [ ] 稳定基准未被随意改写，当前时间/天气/光源状态与道具状态未被旧锚句覆盖？
- [ ] 锚句里没有抽象判断词，全是可渲染的物理细节？

**资产引用锚**

- [ ] 角色、服装、场景、色调都有 资产引用 ID，且已在资产表中登记？
- [ ] 各镜头按视角与表情选择相关整板/裁图，已说明参考职责和真实输入映射，并通过所用实现的小样？
- [ ] 锚句、参考图与资产 ID 的设计版本及状态/文件修订和该镜批准记录对齐，无错用版本？

**画面比对**

- [ ] 相邻镜头的脸型、眼距、发型、发际线可辨认为同一人？
- [ ] 服装的颜色、领型、纹样、材质在跨镜后未改样，配饰没有凭空消失或增加？
- [ ] 同场景的空间、陈设、时间、光线方位前后自洽？
- [ ] 相邻镜头的冷暖、反差、颗粒感连贯，剪辑点上没有"跳质感"？
- [ ] 多人同框镜头无串脸、无多余人脸、身高与体量关系合理？
- [ ] 已通过的镜头全部纳入 hero frame 池并留档？

**3D 漫剧（走 §九 分支时加查）**

- [ ] 全片风格锚句一致（同一风格域，无跨域混搭）？
- [ ] 角色、场景、道具、特效四对象风格域一致？
- [ ] 光照方向、色温、影调跨镜连贯？
- [ ] 每个主要角色有同风格身份造型板（左半身、右正/侧/背全身），四分之三侧等按需补齐？
- [ ] 有同一身份派生的日常表情九宫格，标志性强情绪按需补图？
- [ ] 皮肤/布料/金属/特效材质分别有参考图？
- [ ] 材质描述可渲染（非抽象词），已写进角色锚？
- [ ] 首帧全部来自人工过目过的资产？每 3-5 镜回到资产锚定？风格锚句逐镜原样重贴，未省略未改写？
