# 角色资产参考板

## 一、默认交付：角色双参考板

需要持续保持身份的主要角色，默认交付两张核心参考图：

1. **角色身份造型参考板**（简称身份造型板）：左侧正面半身定妆，右侧正面／正侧／背面全身三视图。
2. **角色日常表情参考板**（简称日常表情九宫格）：同一角色的九种日常表情，3×3 排列。

目的：在有限的参考图名额内集中提供身份、体型、服装与表演范围。**两张是默认资产交付形式，不是每镜固定上传数量，也不是所有模型都更稳定的保证。** 模型是否理解合板、实际缩放后是否仍能辨认面部，必须小样验证。

此标准替代主要角色的旧独立定妆照、肖像特写、三视图交付组合；单图制作方法仍可用于源图和补充参考。一次性剪影、远景路人按实际需要减量并记明原因，不强制九宫格。已有项目不自动重做或迁移。

## 二、两张核心参考板与按需补充

### 2.1 身份造型板：左半身，右三视图

默认使用横向宽图，左侧约 **40%**、右侧约 **60%**；比例可以为可辨识度调整，不固定分辨率或强绑成片画幅。

```text
┌──────────────────┬──────────────────────────┐
│                  │                          │
│ 正面半身定妆图    │ 正面全身  正侧全身  背面全身 │
│ 面部清晰、占比大  │ 同一人物、同套服装、等高排列 │
│                  │                          │
└──────────────────┴──────────────────────────┘
```

- 左侧：正面平视、中性自然表情，脸部、发际线、肩颈和上半身服装清楚，无遮挡。
- 右侧：正面、90度正侧、背面从左到右排列；全身从头到脚完整、等高、中性站姿，不裁脚，不相互遮挡。
- 全板：同一身份、妆造、服装版本、体型、配饰、色调与均匀柔和光线，使用干净中性背景。非写实角色沿用美术设定，不强制摄影或素颜。
- 明确声明“**同一角色的四个展示视图，不是四个人，不是剧情场景**”。左侧半身与右侧全身不要求等高比例；等高要求只适用于右侧三个全身视图。
- 普通身份板不加入动作、剧情背景或长文字。需要分区编号时使用短编号并记录在角色卡；其生成可靠性按工具核验。

### 2.2 日常表情九宫格

从第一张已确认的身份基准派生，不得九格独立文生图重新抽脸。默认从左到右、从上到下为：

| E01 中性放松 | E02 轻微微笑 | E03 自然开心 |
|---|---|---|
| E04 认真专注 | E05 疑惑不解 | E06 轻微惊讶 |
| E07 担忧不安 | E08 克制难过 | E09 不悦、轻微生气 |

- 每格统一头肩构图、脸部大小、正面平视机位、发型、妆造、服装可见部分、背景和光线；**只改变表情，不改变身份**。
- E01 是中性比对基准。其余采用日常低到中等幅度，符合该角色年龄与气质；不默认嚎哭、狂笑、极端愤怒或明显扭曲五官。
- 逐格检查脸型、眼距、鼻形、发际线与年龄感；表情应可区分，但不能靠换脸、换光或换机位表现。
- 剧本需要强烈表演、大侧脸表情或特殊口型时，另从同一身份派生专项图，不用额外图替代默认九格，也不把九格当动作时间序列。
- 明确声明“**同一角色的九种表情，不是九个人，不是分镜，不要求视频依次演出九格**”。

### 2.3 补充资产与存档

| 补充项 | 何时需要 |
|---|---|
| 四分之三侧、俯仰角或清晰面部局部 | 核心板未覆盖机位，或缩放后脸部不足以辨认 |
| 其他服装/造型板 | 换装戏；登记独立服装 ID，仍沿用同一身份，不混用服装版本 |
| 材质与色板 | 布料织纹、光泽、铠甲等在现有板上不可辨认或易漂移 |
| 强表演、特殊视角或口型参考 | 剧本确需九宫格之外的表演 |
| 手持、接触与多人同框关键图 | 关键道具互动、拥抱、递物或易串脸场面 |

项目内建议文件名：`02-资产/角色/CHAR_角色ID_身份造型板_v1.png`、`02-资产/角色/CHAR_角色ID_日常表情九宫格_v1.png`。实际角色 ID 代入文件名；源图放角色目录的 `源图/`，镜头裁图放 `裁图/`，文件名包含角色 ID、父板版本、视角或 E01–E09 编号，不覆盖旧版。

两板相互核对后**共同冻结、统一版本**。修改任一板都升级资产包版本，并复核另一板；未改画面的另一板可沿用内容但须登记其新版本对应关系。服装变更记录服装 ID。裁图记录父板 ID/版本及区域或格号，不作为新身份；必要时从已登记的高清源图导出并记录来源。冻结后的变更遵守项目授权与变更记录规则。

## 三、生成顺序与实现路径

固定顺序：角色设定 → 确认身份与服装基准 → 身份造型板 → 从同一身份派生日常表情九宫格 → 两板核对 → 小样与冻结。**合成一张交付，不等于必须一次生成成功。**

按已登记的出图、参考编辑和拼版能力选择：

- **路径 A：直接出板。** 从无到有探索时可一次生成身份合板；逐区域确认是同一人后，才用于派生表情板。直接出九宫格也必须引用已确认身份。
- **路径 B：已有定妆参考编辑。** 优先从同一已确认定妆基准派生各视角与表情，说明保持的身份、服装及只改动的视角/表情。具体效果逐图核对，不承诺“参考编辑一定最稳”。
- **路径 C：分图校验后拼板。** 用同一身份基准逐张生成半身、三视图和表情，核对通过后拼成两张成板。源图保留，拼版不重新设计人脸；某一区域失败只修相关源图再更新成板。

不能用不同人物参考拼成一个身份包，也不能通过增加更多不一致参考来掩盖漂移。身份先确认、表情再派生；不让未确认九宫格反过来重定义脸。

## 四、提示词模板（按能力适配）

以下为内容模板，不是供应商字段协议。`{身份参考}`、`{服装参考}` 等占位符必须映射为当前工具真实支持的输入；无参考输入能力时不能假装引用生效。

### 4.1 身份造型板（路径 A · 文生图直出用完整模板）

```text
制作一张角色身份造型参考板，横向宽幅，干净中性背景，均匀柔和光线。
角色身份：{年龄感、脸型、五官识别点、发型发色、体型}。
妆造与服装：{妆造、服装ID、版型、材质、主辅色、鞋、配饰}。
美术风格：{已确认风格}。
若有参考：以{身份参考}锁定身份，以{服装参考}锁定服装，说明各自职责。
左侧约40%为同一角色正面半身定妆，脸部与肩颈清晰，正面平视，中性自然表情。
右侧约60%并排三个等高全身视图：正面、90度正侧面、背面；头脚完整，中性站姿。
四个展示视图是同一角色、同一套服装，不是四个人，不是剧情场景。
保持脸型、年龄、发型、体型、服装和配饰一致，只改变取景范围与观看角度。
不重复角度、不裁脚、不互相遮挡、不添加场景道具、文字水印或额外人物。
```

### 4.2 日常表情九宫格（路径 A · 文生图直出用完整模板）

```text
基于{已确认身份造型板或其清晰面部源图}制作一张角色日常表情参考板，3×3九宫格。
九格均为同一角色的头肩近照，统一正面平视、脸部大小、发型、妆造、服装、背景与柔和光线。
从左到右、从上到下：中性放松、轻微微笑、自然开心、认真专注、疑惑不解、
轻微惊讶、担忧不安、克制难过、不悦/轻微生气。
只改变表情，保持脸型、眼距、鼻形、发际线和年龄感一致。
表情符合角色气质，以日常低到中等幅度为主，不通过换脸、换角度或换光表现情绪。
这是同一人物的九种表情，不是九个人，不是分镜，也不是要求依次演出的动作序列。
不要嚎哭、狂笑、五官扭曲、重复填充格、额外人物或文字水印。
```

九宫格/三视图从已确认身份基准派生时（体系禁止九格独立文生抽脸），单格提示词用 §4.3 精简模板——基准格可写完整版，其余单格只写表情变量一行（如"E02 轻微微笑"）。

### 4.3 路径 B/C 精简模板（参考编辑 / 拼板派生）

> 依据：`04-视频生成/平台提示词契约.md` §2.4 图生/多参考模式图文分工；`导演视觉圣经.md` §一·补 分模式纪律。2026-10-13 立。闸门 `tools/check_style_lock.py` 据此分流校验强度。

路径 B（参考编辑）和路径 C（分图校验后拼板）都以**已确认身份基准图**作为图像条件接入生成（参考图已锁身份、风格、光线、材质），文本不复述这些。提示词只写三块：

1. 头部 `模式：图像编辑` 声明行 + `references` 列出基准图路径（机器可读，缺声明按文生从严）。
2. 保持项一两句：「保持参考图的身份、服装、风格、光线、材质不变」。
3. 本次变量：只写本次要改变的东西（视角、表情、局部动作、机位等）。

风格锁全文不进入提示词，只带一句风格锚句（参见 `导演视觉圣经.md` §一·补 分模式纪律）。不在精简模板里复述身份锚、场景锚、色调锚——这些由参考图承担（参照 §四.2 文本锚的引用约定）。

**通用精简模板**：

```text
模式：图像编辑
references: <身份基准图 path> 或 <基准板 path>

【保持项】
保持参考图的身份、服装、风格、光线、材质不变。

【本次变量】
<本镜要改变的内容，例如：仅改变为侧面全身视角；仅改变为 E05 疑惑表情；仅改变为俯仰 30° 微侧 45°>
```

**九宫格单格精简示例**（E02 轻微微笑，从已确认身份基准派生）：

```text
模式：图像编辑
references: <身份基准图 path>

E02 轻微微笑
```

**三视图单视角精简示例**（90° 正侧全身，从身份造型板派生）：

```text
模式：图像编辑
references: <身份造型板 path>

仅改变为 90° 正侧全身视角。
```

分图生成后逐张核对（脸型、年龄、发型、服装、背景），通过后再由 Agent 拼板；某一格失败只修该格源图，不回到完整模板重出整板。拼版不重新设计人脸。

若只生成局部源图，沿用精简模板的"保持项 + 本次变量"结构，只输出指定视角或指定 E 编号表情。需要英文或结构化输入时按能力登记转换，不照搬未验证标签。

## 五、人脸细节与构图风险（按实际结果检查）

原文曾将“脸占比约 15%、多人每脸 5–8%”称为统一像素阈值，但未附可复核的适用模型、分辨率、测量口径或原始测试。**原数值保留为待验证经验，不作为所有模型的质量门槛或行业共识。**原文见本次经验快照。

小脸、多人、遮挡和极端视角可作为风险提示。检查实际图像的身份、五官可辨性和人物关系，不仅靠占比数值；结合构图、参考图和所选实现试样决定怎么修，而非把所有问题归因于一个阈值。

| 场景 | 规则 |
|---|---|
| **近景/特写要保脸** | 情绪与反应戏用近景/特写，确保在实际交付尺寸下能辨认表情与五官，不设统一面积阈值 |
| **远景/大远景不塞正脸** | 环境板里的人物**远景化、背影化、侧影化**，不要求出现清晰正脸；环境归环境板，正脸归角色镜头 |
| **多人同框逐人分述** | 不写"三个人""众人"，按**空间位置**逐个描述（"左侧人物脸…，右侧人物脸…，中间人物脸…"），赋予不同特征，建立个体语义边界 |
| **人群弱脸** | 背景人群用背影、虚化、遮挡、过曝处理，避免观众数到"突然多了一张生脸" |
| **高风险角度** | 纯侧脸、低头、极端俯仰尽量用对应视角的参考图；无参考就改机位，不让模型硬猜 |
| **小脸后期修复** | 确有必要的远景小脸，可用专门的人脸修复（按实际缺陷与修复效果决定，不能借修复改变身份） |

**环境板与人物分离铁律**：场景/环境底图里不要混入陌生正脸（会污染角色参考）。先做无人物的环境板，再把角色按正确站位单独放进画面或交给人物镜头。做法与 `场景与道具资产.md` §2.3“总览、机位板与空间示意图”一致。

## 六、按镜头投喂，不机械上传两张

先核验当前实现的参考张数、输入类型、尺寸/缩放、裁切策略及引用方式；在项目《能力登记.md》登记，不写死通用数量上限。

> **身份绑定层级（2026-10-12，A8）**：G2 冻结后的默认路径是**卡级图像条件**——角色卡/场景卡作为图像条件经 Ref2VA 类参考图节点接入每次生成（本机已验证实现 `MiniMaxH3ReferenceToVideo`，提示词用 `<Picture N>` 引用，参考图上限 9），**不是逐镜另文生首帧**。G3 逐镜首帧从强制降为按需（仅 hero shot / 精确构图锁）。⚠️ 名字陷阱：`MiniMaxH3DirectorGroupReferenceToVideo` 只差 `DirectorGroup` 字样，但它只打包 group、本身不出片，不可互换。G2 冻结后的「一致性前置目检闸」（同角色 2–3 机位/表情人眼确认）保留有效，接在卡级条件之前。

| 镜头/实现条件 | 默认输入策略 |
|---|---|
| 普通人物镜头 | 优先身份造型板；如只需要单一视角或整板不清楚，改用该板对应裁图/高清源图 |
| 表情、对白近景 | 按需增加表情板，或只取目标 E 编号表情；身份与表情分工写清，不要求演遍九格 |
| 侧面、背影或全身动作 | 选择身份板内相关视角；未覆盖机位时按需派生补图，不强求上传整套 |
| 多人同框、需场景/道具参考 | 先按当前输入名额分配职责；不能容纳时先制作同框场景关键帧，不靠塞满拼板绕过限制 |
| 仅支持首帧驱动 | 先由参考板生成并检查正式场景首帧，再用该首帧生成视频；不得直接把角色展示板当剧情首帧 |
| 合板被误读或缩放后面部不清 | 改用冻结板的单视角/单表情裁图，或对应高清源图；仍不支持时回到场景首帧路线 |

一张身份板可分区域承载脸、体型与服装；表情板提供表演范围而不覆盖身份。场景、动作、材质补充参考各有职责，不能相互矛盾。场景按目标 CAM 与时空状态选择总览/机位图，道具按设计版本与当前状态选择身份板/局部/交互图；详细组织与空间、状态规则见 `场景与道具资产.md`。提示词说明各张或各区域“保持什么、只改什么”；整板布局不是输出场景布局。实际上传顺序与标签按实现映射，不要求所有镜头组合和顺序相同。

### 投入批量前的最小验证

先检查**实际送入模型的缩放/裁切后文件**，再做覆盖当前镜头风险的小样：

1. 身份板半身脸与三视图是否仍清楚，右侧是否完整；表情九格是否可辨且同一身份。
2. 能否输出所需单人场景而非多个复制人、网格或展示板，视角和服装是否正确。
3. 表情能否按指定选择，是否误混情绪或依次演完九格；面部是否漂移。
4. 对比预期镜头，登记输入文件/版本、整板或裁图、缩放条件、结果文件及已验证范围；记录到现有能力登记和角色卡，不新增审批链。

不清楚或失败时先修相关区域/裁图并重测；同一路线按 `AGENTS.md` 的重抽预算执行，两次质量重抽仍不过即换办法。不支持多参考时用场景首帧路线；涉及身份、风格或核心效果改变时按授权决策，不能静默换脸。已有工具登记不等于双板策略在该工具上已验证。

## 七、与分镜 / 视频生成的前后联动

1. 分镜表按镜标明视角、景别、服装、情绪，并引用板 ID/版本、所需区域或 E 编号；上传方案与裁图来源登记在镜头提示词或现有清单备注中。
2. 首帧由冻结身份、所需表情和场景构图生成，不凭空重抽人脸；先核对身份、服装、站位与光线，再让视频主要负责动作。
3. 构图与表演从 `影视视听语言速查.md`、`导演构图库.md`、`写实对白微表演.md` 按情节选择，不由合板排版决定镜头。
4. 复杂互动先制作站位/接触关系正确的同框关键图，不把两张独立肖像堆进提示词就当完成。

## 八、参考板审核清单（G2 资产）

**完整性与布局**
- [ ] 主要角色已交付身份造型板与日常表情九宫格；减量角色已说明原因？
- [ ] 身份板左侧为清晰正面半身，右侧为正/侧/背三个等高完整全身，无角度重复、裁脚或遮挡？
- [ ] 九宫格九种表情对应 E01–E09，构图/机位/脸部大小一致，表情可区分且幅度日常？

**一致性**
- [ ] 两板各区域为同一人，年龄、脸型、五官、发际线、发型一致，表情变化不造成换脸？
- [ ] 服装版本、主辅色、领型、纹样、材质、配饰和鞋在可见区域一致，体型比例稳定？
- [ ] 各表情均从已确认身份派生，强表演及特殊视角补图按实际需要准备？

**像素预算与可用性**
- [ ] 实际输入缩放/裁切后半身面部、三视图及九格仍可辨；不清楚时已改用高清源图或裁图？
- [ ] 整板/裁图小样未出现多人复制、拼板入镜、情绪混用或身份漂移；未验证部分已明示？
- [ ] 仅首帧模式已先生成正式场景首帧，不把展示板直接当首帧？
- [ ] 各镜头输入按需选择，来源、父板版本及格号可追溯，两板已共同冻结且版本统一？

## 九、方法依据与边界

- 本版“双参考板”是本体系经用户确认的默认交付设计，不宣称它是所有模型的官方最佳实践或必然优于独立单图。
- 多角度、服装和表情参考的公开方法背景（来源记录不随本包提供）；这些资料不证明任意实现都能理解拼板，执行前仍按能力登记与小样核验。
- 面部像素、参考名额、缩放及输入语法取决于当前实现，不从旧经验推导通用保证。
- 本文不绑定工具，不强制所有角色素颜，不要求每镜两板全上；其目标是组织可复用的身份信息并降低漂移风险，而非承诺零漂移。
