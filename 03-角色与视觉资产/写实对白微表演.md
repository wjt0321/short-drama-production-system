# 写实对白微表演

## 1. 任务定位

**负责**：把"角色说话"从僵硬念词变成有层次的真人生理反应——控制眼神、微表情、口型幅度、头部与手部小动作，并按情绪强度分档。

**不负责**：台词写作（回 01）；镜头节奏与机位（回 02 `分镜类型特则.md`）；配音合成（回 05）。

## 2. 对白表演"一眼假"的四大元凶

| 元凶 | 表现 | 破解 |
|---|---|---|
| **眼神空洞** | 说话时眼睛无焦点、无眨眼、不看任何人 | 给视线落点 + 眨眼 + 视线切换时机 |
| **表情恒定** | 整句/整镜一个表情，情绪与台词内容脱节 | 表演幅度分档 + 表情变化时点 |
| **口型夸张** | 嘴张得比真人说话大、开合频率对不上语速 | 口型幅度分级 + 开口频率控制 |
| **身体僵直** | 说话时头不动、肩不动、手不动，像雕塑 | 头部微动 + 手部小动作 + 呼吸感 |

## 3. 表演幅度分档（核心工具）

把每镜表演强度分四档，写提示词时先定档，再选词：

| 档位 | 定义 | 适用场面 | 控制要点 |
|---|---|---|---|
| **0 静默** | 不说话的镜头：倾听、观察、思考 | 反应镜头、对峙沉默、听对方说话 | 眼神是唯一信息通道；给轻微眨眼与呼吸 |
| **1 微表演** | 表情与身体几乎不动，仅眼神/眉梢/嘴角细微变化 | 试探、隐忍、盘算、压住情绪 | 幅度副词用 subtle / faint / barely perceptible |
| **2 中表演** | 正常交谈的完整表情与手势，符合日常说话 | 普通对话、谈判、情感表达 | 幅度副词用 natural / normal / unforced |
| **3 强表演** | 情绪外放：瞪眼、发抖、哽咽、拍桌、逼近 | 爆发、崩溃、揭穿、摊牌 | 幅度副词用 intense / uncontrolled；且必须给出动作承接物（手、身体） |

**核心纪律**：
- 不是情绪越强越好——**AI 最假的是全程 3 档**。真人说话 80% 时间是 1-2 档，3 档只给全片 2-3 处爆发点。
- 爆发要"先压后放"：3 档前至少一个镜头在同角色身上用 1 档，情绪才有起承。
- 一个镜头内最多一个档位跃迁（如 1→2），跨 2 档（1→3）必须换镜头。

## 4. 视线控制（对白的灵魂）

### 4.1 视线三要素

| 要素 | 写法示例 | 作用 |
|---|---|---|
| **视线落点** | 看向对方的眼睛 / 看向桌面文件 / 看向窗外 / 看向镜头外某处 | 建立关系：看着说是对峙，看向别处说是心虚/思考 |
| **视线切换时机** | 说完关键句后移开视线 / 对方提到某词时突然抬眼 | 潜台词：视线变化=心理变化 |
| **眨眼与眼部微动** | 正常眨眼、轻眯眼、睁大眼、瞳孔微缩（写"eyes widen"） | 生理真实感：全程不眨眼是最重的假人信号 |

### 4.2 视线规则

- **对峙/审讯**：说话人看着对方眼睛；被问者回答时视线先移开再回来，是"现编答案"的生理信号。
- **说谎/隐瞒**：视线落点不在对方眼上——看斜下方或对方肩后；说完后快速回正。
- **情感戏**：重要表白时视线不闪躲；受伤时视线垂落。
- **多人场面**：视线落点写清"看向谁"，一次只看一个人，说话间隙扫其他人。

## 5. 口型幅度分级

### 5.1 口型幅度三档

| 档 | 幅度 | 适用 | 提示词写法 |
|---|---|---|---|
| 低幅 | 嘴张合小、语速平 | 低语、隐忍、OS 画外音边缘 | lips barely parting / small mouth movements |
| 中幅 | 正常说话幅度 | 标准对白 | natural lip movements matching speech |
| 高幅 | 张嘴明显、语速快 | 争吵、逼问、爆发 | exaggerated mouth movements, rapid articulation |

### 5.2 口型同步规则（与 05 配音配合）

- **口型台词**：生成时画面人物必须带说话动作，口型幅度与配音语速匹配——台词写"急促逼问"就配高幅快语，写"低声试探"就配低幅慢语。
- **口型时长**：口型台词占用不超过镜头时长的 90%，其余时间留"说完后的表情停留"——真人说完话不会立刻闭嘴僵住，会有 0.2-0.5 秒的嘴部收束与表情余韵。
- **OS 画外音**：说话人在画面内但背对/侧面/模糊时，无需对口型，但**画面必须给听者反应**（见 02 `分镜类型特则.md` §6.3）。
- 具体口型同步技术选型见 `05-音频/声音实现适配参考.md` §7。

## 6. 双人对戏的表演提示词写法

### 6.1 两镜模板（正反打最小单元）

```
镜 A（说话人单人近景）：
  近景，@角色X 看着@角色Y 的眼睛，表情【档位2：natural】
  说出【台词】，说到"【关键词】"时眉头轻皱（subtle frown），
  说完轻眨一次眼，嘴部自然收束。
  头部微微侧向@角色Y，肩膀放松。

镜 B（听者反应）：
  近景，@角色Y 听到"【关键词】"时【档位1：subtle】
  视线从@角色X 脸上移开片刻，嘴角抿紧（lips pressed together），
  喉结轻动，眼神下垂后重新抬起。
```

### 6.2 提示词组装顺序

`[景别与机位] + [角色身份@] + [视线落点] + [表演档位与幅度词] + [表情变化时点] + [口型幅度] + [头部/手部小动作] + [说完后的余韵]`

### 6.3 常用词库（中英对照）

| 维度 | 英文推荐词 | 中文说明 |
|---|---|---|
| 视线 | looking directly into @X's eyes / gaze drifting away / eyes darting to the document / averting gaze then returning | 直视 / 视线飘走 / 目光扫向文件 / 移开再转回 |
| 眨眼 | slow blink / rapid blinking / eyes widening slightly | 慢眨眼 / 快速眨眼 / 微睁大眼 |
| 微表情 | subtle frown / faint smile / lips pressed together / jaw tightening / brow slightly raised / nostrils flaring faintly | 轻皱眉 / 淡笑 / 抿嘴 / 咬颌 / 微挑眉 / 鼻翼微张 |
| 头部 | head tilting slightly / chin lowering slowly / nodding barely / turning head away a few degrees | 微侧头 / 缓缓低头 / 几不可察的点头 / 转头几度 |
| 手部 | fingers tapping the table / hand clenching then relaxing / adjusting cuff / touching the glass rim | 敲桌 / 握拳又松开 / 整袖口 / 触杯沿 |
| 幅度副词 | subtle / faint / barely perceptible / natural / unforced / intense / uncontrolled | 微/淡/几不可察 / 自然/不刻意 / 强烈/失控 |
| 口型 | lips barely parting / natural lip movements / exaggerated mouth movements, rapid articulation | 低幅 / 中幅 / 高幅 |

## 7. 长对白分档策略

一句长台词（>15 字）按语义分段，每段给不同档位，避免全程一个表情：

```
原文（愤怒质问）：
"你把模型权重给了她？——你知道这在美国国会听起来像什么吗？——不像事实。那真相是什么？"

分段：
  第1句（2档→3档起点）：看着对方，表情渐紧，语速渐快
  第2句（3档）：身体前倾，音量/表情同步加重，瞪视
  第3句（1档急转）：突然压低声音放缓，眯眼，视线危险地定住
  → 停顿半拍（留白），再接对方的反应
```

**急转规则**：情绪"高→低"（怒到冷）比"低→高"（冷到怒）更抓人，写提示词时优先设计一次急转。

## 8. 与一致性锚的配合

- 表演控制写在提示词里，但**脸不变**的前提是 `角色一致性.md` 的角色锚已经生效——表演档位词加进锚句表：每个角色锚句尾附一句表演基线（如"@X 惯用 1 档，只有被逼到墙角才上 3 档"），让全片表演风格统一。
- 两角色对戏时，写清"谁压谁"：强势方表演档位保持恒定，弱势方档位波动大——档位差本身就是权力关系。

## 9. 交付前检查清单

- [ ] 每个对白镜头是否先定了表演档位（0-3），且全程不都是 3 档？
- [ ] 是否给了视线落点（看向谁/哪里），而非"看着镜头"？
- [ ] 是否含眨眼/眼部微动（消除无眨眼假人感）？
- [ ] 口型幅度是否与语速/情绪匹配（低语配低幅，争吵配高幅）？
- [ ] 说完话是否有 0.2-0.5 秒表情余韵，而非立即僵住？
- [ ] 长台词是否分段并设计了一次情绪急转？
- [ ] 爆发点前是否有同角色低档位镜头做铺垫（先压后放）？
- [ ] 双人对戏是否写清视线互动与"谁压谁"的档位差？
- [ ] 表演基线是否已并入锚句表，全片表演风格统一？
- [ ] 是否与 `角色造型与写真.md` 叠加：质感层 + 表演层都进提示词？
