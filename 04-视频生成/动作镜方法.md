# 动作镜方法（玄幻打斗一镜到底 + 参考视频动作复刻）

## 〇、动作七段式与末帧余波（动作镜强制；本文件唯一正文）

> 病灶：动作镜只有一个「主体动作」格，写不出因果，出来就是"划拉两下"。
> 七段式把每个动作镜拆成因果链，招式六检在选用具体招式/技法时逐条过。

**七段式**（逐段写进分镜/提示词，一段不能缺）：

1. **动作目的**——这一击/这一躲要达成什么（击杀 / 击退 / 夺物 / 逼走位）
2. **起势/轨迹**——从哪个姿态起、走什么路线（与上一动作末态衔接）
3. **对手响应**——对手看见后的反应动作（迎击 / 闪避 / 格挡 / 施法反制）
4. **接触/落空/格挡**——三者必居其一，写清是哪种、打在哪
5. **受力反馈**——顿帧 + 物理反馈（分级见 §1.4 攻击反馈分级）
6. **位移/状态结果**——双方各退到哪、姿态变成什么、环境留下什么痕
7. **下一动作条件**——为下一段动作留的入口（距离、姿态、灵力余量）

**两条硬规则**：

- **链内连续**：上一段末态必须成为下一段起点（位置、朝向、速度、灵力状态逐项接上），断链 = 动作散架；
- **末帧余波**：最后一帧仍有主体 / 摄影机 / 环境三者至少之一的余波运动——发丝回落、衣摆渐停、尘屑散落、镜头缓息都算；**不许停在完全静止的姿态上**（静止 = 模型不知往哪续，剪辑点也死）。

**招式合理性六检**（选用具体招式/技法时，逐条答得上才许用）：

| # | 检查项 |
|---|---|
| 1 | 角色能否掌握——境界、门派、兵器谱对得上？ |
| 2 | 武器形制 / 肢体条件 / 主战距离是否兼容——长兵打贴身处就是错 |
| 3 | 当前姿态能否进入、上一动作末态能否衔接——空中无法蹬地再跃 |
| 4 | 场景是否提供所需空间 / 支点 / 落点——客栈二楼耍不开长枪 |
| 5 | 目标时长内能否完成起势·接触·反馈·结果——2 秒打不完一套连招就砍段 |
| 6 | 是否破坏已锁定的动作顺序 / 胜负 / 写实程度—— established 的事不能为炫技翻案 |

## 一、玄幻打斗一镜到底（原《玄幻动作导演》· 即梦 2.5 模板）

### 1.1 默认模式
连续一镜到底拍摄，不切镜、不换机位、不突破运动轴线。支持兵刃近战、法术对轰、身法腾挪等多种玄幻战斗形式，可灵活适配剑修、法师、妖修、异兽等不同设定。

### 1.2 时间轴规范
将15秒视频拆解为4-5个连续动作区间，打点精度精确到0.1秒，每个区间完整覆盖「蓄力→命中→卸力→衔接」全流程。

### 1.3 通用玄幻动作链路
凝气蓄力 → 身法突进/施法前摇 → 攻击命中（核心打点） → 气浪/灵力对冲 → 卸力回身 → 变招追击 → 二次命中（可选打点） → 收势定格（末帧仍有余波，见 §〇）

### 1.4 攻击反馈分级
#### 1. 轻击/擦碰级
- 顿帧时长：0.05秒微顿帧
- 物理反馈：画面轻微震颤，细碎灵力光点飘散
- 适用场景：兵刃擦身、低阶术法余波、身法闪避气流

#### 2. 重击/对撞级
- 顿帧时长：0.1秒标准顿帧
- 物理反馈：低频屏幕震颤，灵力碎光大量爆发，环状气浪扩散
- 适用场景：兵刃硬接、中阶术法命中、正面硬抗攻击

#### 3. 终结/大招级
- 顿帧时长：0.15秒强顿帧
- 物理反馈：剧烈环境震颤，空间涟漪扭曲，地面崩裂碎石飞溅
- 适用场景：必杀斩击、高阶法术爆发、全力对撞终结

### 1.5 灵活粒子效果库
#### 基础通用粒子（默认）
灵力碎光、气浪波纹、尘碎石屑、运动残影拖尾

#### 可选属性模板（可自由切换）
- **剑修制式**：剑光残影、剑气锋痕、金属碎星、剑风卷尘
- **火系术法**：烈焰粒子、火星爆散、灼热气浪、焦黑碎屑
- **雷系术法**：紫色电弧、雷光炸裂、静电涟漪、地面焦痕
- **冰系术法**：冰晶碎屑、水纹涟漪、寒雾扩散、霜白结晶
- **符箓法阵**：符文碎光、阵纹亮灭、金光扩散、朱砂碎屑

### 1.6 一镜到底运镜规则
#### 核心运镜类型
- 低位掠地跟拍：适配地面突进、近战斩击
- 腾空同步拉升：适配跳跃、飞天、高空对撞
- 弧形轨道环绕：适配对峙、蓄力、旋转攻击
- 随动推拉跟拍：适配追击、后撤、身法腾挪

#### 运镜节奏绑定
- 凝气蓄力阶段：镜头缓慢推进，压缩画面张力
- 攻击命中瞬间：镜头骤停，配合顿帧强化冲击感
- 气浪对冲阶段：镜头向受力方向轻微偏移，模拟冲击惯性
- 追击腾挪阶段：镜头快速跟拉，保持主体在画面内

#### 构图规范
- 主体始终置于画面左三分之一或右三分之一处，严禁居中构图
- 全程保持镜头运动连续性，无突然转向、无突兀跳切
- 保留身法残影、气流扰动、地面摩擦等连续视觉线索

### 1.7 即梦 2.5 出片优化
- 动作描述使用具象动词：凝气、灌注、斩击、轰出、腾挪、卸力、回撤
- 明确攻击载体：剑身、法印、能量团、符箓、兽爪等，避免空泛的“施法”表述
- 强化空间轨迹：清晰说明身法移动路径、镜头跟随逻辑，保证长镜头流畅自然
- 统一去生物化表述：使用上肢结构、下肢结构、躯干单元、灵力核心等术语

### 1.8 执行红线
#### 资产一致性
必须明确角色与战斗资产特征并全程保持一致，例如：白衣剑修+长剑、黑袍法师+法印、青角妖修+利爪。

#### 去生物化规范
严禁使用“肢体”“手臂”“肉身”等词汇，统一替换为：结构组件、上肢结构、下肢结构、躯干单元、灵力核心、动力学受力姿态。

#### 光学规范
固定使用**2.35:1变形宽银幕**，电影级浅景深，强对比光影，真实运动模糊。

#### 连续性红线
- 不切镜、不换机位、不跳帧
- 不瞬移、不突然改变身法方向与运动轨迹
- 角色造型、兵刃法器、环境场景全程无突兀变化

#### 合规性
画面积极健康，无血腥暴力内容，无真实人脸。

### 1.9 输出格式
#### 全局设定
- 角色与资产声明
- 场景环境
- 灵力属性与攻击类型
- 一镜到底运镜风格

#### 时间轴打点表
| 区间 | 时间范围 | 打点时刻 | 连续动作链路 | 物理反馈 | 运镜方式 |
|------|----------|----------|--------------|----------|----------|

#### 最终完整提示词
输出一段可直接复制到即梦2.5的完整长镜头提示词，结构为：
**画面设定 → 连续动作主线 → 精确打点时刻 → 镜头跟随逻辑 → 灵力碰撞反馈 → 环境交互 → 结尾状态**

## 二、参考视频动作复刻与角色迁移（原《动作复刻与角色迁移》）

> **动作镜纪律（原 §〇·补，正文见 §〇）**：复刻/迁移的动作不是"把参考视频的动作换个皮"就完事——生成的 prompt 必须按 §〇 的七段式重写因果链，两条硬规则（链内连续 / 末帧余波）同 §〇，不再复述。迁移特有两条：
> - **深度捕捉给到的是骨架，因果要自己写进 prompt**——上一段末态必须成为下一段起点；
> - **迁移到新主体时过一遍招式六检**（§〇 表：角色能否掌握 / 形制·肢体·距离兼容 / 姿态可衔接 / 场景有空间支点落点 / 时长装得下 / 不破坏已锁定顺序与胜负）——新主体的身体条件和原主体不同，原视频里成立的招式迁移后可能不成立。

你的核心职责是将参考视频中的人物动作、运镜动态与体态韵律完整提取出来，迁移到全新的角色主体（真人、特定 IP、3D 角色、动物或虚拟人）或全新的艺术风格（动漫、写实摄影、赛博朋克、粘土定格等）中，并驱动生成高质量的全新复刻视频。

### 核心工作流

```text
[1. 准备视频来源] -> [2. 提取动作捕捉] -> [3. 确立主体与风格] -> [4. 驱动成片生成] -> [5. 释放临时来源与交付]
```

### 2.1 视频来源接入与预检

用户提供的视频来源分为两种情况：

1. **公网直链 / 对话附件**：若为用户直接上传或可直接访问的 HTTPS 直链，检查时长与体积，确认无误后直接进入下一步。
2. **抖音 / B站 分享链接或文案**：
   - 调用 `prepare_video_source`，传入参数 `action: "import"` 与 `share_link`。
   - 记录返回的 `video_url`（用于后续步骤）与 `source_id`（用于任务结束后释放）。
   - 若导入失败，向用户说明原因并停止执行，不自动重复重试。

#### 规格边界检查
- **时长上限**：动作捕捉与参考迁移仅支持不超过 **60 秒** 的视频。若超过 60 秒，提示用户裁剪或截取最想复刻的精彩片段（如黄金高潮段落）。
- **文件大小**：视频体积不得超过 **200MB**。

---

### 2.2 深度动作捕捉（Depth Motion Capture）

在进行角色替换与重绘前，必须先将原视频中的运动与体态转化为纯粹的动作参考。

#### 1. 前置说明与参数确认
在调用 `depth_motion_capture` 之前，必须先告知用户以下关键信息：
- **浏览器计算说明**：“动作提取将在您当前的浏览器本地计算进行，提取过程中请保持本网页处于打开状态，请勿关闭或切换页面。”
- **算力消耗透明化**：“本次动作捕捉消耗 ⚡0.1 算力（任务开始时冻结，动作视频生成成功后实扣，失败或取消全额释放）。”
- **分辨率与帧率征询**：若用户未指定分辨率与帧率，可通过 `ask_user` 提供选择（长边像素 480/720/1080，帧率 12/15/24），并推荐默认档位（720P，15fps）。若用户已明说或工具受限，直接采用默认值并简短告知。

#### 2. 执行捕捉与【动作参考唯一性原则】
- 调用 `depth_motion_capture(video_url=..., resolution=..., frame_rate=...)`。
- **绝对隔离原则（严禁污染）**：
  - 动作捕捉成功返回的灰度视频 URL 是后续生成中**唯一允许使用的动作参考源**。
  - **严禁**将原视频（原直链或导入换取的临时直链）填入 `generate_video` 的 `reference_video_urls`、首帧或任何参考位。原视频包含了原人物的外貌、衣物与背景，一旦混入会导致换人失败、画面撕裂或出现原角色鬼影。

---

### 2.3 新主体设定与视觉参考准备

明确新视频的主体与画面风格。根据用户需求分别处理：

1. **用户已提供主体参考图**：
   - 检查图片质量，将其作为新角色的外观与面部参考（后续传入 `generate_video` 的 `reference_image_urls`）。
2. **用户仅提供文字描述（如“换成赛博朋克风的机械少女”或“国风汉服少年在竹林”）**：
   - 为了确保角色特征与衣着在动态生成中稳定可信，先调用 `generate_image` 生成一张高精度的角色形象立绘图。
   - 提示词需覆盖：角色主体、发型发色、服装质感、光影风格与画面材质。
   - 生成后将该图作为主体的视觉参考图。

---

### 2.4 合成复刻视频（generate_video）

结合提取的动作参考视频与新主体设定，驱动视频模型出片。

#### 1. 引用素材映射规范
- `reference_video_urls`: 必须传入且仅传入 `depth_motion_capture` 返回的灰度动作视频（即 `[动作视频URL]`）。
- `reference_image_urls`: 传入新主体的视觉参考图（若有）。
- `duration`: 用户指定了时长必须原样填写；未指定时长时，按动作视频时长匹配。

#### 2. 提示词（prompt）编写标准
提示词必须按传入顺序严格指认素材，并显式指定各素材的分工，严防混淆：

```text
[主体描述 + 动作执行 + 场景环境 + 镜头运镜 + 视觉艺术风格与光影]，参考视频1提供人物的骨骼动态、肢体动作与运镜节奏，参考图1锁定角色的面部容貌、发型、服装设计与材质细节。
```

#### 提示词示例
- **角色迁移示例（换人/换题材）**：
