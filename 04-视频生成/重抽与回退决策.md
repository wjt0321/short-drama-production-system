# 重抽与回退决策

## 〇、一句话

**一次失败 → 先按"提示词 / 模式 / 模型"三层分类 → 再看预算 → 走回退链 A→E → 每一步都记录。** 超过预算或需要改方向时，停下问用户，绝不让单镜无限重抽。**静帧 + Ken Burns / 冻结只作有意图短插入；主体叙事累计 ≥10% 必须停并告知。有效动作结束就切，不冻结尾帧凑时长。**

## 一、失败分类：先按三层分清性质

> 旧版本把错误堆在一个表里，把"提示词错"和"模型上限"混为一谈，导致回退方向走错。下面按**"提示词 / 模式 / 模型"三层**分类，每层的修法和回退路径不同。

### 1.1 三层错误分类（必看）

| 层 | 含义 | 典型症状 | 修法 |
|---|---|---|---|
| **提示词错误** | 通用骨架本身有问题（违反七段骨架 / 漏五拍 / 摄影机起讫不全 / 硬约束错写 / 合同式反模式 / 首帧是完成态海报） | 整段静态 / 镜头没动起来 / 角色错位 / 主体没事件 / 转场接不上 | 改写提示词 → §二 A 重抽；连续 2 次失败按 §四决策树检查是否层错 |
| **模式错误** | 模式选错（应为 FLF2V 但走 I2V / 应为参考生视频但走 T2V / 应为运动参考但走 I2V） | 物理过渡不准确 / 跨镜漂移 / 复杂动作跑成 PPT / 长插曲位移丢失 | 改模式（按 `平台提示词契约.md` §二选型表）+ 重抽；走 §0C 升级路径 |
| **模型错误** | 当前模型/版本真做不到（已知上限 / 显存不足 / 当前实现不支持） | 任何改写都无法稳定改善；同提示词多平台仍失败 | 走回退链 B→D（换备选实现、降规格、换语法）；走 §0C 三步升级 |

**判定要点**：

- 同提示词换平台立刻能跑通 = 模式错（不是提示词问题）
- 改写提示词后立刻能跑通 = 提示词错
- 改写 + 换模式都失败 = 模型上限，走升级路径
- 跨多镜出现但单镜 OK = 模式错（多镜原生 vs 拼接 I2V）

### 1.2 完整错误分类表（按三层扩展）

| 错误类型 | 层 | 判定信号 | 性质 |
|---|---|---|---|
| 限流/超时 | （瞬时 | 排队超时、接口限流、网络抖动 | **瞬态** → 走技术重试（不占质量预算） |
| 参数不支持 | 提示词 | 非法参数、尺寸超限、格式拒绝 | 输入问题 → 改参数重试 |
| 静态海报首帧 | 提示词 | 首帧已是动作完成态 | 改写 → 首帧改为过程前状态 |
| 缺五拍 / 缺摄影机起讫 / 缺转场接力 | 提示词 | 整段静态、镜头漂浮、转场接不上 | 改写补全骨架 |
| 合同式反模式 | 提示词 | 堆叠 `No / never / 不出现` | 改写 → 正向描述 |
| 角色漂移（提示词层） | 提示词 | 脸/服装/身形漂，但参考图未给 | 补参考图 + 锚句 |
| 模式错配 | **模式** | 精确交互走 I2V / 跨镜同服装走 T2V / 复杂动作走单镜 | 改模式（按选型表） |
| 跨镜一致性失败 | **模式** | 单镜 OK / 拼接处漂移 | 改多镜原生 / 参考生视频 |
| 长插曲位移丢失 | **模式** | 武术 / 多目标接触 / 长连续空间 | 改运动参考 / §0C 升级 |
| 角色漂移（模型层） | **模型** | 给参考图仍漂；不同 seed 都漂 | 模型上限；换参考生视频实现 |
| 物理过渡不准确（模型层） | **模型** | FLF2V 仍走样；物理动作连续 5 镜以下 | 模型上限；走升级 |
| 场景漂移 | 模型 | 场景布局/光线与场景卡不符（提示词层 OK） | 换参考实现 / 加场景锚 |
| 动作错误 | 提示词/模型 | 动作不符合分镜描述 | 提示词改写；模型上限则升级 |
| 口型/音画错误 | 模型 | 口型与台词不对、音画不同步 | 重抽或走 lip-sync 管线（`05-音频/声音实现适配参考.md` §7） |
| 合规拒绝 | （合规 | 内容被审核拦截 | **必须停下** → 改内容，问用户 |
| 文件损坏 | （瞬时 | 输出文件无法解码 | 瞬态/工具问题 → 技术重试 |
| 用户审美不通过 | （主观 | 用户明确说"不对味" | 主观 → 重抽或换方向 |

### 1.3 静帧 / Ken Burns / 冻结 的特殊处理（必看）

> 这三类是**应急手段**，不是叙事手段。下面规则与 §三 E（回退链 E 改变方案）联动。

| 用法 | 是否允许 | 条件 |
|---|---|---|
| **有意图的短插入**（< 2 秒） | ✅ 允许 | 写明"为何此处需要静帧/Ken Burns/冻结"——例如"呼吸间隔的留白""时间凝固感""主观心境广告时间切换" |
| **过渡/转场辅助**（< 2 秒） | ✅ 允许 | 跨段技术接缝处的视觉桥（不是叙事主体） |
| **主体叙事片段** | ❌ 不允许 | 哪怕只用 1 秒，也属"让静帧承担叙事推进"——必须停并告知 |
| **全片累计 ≥ 10%** | ❌ 必须停 | 累计时长占总时长 ≥10% 时，立即告知用户，停下重抽预算，进入 §三 E 候选 |

**累计统计口径**：静帧 + Ken Burns + 冻结 三类时长累加；占总时长 ≥10% 即触发。判断动作：`01 整理当前片中三类时长与占比 → 02 ≥10% 则停下 → 03 在项目重抽日志记录 → 04 把候选方案交用户裁决（不允许静默沿用）`。

**有效动作结束即切**：当生成段里主体动作已经完成有效结果（拿到物品 / 转身 / 反应呈现），就**直接切下一镜**，不要用冻结尾帧或续拍把时长凑到模型标称上限。判断动作：`01 看有效结果是否已呈现 → 02 是 → 在剪辑阶段用尾帧后裁剪到结果那一刻 → 03 不冻结尾帧`。

### 1.4 I2V / FLF2V / 首帧错误的强制提示词

- **I2V 不复述首帧**：首帧图已经给了视觉信息，提示词只写"接下来发生什么"，不重复"画面中有一个男子站在雨里"——写动作过程。
- **首帧不能是完成态海报**（与 `平台提示词契约.md` §一.3 "首帧三禁"对齐）：首帧不是动作结果、不是模糊远景/纯色块、不暗示资产版本外的额外特征。
- **有效动作结束就切**（与本节 1.3 第二段对齐）：不冻结尾帧、不续拍把时长凑到模型标称上限。

## 二、预算规则

- **质量重抽默认 ≤2 次**：同一镜/同一资产第 2 次仍失败，必须进回退链，不许无限重抽。
- **技术重试额外 1 次**：仅限限流/超时/网络抖动等瞬态错误；不占质量预算，但必须在重抽日志标记"技术重试"。
- **预算用尽 → 自动进入回退链并通知用户**（对齐 AGENTS.md 纪律：不让单镜卡死全片）。
- **静帧/Ken Burns/冻结 三类累计 ≥10%** → 不再走重抽预算，直接停下告知用户，触发 §三 E 候选。

## 三、回退链 A–E（按序使用）

| 级别 | 动作 | 适用 | 是否需用户批准 |
|---|---|---|---|
| A | 改写提示词（按 §一.1 三层判定属"提示词错误"才走） | 首次失败、方向没错 | 否 |
| B | 换同能力的备选实现（查 `视频实现适配.md` §0A 差异速查表） | A 后仍失败；或明确属"模式错误"先于 A 走 | 否 |
| C | 降规格（分辨率/时长/运动复杂度下调一档） | 显存/超时/质量不稳 | 否（但记录） |
| D | 换提示词语法或输入协议（按当前实现要求重新适配） | 语法不兼容、持续报错 | 否 |
| E | 换方案（**主体叙事改为静帧+KenBurns 是最后选项**） | A–D 全失败；或静帧/Ken Burns 累计 ≥10% | **是，仅当改变核心方向或触发五类停问事项；否则否**——Agent 自主执行并记《变更记录.md》 |

> 关键区分：**A–D 是执行细节，Agent 自主决定并记录；E 的改变是否交用户裁决，只在「核心方向改变」或「触发五类停问事项」时成立，其余由 Agent 自主执行并记《变更记录.md》**（对齐 `AGENTS.md` §一.4「五类停问事项」与 §九候选决策协议）。
>
> **§三 E 的特殊限制**：把"主体叙事"换成"静帧 + Ken Burns / 旁白带图 / 删镜改叙事"是改变核心效果的回退，按上一条判定——改变核心方向或触发五类停问事项时交用户授权，否则 Agent 自主决定并记《变更记录.md》。**静帧/Ken Burns/冻结 只作有意图短插入（< 2 秒）或过渡辅助；不能承担主体叙事；累计 ≥10% 必须停**。

### 3.1 §三 E 的判定与候选模板

触发 §三 E 时，按以下顺序整理候选：

```
1. 删镜改叙事（删这一镜 / 与邻镜合并 / 改用意境镜头）
2. 静态帧 + Ken Burns（仅作短插入 < 2 秒，累计 < 10%；不是主体）
3. 旁白带图（用配音 + 静帧画面）
4. 换实现平台（H3 → Seedance / Kling / Veo 等）
5. 改分镜 / 重排（回 G3 重审）
```

每条候选写清：效果损失、新增费用/时间、风险、可逆性、推荐项。不足两个候选如实说只有一条或暂不可行，不凑数。

## 四、决策流程（Agent 照此执行）

```
失败发生
  │
  ├─ 合规拒绝？ ──是──→ 先改述重试（按 §四，不进回退链）；两次仍拒 → 停下告知用户并给替代方案，不改叙事方向时 Agent 自主决定并记《变更记录.md》
  │
  ├─ 瞬态错误（限流/超时/网络/文件损坏）？
  │     └─是──→ 技术重试 1 次（标记"技术重试"）→ 仍失败按质量流程
  │
  ├─ 质量/参数/审美失败？
  │     ├─ 按 §1.1 三层判定：提示词错 / 模式错 / 模型上限
  │     │     ├─ 提示词错 → 重抽 ≤2 次：改写按 `平台提示词契约.md` §四
  │     │     │     改写方向：补五拍 / 补摄影机起讫 / 改首帧 / 删合同 / 补接力
  │     │     │     每次记录；2 次仍失败 → 进入回退链
  │     │     ├─ 模式错 → 改模式（按 §0 选型表）+ 重抽 ≤1 次
  │     │     │     仍失败 → 进入回退链
  │     │     └─ 模型上限 → 直接进入回退链（不再 A 重抽）
  │     ├─ 2 次仍失败 → 回退链：
  │     │     B 换备选实现 → C 降规格 → D 换语法 → 每步记录
  │     ├─ A–D 全失败 → E：按 §3.1 整理 2–4 个候选
  │     ├─ 静帧/Ken Burns/冻结累计 ≥10% → 停下告知，触发 §三 E 候选
  │     └─ 停下，交用户裁决
  │
  └─ 每步都写入《重抽日志.md》：错误类型（按 §1.2 表）/ 三层判定 / 重抽次数 / 回退级别 / 修改内容 / 成本 / 结果 / 用户决策
```

### 4.1 三层判定快问

```
Q1：同提示词换平台能跑通吗？
    └─ 是 → 模式错（不是提示词问题）

Q2：改写提示词（首帧 / 五拍 / 摄影机 / 接力 / 硬约束）能立刻跑通吗？
    └─ 是 → 提示词错

Q3：改写 + 换模式都失败？
    └─ 是 → 模型上限（走升级路径 §0C）

Q4：跨多镜出现但单镜 OK？
    └─ 是 → 模式错（多镜原生 vs 拼接 I2V）
```

## 五、记录规范（对齐模板 `04-镜头/重抽日志.md`）

每次失败至少记录：

- 时间、镜号/资产号、能力（登记中的实现）、版本
- **三层判定**（提示词 / 模式 / 模型）
- 错误类型（用 §1.2 分类词，不写"失败了"）
- 质量重抽次数 / 技术重试次数（分开计数）
- 静帧 / Ken Burns / 冻结 时长与累计占比（如触发 §1.3 阈值）
- 回退级别 A–E
- 修改内容（改了什么，提示词原文存 `04-镜头/prompts/`）
- 成本、结果（成功/失败）、用户决策（通过/修改/暂停）

## 六、与生产流程的接口

- **G2–G3（资产/首帧）**：重抽失败 → 回到资产卡改身份特征描述，不反复抽同一提示词。
- **G4（镜头）**：每 2–3 镜审核时，把该批重抽记录一起呈现；批量生产模式按里程碑批次汇总。
- **G5（音频）**：口型/音画错误走 lip-sync 选型（`05-音频/声音实现适配参考.md` §7），不盲目重抽配音。
- **解冻**：回退链走到删镜/改叙事（E）时，按 `AGENTS.md` 回到 G1/G3 重新审核，登记《变更记录.md》与《用户裁决日志.md》。
- **静帧/Ken Burns/冻结累计 ≥10%**：按 §1.3 停下告知，更新项目状态摘要的"当前风险与等待模式"字段。

## 七、常见错误示例（提示词层 vs 模式层 vs 模型层）

### 7.1 提示词层错误

| 症状 | 原因 | 改法 |
|---|---|---|
| 全段静态 | 五拍缺一 / 摄影机无起点终点 / 缺环境异步 | 补五拍；写摄影机起讫四要素；加环境异步 |
| 角色漂移（未给参考图） | 锚句不够 + 无参考 | 补角色参考图 + 锚句详细化 |
| 静态海报首帧 | 首帧已是动作完成态 | 改首帧为过程前状态；下一镜首帧用本镜末状态 |
| 合同式反模式 | 堆叠 `No / never / 不出现` | 删负面约束；正向描述替代；硬约束只留三类白名单 |

### 7.2 模式层错误

| 症状 | 原因 | 改法 |
|---|---|---|
| 精确交互走样（液体/接触/变形） | I2V 不知 A→B 路径 | 改 FLF2V；或拆段 + I2V 强制首尾衔接 |
| 跨镜角色服装漂移 | T2V 不知角色外观稳定 | 改参考生视频；锁角色参考图 |
| 长插曲位移丢失 | 单镜 I2V 拼接损失节拍 | 改多镜原生；或运动参考（如本机支持） |
| 复杂武术走成 PPT | T2V 缺任何锚定 | 改运动参考 + 关键帧参考；按 §0C 升级 |

### 7.3 模型层错误

| 症状 | 原因 | 改法 |
|---|---|---|
| 给参考图仍漂（多 seed 都漂） | 模型上限 | 换参考生视频实现 / 升级到 §0C 第二步 |
| FLF2V 仍走样 | 模型上限 | 改拆段 + I2V；按 §0C 升级 |
| 物理动作连续 5 镜以下失败 | 模型上限 | 远程 API；按 §0C 第二步 |

### 7.4 运动学失败（一次 S03 A/B 实测 实证）

> 这一节是上一节之外的第三类常见失败：**画面里有动作，但动作的"运动学"不对**——主体朝向、步态、手-道具接触、车轮运动与世界坐标方向不一致。
> 来源：项目实测结论已归纳进本文件；研究档不随本包提供，本通用决策表不依赖私人项目路径。

| 症状 | 原因 | 改法 |
|---|---|---|
| **人物面朝摄影机却随车向后退** | 摄影机方向与主体相对速度不对 + 脚步方向与车轮方向不一致 | 补 §一.9 摄影机方向 + 脚步 / 重心；或改多镜原生让摄影机不动 |
| **手与车把接触错位 / 消失** | 缺手-道具接触点 / 承重 / 解除时机的具体描述 | 补 §一.9.5 「哪只手 / 哪根手指 / 哪个部位接触道具哪一处 + 承重方式 + 解除时机」 |
| **推车时车轮不转 / 反转** | 缺道具 / 轮子从属运动的链式描述 | 补 §一.9.6 「手把→踏步→身体→轮转→远景视差，五项方向一致」 |
