## 7. 提示词英文定稿（可选环节）

**什么时候需要翻译**：不是所有平台都要英文，先按下表判断——

| 情况 | 要不要英译 |
|---|---|
| MiniMax H3 | **必须**。官方写作语言就是英文（仅对白/画面文字保留原文），直接按 `H3与即梦语法.md` §3 用英文成稿 |
| 即梦 / Seedance / Vidu（中文原生模式） | **不要**。三家官方都是中文原生，翻成英文反而丢精度 |
| Kling / Veo / Runway / Luma / Firefly / PixVerse | **建议**。这类模型英文训练语料占比高，英文提示词普遍更稳定；Firefly/PixVerse 配 UI preset 时部分用英更稳 |
| ComfyUI 本地 | 按节点模型决定：Wan/Hunyuan 推荐英文；H3 节点按 H3 字段英文 |
| 实测发现中文版效果漂移 | **可以试**。同镜头中英各跑一版对比，哪个稳用哪个 |

**翻译纪律（翻译不是改写）**：

1. **先中文定稿，再翻译**。中文稿是唯一事实源；翻译中发现内容要改，回中文稿改完再重译，不要在英文版上直接改。
2. **术语一次选定、全程不变**：运镜/景别词从 `Seedance语法与三家对照.md` §2.2 映射表和 `H3与即梦语法.md` §3 运镜词表取，同一个镜头动作在全片只用一个英文词（比如定了 `push in` 就不要下一镜又写 `dolly in`）。
3. **这些原样不动**：`@Image1` 等引用语法、文件名、专有名词、画面中的可见文字、对白原文（H3 里 `<d>` 标签内保留原文语种）。
4. **译后逐槽核对**：对照 `Seedance语法与三家对照.md` §2 的八个槽位逐个问"英文版有没有丢信息、有没有多写"，丢了的补，多了的删。
5. **中英两版都存档**，文件名加 `_zh` / `_en` 后缀，便于返修时对照。

> 这不是一个新阶段，只是第 4 阶段交付前的最后一步：中文稿（即梦/Seedance 直接可用）→ 需要时 → 英文定稿。

## 9. 国际模型公式速览（迁移参考）

> 按需查阅：只有当目标平台换成国际模型（或用户明确要求对比）时读本节。本体系主力仍是 H3/即梦/Seedance，主片 §0A 的差异速查表是当前唯一权威；本节作为补充，附每个平台的官方/社区公式要点。本机能力见主片 §0B。

### 9.1 各模型官方/社区公式的要点

| 模型 | 核心公式 / 记忆点 | 适配风险 |
|---|---|---|
| **MiniMax H3** | 固定字段三件套 + `[Shot N] At MM:SS.mmm` + 运镜三轴 | 详见 `H3与即梦语法.md` §3 |
| **即梦 3.0 Pro** | 中文语义顺序 + 镜头词 + 程度副词 + 多镜语义分段 | 详见 `H3与即梦语法.md` §4 |
| **Seedance 2.0/2.5** | 中文分段标签 + 主体/动作/场景/镜头/风格；`@Image1`/`@Video1`/`@Audio1` 引用 | 详见 `Seedance语法与三家对照.md` §5 |
| **Kling 3.0** | 官方能力：Multi-Shot/Custom Multi-Shot/原生音频；五层结构仅为推荐写法 | 物理强动作；写动作"起→中→止"时序；元素绑定 + Custom Multi-Shot |
| **Veo**（Google） | 自然语言描述主体、动作、摄影机、光线与声音；示例句不是固定字段 | 原生音画一体；对白写引号并归属到人；物理与写实度是当前标杆；Ingredients + 时间戳 |
| **Runway Gen-4/4.5** | 输入图锁定主体与风格，提示词主要写运动和摄影机 | 品牌色/指定画风必须不走样的项目首选；不支持负面提示 |
| **Luma Dream Machine** | `@character` / `@style` / Boards 上下文；Keyframes + Modify / Extend；loop 关键词；Camera Motion 预设 | 上下文 Boards 锁跨镜 |
| **Firefly Video**（Adobe） | UI style/composition preset；合作模型切换；Content Credentials 自动水印 | 与 Pika / Luma 互通；自动带 Content Credentials（合规用） |
| **PixVerse** | 当前未核验固定 prompt grammar；产品工作流与追踪字段不进入提示词规范 | 特效模板多；适合快剪风格 |
| **Vidu** | Reference-to-Video API 使用 `subjects` 与主体名称；能力随模型/端点变化 | 适合分镜式预可视；运动幅度三档可控 |
| **ComfyUI 本地** | 节点串接；按控制需求分流（T2V / I2V / FLF2V / Fun Control / Camera Control / Animate / 音频驱动 / 视频编辑）；208+ 官方模板 | **作者实测环境仅 H3 + Wan2.2 5B 已就绪（买家需按自己环境重新登记）**；Wan 14B FLF2V/控制族、LTX/Hunyuan 未就绪（见主片 §0B）；加速 LoRA/Turbo 仅草稿用 |

### 9.2 国际社区四条铁律（与 `Seedance语法与三家对照.md` §2 通用槽位互补）

1. **逐镜提示，不整段提示**：别写"a 30-second sequence of X, Y, Z"——模型只会前 3 秒合格、后面漂移。长片 = 分镜 + 剪辑问题，不是提示词问题。
2. **片段时长是硬约束**：模型一档几秒就按几秒设计节拍，超容量的叙事必翻车。
3. **I2V 优于 T2V**：先锁首帧（见 `02-分镜与镜头/分镜工作流.md` §九 首尾帧分镜法），视频模型只负责动。
4. **按镜头选模型，不按项目选模型**：对白密度高的镜头给 H3/Veo 3.x，物理动作镜头给 Kling/Seedance，风格锁定镜头给 Gen-4。单一模型打全场 = 每类镜头都留遗憾。

## 10. 跨平台通用进阶：连续性锁表 · 微动作词库

### 10.1 连续性锁表（continuity lock sheet）

同一场戏的所有镜头，开拍前把六项锁死，逐镜原样重贴（与本体系锚句机制同源，此处补全国际社区惯用项）：

| 锁定项 | 示例 | 漂移症状 |
|---|---|---|
| 时间/天气 | 雨夜，霓虹反光 | 相邻镜头一个晴一个雨 |
| 服装 | 灰色风衣，左胸口袋巾 | 配饰凭空出现/消失 |
| 主光源方位 | 顶光偏左 45° | 影子方向前后相反 |
| 180° 轴线 | 镜头永远在两人连线的同侧 | 越轴导致人物左右互换 |
| 色彩基调 | 青橙对比，低饱和 | 剪辑点"跳质感" |
| 种子/参考 | 同种子或同组参考图 | 同提示词两次生成两张脸 |

### 10.2 微动作词库（micro-motions）——"纹理=可信度"

画面"塑料感"的解药是给静止主体加一层真实世界的微运动，每镜挑 1-2 个，不要全堆：

`呼吸起伏` · `眨眼` · `发丝被风掀动` · `布料轻微摆动` · `蒸汽/热气升腾` · `尘埃在光柱里浮动` · `水面反光晃动` · `霓虹/烛光闪烁` · `呵出的白气` · `手指无意识摩挲物件`

同理，**光源要写真**：不写"dramatic lighting"，写"闪烁的日光灯管""雨夜便利店霓虹""烛光+窗外闪电"——具名光源才生成可信光影。

### 10.3 运动动词专业化

模糊动词（moves / goes around）等于放弃运镜控制。用专业词：

| 想要的效果 | 写法 |
|---|---|
| 缓推近 | dolly push / slow push-in |
| 拉远揭示 | pull-out / crane up revealing |
| 快速横摇 | whip-pan |
| 急速变焦 | crash zoom |
| 瞬间合焦 | snap focus |
| 环绕主体 | orbit / arc around |
| 手持晃动 | handheld drift / shoulder-cam shake |

> 本节参考：Kling 3.0 Prompt Guide（atlabs.ai 整理）；AI Video Prompting: The Complete 2026 Guide（sureprompts.com）；Cinematic AI Video Prompts 2026 Playbook（truefan.ai）。

## 12. 已批准分镜的转换边界

本文件负责把已批准的生成段翻译为当前实现可执行的表达，不负责重新拆镜或改变叙事。转换必须继承：资产版本、风格锚、首状态、变化过程、尾状态和镜头主要观看重点。

当当前实现无法同时满足要求时，输出 2–4 个候选：拆段、降低运动复杂度、改用更稳妥机位、或经用户同意更换方案。不得静默省略角色身份、关键道具、动作结果或连续性字段。

## 镜头语言、画面语言与色彩路线

视频提示词在动作链之外补齐三项即可：

- 镜头语言：机位/视角、景别和运动目的；必要时写焦点如何从人物转到道具或环境。对话与移动写轴线、视线和屏幕方向，不用无理由越轴。
- 画面语言：第一视觉焦点、前中后景、引导线/留白/前景遮挡、主体层次和遮挡关系。提示词限制长度时优先保留主动作、焦点和空间关系。
- 色彩路线：当前阶段主色/材质、光线色温、对比/饱和度，以及与前后段的继承或变化理由。不能每镜换滤镜；相邻镜头同一时空优先统一白平衡和肤色。

这些是可执行事实，不是“电影感、唯美、高级”等评价词。详情用`影视视听语言速查.md`，光源层次用`导演视觉圣经.md` 照明卡；不绑定平台。
