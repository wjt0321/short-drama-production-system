## 0. 使用前必读：三条诚实声明

以下结论来自官方文档调研（2026-09），用于防止误信社区传言：

1. **即梦官方未公布 `@` 引用语法**，也没有独立的"提示词指南"页。可用的官方 Prompt 建议散见于火山引擎《即梦 AI 视频生成 3.0 Pro 产品介绍》§4。网上流传的"即梦 @图片1"写法是把 Seedance 语法张冠李戴。
2. **Seedance 和即梦都没有独立的 negative prompt 字段**（官方指南均未列出）。社区在 prompt 末尾内联 `NEGATIVE: ...` 或反向写"不要 XX"的做法**不是官方承诺的参数**，效果因版本而异。MiniMax H3 则通过 `non_diegetic_music: N/A` 这类字段值表达否定。
3. **三家的官方写作语言不同**：H3 官方模板是**英文**（对白/画面文字保留原文语种），即梦和 Seedance 官方模板是**中文**。把 Seedance 的中文段落直接喂给 H3，或把 H3 的英文字段名写给即梦，都是常见翻车点。

## 1. 平台路由决策树

拿到一个镜头/一段分镜后，先决定用哪家生成：

```
这个镜头需要什么？
│
├─ 需要精控对白、口型同步、说话人区分、原生音效与配乐分层？
│    └─ 是 → 优先从已验证的音画一体实现中路由；当前能力登记中 H3 可把 diegetic 声效 / 对白 / BGM 分字段控制，但不是永久唯一供应商
│
├─ 需要上传图/视频/音频做混合参考、视频编辑、视频延长？
│    └─ 是 → Seedance 2.0/2.5（@ 引用语法 + 任务类型分类最完整）
│
├─ 需要首尾帧精确锚定的物理过渡（A 状态 → B 状态）？
│    └─ 是 → H3 FL2VA 或 Seedance 首尾帧任务（两者都支持，按画面风格偏好选）
│
├─ 需要一段 prompt 直接出多镜头连贯叙事（不切给多个生成请求）？
│    └─ 是 → 即梦 3.0 Pro（"镜头1+主体+动作1+镜头2…"）或 Seedance（"镜头切换"）
│
└─ 只是普通单镜头、三家都能做？
     └─ 按画风偏好与手头账号选；玄幻打斗一镜到底优先走同目录 `动作镜方法.md` §一（即梦 2.5 模板）。
```

| 维度 | MiniMax H3 | 即梦 3.0 Pro | Seedance 2.0 / 2.5 |

| 参考文件上限 | 图片 ≤9、视频 ≤3、音频 ≤3，且总数 ≤12 | 3.0 Pro 官方文档未列 | 图片 ≤9、视频 ≤3、音频 ≤3，且总数 ≤12（2.5 单次最多 50 个素材） |
| 原生音频 | ✅ 原生立体声；环境声/对白/BGM 分字段 | 产品页未公开原生音频能力 | ✅ 2.0 起原生音效 + 多语言唇形同步对白 |

## 2. 通用槽位模板（本文件核心：一次构思，三端输出）

### 2.1 八槽位通用模板

构思任何镜头时，先填这 8 个槽位，与目标平台无关：

```text
【风格画质】整体媒介与画质基调（写实/3D CG/2D 动画/胶片感；分辨率与流畅度诉求）
【主体】谁/什么：身份、外貌、服装、当前状态（写作纪律：不用代词，见《角色一致性.md》）
【场景】地点、时间、天气、关键道具与陈设
【动作】按时间顺序的连续动作链（先动后静，动作优先于修饰）
【镜头】景别 + 运镜 + 视角 + 起幅/落幅
【光影】光源性质、方向、色温、时间感
【声音】对白（原文）、环境音、音效、配乐（不需要就标注"无"）
【约束】必须保持不变的东西（面部/服装/logo）+ 明确禁止项
```

### 2.2 通用槽位 → 三家语法映射表

| 通用槽位 | MiniMax H3 | 即梦 3.0 Pro | Seedance 2.0/2.5 |
|---|---|---|---|
| 风格画质 | `integrated_multimodal_description` 首句 `[Shot 1] <style>, a <shot> frames...` | 句首风格关键词（"古风，…"） | 独立一行"风格与画质："或句首 |
| 主体 | 首句内 `frames a <subject>...`，英文详写外观 | "主体 + 外观描述"自然语句 | `主体：` 标签行 |
| 场景 | 同句内环境描写 | "背景"自然语句 | `场景：` 标签行 |
| 动作 | 同段按时序展开；新镜头用 `[Shot N] At MM:SS.mmm` | "动作"自然语句；连续动作用"主体+运动1+运动2" | `动作：` 标签行，按时序分句 |
| 镜头 | 英文运镜三轴：`<Motion Type> with <small/large> amplitude at <slow/fast> speed` | 官方中文词典（"镜头缓慢左移跟随"）+ 程度副词 | `镜头：` 标签行，景别与运镜分开写（先"中景"再"缓慢推镜"） |
| 光影 | 融入 description 的环境描写 | 句尾"光影/氛围"自然语句 | `光影：` 标签行 |
| 声音 | **拆三处**：对白进 `description`（`<d>[语种]…</d>` + `(S1)` 说话人标签）；环境音进 `overall_soundscape`；配乐进 `non_diegetic_music` | 无官方音频字段，写在语义句中或不写（后期配音） | 写在句中（"她说：……"）；或用 `@Audio1` 引用音频 |
| 约束 | Ref2VA 用 `retention_analysis` 声明保留关系；基础模式在句中写"keep ... unchanged" | 句中反复重申主体外观（"你详细描述了什么，什么就能最大限度保持稳定"） | `约束：` 标签行（"面部稳定不变形"等）；多模态任务用 `@` 引用锁定 |
| 参考素材 | 开头对齐指令段 + 空行（如 `For the target video, at 0.00 seconds..., <Picture 1> is fully referenced.`） | 官方未公布引用语法 | `@Image1 作为角色参考，@Video1 提供运镜节奏` 等自然语句 |

### 2.3 翻译工作流

1. 用八槽位把镜头构思完整（这一步与平台无关，可在分镜阶段就填好）；
2. 按 §1 决策树选定平台；
3. 按 §2.2 映射表逐槽翻译，**然后通读一遍目标平台的官方写法章节（H3/即梦见 `H3与即梦语法.md` §3/§4，「Seedance 见本片 §5」）做合规检查**——映射表负责"不丢信息"，官方章节负责"不踩语法坑"。

## 5. Seedance 官方模板

> 本节为实现适配示例；执行前必须按《能力登记.md》中已验证的当前规格复核。

### 5.1 官方万能公式

```text
提示词 = 主体 + 动作 + 场景 + 镜头语言 + 风格
```

| 部分 | 解决问题 | 要点 |
|---|---|---|
| 主体 | 主角是谁 | 人/动物/物体/角色 |
| 动作 | 在做什么 | 说话/运动/表演；**官方共识：动作描述最敏感，先动后静** |
| 场景 | 在哪儿发生 | 室内/室外/现代/古代 |
| 镜头语言 | 镜头怎么动 | 推/拉/摇/移/环绕/跟随/升/降/变焦 + 景别；**运镜与景别分开写** |
| 风格 | 整体视觉风格 | 国漫/写实/复古/赛博…… |

进阶社区共识版（官方未点名、广泛沿用）：主体 + 动作 + 场景 + **光影** + 镜头 + 风格 + **画质** + **约束**。

### 5.2 分段标签版模板（短剧推荐写法）

```text
<总体风格/画质>

主体：<人物/动物/物体，详尽外观>
场景：<地点、时间、光线、道具>
动作：<分时序的连续动作>
镜头：<景别> + <运镜> + <视角> + <跟焦/景深>
光影：<光源、方向、色温>
风格与画质：<画面风格>，<画质描述>，<稳定/流畅性>
约束：<角色稳定性>，<禁止项>

[可选 · 多模态参考]
@Image1 作为<角色/风格/构图参考>，@Video1 提供<动作/镜头>，@Audio1 作为<BGM/音色>。
```

### 5.3 官方运镜与景别词典

- 基础运镜：**推、拉、摇、移、环绕、跟随、升、降、变焦**（官方确认精准响应）；
- 景别：远景 / 全景 / 中景 / 近景 / 特写；
- 视角：水下镜头 / 航拍 / 高机位俯拍 / 低机位仰拍 / 微距摄影 / 以 xx 为前景 / 过肩镜头；
- 风格库（部分）：黑白线稿、像素、毛毡、粘土、插画、2D/3D 动画、3D CG、美漫、日漫、油画、复古电影、恐怖片、欧洲文艺电影、复古香港电影、高清写实、微距延时、赛博、科幻电影……

### 5.4 多镜头叙事（官方机制）

> 支持在同一 prompt 里包含多个切镜，切镜会根据提示词保持主体/风格/场景的延续性。镜头的变化通过"**镜头切换**"连接；切镜之后如果场景和人物发生变化，可以用 prompt 刻画新人物/场景的特征。

官方五镜示例：

> 推到红发女孩惊讶的表情特写，镜头切到废墟中的一个窗台上的花盆，里面种着一个蓝色的多肉植物，镜头切到俯瞰，女孩走向这个多肉植物，切过多肉植物前景女孩双眼特写，摇到女孩的嘴，碎碎念出植物的名字。

### 5.5 `@` 引用语法（官方）

| 用途 | 写法 |
|---|---|
| 设置首帧 | `@Image1 作为第一帧` |
| 参考动作 | `参考 @Video1 的打斗编排` |
| 复制镜头运动 | `跟随 @Video1 的镜头运动和转场方式` |
| 加入音乐 | `使用 @Audio1 作为背景音乐` |
| 视频延伸 | `将 @Video1 延伸 5 秒` |
| 替换角色 | `用 @Image1 替换 @Video1 中的女性` |

API 侧对应 `content.role`：`first_frame` / `last_frame` / `reference_image` / `reference_video` / `reference_audio` / `base_video`。文件上限：图片 ≤9、视频 ≤3、音频 ≤3，且总数 ≤12（视频/音频单段 ≤15s；2.5 单次最多 50 个素材）。

### 5.6 任务类型分类（2.5 官方，含锁定项）

| 类别 | 任务 | 锁定项 | 触发条件 |
|---|---|---|---|
| 有锁定 | 视频编辑 | 宽高比=adaptive，时长=-1 | reference_* 素材 + "编辑视频/增加/删除/修改/替换/改成" |
| 有锁定 | 首帧 / 首尾帧 | 宽高比=adaptive，首尾帧画幅建议一致 | role = first_frame / last_frame |
| 有锁定 | 视频延长 | 宽高比=adaptive | reference_* + "向前/向后延长、延续、续写" |
| 无锁定 | 参考生视频（主体/运动/风格/音频等） | 用户可指定 | role = reference_image/video/audio |
| 无锁定 | 多宫格分镜 / 关键帧参考 | 用户可指定 | 分镜合并图 / 多张独立分镜图 |

### 5.7 负面提示词说明

**官方指南未列出独立 negative prompt 字段。** 社区在 prompt 末尾内联 `NEGATIVE: no blur, no watermark...` 或反向写"不要 XX"的做法**不是官方承诺**，不要当作标准参数依赖。更可靠的"约束"写法是 §5.2 的 `约束：` 标签行（正面声明要稳定的东西）。

### 5.8 Seedance 深度路径

多镜头剧本量产、台词容量公式、密度门、10 项自检 → 走同目录 `Seedance适配.md` 第一部分（工业级）；15 秒时间轴节奏、13 类场景配方、延长/改写语法 → 走同文件第二部分（轻量速查）。本文件只负责"Seedance 与另外两家怎么对齐"。

## 6. 同一镜头三端对照示例

**统一例题**：古风女子在雨中撑伞走过青石板巷（5 秒单镜头）。

**八槽位通用构思**（与平台无关）：

```text
【风格画质】古风写实电影感，高清流畅
【主体】年轻女子，白色交领汉服，墨色长发低髻，持米白色油纸伞
【场景】青瓦白墙中式窄巷，青石板路，中雨，远处一盏暖红纸灯笼
【动作】持伞缓步前行，裙摆微湿，回眸一笑
【镜头】中景，缓慢左移跟随，浅景深
【光影】傍晚，雨雾，软光，暖色高光 + 青灰阴影
【声音】雨声、布料摩擦声；古筝配乐（无对白）
【约束】面部稳定不变形，雨丝连贯
```

### 6.1 MiniMax H3 版（英文三字段）

见 §3.7 官方示例——该例正是本题按 H3 官方范式的成品。注意：动作与画面全英文，运镜用三轴写法（`trucks left with small amplitude at slow speed`），环境音与配乐拆进两个独立字段。

### 6.2 即梦版（中文语义顺序）

```text
古风，青瓦白墙的中式老巷，湿润的青石板路，
中雨，
一位身着白色汉服的年轻女子，墨色长发，撑着米白色的油纸伞，
固定镜头，镜头缓慢左移跟随女子，
女子沿着青石板路缓缓走来，裙摆微湿，远处一盏暖红色纸灯笼映在雨雾里。
```

### 6.3 Seedance 版（中文分段标签）

```text
古风写实电影感，5 秒。

主体：白色交领汉服女子，墨色长发绾成低髻，米白色油纸伞。
场景：青瓦白墙的中式窄巷，湿润的青石板路面，远处一盏暖红色纸灯笼。
动作：女子持伞缓步前行，裙摆微湿，回眸轻轻一笑，目光望向镜头外。
镜头：中景，缓慢左移跟随人物，景深浅，灯笼在背景虚化中泛光。
光影：傍晚天色，雨雾弥漫，软光，暖色高光 + 青灰阴影。
风格与画质：国风电影美学，4K 高清，稳定运镜，画面丝滑不卡顿，细节清晰。
约束：面部稳定不变形，人体结构正常，背景雨丝连贯。
```

**三端差异要点回顾**：H3 必须英文 + 字段名 + 运镜三轴；即梦是自然中文语序 + 官方中文运镜词；Seedance 是中文标签分段 + 景别运镜分开写 + 显式约束行。

## 8. 常见错误对照表

| 平台 | 致命错误 | 正确做法 |
|---|---|---|
| H3 | 一段不分段的大段落 | 按 `[Shot N]` 时间戳分段 |
| H3 | 上传参考文件但不声明作用 | Ref2VA 写 `subject_definitions` + `retention_analysis` |
| H3 | 声音需求自相矛盾（既要 BGM 又禁 BGM） | 三个声音字段各写一处，不需就 `N/A` |
| H3 | 想一镜到底却写了 Shot 1/Shot 2 | 一镜到底只保留 `[Shot 1]` |
| H3 | 用中文写画面描述 | 画面英文，仅对白/画面文字保留原文 |
| 即梦 | 堆古诗词、抽象形容词 | 官方五原则：简洁、具体、自然语言 |
| 即梦 | 给超出时长装不下的动作 | 按时长只写能完成的指令 |
| 即梦 | 要求精准生成画面文字 | 官方明确不适用于生成文字，避免 |
| 即梦 | 误用 `@Image1` 语法 | 即梦官方未公布引用语法，用首帧图入口 |
| Seedance | 运镜和景别混写一句 | 先"中景"再"缓慢推镜"，分开写 |
| Seedance | 先写外貌再写动作 | 动作最敏感，先动后静 |
| Seedance | 把 `NEGATIVE:` 当官方字段 | 用 `约束：` 行正面声明稳定性 |
| Seedance | 延长视频不写清秒数 | "将 @Video1 延伸 5 秒"，延伸 5 秒 = 生成 5 秒 |
| 通用 | 一套提示词原样喂三家 | 走 §2 八槽位 → 映射表翻译 |
