# 跨镜连续性与帧链法

锚句解决的是**单镜之内**的问题：这一镜里角色长相、服装、场景对不对。但观众感受到的"乱"几乎 always 发生在**两镜之间**：上一镜末帧和下一镜首帧不是同一个房间、不是同一台机器、色温撕裂、空间关系说不通。逐镜独立生成 + 每镜重贴锚句，只能把单镜做好，**镜与镜之间没有任何机制保证连续**——这是"分开来哪里都对，合在一起非常乱"的根因。

本 skill 在锚句之上补两层机制：**帧链法**（执行层，链内强制像素级连续）和**接缝审查门禁**（质检层，烧之前拦住错误）。

> **同场起点（2026-10-31，协议见 `AGENTS.md`「成片生成裁决」）**：新场次第一镜用过检资产做出的首帧或 Ref2VA，禁止纯文生图重锚。同场下一镜的起点必须是上一镜审核通过的末帧，或由该末帧修好的静帧，再做图生视频。禁止只贴角色卡把同场下一镜重新采样。这不是把多镜塞进一条低清 fl2v 链；段长和分辨率仍按技术资产的独立段画质档，末帧只充当下一镜的图像条件。

## 一、症状速查：你的片子是连续性病吗

逐条对照已生成的镜头序列，中两条以上就该走帧链法重烧：

| 症状 | 典型表现 |
| :--- | :--- |
| **房间瞬移** | 上一镜末帧还是木质客厅，下一镜首帧变成白墙公寓：门窗位置、家具、墙面材质全变 |
| **主角换人** | 同一角色跨镜脸型/发型/服装细节漂移；机体、怪物等复杂主体漂移更剧烈（"四台不同的机器人"） |
| **色温撕裂** | 相邻两镜一冷一暖、一高一低反差，剪辑点上出现"跳质感"（同一场戏内尤其致命） |
| **空间矛盾** | 门的方向开错、角色从 A 门进却从 B 门出、人物左右关系反转（越轴） |
| **物理错误** | 脚踩进地面下陷、道具换手、手指数量错、悬空无支撑、重力方向矛盾 |
| **黑洞镜头** | 个别镜头整段死黑或空无一物，剪辑节奏被打穿 |

**根因**：每次生成都是从当前 prompt 独立采样，模型看不到上一镜的结果；prompt 里写"same room as before"没有任何约束力。而运镜（推、拉、摇、跟）写得越多，模型在镜头运动过程中"重画"世界的自由度越大，漂移越严重。

## 二、帧链法：以上一镜末帧为参考，审核下一镜首帧

### 2.1 核心机制

对**支持首帧参考的视频模型**（i2v / 图生视频路线）：

1. 组内第一镜（**组首镜**）用一张精心设计的首帧图开烧。这张图必须从第 3 阶段过检的角色/场景资产**图生图**重锚（拿定妆照、场景图、机体转面图做参考图生成），**禁止纯文生图**——纯文生图的首帧本身就是漂移的源头。
2. 组首镜烧完后，立刻抽它的**末帧**。
3. 把末帧作为组内第二镜的**衔接参考**。先做接缝审查；若存在形变、脏帧、构图不适合起镜或状态冲突，先修复并保存为新的首帧资产。只有审核通过的首帧才能进入生成。第二镜的 prompt 第一段描述该审核首帧的真实状态，再把动作演到本镜设计终态。
4. 烧第二镜 → 抽末帧 → 审核/必要时修复 → 登记第三镜首帧……组内严格串行。

目标是让相邻镜头在身份、空间、状态、光色与运动方向上可验证地连续。若实现支持同源首帧，可提高连续性，但不能跳过人工/规则审核，也不能把带缺陷的尾帧直接向后传播。

> **衔接帧取动作中间态（2026-10-13 立）**：抽上一镜末帧给下一镜做衔接参考时，**优先取"动作进行到一半"的帧**（抬手抬到一半、转身转到一半、迈步中途），不取动作结束后的静止完成态；下一镜提示词相应写"继续……"而不是"开始……"。依据：① 经典剪辑的 cutting on action / match on action——剪接点落在动作中时观众注意被运动锁定、切点不可见（Wikipedia "Cutting on action"；Adobe 称 match on action 为 "invisible editing"；Smith & Henderson 2008 实验心理学证据 "edit blindness"）；② AI 侧工作流经验——Seedance 系教程对视频续接的要求即"角色处在同样位置、动作进行到一半，本镜把动作平滑延续"，社区实测工作流也是"截上段动作中间帧作下段首帧"。两条限定：a) 剧烈动作（打斗/高速运动）的中间态容易触发肢体变形，这类镜头宁可拆慢或硬切；b) 这是"显著改善接缝"不是"完美消除"，接缝两侧各裁数帧的后期微调仍是标准动作（官方文档亦承认帧对齐后可能有细微跳变）。与 §一.3（`04-视频生成/平台提示词契约.md`）"首帧不是完成态海报"同源，本条是它在中段衔接处的具体化。

### 2.2 分镜表要配合帧链法改写法

帧链法下，prompt 的时间轴描述分两段写：

- **首段（0.00 起）**：如实描述 `<首帧图>` 里有什么——这是上一镜的真实终态，写得越具体（主体位置、朝向、光线、道具状态），模型越不会重画。
- **后段**：动作从该状态演到本镜分镜设计的终态。时间轴合计必须等于本镜时长档位，节拍与分镜表一致。

同场回切（空镜或插入镜回到人物、正反打）用硬切，靠动作或视线咬住。禁止改写成「从空镜缓缓摇回，再推近到特写」——模型会在这段运镜里把空间重画一遍。镜内切只允许写在该生成段事先定好的机位切换上。协议见 `AGENTS.md`「成片生成裁决」。

组内如有**匹配剪辑**（同构图、反动作的两拍，如"机械手松开锁扣" vs "人手推回锁扣"），让 B 拍从 A 拍末帧经审核或修正后形成的批准首帧开烧：构图天然一致，只换光照与动作，剪辑点咬得最死。

**空间锚点四子项 + 衔接链闭合（分镜表强制块，2026-10-12）**：帧链法解决"视频怎么接"，锚点块解决"分镜怎么写才能被检查"。每镜在分镜表的锚点子块里填齐四项——**固定地标**（场景卡的命名地标 + 在本镜画面中的相对位置）· **人物位置**（以机位视角描述，不写抽象方位）· **退场人物状态**（离场者去向与状态，未退场写"无"）· **光位基线**（具名光源 + 方向/高度/软硬相对上一镜的变化）。衔接链闭合两条硬规则：① 同场次内上一镜 `镜后状态` 与下一镜 `镜前状态` 必须同指一件事（都非空、状态一致）；② 上一镜 `对下一镜约束` 填 `HARD CUT` 时，必须在同格给出 ≥4 字的硬切理由，不许裸 HARD CUT。场景间允许重锚（见 §2.3），但同场内链必须闭合。机检：`python tools/check_anchor_chain.py <项目目录>`。

### 2.3 场次边界：链在组内，场间允许重锚

帧链以**场**为单位：同一场戏内链下去；跨场是设计好的跳切（时间/地点变化），允许重新锚定首帧——这正是"组首镜重锚"的含义。如果场间跳跃太硬，把硬切交给第 6 阶段的**场间叠化**（见 `成片与字幕.md`），不要在生成层硬凑连续。

### 2.4 防漂移纪律（链内仍要遵守）

帧链锁住的是"起点"，镜头运动过程中模型仍会重画细节。组首镜之后的每一镜，prompt 里仍要：

- 重贴第 3 阶段定稿的**主体锚句**（角色/机体/场景的完整英文描述，一字不改）；
- 显式锁**容易被改掉的设计特征**（例：核心必须是球体不是平面镜头眼；圆肩甲；无额外装备）；
- 慎用大范围运镜：能推近就不全景横摇，运镜幅度越大漂移越多。确需大运动时（跟拍→上摇→推近的一镜到底），把运动拆成带时间戳的明确节拍写进 prompt。
- **15 轴逐镜比对**：面部 / 头发 / 服装（每层） / 道具 / 湿·脏·血 / 伤损·妆容 / 光线方向 / 时段 / 天气 / 地理 / 银幕方向 / 视线 / 机位高度 / 色彩调色板 / 镜头感。只写“保持一致”不算检查，要指出哪轴、朝向哪边变了、是否可接受。

### 2.5 生成段复杂度门禁

- 一个生成段默认只承载一个主动作目标和一条连续摄影机运动逻辑。
- 出现机位突变、主体切换、轴线重置、独立高潮或多个关键动作时，必须拆成多个生成段。
- 复杂运动失败时，优先拆动作与机位，再考虑降规格；不得用更长提示词掩盖超容量。

### 2.6 串行纪律

- **严格单线程逐镜**：烧完一镜、抽帧、看过、写下镜 prompt，再烧下一镜。提前批量抽帧没有意义（新镜还没烧出来），并发烧镜在多数本地/云端队列里只会超时或互相干扰。
- 烧一镜检查一镜：末帧抽出来目检（房间对不对、主体对不对、有没有物理错误），发现问题立刻重烧本镜再续链，**不要把错误传下去**——链上每一环的漂移都会传染给全组。

## 三、烧前接缝审查门禁（烧视频之前）

帧链法的组首镜烧完、组内链开始之前，先做一次**组首锚定审查**；每个组烧完后，做一次**组间边界审查**。两条门禁共用一张对图检查法：

> 抽"上一镜末帧"与"下一镜首帧"两张图并排目检，逐项过下面两张清单。**任何一项不过，不许烧/不许过，先修。**

### 3.1 连续性四项（对图检查）

| 检查项 | 通过标准 |
| :--- | :--- |
| 场景地理 | 门窗位置、家具陈设、墙面材质、地标一致；该在场的东西都在 |
| 主体一致 | 角色脸/发型/服装、机体造型、道具细节，两帧是"同一个" |
| 色温质感 | 冷暖、反差、颗粒感一致；跨场则确认差异是设计而非事故 |
| 站位关系 | 人物与场景、人物与人物的相对方位说得通，无越轴 |

### 3.2 物理逻辑清单（逐镜过）

| 检查项 | 说明 |
| :--- | :--- |
| 门方向 | 进/出门的方向、门轴开向、房间之间的方位关系，与分镜设计一致 |
| 肢体-地面接触 | 脚/物体**踩在地表之上**，有正确接触阴影；严禁下陷进地面（prompt 里显式写 feet planted firmly on top of the surface, correct contact shadows） |
| 重力与支撑 | 无悬空无支撑的物体；跳跃/坠落轨迹合理 |
| 手部与道具 | 手指数正常；道具在正确的手里/位置，不瞬移 |
| 人数 | 画面里只有该在的人，无多出来的路人/幽灵肢体 |
| 文字 | 画面内无可读文字（除非设计好的彩蛋），尤其警惕生成模型自造的标语/编号 |

### 3.3 黑洞与空镜检查

逐镜抽首/中/末三帧，任何一帧接近全黑且非设计黑场（设计黑场如"声音抽干"的静默点，必须在分镜表里登记过），即视为报废重烧。普通镜头也要保证末帧有可读信息，给剪辑留得住的落点。

## 四、何时值得重烧

- **单镜内瑕疵**（表演不满意、动作幅度不够）：重烧该镜即可，链从该镜重新接续。
- **连续性断裂**（本 skill 的症状表）：只修出问题的组，从组首镜重锚，组内全链重烧。不要去逐镜微调 prompt 碰运气——像素不同源的问题，prompt 层面修不好。
- **全片系统性重拍**（风格换轨、主角换设计）：全部组首镜重锚，全链重烧。旧镜整批归档 `_v1_archive/`，不覆盖、不删除。

## 五、与其他环节的关系

- 第 3 阶段（角色与视觉资产）：帧链法的组首首帧**必须**从过检资产图生图，资产没过检就别开烧。
- 第 4 阶段（视频生成）：首帧文件名、抽帧命名、串行队列按本 skill 的"一镜一抽一烧"执行；具体工具的调用方式登记在各项目的能力表，模板层不写死任何工具。
- 第 6 阶段（剪辑）：组内硬切已通过连续性审核；场间用 8–12 帧叠化、情绪点后加定格呼吸、声音用 J/L-cut 桥接，详见 `成片与字幕.md`。

## 六、首尾状态快照与有意断开

帧图只能证明画面外观，状态快照负责证明叙事连续。每个连续生成段至少记录：

| 类别 | 首/尾状态字段 |
|---|---|
| 角色 | 人物 ID、画面位置、朝向、姿态、表情、视线、左右手动作 |
| 场景 | 场景 ID/设计版本、CAM/时空状态、轴线、光源空间位置及本机位投影、背景关键物位置 |
| 道具 | 道具 ID/设计版本、持有者、左右手/接触部位、位置/摆放朝向、数量/缺件、开合/破损/亮灭状态编号 |
| 画面 | 景别、构图重心、运动方向、焦点、可见文字 |
| 声音 | 台词是否说完、环境声连续点、音乐节拍或停顿 |

下一段首状态默认逐项继承上一段尾状态。若故意不继承，必须标注：`有意跳切 / 时间跳跃 / 空间转换 / 蒙太奇 / 主观镜头`，并写明观众如何理解。

关键姿态变化和道具状态变化必须在画面中发生；不能让角色在段间从站立直接变成倒地、让道具无过程换手或消失。状态冲突时先修分镜/状态表，不用视频参数掩盖。

场景和道具的设计版本与剧情状态分开：同一资产开关、损坏或换手须有事件依据，但不自动换设计版本。总览/所需机位板、身份细节板及状态/交互图的组织与当前输入选择见 `03-角色与视觉资产/场景与道具资产.md`。
