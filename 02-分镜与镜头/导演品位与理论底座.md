> **体系定位**：本文件属于【短剧成片体系】`02-分镜与镜头/` 的**专项方法**，是"识别"与"推导"两件事的合一：§一–§四 给 Agent 一个可执行的**平庸识别**标准，把"感觉差点意思"翻译成具体可改的画面事实（适用 G3 分镜、G4 逐镜、G6 成片回放）；§五–§八 在没有现成参考、或需要在多个候选间做导演判断时，提供一套**有出处、可分级**的推导方式，替代"凭感觉"与"凭想象"。默认按需加载，不参与默认加载集。
> 来源分级：判断条目与推导结构**改编自**多个开源导演方法论（方法来源研究档不随本包提供），一律用本体系自己的中文重写，不建立字面继承关系；**不引用具体影片的镜头/台词/角色/情节**，只保留可独立论证的方法内核。画幅与数值基准随本体系权威默认（横屏 16:9 优先，竖幅 9:16 为备选分支），见 `导演视觉圣经.md`「画幅默认」。

# 导演品位与理论底座

## 〇、为什么需要这份文件（两半理由）

**第一半——平庸是系统默认。** Agent 生成的内容有一个**系统性偏向：中庸**。它不会拍得很烂，而是拍得"哪儿都对、哪儿都没劲"——构图挑不出错，光线挑不出错，就是没人想看第二遍。

原因不是能力不足，而是**没有一个模型天然会因为"安全"而受过惩罚**。平均、居中、对称、明亮、信息完整，是统计意义上的最稳解，也正好是最无聊的解。

所以 §一–§四 不写"要有美感"这类无法执行的话，只做一件事：**把平庸拆成可以逐条指认的画面事实**。每一条都写成一个问句，答案必须是你在首帧或回放里**看得见的东西**，不是感觉。

**第二半——没有参考时最容易编。** 手上没有参考画面、又必须在几个候选间做判断时，凭感觉与凭想象都会留下无法追溯的依据。§五–§八 提供推导与标注纪律：

1. **不编造**。不得虚构导演方法、影史论断、书籍论断或案例。说不清出处就把级别降到 `假定`，或直接标 `待查证`。
2. **标出处级别**。所有结论必须带级别（见 §六）。**`假定` 级不得作为普通承重规则**——可以用来试探，不可以拿来锁定一串方案。全片可以另留一处不写推断链的决定，只写在导演笔记里，并且只破一条已登记的闸。
3. **导演名不是模板**。以某位导演命名的方法，只在其出处能支撑**该条具体原则**时才可采用；否则不得写成"某导演风格"。真实影片的具体表达一律不进本体系。

> **这条最重要**：把"某导演就是这么拍的"当成依据，是最常见也最难查的伪依据。本体系只接受**可独立论证的技法原则**，不接受名人背书。

**用法**：G3 定稿前、G4 每 2–3 镜、G6 回放时各过一遍 §一–§四。命中任意一条不等于必须推翻，但**必须写明保留理由**；写不出理由就改。

> 一条纪律：**"说不上来哪里不对"不算通过，算未检查。** 说不出来就说明还没看清，回去逐条对。

## 一、平庸的六个签名（逐条指认）

### 签名 1 · 没有第一眼重点

- **问**：这一帧眯眼看，第一眼落在哪里？只有一个吗？
- **平庸的样子**：两个以上区域亮度/饱和度/面积接近，眼睛来回跳；或者第一眼落在空处（背景比人亮、道具比脸显眼）。
- **可改**：压暗次要区域、收窄景深、挪机位让主体独占一个小块高对比区。
- **对照**：`导演构图库.md` 的"第一焦点"条目。

### 签名 2 · 构图可以不用脑子就看懂

- **问**：把主体放在画面正中、抬高到水平线、完整入画，会不会更好懂？如果是——那就说明现在是安全的正解，也就是没有表达。
- **平庸的样子**：主体居中、水平线在中分位、人物完整、四周留白均匀。这没有错，但**它没有替内容做选择**。
- **可改**：按内容选一个不对称的落点。想表达"被挤压"就把人推到边角留出大片压制空间；想表达"失衡"就打破水平。
- **注意**：**不是必须斜构图**。对称可以是强表达（权力、仪式、宿命）。区别在于**对称是选来的还是默认的**——问自己"如果不是这个内容，我还会这么摆吗"。答不上来就是默认。

### 签名 3 · 光线没有来源

- **问**：这道光是从哪儿来的？画面上能不能指出光源本身（灯、窗、霓虹、烛、屏）？
- **平庸的样子**：人脸均匀明亮、方向不明的柔光、处处高光、没有阴影落点。观众说不出光从哪来，只觉得"挺亮的"。
- **可改**：给光一个具名来源；让人物进入或走出光束；用阴影落点交代空间。
- **对照**：`导演视觉圣经.md` 照明卡。
- **提示**：**"自然光"是合格答案，"来源不明的亮"不是。** 前者是选择，后者是缺失。

### 签名 4 · 画面里的事可以发生在任何地方

- **问**：把人物换到另一个完全不同的场所，这个构图/光线/道具还成立吗？
- **平庸的样子**：背景是通用虚化、道具不参与叙事、环境不约束任何动作。这场戏搬到哪儿都一样演。
- **可改**：让空间参与——门框切分层次、走廊限制走位、桌上物件成为视线落点或情节道具。
- **对照**：`导演视觉圣经.md` 卡 A 的"前景遮挡窥视感"、`02-分镜与镜头/跨镜连续性与帧链法.md`。

### 签名 5 · 动作全在"完成态"

- **问**：这一帧抓的是动作的哪一刻？**起始、中途，还是已经做完？**
- **平庸的样子**：动作已定格——手已经举起来、门已经关上、人已经站好、杯子已经放下。都是结果，没有过程。这是 AI 最典型的中庸签名。
- **可改**：抓动作中途（手到一半、身在半转身、表情刚变化的那两帧）；或者反过来，故意在动作前的静止里蓄力。
- **对照**：`02-分镜与镜头/机位与运镜.md` §八.2 呼吸感与真实瑕疵；`分镜工作流.md` §13.7.5 动作与台词配合。

### 签名 6 · 每个镜头的信息量一样

- **问**：这一刀给的信息，和上一刀比是更多、更少，还是差不多？
- **平庸的样子**：每镜都在交代"人在这里、在做这件事"，信息量平铺，没有轻重。观众不会累，但也不会被抓住。
- **可改**：按 `分镜工作流.md` 的"本刀新信息"列逐刀核；该给信息的刀给足，该只给反应/细节的刀把信息让出去。
- **对照**：`分镜工作流.md` §五 长短刀与转场接力（时长由内容定）——时长与信息量是同一件事的两面。

## 二、四个"看起来高级、实际平庸"的陷阱

这几项**观感上很像有品味，实质上是另一种默认解**，因为它们都是"加东西"就能做出来的。

| 陷阱 | 为什么它是平庸的 | 什么时候才成立 |
|---|---|---|
| **堆砌氛围词** | 雾、光晕、慢镜、颗粒全上，等于没有取舍 | 单一手段服务单一目的，且能说出为什么是它 |
| **每镜都要炫** | 全片高能＝全片无高能，观众会疲劳 | 遵循"一场一技"；炫技点前后留静 |
| **全片一个色调到底** | 统一 ≠ 单调；没有变化就没有情绪曲线 | 按色彩脚本分段变化，峰值与低谷不同 |
| **不断切镜制造节奏** | 快切只制造焦虑，不制造节奏；节奏来自长短对比 | 长刀短刀混用，重要的给长 |

> **共同点**：它们都是**可用手段的默认全集**。有品味的选择是**敢于不用**——该静的时候不切，该暗的时候不亮，该简单的时候不炫。

## 三、正向基准：什么时候算"有选择"（正向四问）

---


以上都是排除法。正向只需问四个问题，**四问都能答，就算这一镜有导演意图**：

1. **观众此刻该看什么？**（焦点，唯一）
2. **观众此刻该知道什么、不该知道什么？**（信息，含刻意隐藏）
3. **观众此刻站在谁那边？**（立场，机位高度与距离即立场）
4. **这一镜结束后，观众的情绪比上一镜高还是低？**（曲线，不能平）

第 4 问答"一样"就是节奏失败，即使单看每一镜都很漂亮。

> **与 §七 的"反默认四问"不同**：本节的四问是**正向**的（有选择长什么样），§七 的四问是**反向**的（怎么证明当前方案不是默认解）。两套一起过才算完整。

## 四、可复用的替代清单（平庸 → 有选择）

---


不确定怎么改时，按内容从下表挑一个**方向**，不要全上：

| 平庸做法 | 有选择的替代方向 | 适用 |
|---|---|---|
| 人物居中完整 | 推到边角并留出压迫空间 / 用前景遮挡切层 | 权力、压抑、孤立 |
| 均匀明亮 | 具名光源 + 半明半暗 / 人物在光里走 | 情绪、对峙、内心 |
| 通用虚化背景 | 让环境元素参与构图或叙事 | 空间叙事、地域感 |
| 动作完成态 | 抓动作中途 / 蓄力静止 | 打斗、转折、揭穿 |
| 每镜平铺信息 | 建立镜给足，反应镜只给情绪 | 通用 |
| 平铺直叙的对话 | 反打 + 反应镜头经济学 + 压迫留白交替 | 文戏（见 `分镜类型特则.md` §六–§七） |
| 全片统一色调 | 分段色彩脚本，峰值/低谷区分 | 通用 |

## 五、七维判断支柱（从"要什么效果"推导"怎么拍"）

不按导演名切分，按**技法维度**切分。遇到"这场戏该怎么拍"时，逐维过一遍，能回答的维度就有依据，答不出的维度就是风险点。

| 维度 | 要回答的核心问题 | 落到哪个产物 | 常见失效信号 |
|---|---|---|---|
| **① 导演意图** | 用一个概念能不能统一这场戏的所有选择？ | 风格提案的"核心不可协商效果" | 说不出统一概念，只有一堆好点子 |
| **② 影片形式** | 倾向呈现还是叙事？观众是在"看发生的事"还是"被人讲给听"？ | 分镜的整体处理方式 | 时而极度写实时而极度风格化，无理由 |
| **③ 表演逻辑** | 给演员的是**动作**还是**结果**？ | 分镜的表演提示 | 写"她很伤心"（结果）而不是"她不看对方、手指抠住衣角"（动作） |
| **④ 剪辑逻辑** | 这一刀为什么现在切？ | 分镜刀型与"本刀新信息" | 切点等距，或仅为"换个角度"而切 |
| **⑤ 声音逻辑** | 观众听到的是现场声、主观声还是被削减的声音？ | 声音清单与音效提示 | 全程只用环境垫底，声音不参与叙事 |
| **⑥ 信息逻辑** | 观众何时知道什么？悬念是"知道有危险"还是"突然被吓"？ | 分镜的信息释放顺序 | 所有信息一次给完，之后无张力 |
| **⑦ 身体化逻辑** | 情绪有没有变成**物理事实**（天气、距离、物件、动作）？ | 画面内容与动作设计 | 情绪只在台词里，画面里什么都没发生 |

### 剪辑维度的权重参考

判断"这一刀该不该切"时，多个来源的通行结论都指向**同一个优先级**（此处只记结构，不记某家数值）：

1. **情感**——最高优先。这一刀是否服务情绪？
2. **故事**——是否推进情节？
3. **节奏**——是否在最恰当的时刻（"right moment"）？
4. **视线**——观众此刻想看哪里？
5. **二维平面**——画面内的空间关系是否连贯？
6. **三维空间**——空间立体的合理性（最弱）。

**用法**：当两条冲突时，**取序号小的**。例如画面连贯性（5）与情感（1）冲突时，保情感。

> 画幅注意：短剧切点极短（1–8 秒），前三项权重进一步放大。第四项（视线）在**两种画幅都**容易违反；竖幅 9:16 画面窄、可容纳的参照物少，观众更难自己补出空间关系，**竖幅下"视线"要比横屏更当心**。本体系画幅默认见 `导演视觉圣经.md`「画幅默认」（横屏 16:9 优先）。

## 六、三档标注法（防伪依据）

任何导演判断写进产物前，标注其级别：

| 级别 | 含义 | 可否作为承重规则 |
|---|---|---|
| **`已核实`** | 有明确出处（官方文档、本机实测、可查证的公开方法论条目） | 可以 |
| **`推断`** | 由已核实结论合理外推，逻辑链可复述 | 可以，但要写明推断链 |
| **`假定`** | 无出处，属于经验猜测或风格偏好 | **不可以**当作普通锁定依据。全片可以另有一处不写推断链的决定，只写在导演笔记「一处不可解释的决定」里，并且只破 `hook收尾`、`静止比例`、`色彩情绪` 中的一条 |
| **`待查证`** | 曾被这样说过，但当前无法核实 | **不可以**。不得当结论使用 |

**与体系既有分级的对应**：本文件三档用于**导演判断**；能力/实现的证据分级仍按 `04-视频生成/平台提示词契约.md` 与 `AGENTS.md` §八.6 执行。两套并存，不互相替代。

**写法示例**（注意不是抄结论，是抄格式）：

```text
判断：这场对峙用低机位。
级别：推断
推断链：低机位让对象显强大[已核实：通行技法条目] → 本场内容是弱势方夺取主动[剧本] → 因此观众应被压在弱侧视角。
保留理由：若本场改为"弱势方被彻底压制后反打"，则应改高机位。
```

**没有"保留理由"的判断不算完成**——它意味着你没考虑另一种可能。

## 七、反默认自检（四问）

在有把握之前，先证明**当前方案不是因为"最省事"才被选中的**：

1. **如果我的第一直觉是这个方案，第二个方案是什么？** 说不出第二个＝没比较过。
2. **这个方案是不是"不需要理由也对"？** 是＝它是默认解，不是选择。
3. **如果我把它反过来做，会不会也很好？** 会＝说明它本来就不承担表达。
4. **我能说出"不这么拍会损失什么"吗？** 说不出＝这条判断没有承重作用。

四问全过＝有依据。任一条答不出，回到第一节逐维检查，或明确标注为 `假定` 并说明是试探。

> 与 §一–§四 配合使用：那一半负责**识别平庸**，本节负责**推导替代**。

## 八、什么时候用推导层

**应该用**：

- 拿到题材但**没有任何参考**，需要自己推导导演方案
- 有 **2–4 个候选**方案，需要在它们之间做判断
- 某个镜头反复重抽不成，需要**换推导路径**而不是继续重抽
- 争议点：有人（或自己）认为"应该这么拍"，需要判断依据是否成立

**不必用**：

- 已有明确参考画面（直接用参考，不要用理论覆盖实证）
- 属于能力/实现问题的（那是 `AGENTS.md` 能力路由，不是导演判断）
- 纯执行细节（格式、命名、参数——`AGENTS.md` §九 由 Agent 自主决定）

> **纪律：参考优于理论。** 手上有一张真实参考画面时，以参考为准；理论用于**在没有参考时生成候选**，以及在参考之间做取舍。不得用理论推翻已实际查看的参考。

## 九、与体系其他环节的关系

- **本文件不定义风格**。风格基线（九张卡）在 `导演视觉圣经.md`；本文件只在**任何风格下**判断这一镜是不是平庸，并给出没有参考时的推导方式。
- **本文件不定义怎么摆机位**。具体调度在 `机位与运镜.md`；本文件负责指出"这里有问题"、以及"没有参考时怎么推"，那份文件负责"怎么改对"。
- **本文件不替代机器闸门**。机器检查通过 ≠ 艺术质量通过（`SKILL.md` 第四节）。本文件是人工/Agent 目检的判断依据，不能被 `run_all_checks.py` 全绿替代。
- **不通过时必须走回退链**：本文件判定不通过，按 `AGENTS.md` 第五节回退链处理（质量重抽 ≤2 次，之后进 B–E 步），不无限重抽。
- **不重复导演判断的落地位置表**：八个维度的落地位置唯一维护在 `07-端到端管线/生产证据与片型路线.md`"主动导演判断与前置风险预检"，本文件补充的是**推导纪律与出处分级**，不再复制一张落地表。
