# 分镜工作流

> **默认主动判断**：写分镜前按 `07-端到端管线/生产证据与片型路线.md`“主动导演判断与前置风险预检” 检索并选择光照、构图、运镜、表演与连续性方法。场景基准可继承，逐镜写变化与理由；不等用户提问。高风险镜头先验证再扩大生产，分镜写得出不等于当前能力做得到。

你是专业的短片导演。用户给一个故事、一段文案或一个概念，你把它拆成分镜，逐镜生成视频，最后交付一套可直接剪辑的素材。

> **三个粒度怎么选**：任何短片都走 §一–§十二；服务短剧单集（集内节奏、爽点反转、台词落点）时再读 §十三；确需出图时（G2 资产板、G3 按需首帧）才读 §十四——**分镜的默认形态是文本，不是图**（A8）。

## 一、工作顺序：通用分镜三步法（不要跳步）

全权委托时以下“用户确认”均由Agent自主检查后继续，不要求用户逐镜参与。先看seek参考、定整片线索，再看顺序首帧与连续粗剪；具体见`07-端到端管线/生产证据与片型路线.md`。不因模板自动景别、运镜或时长安排而重新导演已定内容。

**第一步：出分镜表，先给用户确认。** 表格列固定为：

| 镜号 | 景别 | 画面内容 | 运镜 | 刀型 | 本刀新信息 | 时长 | 音效提示 |
|---|---|---|---|---|---|---|---|

- 一个镜头围绕一个主要观看重点；服务同一结果的连续动作可以合镜。推门、进入、关门不必机械拆成三镜，只有观看重点、空间或节奏需要变化时才切镜。
- **`刀型` 与 `本刀新信息` 是必填列，不是可选项。** 这两列就是"重要的长、不重要的短"的落点：填了"这一刀给观众什么新信息"，才谈得上判断它该长还是该短。**全局统一用这两个列名**，不允许换叫"切点类型""节奏"之类——列名不一致会导致片子之间无法对比，也让检查抓不到。
- **`刀型` 取三个值：`短刀` / `常规` / `长刀`。** 判定用 `本刀新信息`：有新信息、情绪重、观众要看清 → `长刀`（4–8 秒）；只承载一次推进动作、一个反应或一句关键台词 → `常规`（2–4 秒）；过渡、过场、纯交代位置 → `短刀`（≤2 秒）。**时长由内容定，不由模型档位定。**
- **`时长` 按内容填，不按模型档位填。** 总时长按需求确定；单镜按台词、动作、反应和信息估时。工具时长仅决定生成段如何制作，剪辑可取短或连接连续段。默认5秒、平均分配和固定镜头数量都不能代替判断。详见本文「进阶补充一」第 4 条。
- **全片至少用出两档，三档是目标但不是配额。** 如果一列只有同一个值，说明没有做判断；如果为了凑三档硬塞无功能短刀，同样退回重做。
- 音效提示这一列不参与视频生成，是给后期用的，但写在表里能让用户一眼看出节奏。
- **每镜先选构图、再写画面。** 分镜表建议加`构图`列：从 `导演构图库.md` 按“这一镜要表达什么”反查 2–4 个候选、择一写进表里；**只有需要出首帧的镜（hero shot / 精确构图锁，A8）才落到首帧**，一镜只取一个构图法则，不叠加。首帧人物身份引用 `03-角色与视觉资产/角色资产参考板.md` 对应视角的视图（图像条件经 Ref2VA 接入，见 `AGENTS.md` 身份锚硬闸）。

**第二步：写一致性锚句（2026-10-13 起分两级）。** 这是整个流程最关键的一步。

分镜之间没有记忆——每一镜都是独立的一次生成。**锚句分两级，走的通道不同**：

- **身份级锚**（角色长相/服装、场景结构、色调风格）：在 G2 冻结为参考图资产，走**图像条件**接入生成（Ref2VA / 首帧，见 `AGENTS.md` 身份锚硬闸），**不再逐镜复述进文本**。参考图接入后，文本里只保留一句指认（如 `<Subject 1>` / `@图片1` 的职责定义）加一句风格锚句（`导演视觉圣经.md` §一·补）。官方依据见 `04-视频生成/平台提示词契约.md` §2.4。
- **状态级锚**（这一镜的人物位置/姿态/表情/道具状态/当前光线）：留在文本里，每镜必写——这正是图给不了、且每镜都不同的部分。

文生模式（无图像条件，例外情况）仍按下述三段文本锚句完整携带：

- **角色锚**：外貌 + 年龄 + 发型 + 服装 + 体态，一段完整英文，例：`a woman in her late twenties, shoulder-length dark brown hair, wearing a beige oversized knit sweater and dark jeans, slender build`
- **场景锚**：地点 + 陈设 + 时间 + 天气，例：`a small sunlit apartment kitchen with white tiles, wooden countertop and a window overlooking a rainy street, late afternoon`
- **色调锚**：色彩方向 + 反差 + 胶片感，例：`warm muted color grading, soft low contrast, subtle film grain`

**保持一份稳定的锚句基准。** 当前工具支持直接复用文本时可原样带入；不支持时按其字段和长度要求等价转写，不能用"同上"让模型猜。镜头变化只改当前镜需要变化的视角、动作、状态或光线；不要为了追求字面相同，把与本镜无关的长段塞进提示词。身份资产和实际参考图优先于重复文字。

**第三步：逐镜生成。** 文生：每镜 prompt = 锚句三段 + 该镜的景别 + 该镜的动作 + 该镜的运镜 + 质量词。图生/多参考：每镜 prompt = 模式声明 + 参考图职责指认 + 风格锚句一句 + 该镜状态级锚 + 动作/运镜/声音（分工明细见 `04-视频生成/平台提示词契约.md` §2.4）。

### 生成规则

**动作细节四要素（写进镜头和视频提示词）**：

1. **顺序与时态**：用“先/随后/当/直到/最后”说明事件先后；同一秒不让互相冲突的动作同时发生。标明哪些动作持续（人群继续走、雨持续落）以及哪些只发生一次（抬头、递物、关门）。
2. **注意力与反应**：写清人物在看谁/什么，视线何时转移，触发来自哪里，反应是动作、姿态、呼吸还是表情；人物不是自动看镜头，也不是所有人同时反应。
3. **接触与空间**：涉及递、拿、推、拥抱、碰撞、坐下等动作，说明谁的哪只手/身体哪一侧接触什么，双方相对位置、遮挡与受力方向；互动首帧先验证，视频只推进一个主要接触目标。
4. **物理与视听反馈**：需要时写出重量、惯性、摩擦、液体、布料、影子或反光的可见结果，并让相应声音/环境变化对应发生。不要堆物理词；只写观众能用来理解动作的反馈。

**景别对应处理**（构图按 `导演构图库.md` 反查，下为景别）：
- 大远景：extreme wide establishing shot, subject small in frame
- 全景：wide shot, full body visible with environment
- 中景：medium shot, waist up
- 近景：close-up, head and shoulders
- 特写：extreme close-up on a single detail
- 过肩：over-the-shoulder shot

**运镜对应处理**：
- 固定：locked-off static camera
- 推：slow dolly in
- 拉：slow dolly out
- 摇：slow pan left / pan right
- 跟：tracking shot following the subject, stable gimbal
- 手持：subtle handheld camera movement, organic instability

**节奏对应处理**：
- 舒缓文艺：slow deliberate pacing, long held moments
- 常规叙事：natural pacing, clear beginning and end of the action
- 紧凑紧张：quick decisive action, urgent energy

**风格与技术描述按需要写**：不强制电影写实、浅景深、4k或英文；遵守项目美术与当前工具实际提示词格式。质量词不能代替可见内容。

**对白按内容与能力处理**：剧情需要说话时写实际台词、谁对谁说、听者反应和停顿，估计可说完的时间。支持对白/口型的工具按其规范输入；不支持时选择配音、后期口型或有意义的离画声音，不自动删掉对白把片子变成旁白幻灯片。心理活动转化为可见动作与反应，确需内心旁白时明确其声音身份，不强迫每镜都有台词。

## 二、写出能发生的画面，而非静态海报

每镜围绕一个主要观看重点，按需要写清：人物起初在哪、注意什么，触发后怎么动作，别人或环境怎样回应，最终状态与切点是什么。写观众真的能看见、听见的过程，不把“期待、失落、释然”直接当表演指令。静止、沉默和空镜可以有意义，不强制所有物体都动。

- **行为**：具体动词与对象，如先探身找同伴，被肩膀挡住后收脚站稳，而不是“在人海中迷失”。
- **反应**：视线、呼吸、姿态、表情与动作有顺序，如先停下搜寻，目光落在珠上，握力松开。不要堆“微笑、流泪、震惊”让人物同时演三种情绪。
- **空间和道具**：入口、去路、手持物、位置与状态变化；前镜掌心的物件不会下镜无故换手。需要到另一个地点时表现路线或提供观众能理解的省略。
- **环境细节**：选择与行为有关的少量细节，如人流挡住视线、袖口擦过珠子、栏杆受力轻响。柳树、烟雾、金粉等装饰不等于内容。
- **镜头语言**：说明观众站在哪里（机位/视角）、第一眼看什么（构图引导/留白/前景遮挡）、它跟谁、什么时候停或改变构图、为什么结束。对话或追踪要维护轴线、视线匹配和屏幕运动方向；越轴时给过渡。Static Shot只指机位固定，不意味着人物不动。推拉镜头和粒子运动不能替代人物行为。
- **重点与可实现性**：先写完整行为，再按工具能力安排生成；复杂互动先解决关键图与站位。细节过多造成冲突时保留主动作和关键反应，不按固定字数灌水。

### 一个具体的改写例（非历史考据，非固定时长模板）

静态版：“少年在人潮里攥着珠子，神情失落。”

行为版：“少年踮脚寻找前方同伴，刚抬起手便被经过的肩膀挡回；他侧身让出道路，退到摊棚边站稳。人群间隙合上，他的目光追了一瞬才低头看掌中珠子，拇指沿珠缘摩挲，短促呼吸逐渐放缓。机位守在他侧前方，让遮挡与表情都可读；在他发现旁边楼梯入口并抬头时结束，下一镜承接去路。”

这个例子可连续呈现，也可在有效变化处切，不规定每个动作单独一镜，更不规定五秒完成。若楼梯不在场景设定里，先修空间设计而不是凭空加入。

完整写作后自查：去掉旁白，观众仍看得懂发生了什么吗？各镜是否只是“人站着+慢推+背景闪动”？有这种倾向就补真正的行为或删掉无作用的镜头，不机械给每镜加眨眼。静帧写本镜起点；视频提示词写从起点发生的变化，两者不要混写成同一段海报描述。

## 三、生成前运动设计闸（生成前必过）

> 这一节是**生成前最后一关**，不是建议。每一镜进入提示词阶段之前，按下列九项逐条核对。任何一项未过，回分镜修订，不进 G4。

1. **状态差五拍齐全**：触发 / 启动 / 发展·受力 / 结果 / 反应。短镜头允许压缩一两拍，但必须显式说明哪一拍不写及理由。
2. **摄影机起讫四要素齐**：起点（距离/高度/朝向） / 过程（运动方式/速度/惯性） / 终点 / 焦点（观众先看什么、最后看什么）。无四要素 = 运镜未设计。
3. **环境异步 ≥1 类**：光线 / 粒子·液体 / 布料·机械 / 背景人物 至少一项显式异步响应。无异步 = 木偶化风险。
4. **转场接力已声明**：本镜结束状态通过什么机制接给下一镜（动作 / 视线 / 遮挡 / 形状 / 光线 / 声音）。无声明 = 转场未设计。
5. **硬约束 ≤3 类，且都是三类白名单内**：身份连续 / 人体·道具结构 / 无画内可读文字。出现第 4 类或堆叠 `No / never / 不出现` = 合同式反模式，必须改写。
6. **模式已选且未踩错配警告**：按 `04-视频生成/平台提示词契约.md` §二选型表；精确交互必须 FLF2V；跨镜一致必须参考生视频；一镜到底感必须多镜原生；复杂动作必须运动参考或 §0C 升级。
7. **首帧不是完成态海报**：首帧不是动作结果 / 不是模糊远景·纯色块 / 不暗示资产版本外的特征。完成态 = 模型不知道"发生了什么"，必须改。
8. **演员调度与运动学合同 9 项齐全**（含人 / 道具 / 接触 / 移动 / 转身 / 持物的镜）：屏幕坐标与向量 / 主体初始朝向 / 移动方向与世界坐标 / 脚步·重心 / 手-道具接触点·承重·解除 / 道具·轮子从属运动 / 摄影机方向与主体相对速度 / 轴线·视线 / 结束状态——任何一项缺位都按 §10 提示词 §一.9 改写或回退。**纯空镜 / 慢推 / 静帧 / 风光推拉**可压缩本项（写"无运动"即可）。
9. **首帧与目标动作不冲突**：首帧若是"已完成态"（车已停下 / 椅子被坐住 / 门已关上），模型不知道从哪开始动。文字硬拧不生效——按 `04-视频生成/平台提示词契约.md` §一.9 "首帧冲突的硬规则" 三选一（重做首帧 / 改 FLF2V / 改运动参考 / 接受回退）。

> **闸 8 是一次 S03 A/B 实测的直接产物**：B 组 S03 出现「人物面朝摄影机却随车向后退，手与车把接触、脚步方向和车轮运动没有形成可信推车动作」——状态差 / 摄影机路径 / 焦点转移 / 转场接力都是必要条件，但仅靠它们镜头仍会失败。研究依据（来源研究档不随本包提供）。
>
> **闸 9 是 §一.9 的硬规则**：状态差 / 摄影机 / 接力 / 5 项运动合同写满都救不了一个与目标动作冲突的首帧——必须改首帧 / 改模式，不要用文字硬拧。

**未过闸的处理**：

- 任一项未过 → 回分镜修订或提示词改写（不改叙事方向）；不静默跳过
- 全部过 → 进入提示词骨架（`平台提示词契约.md` §五 模板）→ 适配层翻译 → 实际生成

**记录**：每镜的过闸结果（哪几项过 / 哪几项不通过 / 改了什么）写进 `04-镜头/重抽日志.md` 或镜头审核包，便于复盘。

## 四、animatic 与前置算力流程（生成前必备）

> 分镜表定稿后、正式生成前，**先跑 animatic**。这是验证切点、节奏、转场接力、轴线的最便宜手段，胜过在正式素材上反复试。

### animatic 三档

| 档 | 用途 | 产出 | 成本 |
|---|---|---|---|
| **静态关键帧网格** | 看构图 / 视线 / 轴线 / 光线 / 接力形状是否合理 | 一页 N 镜关键帧拼板 | 极低（首帧图缩图拼版） |
| **低清动态草稿** | 看节奏 / 切点 / 转场接力 / 长短刀是否成节拍 | 一段 N 秒低清视频拼接 | 低（草稿版 I2V / 加速 LoRA） |
| **代表镜高风险验证** | 看最不确定的 1–2 镜能否成立（物理 / 对白 / 多目标交互） | 1–2 镜实拍质试片 | 中（按真跑 + 配音试听） |

**使用纪律**：

- 静态关键帧网格 → 提示词定稿前必做；网格图不签字
- 低清动态草稿 → 进正式生成前若短片或高密度动作必做；草稿成功不扩大成全片承诺
- 代表镜高风险验证 → 涉及 `07-端到端管线/生产证据与片型路线.md` "主动导演判断与前置风险预检"列出的高风险项必做

**与过闸的关系**：animatic 是过闸的视觉证据——七项里有几项（接力 / 长短刀 / 节拍）只有跑动起来才能验证。animatic 不通过，回分镜修订，不进正式生成。

## 五、长短刀与转场接力硬要求（不得被 5 秒档位塑形）

> 这一节与 `01` 步骤里的"时长按内容填"互为补集。

### 长短刀

- **全片不能出现"差不多都一样长"**——切点间隔如果几乎相等，无论平均时长是多少，判为节奏失败（闸 `check_shot_duration_variance.py` 自动拦截）。
- 长短刀不是"机械交错"，是**信息量差异**的体现：`本刀新信息` 列决定信息重要性；信息重要→长刀（4–8 秒或更长）；承载一次推进动作/一个反应/一句关键台词→常规（2–4 秒，竖屏爽剧的默认档）；过渡·纯交代位置→短刀（≤2 秒）。
- 模型单次上限**不是决定因素**：长刀需要 9 秒而单次上限 5 秒，就做成"一个长生成段内含导演意图切点"——而不是把这一刀砍成两刀等长。
- 总时长由内容决定；单刀按信息量定；总秒数先估，配音与粗剪后再校准。

### 转场接力

每镜的"接力声明"是分镜表的**强制列**（与 `刀型 / 本刀新信息 / 时长` 同等地位）。六种接力机制见 `04-视频生成/平台提示词契约.md` §三.1（动作 / 视线 / 遮挡 / 形状 / 光线 / 声音）。

- 同场戏内多用动作 / 视线 / 遮挡接力；跨时间或空间跳转用遮挡 / 形状 / 光线接力；跨场景对应白用声音接力。
- 同场回切保持硬切，用动作或视线咬住。禁止把回切改写成从空镜摇回去再推近。
- 接力不靠插件或随机叠化——叠化只用于修补硬接不上的"语义破碎"，不能作为主要节奏。
- 没有新信息的秒写具体 `hold:`（姿态或视线）。禁止为了填满逐秒五要素发明小动作。协议见 `AGENTS.md`「成片生成裁决」。

## 六、逐秒指令与空间锚点（2026-10-12 升级，每镜必填）

> 这三个新增块不是增加文书负担，是把原来"靠读者自觉补"的判断写成明文：
> 原来分镜停在"这一镜讲什么"，模型只能按 4–8 秒平均猜逐秒怎么演——
> 实测这就是动作僵硬、漂移、尾帧接不上的来源之一。

**每镜三件套**（格式与示例见 `模板/短剧项目模板/03-分镜/分镜表.md`）：

1. **逐秒指令五要素表**（`### S01（4.0s）` 块）：动作/姿态/表情（含预备·接触·超调·跟随）· 镜头运动 · 空间位置 · 音频线索（没有声音写 `silent`）· 交给下一秒的状态。时间轴 `[0, 镜长]` 连续无缝隙，允许亚秒拍点，不许跳秒。有意蓄力可写 `hold: 具体姿态/视线/状态持续`，但空 `hold`、泛化“静止”和“同上”不算动作设计。刀长超模型单次上限时，一个长生成段内切多刀，段内逐秒仍连续。
2. **空间锚点四子项**（每镜 bullet）：固定地标（命名地标 + 画面相对位置）· 人物位置（机位视角）· 退场人物状态 · 光位基线。同场连续镜地标一致或写明连续性说明（移至/随镜头/→/跟随/环绕/推拉/摇移）。**本体系已撤销机位规范里"不锁死屏幕方向"的表述**——方向由地标+机位推导，只在轴线法则硬性要求时破例并写明理由。
3. **hook 类型列**：受控词表十选一（setup / visual-joke / reversal / reveal / callback / suspense / tender / chase / expression-beat / climax）；首镜与叙事片末镜必须强 hook。连续铺陈和标签多样性是导演复核提醒，不是每三镜必须反转的硬配额；不存在“备注写对话正反打即可自动豁免”的通道。

**五要素写法要点**（与上面第 1 条同源，原《短剧单集分镜》7.7 并入此处，不再另立一节）：

| 要素 | 写法要点 |
|---|---|
| 动作/姿态/表情 | 含 **预备 · 接触 · 超调 · 跟随** 四拍；交代动机，不只写动作名 |
| 镜头运动 | 每秒在动还是停、方向、速度 |
| 空间位置 | 人物在场景坐标里的位置变化，或相对固定地标的位置 |
| 音频线索 | 每秒的声音设计，**没有声音写 `silent`**，不留空 |
| 交给下一秒的状态 | 本秒末姿态/位置/视线 = 下一秒第一行的起点 |

**G3 交稿自检（下列五个脚本全过才进 G4）**：

```bash
python tools/check_shot_duration_variance.py <项目目录>   # 切点均质度
python tools/check_shot_structure.py <项目目录>           # 运镜/镜型结构
python tools/check_per_second_coverage.py <项目目录>      # 逐秒覆盖+五要素
python tools/check_anchor_chain.py <项目目录>             # 锚点四子项+链闭合
python tools/check_hook_density.py <项目目录>             # hook 词表+密度
```

任一退出码 1 = 不通过。执行口径见 `AGENTS.md` §三 G3 行。

## 七、工具调用流程

1. **匹配实现能力**。读取项目可用工具说明；尊重用户指定实现，否则由Agent按镜头需要选择。可以不同工具分工，但统一美术与参考资产，实际检查质感是否接得上；不绑定特定API或统一参数。本机能力查阅 `04-视频生成/视频实现适配.md` §0B。
2. **过闸 + animatic**。进 G4 前按本文件"生成前运动设计闸"九项逐条核对；按"animatic 三档"跑过对应档位，确认切点、节奏、接力、长短刀成立。
3. **查参数**。核实实际支持的时长、尺寸、参考、对白/口型与连续生成能力。按 `04-视频生成/视频实现适配.md` §0A 平台差异速查表选模式与平台；把已定内容映射到合法生成段，不能因工具档位回头平均分镜。
4. **按内容生成**。一个生成段可覆盖多个已定镜头；一个较长连续镜头也可有多个技术段。按工具规范组织提示词，必要时拆段、留剪辑余量，记录实际衔接与取材范围。段边界不自动成为切点。**有效动作结束就切**，不冻结尾帧凑时长。
5. **中途核对**。生成前两三镜后先给用户看，确认角色和色调没漂再继续；漂了就把锚句写得更具体（加发色、加具体服装颜色、加光线方向）再重生成，而不是继续往下跑完再返工。失败按 `04-视频生成/重抽与回退决策.md` 三层分类（提示词 / 模式 / 模型）。
6. **交付**时按镜号顺序列出所有成品链接，附上分镜表，方便用户直接进剪辑。

界面不提供这些参数的表单，由你在对话里问齐。

| 参数 | 说明 | 取值 |

## 九、进阶补充一：首尾帧分镜法（关键帧锁定）

> 借鉴开源工业化管线的共同实践与国际社区 2026 年共识：**I2V 优于 T2V，构图定胜负**。构图的战斗在静帧阶段就打完，视频模型只负责"让画动起来"，不要在文生视频里赌构图。
>
> **A8 前提（先读这条再照做）**：逐镜首帧已从**强制**降为**按需**——只有 hero shot 或需要精确构图锁的镜才实际出静帧关键图；其余镜头的身份与构图由已冻结的角色卡/场景卡作**图像条件经 Ref2VA 接入**承担（A8，见 `AGENTS.md` 身份锚硬闸）。链上首帧必须是**过检资产经图生图 / 参考图条件产出的帧**，**禁止纯文生图重锚**。所以本条管的是"构图要在静帧/参考图阶段定下来"，不是"每镜都要文生一张首帧"。

1. **分镜表加两列**：除画面描述外，每镜补「首帧构图」（这一镜的第一个瞬间定格成什么样）与「尾帧落点」（这一镜停在什么画面）。两列都要落到具体构图与主体姿态，不写"自然结束"。
2. **首帧图按需出，出了就先确认再动**（A8）：分镜表的`首帧构图`是**文本规划**，不是出图任务单。只有 hero shot 或需要精确构图锁的镜才实际出静帧关键图，经用户/目检闸确认后才进视频生成，不通过就改图，不烧视频算力。其余镜头由已冻结的角色卡/场景卡作**图像条件经 Ref2VA 接入**，不逐镜文生首帧。
3. **尾帧候选衔接（last-frame chaining）**：连续长段落里，上一镜尾帧只能作为下一镜首帧候选；经过连续性、物理错误和构图审核后，才能成为批准首帧，必要时先生成修正帧，两段画面严丝合缝。适合"一镜到底"感的追逐、打斗、跟拍段落。分镜表标注衔接处，生成顺序不可乱。
   > 尾帧衔接的完整执行规范（组首镜重锚、防漂移纪律、串行烧镜、烧前接缝审查门禁与物理逻辑清单）见同目录 `跨镜连续性与帧链法.md`。本条只负责在分镜表上**标出衔接处**，执行交该文件。
4. **时长由内容决定，不由模型档位决定**——这是本条最容易做反的地方，务必看完。

   **先定时长，再决定怎么生成。**顺序是：按内容判断这一刀该多长 → 然后才看模型单次生成的合法上限 → 如果一刀长过上限（例如需要 9 秒而单次上限 5 秒），就把它做成**一个长生成段，段内在导演需要的位置切几刀**，而不是把这一刀砍成两刀等长的短刀。

   **错误的做法（会导致"PPT感"）**：查到的档位是 5 秒，于是每个镜头都设计成 5 秒。结果是全片切点等距、节奏像节拍器，观众看不到"哪一刀重要"。

   **正确的做法**：
   - **重要的刀长**（新信息多、情绪重、观众要看清的东西）——给足时长，4–8 秒甚至更长；
   - **不重要的刀短**（过渡、过场、只是接一下、纯交代位置）——1–2 秒就够；
   - **同一件事不要切成两刀**；只有观看重点、空间或节奏需要变化时才切；
   - 一条硬要求：**全片不能出现"差不多都一样长"**。切点间隔如果几乎相等，无论平均时长是多少，都判为节奏失败。

   「8 秒里塞三个节拍」仍然禁止——但禁止的是**超容量**，不是禁止长短不一。长度上限是模型给的，**长短搭配是导演定的**。

## 十、进阶补充二：时间码分镜与剧本→景别推算

### 时间码分镜格式

对已验证支持多镜头叙事的实现，分镜表可直接带时间码，提示词里逐段标注：

```
Shot 1 (0-3s)：全景，主角冲进雨夜的便利店，浑身湿透
Shot 2 (3-6s)：中景，柜台后的店员抬头，表情从困倦转为警觉
Shot 3 (6-9s)：特写，主角把手拍在柜台上，掌心是一枚带血的徽章
```

**纪律**：每 Shot 一个主体动作 + 一个镜头运动，不叠加；时长必须落在模型单片段上限内，超长段落拆成多个片段交给剪辑接。

### 剧本动词 → 景别推算（DirectorAI 式思路）

从剧本动作描述反推景别，比自己拍脑袋更稳：

| 剧本信号 | 默认景别 | 理由 |
|---|---|---|
| 情绪动词（颤抖、哽住、眼神躲闪） | 特写/大特写 | 情绪信息全在脸上 |
| 关系动词（对峙、擦肩而过、围坐） | 中景/双人中景 | 要同时看清两个人 |
| 位移动词（冲入、逃离、翻窗） | 全景/跟拍 | 身体与空间关系是信息主体 |
| 交代性内容（新场景第一次出现） | 远景/建立镜头 | 先立空间再进戏 |
| 关键道具（证据、信物、武器出手） | 特写 | 道具是后文的锚，必须看清 |

### animatic 省算力流程（长篇项目建议）

正式生成前，先用**低清快速版**（低分辨率或草稿模型）把整集分镜过一遍动线与节奏，确认没有"这镜根本接不上"的硬伤后，再按正式规格逐镜重跑。多集连做时，这一步能拦掉大半返工。

## 十一、进阶补充三：弹性拆镜与生成段规划

### 真实剪辑镜头不等于一次生成段

技术分段时，把动作上下文带入每段：上一段已完成什么、这一段从什么状态开始、这一段结束后要留下什么。不要仅复制同一首帧和一段泛化动作；需要连续运动时记录段内时间顺序与接缝状态。

- **真实剪辑镜头**是成片叙事单位：观看重点、主体、情绪、动作阶段、空间方向、道具状态或声音理解发生变化时，优先切镜。
- **生成段**是一次执行单位：可以覆盖一个镜头，或同机位、同主体、动作连续的多个短镜头；不能跨越身份切换、空间跳跃、关键姿态/道具突变或多个独立高潮。
- 镜头数量服从剧情和观看任务，不固定六镜，也不按每个动词机械切分。
- 同一构图能清楚承载、多个动作共同服务同一结果时可以合镜；两个核心信息互相争夺注意力时必须拆镜。

分镜表**必须**包含：`刀型`、`本刀新信息`、`时长`（这三列是「重要的长、不重要的短」的执行落点，列名全局统一，见「第一步」）。

分镜表建议增加：`生成段 ID`、`镜头功能`、`主要观看重点`、`首状态`、`尾状态`、`与前后镜的因果/剪辑关系`、`屏幕坐标与向量`、`主体初始朝向`、`脚步/重心`、`手-道具接触点/承重/解除`、`道具/轮子从属运动`、`轴线/视线`。

> 上述字段服务于"生成前运动设计闸"第 8 项——**含人 / 道具 / 接触 / 移动 / 转身 / 持物的镜**必须填，纯空镜 / 慢推 / 风光推拉可压缩（写"无运动"即可）。

### 拆段时的补充规则（原《分镜故事板与批量出图》§二 并入）

- **先按内容定时长，再核对实现**：按内容确定镜头时长，再核对当前实现的输入类型与单段时长范围；技术拆段和成片切点不是一回事，详见 `07-端到端管线/生产证据与片型路线.md`“时长、切点与连续呈现”。
- **短于最小生成时长**：生成足够长的素材后截取所需片段，或选择更合适的实现；不要强行合并剧情镜头。
- **字段**：使用分镜表已有的 `生成段ID`（无该字段才新增）；项目镜号按 `AGENTS.md`，不要增加带供应商名的字段。
- **段间接续**：下一段输入须同时对照身份资产和前段完成状态，过检后使用，不盲目把末帧串下去（帧链执行见 `跨镜连续性与帧链法.md`）。

### 分镜转执行描述的边界

已通过的分镜进入执行阶段后，只做可执行翻译，不重新导演：

1. 原样继承角色、场景、道具和风格版本；
2. 写清开始状态、可见变化过程和结束状态；
3. 一个生成段围绕一个主动作目标；同一目标中的前置、完成和即时反应可以连续发生，不要把工具分段强行当作剪辑切点；若同时存在两个争夺注意力的目标，再拆成多个生成段或镜头；
4. 实现无法同时满足多个要求时，返回 2–4 个拆分/降规格候选，不得静默删除关键要求；
5. 通过的执行描述按镜号和版本保存，重抽不覆盖旧版。

## 十二、视听连续性补充：镜头、画面与色调

镜头语言不是景别词堆叠。每段先决定观众站位、观看路径与信息揭示，再选择机位、焦段、景别和运动；运动有主体或情绪目的，不能只写“电影感慢推”。

- 对话/对视维护轴线、视线匹配和屏幕方向；角色移动要保持行进方向，改变方向时给转身、过轴或空间重建。前景遮挡、门窗/栏杆框架、引导线和留白要服务观看重点，不为装饰强加。
- 构图描述要说明主体层次（前/中/后景）、第一视觉焦点、观看路径、关键遮挡和焦点转移；复杂画面先减少竞争主体。首帧负责空间关系，视频提示词负责焦点/视线/运动如何变化。
- 色调写“色彩路线”而不是一个滤镜：每个阶段保留主色与材质基准，同时说明何时增加/削弱某种色温、饱和度、明暗或对比，以及叙事原因。相邻镜头保持同一时空的白平衡和肤色；跨时间、空间或心理节点才改变，并给画面或声音过渡。色彩变化不能代替剧情变化，也不能每镜随机换色。
- 光线与色调分别描述：光线是光源、方向、阴影和反射；色调是整体色彩关系和阶段变化。一个画面可以主光相同而通过背景、服装、反射或后期色彩变化产生层次，也不能用色调词掩盖没有光源逻辑。

生成前按顺序检查：视线/运动方向是否接得上，首帧是否能读出空间和焦点，色彩/光线变化是否有理由；粗剪后再看实际运动是否破坏轴线、构图焦点或色彩连续性。

## 十三、短剧单集执行稿（集内节奏与执行）

> 本节是同一件事在**短剧单集**粒度上的展开：§一–§十二 管"这一镜怎么设计、怎么过闸"，本节管"这一集怎么拆成一串镜头、每镜给什么、停在哪里"。上游拿到的是已经确定的单集剧情或剧本，本节只做执行稿，不重新策划整部剧。

### 13.1 任务定位与职责边界

你的职责是把“已经确定要发生什么”的单集剧情，进一步拆成“这一集具体怎么拍、每个镜头表现什么”的短剧分镜执行稿（默认横屏 16:9；竖屏 9:16 仅作竖屏平台备选）。

你处于短剧生产链路的中间层：

短剧策划 / 分集剧情 / 单集剧本 → 本 Skill 做单集分镜 → 下游生图 / 生视频提示词 Skill

本 Skill 负责：

- 单集节奏拆解。
- 镜头顺序设计。
- 景别与简单拍法。
- 画面内容。
- 人物动作、表情和情绪。
- 台词在具体镜头中的落点。
- 爽点、反转、证据、秘密和结尾钩子的视觉放大。
- 本集人物资产与关键画面资产整理。

本 Skill 不负责：

- 重新设计整部短剧的世界观、主线和结局。
- 无故修改已经确认的人设、事件顺序或核心反转。
- 一次性为整部几十集短剧逐镜拆分。
- 输出具体生成实现的最终提交提示词。
- 输出具体模型参数、运镜参数语法、参考图编号或剪辑工程方案。

当用户后续需要生图或生视频时，应把这里生成的分镜执行稿交给对应下游 Skill 继续处理。

### 13.2 默认制作目标与优先镜头库

默认按横屏 16:9 AI 短剧执行逻辑处理（竖屏 9:16 为竖屏平台备选）。

单集默认时长为 1–3 分钟，但必须优先服从用户已经给出的时长、剧本和剧情长度。

分镜的首要目标不是电影感炫技，而是：

- 前 3 秒抓住观众。
- 信息推进清楚。
- 冲突进入快。
- 人物表情和关系变化明确。
- 爽点、虐点、秘密、反转有视觉落点。
- 镜头数量可控。
- AI 容易生成。
- 人物与场景容易保持一致。
- 后续容易继续转换成生图或生视频提示词。

优先选择叙事效率高、AI 稳定的镜头：中近景、近景、特写、人物反应、证据特写、眼神变化、转身、逼近、拦截、推门、打断、甩出证据、身份揭露、关系破裂、动作结果；横屏可适当加入大远景与横向调度。

少用没有叙事功能的大空镜、大场面、复杂群演调度和仅为了“好看”而存在的镜头。

### 13.3 接收输入与任务判断

先在内部判断用户给的是哪一种输入。

#### A. 单集分集大纲

直接展开为完整单集分镜。

可以补足必要动作、情绪和台词衔接，但不要改变核心剧情。

#### B. 单集详细剧情或剧本

优先忠于原剧情和台词。

你的工作是把文字事件重新组织成适合横屏电影感观看的镜头节奏（竖屏项目改用竖屏节奏），而不是再次改写剧本。

如果原台词明显过长，可以在不改变信息和人物态度的前提下压缩。

#### C. 单个场景

只拆这个场景，不自行补完整集。

输出这个场景内部的镜头顺序、表演、台词落点和关键视觉资产。

#### D. 整部短剧资料，但没有指定某一集

不要直接把整部剧全部拆成分镜。

优先根据材料识别最适合作为当前执行对象的一集，例如：

- 第一集开场钩子集。
- 第一次正面冲突集。
- 第一次反击集。
- 身份揭露集。
- 关键真相集。
- 强付费钩子集。

明确说明当前选择的是哪一集，再进行单集拆解。

#### E. 只有粗略故事想法

如果连本集核心事件都没有确定，不要擅自承担整剧策划职责。

可以保守整理出一个“可执行的本集事件版本”，但应保持范围小，只为完成当前分镜所需的信息，不扩写完整系列。

### 13.4 信息不足时的处理规则

只要能够合理执行，就直接做，不要因为普通细节缺失而反复询问。

例如用户没有给出：

- 精确年龄。
- 房间装修细节。
- 具体衣服颜色。
- 手机型号。
- 某个配角姓名。

可以做保守、易生成、符合人物身份的暂定设计，并保持本集内部统一。

只有出现以下问题时才需要指出：

- 人物关系互相矛盾。
- 关键事件顺序无法成立。
- 同一角色在同一时间出现在不可能同时存在的位置。
- 反转前提与已知事实直接冲突。
- 用户要求的镜头与剧情本身相互排斥。

即便如此，也优先给出一个最小修正版，然后继续完成分镜，不让工作停在提问阶段。

### 13.5 单集内部节奏

完整一集默认具有以下节奏，但不要机械套模板：

抓人 → 进入冲突 → 压力升级 → 情绪蓄积 → 关键信息出现 → 反击 / 反转 / 关系变化 → 新问题爆出 → 戛然而止

不同题材可以改变节奏重点。

#### 复仇 / 逆袭

压迫要明确，反击要有因果，爽点不能只靠嘴赢。

优先表现：证据出现、态度反转、权力重新分配、对手失控、主角做出关键行动。

#### 甜宠 / 情感

重点不是不断争吵，而是关系状态发生变化。

优先表现：误解、试探、保护、吃醋、秘密、选择、确认关系、失去安全感或重新建立信任。

#### 悬疑 / 读心 / 秘密类

重点是观众比人物多知道一点，或者突然重新理解之前的信息。

优先表现：异常表情、细微停顿、手机内容、物件证据、偷听、反常动作、人物知道不该知道的信息。

#### 家庭伦理

重点是利益、亲情、身份与尊严之间的现实冲突。

不要让多人长时间站着轮流说话。把冲突拆成动作、反应、证据和立场变化。

#### 喜剧

节奏依靠目标、误判、升级、结果反差。

不要用大量解释笑点，尽量让镜头本身产生反差。

### 13.6 前 3 秒规则

第一镜头或前两个镜头必须尽快给出观看理由。

优先从以下内容开始：

- 正在发生的冲突。
- 极端关系状态。
- 角色刚听到的秘密。
- 一句足以改变关系的话。
- 明确危机。
- 强烈反差。
- 异常行为。
- 即将被揭露的证据。
- 观众一眼看不懂但强烈想知道原因的结果。

不要默认从：

- 建筑外景。
- 城市空镜。
- 角色起床。
- 角色慢慢走路。
- 无意义环境展示。
- 大段旁白介绍人物背景。

开始一集。

如果环境信息很重要，应把它和冲突同时出现。

### 13.7 镜头设计原则

#### 13.7.1 每个镜头必须有功能

一个镜头至少完成一项：

- 推进事件。
- 传递新信息。
- 放大情绪。
- 展示人物态度变化。
- 展示证据或秘密。
- 完成动作结果。
- 制造期待。
- 完成爽点或反转。
- 为下一镜头建立因果。

如果删掉一个镜头完全不影响剧情、情绪和理解，通常就应该删。

#### 13.7.2 镜头数量

完整单集默认约 8–20 个镜头，根据实际时长和剧情密度调整。

简单剧情宁愿 8–12 个高效率镜头，也不要硬拆成 20 多个碎片。

激烈争执、动作反击、身份揭露等段落，可以增加人物反应特写和动作结果镜头，让情绪真正落地。

**时长与刀型**：时长按内容定、不按模型档位定——完整规则（长刀/短刀判定表、三条纪律、`刀型` 与 `本刀新信息` 必须入表）见本文件 §一「第一步」与 §五「长短刀与转场接力」，本节不重复。

#### 13.7.3 景别

横屏默认（16:9）各景别都可用，按叙事递进：

- 大远景/远景：开场建立空间与氛围，横屏的优势景别。
- 全景：交代空间关系、人物数量或重大场面。
- 中景：建立两人关系和动作。
- 中近景：承担主要对话。
- 近景：承担强情绪和态度变化。
- 特写：眼神、手、证据、戒指、文件、伤痕等关键信息。

竖屏项目则以中近景/近景/特写为主，远景仅在必要时使用。

#### 13.7.4 反应镜头

重要台词之后，不要总是立刻进入下一句。

当一句话造成：

- 震惊。
- 怀疑。
- 心虚。
- 崩溃。
- 愤怒。
- 被识破。
- 情感动摇。
- 身份反转。

应给关键人物一个可见反应。

但是不要每一句对白都切反应，反应镜头只服务重要情绪变化。

#### 13.7.5 动作与台词配合

人物不要一直站着说话。

优先让台词与动作同时发生，例如：

- 一边收拾行李一边宣布离开。
- 把手机推到对方面前时揭露证据。
- 推门进入时打断谈话。
- 摘下戒指时说出决裂台词。
- 转身离开后再停下补一句关键话。
- 对方正准备触碰时后退一步。

动作是情绪的实体化。

#### 13.7.6 重要信息视觉化

能够被看见的信息，尽量不要只靠人物口述。

例如：

“他出轨了”可以通过聊天记录、酒店记录、照片、来电备注、戒指、衣物等视觉证据强化。

“她身份不简单”可以通过他人态度、门禁权限、车辆、文件签名、下属称呼等方式表现。

“他在撒谎”可以通过眼神回避、手部动作、手机藏起、前后细节冲突来表现。

### 13.8 爽点与反转的镜头放大

爽点不能只写成一句剧情总结。

当本集出现真正的情绪回报时，至少设计完整的“蓄力 → 行动 → 结果 → 对手反应”链路。

例如身份揭露不要只写：

“众人发现她是董事长。”

而应该拆出：

- 对手继续轻视。
- 新人物或证据出现。
- 称呼 / 权限 / 文件改变现场认知。
- 对手表情变化。
- 主角保持克制或给出短句。
- 现场关系发生逆转。

反转后的结果必须被人物感受到。

不要刚揭晓重要真相就立刻跳过。

### 13.9 台词设计规则

台词服务镜头，不单独追求文采。

默认原则：短、直、准、有情绪、有信息、有关系压力。

#### 13.9.1 台词功能

每句重要台词至少完成一项：

- 施压。
- 拒绝。
- 试探。
- 揭露。
- 反击。
- 威胁关系。
- 改变立场。
- 暴露秘密。
- 制造误解。
- 完成承诺。
- 制造结尾钩子。

不要保留没有功能的寒暄和解释。

#### 13.9.2 信息直给，但不要全靠解释

短剧认知负担要低。

背景信息尽量压缩进冲突，例如不要让人物长篇介绍自己的家庭史，而让对手用一句带立场的话把核心背景说出来。

但是如果动作、眼神、证据已经能表达，就不要再让人物把同样信息复述一遍。

#### 13.9.3 情绪优先，但不制造低智冲突

短剧需要高情绪密度，但不要理解成“逻辑完全不重要”。

可以压缩现实过程，可以让戏剧性高于生活化，但关键因果必须让观众看得懂。

爽点来自观众知道“为什么这个反击成立”，而不是人物突然获得无来源的能力。

#### 13.9.4 反派台词

反派的台词应制造真实压力，而不是单纯粗口。

优先用：

- 利益剥夺。
- 身份轻视。
- 关系威胁。
- 掌握资源。
- 公开羞辱。
- 掌握秘密。
- 逼迫选择。

少用重复的人身攻击、低俗辱骂和单一“你配吗”式台词。

#### 13.9.5 主角反击台词

主角反击最好与行动、证据或局势变化绑定。

比起连续说狠话，更有效的是：

- 一句短台词。
- 一个明确动作。
- 一个已经准备好的证据。
- 对手发现自己失去筹码。

主角越强，越不需要长篇解释自己有多强。

#### 13.9.6 身份揭露

身份揭露的爽感通常来自“周围人态度发生 180 度变化”。

不一定让主角自己宣布身份。

可以通过：

- 权威人物称呼。
- 文件签名。
- 权限验证。
- 下属进入。
- 对手突然认出。
- 现场规则被改变。

完成揭露。

#### 13.9.7 情感类台词

甜宠、虐恋、关系冲突不要全部写成宣言。

可利用：

- 没说完的话。
- 回避。
- 反问。
- 口是心非。
- 动作先于承认。
- 明明在意却故意冷淡。
- 说出事实但隐藏动机。

制造拉扯。

#### 13.9.8 合规爽感

不要依赖极端粗鄙辱骂、血腥威胁、违法私刑作为主要爽点。

优先使用证据揭露、关系反制、商业或身份资源重构、公开真相、合法追责、智力压制等方式产生情绪回报。

### 13.10 结尾钩子

结尾必须产生“下一秒我还想看”的未完成状态。

优先使用：

- 新身份刚被发现。
- 秘密只揭开一半。
- 某人听到了不该听到的话。
- 证据刚被拿出来。
- 关键人物突然出现。
- 关系刚刚破裂。
- 角色做出无法撤回的选择。
- 危机马上发生。
- 观众知道真相，但角色还不知道。
- 角色准备执行反击，但结果未揭晓。

不要用：

- 大家散场。
- 主角回家。
- 情绪自然平复。
- 旁白总结。
- “事情终于结束了”。

作为普通连续剧集的结尾。

钩子最好同时包含画面和一句能够卡住情绪的台词，或者干脆让画面本身完成卡点。

### 13.11 AI 制作友好原则

分镜要考虑后续 AI 生产，而不是只考虑真人剧组。

#### 13.11.1 控制同镜复杂度

尽量避免一个镜头同时需要：

- 多个主要人物。
- 大量群演。
- 多重复杂动作。
- 大范围场景运动。
- 同时出现大量文字信息。

复杂场面可以拆成建立镜头、人物反应、动作特写和结果镜头。

#### 13.11.2 保持人物资产稳定

同一场戏没有剧情原因，不随意改变：

- 发型。
- 服装。
- 妆面。
- 配饰。
- 伤痕。
- 手中关键道具。

跨场变化需要有清楚原因。

#### 13.11.3 保持空间连续性

明确人物大致位置和关系：

- 谁坐着。
- 谁站着。
- 谁靠近门。
- 谁拿着手机。
- 关键道具在谁手上。

不要连续镜头出现无法解释的位置跳变。

#### 13.11.4 文字类资产单独列出

手机聊天、合同、检测报告、病例、监控、新闻页面、转账记录等，应在关键画面资产中单独列出，方便后续单独制作。

### 13.12 默认完整单集输出格式

用户要求“完整单集分镜”时，默认使用以下结构。

#### 这一集定位

用 1–2 句话说明这一集在整部剧里的功能。

#### 核心冲突

说明这集谁和谁因为什么发生正面矛盾。

#### 核心情绪回报 / 爽点

说明观众这一集最值得等待的画面或关系变化。

#### 结尾钩子

一句话说明这一集停在哪里。

#### 分镜正文

格式：

镜头1｜约 X 秒｜景别 / 简单拍法  
画面：具体可见内容。  
人物：动作、表情、情绪变化。  
台词：角色名：“……”

镜头2｜约 X 秒｜景别 / 简单拍法  
画面：……  
人物：……  
台词：……

依次完成本集。

没有台词的镜头可以省略“台词”。

简单镜头可以把“画面 + 人物”合并成一个短段落，不必为了格式变得冗长。

#### 这一集展现重点

列出 3–6 个真正需要视觉放大的内容，例如：

- 最抓人的开场画面。
- 本集最关键表情。
- 最值得停顿的动作。
- 最有传播潜力的台词落点。
- 最适合做封面或切片的镜头。
- 结尾钩子的核心画面。

这部分不是拍摄清单，不要重复全部镜头。

#### 这一集人物资产

对本集实际出现的重要人物逐个整理：

人物名称：  
身份定位：  
与主角关系：  
外观关键词：  
年龄感：  
发型 / 妆面：  
服装关键词：  
当前情绪状态：  
本集关键动作或表演点：  
是否为本集重点人物：是 / 否

如果上游已经有固定人物卡，优先沿用，不重新设计外貌。

#### 关键画面资产

列出后续 AI 生图、画面合成和剪辑真正需要单独准备的资产，例如：

1. 手机聊天界面：需要显示的核心信息。
2. 离婚协议：剧情必须看到的签名或条款。
3. 戒指：在哪个动作中使用。
4. 病历 / 检测报告：需要被镜头看到的关键结果。
5. 监控画面：必须证明什么事实。

只列剧情相关资产，不把普通家具全部罗列出来。

### 13.13 单场戏输出格式

用户只要求一个场景时，输出：

#### 场景功能

这场戏要完成什么剧情变化。

#### 场景分镜

按照完整单集同样的镜头格式拆分，但只覆盖当前场景。

#### 本场重点画面

列出最值得放大的 1–3 个画面。

#### 本场人物与关键资产

只列本场实际需要准备的内容。

### 13.14 用户要求精简时

如果用户明确说“简单一点”“不用这么细”“只要分镜”，压缩为：

镜头编号｜时长｜景别｜刀型（短刀/常规/长刀）
画面 + 动作情绪 + 台词

**精简不等于省掉 `刀型`。** 这一列是「重要的长、不重要的短」的唯一落点，省了它时长就会退回平均分配。哪怕只输出上面这一行，`刀型` 和 `时长` 也必须一起给。

不要继续输出长篇创作分析。

如果用户已经明确要拿结果交给下一步提示词 Skill，可以减少解释，只保留最具执行价值的信息。

### 13.15 不要犯的错误

不要把单集分镜重新写成文学小说。

不要写传统电视剧式长篇场次说明和大量舞台调度。

不要把所有镜头都写成“中景，两人对话”。

不要连续多个镜头重复同一个信息。

不要只写台词，不写人物动作和表情。

不要只写情绪，不推进事实。

不要为了“电影感”加入大量无功能空镜。

不要让爽点一句话带过。

不要让反转没有前置条件。

不要让人物突然知道自己不可能知道的信息。

不要让结尾情绪落平。

不要自动修改上游已经确认的核心故事。

不要把分镜直接写成某个视频模型的长提示词。

不要为了追求镜头丰富而制造 AI 难以维持的人物、服装和场景连续性问题。

### 13.16 连续性检查

输出前在内部检查：

- 本集人物关系是否与上游一致。
- 人物知情范围是否正确。
- 证据出现之前是否已经合理获得。
- 角色衣服、发型、伤痕、道具是否连续。
- 场景内人物位置是否合理。
- 每个重要动作是否有结果镜头或人物反应。
- 前 3 秒是否有抓点。
- 本集是否存在明确的冲突变化。
- 爽点或关键情绪是否真正被视觉化。
- 结尾是否仍有未完成状态。
- 镜头画幅是否符合本片基准（默认横屏 16:9；竖屏项目为 9:16）。
- 镜头是否便于后续 AI 生成。

如果发现某一镜头只是重复信息，优先删除或合并。

### 13.17 最终职责边界

本 Skill 的最终交付物是“单集分镜执行稿”，不是最终视频提示词。

每个镜头应该已经清楚到让下游知道：

- 拍谁。
- 拍什么。
- 人物在做什么。
- 人物是什么情绪。
- 哪一句台词在这里发生。
- 哪个信息必须被观众看见。
- 这一镜与前后镜头为什么连得起来。

做到这一步后停止。

除非用户明确要求，否则不要继续替下游模型补生图提示词、生视频提示词或具体模型参数。

## 十四、故事板与按需出图（批量方法）

> **本节只在确需出图时启用**（A8）：需要图的地方只有两类——① G2 资产板（角色/场景卡，冻结后经 Ref2VA 作图像条件接入）；② G3 按需首帧/尾帧（hero shot / 精确构图锁）。纯文本分镜不产生图，也不产生出图成本。
> 清单本体（列结构、填法、自动生成规则）唯一权威 = 模板 `模板/短剧项目模板/03-分镜/图片生产清单.md`；SOP 侧 `02-分镜与镜头/图片生产清单.md` 只作指针。本节补的是那份清单之外的"**怎么高效产出与筛选**"，**不改动清单的表结构**，只回答两件事：① 清单执行前怎么排批次；② 搓完之后怎么筛。

### 14.1 一句话：瓶颈不是搓得慢，是串行地搓

**出图的瓶颈不是"搓得慢"，是"串行地搓"——一镜一镜重抽，抽十次错三次就是十倍成本。正确姿势是：先一次性把一整段的分镜静帧批量摆出来，用最低成本看完节奏，只对"要留的"精修。**

> **默认形态边界（2026-10-12，A8）**：分镜的默认形态是**文本**，不是图——文本分镜承载完整质控载荷（逐秒五要素/锚点/hook/音频轨，全部由校验器把关），成本几乎为零。批量出图只发生在两处：① G2 资产板（角色/场景卡，冻结后经 Ref2VA 作图像条件接入）；② G3 按需首帧（hero shot / 精确构图锁）。不为"看起来更专业"给每镜配首帧——那正是旧流程把漂移面从 1 张放大到镜数张的病灶。

---

### 14.2 铁律：确需出图时，静帧阶段敷衍就救不回来

**前提（A8）**：需要出图的地方只有两类——G2 资产板、G3 按需首帧/尾帧。纯文本分镜不产生图，以下铁律适用于**实际要出的那些图**，不构成"每镜都要配一张首帧"的要求。

这是本节存在的全部理由。

| 阶段 | 能修的错 | 修不动的东西 |
|---|---|---|
| **静帧阶段（G2→G3）** | 构图、景别、站位、光影、色调、人物一致性 | —— |
| **视频阶段（G4）** | 运镜节奏、动作幅度、局部质感抖动 | **构图错、光影脏、人物长错脸、轴线乱** |
| **剪辑阶段（G5）** | 节奏、转场、音画 | 上面两层的任何问题 |

原因很直接：图生视频的输入是**一张已经定死的静帧**。构图和光影是这一张图的属性，模型只能在上面加运动，改不了骨架。

> **实操判据**：一张静帧如果在"静止播放"时就已经不好看、不舒服、不像那个时代/那个地方/那个人，那么让它动起来只会更糟。**先把静帧打磨到能当剧照发出去，再交给 G4。**

**新增到检查清单里的一句话**（配合 `导演视觉圣经.md` §六 使用）：
- [ ] 每张入选静帧，**静音单看 3 秒**，是否已达到"可当剧照单独发布"的水准？达不到就退回重出，不要进视频段。

---

### 14.3 九宫格故事板：一次出 N 格

#### 14.3.1 它解决什么

探索期逐镜出图的问题：出到第 6 镜才发现第 1 镜的机位选错了，**前 5 镜全废**。（A8 后正式首帧按需出，九宫格的用途是**探索期低成本预览**与**确需批量看一段构图时的筛选**，不是"每镜都要出正式首帧"。）

九宫格把这件事提前暴露：一张图里同时给出 6–9 镜的静帧，**一眼看完整段节奏**，再决定哪几格值得精修。

#### 14.3.2 提示词骨架

与 `07-端到端管线/片型全流程.md` §2.5.6 的**场景所需机位参考板**不同——那是同一空间的所需机位，不强制九格；本节是"**9 个不同镜头的静帧**"。两者不要混用。

```text
一张 3×3 排列的分镜故事板图，九个格子从左到右、从上到下依次为第 1 到第 9 镜。
[全局锁定句]（角色锚句 + 场景锚句 + 色彩/光影基调，整张图共用，逐格复述）
[格 1] 景别+机位+构图+主体动作+场景+光影
[格 2] 景别+机位+构图+主体动作+场景+光影
...
[格 9] 同上
整体风格：<写实/水墨/敦煌壁画质感/3D CG>，色调 <色彩脚本主色>，
画面比例 <随本片画幅：横屏 16:9（默认）/ 竖屏 9:16>，每格之间留 2% 白色分隔线，格内不加任何文字标注。
```

**关键约束**：
1. **全局锁定句必须在每一格里复述**（不要只在开头写一次）——网格生成最容易丢全局约束。
2. **"格内不加任何文字标注"** 必须写，否则模型爱在格子里写字。
3. **首帧引用锁**用图生图/参考图方式带入（挂 A-01 定妆照），不要靠文字描述长相。
4. **六宫格 vs 九宫格**：成本敏感时用**六宫格**（2×3）——格子越多，每格可用分辨率越低，人物脸容易崩。六宫格在"看节奏"这个目的上已经够用。

#### 14.3.3 什么时候不要用

- **单镜特写/大特写**：格子太小，脸崩了看不出好坏 → 逐镜单独出。
- **需要精确轴线控制的正反打**：九宫格不保证相邻格的空间连续 → 先用九宫格定大方向，轴线仍按 `角色一致性.md` 逐镜锁。
- **人物特写占比高的段落**：同上。

**九宫格是"筛"的工具，不是"交付"的工具。** 它的产出是"哪些镜头值得做"的决策依据，不是最终首帧。

### 14.4 并行候选 vs 串行重抽

#### 14.4.1 两种花钱方式

| 策略 | 做法 | 成本 | 适合 |
|---|---|---|---|
| **串行重抽**（`AGENTS.md` 现有铁律） | 出 1 张 → 不满意 → 改提示词 → 再出 1 张 → …直到满意 | 第 N 次满意的图花了 N 次钱 | 构图已定、只差微调 |
| **并行候选**（本节补充） | 一次出 3 张同构图变体 → 选最好的一张 → 只对它精修 | 3 张里 1 张可用，比串行抽 3 次便宜且选择更多 | **分镜探索期、风格探索期** |

两者不是替代关系，是**分工**：

- **探索期**（还没定这个镜头怎么拍）→ 用并行候选，一次摆 3 张挑一张。
- **定稿期**（构图已锁定，只差细节）→ 用串行重抽，走 `AGENTS.md` 的 2 次预算。

#### 14.4.2 执行规则

1. **并行候选 = 同一提示词 + 换 seed/参考图**，不要改提示词。改提示词就不是候选了，是另一个方案。
2. **每格出 3 张，出 3 张只选 1 张**是分镜阶段的默认动作，不是浪费。
3. **选图标准写在前面**：按 `导演视觉圣经.md` 的色彩与光影基调判，不按"哪张好看"判——好看但跑偏基线卡的图要打回。
4. 选定后**把选中的那张登记为该镜的"过检静帧"**，进入 `模板/短剧项目模板/03-分镜/图片生产清单.md` 的状态流转（项目内即 `03-分镜/图片生产清单.md`）。

#### 14.4.3 与成本台账的关系

并行候选的钱记进项目《成本台账.md》。建议在台账里**分两栏记**：`探索期并行候选支出` 与 `定稿期重抽支出`。两者的成本曲线完全不同，混在一起会误判项目盈利能力。

### 14.5 零成本出图路线

在《能力登记.md》把某工具登记为"本片实现"之前，先问一句：**这一步能不能免费做完。**

#### 14.5.1 免费档（用于分镜探索期，不用于定稿）

| 环节 | 工具 | 说明 |
|---|---|---|
| 写分镜文字 | 对话式大模型 | 让它按 `影视视听语言速查.md` 的八要素，把分镜表逐镜展开成带运镜术语的英文描述 |
| 逐格出图 | 该模型的图像能力 | 按上一节格式，一格一张（不做网格），出 3 张选 1 |
| 拼接故事板 | 本地任意拼图工具 | 拼成一张竖排故事板，供人工看节奏 |

**零成本路线的定位**：只用在**第 2–3 阶段的故事板梳理**，不用于 G2 资产冻结——资产必须过 `角色一致性.md` 的检验规则，免费的松散图过不了检。

**它最大的价值是"早"**：在剧本刚定稿、分镜表刚出来的时候就能看到画面节奏，那时候改镜头的代价接近零。等进了 G4 再发现节奏问题，返工成本是前面的十倍。

#### 14.5.2 什么时候必须用付费工具

- 需要**角色身份锚定**（首帧必须来自人工过检资产）→ 见 `角色一致性.md` 身份锚定铁律。
- 需要**与全片色彩脚本严格一致**的图。
- 最终进入 G4 的首帧。

**判据**：这张图会不会成为某个镜头的首帧？会 → 必须走付费档 + 过检。不会（只是看节奏）→ 免费档够用。

### 14.6 风格化滤镜：已出图后的低成本统一

当一批图已经出来了但**画风不统一**，重出很贵。此时用风格化滤镜做**一次性统一**，比继续抽图便宜得多。

常见滤镜与其用途：

| 滤镜方向 | 效果 | 适用 |
|---|---|---|
| 黑白 / 去色 | 去掉色彩噪音，只留明暗关系 | 国风志怪做"褪色壁画感"；强调整构图时 |
| 冷调压低饱和 | 统一到幽冥/雪/夜 | 山海经、鬼怪段落 |
| 暖调提亮 | 统一到市井/灶火/黄昏 | 温情、归家段落 |
| 复古胶片 | 加颗粒与色偏 | 把不同模型产出的"数字味"压掉 |

**使用纪律**：
- 滤镜是**统一手段，不是创作手段**——不要用它来"救"一张本来就不合格的图。
- 滤镜一旦选定，全片统一，参数写进 `导演视觉圣经.md` 的色彩脚本。
- 滤镜会**破坏参考图的可用性**（滤镜后的图不能再当下一镜的图生图输入，会带上滤镜痕迹）。所以：**过滤镜的那张原图必须留着**。

---

### 14.7 执行清单（可直接照做）

1. **先确认这段真的需要图**（A8）：只在 G2 资产板、G3 首帧/尾帧按需场景下走本节；再读分镜表、关联生成段ID（超出已登记单段能力的镜头按动作阶段拆段，并检查连续性，规则见 §十一）。
2. **决定本段是否值得九宫格**：多镜同场景 + 人物非特写 → 值得；特写/正反打 → 跳过。
3. **出九宫格（或六宫格）故事板**：写全局锁定句 + 逐格八要素 + "格内不加文字"。
4. **肉眼筛**：哪几格值得做、哪几格机位要改——**这一步省掉后面 80% 的废图**。
5. **对入选的每一格，并行出 3 张候选**（同提示词换 seed），选 1。
6. **按色彩脚本基线卡验收**，不按"好看"验收。填项目 `03-分镜/图片生产清单.md` 状态。
7. **需要整体统一画风时，再上一次风格化滤镜**（原图保留）。
8. **把探索期支出单独记进成本台账**。
