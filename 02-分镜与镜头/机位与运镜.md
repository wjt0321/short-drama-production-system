## 一、先定空间，再定机位

不先锁定空间就摆机位，必然跳轴、必然前后景错乱。**顺序不能反。**

### 1.1 开工前必须回答的四问

1. **场地几何**：这是一个什么形状的空间？主要的墙/门/窗在哪？人能往哪走？
2. **人物初始位置**：这场戏开始时，每个人站在哪、朝向谁？
3. **核心关系轴**：这场戏最主要的**两个端点**是什么（人对人 / 人对物 / 人对空间出口）？
4. **动作终点**：这场戏结束时，谁到了哪、谁离开了？

**把这四问答出来，画成一张俯视示意图**（草图即可，不必进正式产物）。没有这张图就不要摆机位。

### 1.2 轴线（180° 规则）

- **定义**：两个主要人物（或人物与其注意目标）连成一条线，摄影机应始终待在**这条线的一侧**。
- **为什么**：越轴会让观众瞬间失去空间方向——A 从左边看 B，下一镜却变成从右边看，观众会以为空间变了。
- **画幅提示**：横屏横向余地大，越轴后观众更容易重建空间，容错稍高；竖幅 9:16 的横向空间窄，**越轴的视觉冲击比横屏更明显**，因为人物横向位移余地小，竖幅下要更严格地守轴。两种画幅都**默认守轴**，越轴必须走 §1.2 的四条合法路径。
- **合法越轴方式**（想越时必须用其中一个，不能直接跳过去）：
  1. **运动越轴**：让摄影机在镜头内连续移动过线，观众看见过程。
  2. **中性镜头**：插一个正对轴线的镜头（人正对或背对摄影机），作为过渡垫。
  3. **角色运动越轴**：让人物自己走过线，轴线随之改变。
  4. **明确转场**：用切黑、空镜或场景转换隔开。

### 1.3 视线与朝向映射

- **视线方向 = 观众的空间锚**。若 A 看向画面右侧，则 B 应出现在**画面左侧**看向右（互为反向）。
- **看错方向的典型症状**：两个人像都在看同一边，观众会觉得他们在看**画面外的第三个人**。
- **强制项**：建立关系后，**逐镜检查视线方向是否成对反向**。这是最容易犯、最容易靠机器漏掉的错误。

## 二、机位：三要素决定一个机位

任何一个机位都由三个量确定，**三个都要有理由**：

| 要素 | 可选项 | 决定什么 |
|---|---|---|
| **高度** | 低 / 平视 / 高 | 立场与权力。低机位给人力量、压迫观众；高机位让对象弱小、被审判；平视=平等 |
| **距离** | 近 / 中 / 远 | 亲密度与信息量。越近情绪越强、空间越少；越远信息越多、情绪越淡 |
| **角度** | 正面 / 侧面 / 背面 | 心理可读性。正面=坦白、侧面=暧昧、背面=被排除在外 |

### 2.1 高度即立场（最常被浪费的杠杆）

- **默认是平视**。平视没有错，但**平视是"没有立场"**——只有当你不希望观众偏向任何一方时才对。
- 短剧高频用法：
  - **低机位**给主角在反击/觉醒那一刻（观众被压住＝主角显强）。
  - **高机位**给反派施压或主角受制（观众俯视＝对象弱）。
  - **同一场戏内高度变化**本身就是叙事：从高处跌到平视＝地位丧失。

### 2.2 画幅适配：横屏为默认，竖幅是分支（重要）

**本体系默认横屏 16:9**（权威见 `导演视觉圣经.md`「画幅默认」）。下面的三条**只在竖幅 9:16 项目**才启用：
**横屏思维直接搬进竖幅会系统性出错，反之亦然。**

**横屏 16:9（默认）的调度优势——要主动用满**：
1. **横向铺开可用**：并排 3 人以上、左右对峙、队列、横移跟随都成立，这是横屏的气势来源。
2. **环境进画**：大远景/全景先交代空间再切人物，环境本身是叙事。
3. **多人同框自然**：双人对峙、过肩对话不需要拆成单人轮换。

**竖幅 9:16（备选分支）三条修正**：
1. **横向排布失效**：9:16 装不下并排的 3 人以上。多人不要横向铺开，改为**沿纵深排**（前后错位、台阶、前后景分离）。
2. **单点透视更压迫**：竖幅的透视收敛方向与画面长边一致，走廊、门洞、天井的**纵深感比横屏更强**，适合制造压迫与宿命感。
3. **头顶留白与脚下空间**：竖幅下人物上下空间充足、左右局促。用**上下**做留白与压迫（头顶大留白＝渺小；脚边切掉＝紧张），不要用左右。

### 2.3 机位的"可指认光源"绑定

机位选定后立刻检查：**这个机位下，光源还在合理位置吗？**
- 反打换机位后光源方向如果没跟着变，穿帮。反打表要同时记录**光位**。
- 详见 `导演视觉圣经.md` 照明卡。

## 三、人物站位与走位

### 3.1 站位距离的语义

人体距离自带含义，**用距离交代关系，不要靠台词解释**：

| 距离 | 关系语义 | 短剧常见用途 |
|---|---|---|
| 贴身 / 接触 | 亲密、威胁、失控 | 感情戏、对峙爆发、揪衣领 |
| 一臂内 | 私密对话、试探 | 密谋、表白、谈判靠近 |
| 社交距离 | 正式、疏离、公事 | 办公、陌生人对峙 |
| 远距离 | 隔阂、地位差、被排除 | 决裂、身份揭穿后的距离 |

**刻意改变距离即叙事**：这场戏开始时两人隔着远距离，结束时一方走近——不需要台词，关系变化已经演出来了。

### 3.2 三人及以上的站位（短剧高频）

三人戏最容易摆成"一排木偶"。三个可用结构：

1. **三角形**：两人近、一人稍远。近的两人形成联盟，远的那个自然被孤立。适合"二对一"。
2. **纵深错位**：一人前景背身、两人中景面对。前景者是观众的代入位，同时挡住部分画面制造窥视感。
3. **换位**：让其中一人中途移动改变三角形状——**位置变化＝立场变化**。

**禁区**：三人一字排开并且都正面朝镜头——这是"汇报演出"，不是调度。

### 3.3 走位的三条纪律

1. **走位要有阻力和目的地**。人不会无缘无故走。每一步要么被什么推动，要么走向什么。
2. **走位不要与台词同时满负荷**。人物边走边说且信息量大时，观众顾不过来。选择：要么走完再说，要么说完再走，要么走时只给短句。
3. **横移看画幅**。横屏下横向横移是主力（跟随、扫过、揭示）；**竖幅下少做横向横移**，横移在 9:16 里会很快出画或顶到边，竖幅优先**纵深前后移动**，视觉信息最多。

### 3.4 空间连续性（跨镜不能断）

逐镜检查下表，任一项不一致即为穿帮：

- 人**相对**门/窗/家具的位置是否一致
- 光源方向与阴影落点是否同向
- 道具的位置与状态（开/关、满/空、在手/在桌）
- 人物朝向与视线方向是否成对反向
- 服装、发型、伤痕等状态是否延续

**与前后的衔接**：见 `02-分镜与镜头/跨镜连续性与帧链法.md`；身份与外观锁定见 `03-角色与视觉资产/角色一致性.md`。

## 四、覆盖策略：一组镜头怎么覆盖一场戏

"覆盖"= 用哪些镜头把这场戏拍全，同时**保证剪辑时有得选**。

### 4.1 基础覆盖四件套（对话/对峙场）

| 类型 | 作用 | 数量建议 |
|---|---|---|
| **建立镜** | 交代空间、人物位置、关系 | 1 个，开场用 |
| **主镜** | 完整呈现主要动作/对话，可独立看懂 | 1 个，作为安全网 |
| **过肩/反打** | 正反打的主体，形成对话节奏 | 每人 1 起 |
| **反应镜** | 给情绪反应，剪接的呼吸点 | 按情感节点 |

### 4.2 先拍什么：从"最危险"开始

**顺序原则：先拍最不确定的，最后拍最有把握的。**

理由：最不确定的镜头如果拍不成，方案要改——**先拍它是为了让失败尽早暴露**，而不是拍完一堆素材才发现核心镜头做不出来。这与 `07-端到端管线/生产证据与片型路线.md` 的"前置风险预检"同源。

AI 生成尤其适用：**先跑风险最高的一镜做探针**，成了再批量。

### 4.3 主镜（安全网）的纪律

- 如果只保留一个镜头还能让人看懂这场戏，那个就是主镜。**必须有。**
- 主镜不追求漂亮，追求**信息完整**。
- 主镜拍成之前，不要把所有预算投在碎切镜头上。

### 4.4 反应镜的经济学

- 反应镜是**节奏货币**：它是让观众"消化"的时刻，也是掩盖动作接缝的地方。
- **不要给每个反应都切镜**。只在情绪转折点给。
- 详细规则见 `分镜类型特则.md` 文戏对白一节 §6.3。

### 4.5 画幅对覆盖的影响

**横屏 16:9（默认）**：双人中景、过肩对话、多人同框都是常规手段，覆盖时直接用；横向空间足，不必刻意拆镜。

**竖幅 9:16（备选分支）**：传统"双人中景"在 9:16 里**很难同时装下两人的有效表演**（横向不够）。替代方案：
- **前后景分离**：一人前景虚焦、一人中景实焦。
- **上下分割**：高低差（楼梯、站立对坐）利用竖向空间。
- **单人流**：干脆放弃双人同框，用视线方向配对 + 反应镜组接。

- **通用判断**（两种画幅都成立）：如果一个"双人同框"镜头里两人都小到看不清表情，又没有环境或关系信息要交代，这个镜头就是无效的——竖幅下更早触发，横屏下也可能是废镜。

## 七、先弄清镜头想做什么

帮用户把"想要的镜头"写成视频模型能执行的分镜提示词。核心认知：**摄像机才是观众的眼睛**。画面里不只人物有动机，摄影机运动也有动机——大多数提示词失败，是因为只写了"画面里有什么"，没写"镜头怎么带观众进现场"。

动笔前用一两句话向用户确认（已有信息不重复问）：

- 这一镜的**情绪目的**：是把观众带进现场、揭示信息、还是跟随人物？
- **起点与终点**：镜头开始在哪、结束在哪，看见了什么变化？
- **时长**：目标模型一段大约几秒，决定能塞几个动作阶段。
- **参考来源**：有参考片段/截图/口头描述？

用户拿不准时，给出你的默认建议让他确认，不要让他填空。

#### 有参考片段时

- 用户贴了截图或帧图：用 `view_image` 看清构图、光源方向、人物站位，作为拆解依据。
- 用户给了视频直链或抖音/B站分享链接，想直接反推：可用 `reverse_video_prompt`，并在 `instruction` 里指明按本 Skill 的六个区块拆解运镜、光影、空间、背景人物。**该工具按视频分段产生费用，调用前必须先说明费用并获得用户明确同意**，同意后才带 `cost_acknowledged: true` 调用；用户没给链接不要猜。
- 反推结果只是素材，仍要按下面的方法重写——机器拆解通常会漏掉惯性、呼吸感和光影变化。

## 八、结构化拆解（六个区块）

先按区块写，方便逐块检查和修改。每块写"规律"，不写形容词堆砌。

### 1. 镜头运动 —— 把摄影师想成一台贴近人物飞行的虚拟无人机

写清运动**轨迹与规律**，而非一个词带过（"环绕镜头"不够）：

- 运动类型：前进/后退、侧移、环绕、升降、偏航、俯仰，可以复合。
- 起点位置：离主体多远、离地多高、朝向哪里。
- 过程：以什么速度、绕哪个中心、转过多少角度、在哪里加速减速。
- 终点位置：同样写距离、高度、朝向。
- **惯性**：起步有加速、停下有缓冲，转向时机身略微过冲再回正。

示例：`镜头从 A 的右后方 2.5 米、高约 1.6 米处起步，以低速逆时针环绕 A，前 2 秒缓慢加速，绕过 A 正面时距离缩至 1.8 米、高度降到与胸口齐平，第 5 秒到达 A 左前方时减速带轻微过冲，最终停在 A 左侧 45°、距 2 米处。`

### 2. 呼吸感与真实瑕疵

真实拍摄不是完美轨道。写入：

- 镜头相对人物动作**略微提前或滞后**，不是完全锁定。
- 允许前景人物或物体**短暂遮挡**镜头（半秒以内）。
- 快速运镜结束时可有**短暂失焦后回焦**。
- 轻微手持/气流感的微晃，幅度要写"轻微"，避免模型做成剧烈晃动。

### 3. 光影 —— 光源固定，人在光里走

避免"光永远跟着人脸"的假象。写清：

- **主光源**是什么、在场景哪个方向、什么色温（路灯、窗光、警灯、日光…）。
- 人物与光源的**相对位置**，以及运镜过程中这个关系怎么变：正面受光→侧光→逆光轮廓。
- 环境光/补光的性质（冷暖、软硬），以及脸上明暗随镜头绕行的变化。
- 有闪烁或移动光源时，写它的节奏和落在什么表面。

### 4. 空间与编号

给每个主要人物编号（A、B、C…或 人物1、人物2…），不用"男人""那个人"这种容易混淆的指代。写清：

- 人物之间的相对距离和朝向。
- 镜头离人物多远、离地多高。
- 运镜从开始到结束，这些相对位置发生了什么变化。
- 关键道具/地标的位置，作为空间锚点。

### 5. 背景人物 —— 独立、不完全同步的生活化行为

按角色分组，各写一两个具体小动作，节奏各不相同；允许少数人短时间静止，不要求所有人一直在动。例如某类人"偶尔抬头看一眼"、另一类"半蹲拍照、调整物品"、还有人"压低声音交谈，手里拿着东西"。避免"人群走动"这种统一指令，那会生成整齐划一的木偶感。

### 6. 主体动作与节奏

主体的动作写成有时间点的阶段（第几秒做什么），与镜头运动对齐——这样镜头的提前/滞后才有参照。主体信息放在这一块而不是开头，防止模型把注意力全押在人物上。

## 九、合成最终提示词

把六个区块合成一段连贯的提示词，**先中文再英文**，两版信息量一致：

- 顺序建议：场景与光源 → 空间站位 → 镜头运动全程（含惯性、瑕疵） → 主体动作时间线 → 背景人物 → 画质/风格尾注。
- 用具体数字（米、秒、角度、高度）代替"很近""慢慢"。
- 一段控制在目标模型能接受的长度内；太长就砍风格形容词，不砍运动规律。
- 英文版用摄影术语（dolly in, orbit counterclockwise, crane down, yaw, tilt, ease-in/ease-out, rack focus, brief occlusion），保留编号与数字。

输出格式：

```
## 结构化拆解
1 镜头运动 / 2 呼吸感 / 3 光影 / 4 空间编号 / 5 背景人物 / 6 主体节奏

## 中文提示词
（一段）

## English Prompt
（一段）

## 生成后可能需要微调的点
（1–3 条：哪个参数最可能跑偏，怎么改）
```

## 十、运镜交付前自检

- 镜头运动有没有起点、过程、终点和惯性四要素？
- 删掉所有运镜描述后，这段是不是还成立？如果是，说明运镜写得太弱。
- 光源位置固定了吗？人脸明暗会随运镜变化吗？
- 每个人物都有编号且距离可量化吗？
- 背景人物是不是至少有两种不同节奏？
- 中英文版本信息是否对齐？

## 十一、用户说"效果不对"时

不要整段重写。先问清哪里不对，定位到对应区块修改：

| 症状 | 优先检查 |
|---|---|
| 镜头没绕起来 / 只是平移 | 区块1：是否写了环绕中心、角度变化、起终点朝向 |
| 镜头像轨道车一样死板 | 区块2：补呼吸感、提前/滞后、惯性 |
| 光永远打在脸上 | 区块3：主光源方向与人光关系变化 |
| 人物错位、镜头忽远忽近 | 区块4：编号、距离、高度是否写全 |
| 背景像木偶或统一摇摆 | 区块5：分组、异步、允许静止 |
| 主体动作和镜头对不上 | 区块6：给动作加时间点 |

每轮只改一两个区块，并告诉用户改了什么，方便对照结果归因。

## 十二、两部分怎么配合

调度（§一–§六）决定**机位与人的关系**——谁在画面哪一侧、高度给谁压迫、视线怎么配对；运镜（§七–§十一）决定**摄影机在这套关系里怎么走**。顺序不能反：先在 §一 的俯视示意里定好空间与轴线，再按 §七 的六区块写运动；反过来先编运镜，必然出现"镜头绕着转但空间说不通"。

- §二 的机位三要素（高度/距离/角度）与 §八 区块 4（空间与编号）是同一批信息的不同粒度，写提示词时直接沿用调度结论，不要另起一套。
- §五 的"结论落进既有列、不新增列"同样适用于运镜：运镜结论写进分镜表既有`运镜`列，六区块是**写提示词时的内部检查结构**，不是新的表格列。
