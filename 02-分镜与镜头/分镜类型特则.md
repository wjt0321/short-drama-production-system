# 分镜类型特则

## 一、炫技镜头库（记忆点型 · 镜头层）

每条含：效果 → 构造要点 → 提示词骨架（中文，按 04 号文件映射到目标平台）。占位符：`{主体}` `{场景}` `{情绪}`。

### 1.1 一镜到底跟随（Oner）

**效果**：一个连续镜头跟一个主体穿 2–3 个空间，大片幻觉的第一来源。

**构造要点**：时长 10–15 秒最佳；空间必须有"门/走廊/转角"做段落标记；主体动作一次只做一件；镜头运动单一（全程跟或全程环绕，中途不换运动方式）。

**提示词骨架**：
```
一镜到底，镜头跟随{主体}穿过{空间A}，经过{转折物}进入{空间B}，
{主体动作1}，随后{主体动作2}，{环境动态}，{情绪}氛围，
{主光描述}，{焦段}，电影感，{质感基准}
```
**能力适配**：按已登记能力选择连续生成、视频延长或首尾状态约束；多镜头叙事不等于一镜到底，实际检查跨段连续性。

### 1.2 FPV 穿越机（穿窗/穿廊/穿人群）

**效果**：第一人称飞行镜头穿狭窄空间，肾上腺素型炫技。

**构造要点**：路径必须写成"从哪穿到哪"的连续空间句（穿窗→掠桌面→急转上楼）；速度感来自"贴障碍物掠过"而非笼统的"快速"；终点落在一个情绪画面上，不穿完就断。

**提示词骨架**：
```
FPV 穿越机视角，从{起点}高速穿过{狭窄空间}，掠过{障碍物}，
急转进入{终点空间}，最终停在{情绪画面}上，
运动模糊，速度感，{光线}，{质感基准}
```
**慎用**：晕 3D 观众占比不低，一部短片最多一次，且不超过 5 秒。

### 1.3 时间切片（Time-slice / 环绕定格）

**效果**：主体动作瞬间，镜头环绕，环境凝固或极慢——"子弹时间"。

**构造要点**：只用于"决定性瞬间"（拳头命中前一秒、玻璃碎裂、身份揭晓）；环绕角度写死（90°/180°）；主体极慢微动，环境粒子（雨/雪/火星）近乎静止。

**提示词骨架**：
```
时间凝固效果，{主体}在{决定性瞬间}几乎静止，
镜头缓慢环绕 180°，{粒子}悬浮在空中，
主体仅有极缓慢微动作，戏剧化{主光}，电影感
```

### 1.4 抽帧慢门拖影（王家卫步印）

**效果**：动作卡顿拖影 + 快门模糊，时间失重感。光影叙事系卡片的招牌。

**构造要点**：只用在情绪峰值或回忆段；人物拖影但面部相对清晰（写"面部保持清晰，肢体拖影"）；配 VO 独白效果翻倍。

**提示词骨架**：
```
抽帧拖影效果，{主体}动作呈现顿挫的拖影，
面部保持清晰，快门模糊的背景人流，
{霓虹/暖光}，慢门摄影质感，情绪浓烈
```
**平台适配**：模型不直接支持抽帧时，正常生成后用后期抽帧/帧混合实现（见 06 后期文件思路：生成正常镜头，后期做步印）。

### 1.5 英雄低机位 + 体积光剪影

**效果**：低角度仰拍 + 背光剪影，角色登场或立 flag 时刻。

**提示词骨架**：
```
极低机位仰拍，{主体}逆光剪影，{体积光源}从身后透出轮廓，
{环境粒子}在光柱中浮动，缓慢推近，史诗感
```

### 1.6 匹配剪辑（Match Cut）

**效果**：两个时空的画面在形状/动作/构图上"接得住"，转场即叙事。

**构造要点**：配对两镜必须在分镜表阶段就设计好（构图相似：圆对圆、转身对转身、关门对睁眼）；生成时两镜的构图描述用词保持一致。

**示例配对**：特写（陀螺旋转）→ 特写（车轮旋转）；全景（人坠落）→ 特写（跌入床里惊醒。

### 1.7 速度斜坡（Speed Ramp）

**效果**：同一镜头内快→慢→快，动作片的呼吸感。

**构造要点**：慢的部分必须是信息核心（表情/道具/命中点）；提示词里写清"前段快速运动，中段骤然慢速，末段恢复"。

### 1.8 监控/行车记录仪/手机自拍视角（糙质感炫技）

**效果**：故意降低质感制造"真实感"或喜剧效果，常出现在反转点之后（卡 C 的核心武器）。构造最简单：定机位 + 广角畸变 + 时间戳/噪点描述，与前面的精致画面形成质感落差。

## 二、无厘头结构库（记忆点型 · 叙事层，配合 01 编剧引擎使用）

> 无厘头的公式 = **用极度认真的形式，承载完全不匹配的内容**。镜头越正经，内容越离谱，反差越大越好笑/越深刻。

### 2.1 异常冷开场（前 1 秒出事）

第一帧就是异常状态：丧尸在排队打卡、刀已经架在脖子上但两人在讨论外卖。观众的大脑会问"为什么"，这就追下去了。**前 3 秒钩子四型（01 文件）的第五种：异常状态型**，与卡 C 天生适配。

### 2.2 反差旁白 / 声画对位

画面越紧张，旁白越日常。恐怖画面配养生讲座语气，末日逃亡配购物清单式碎碎念。执行铁律：
- 旁白内容必须与画面**同主题但错位**（都在讲"吃"：画面在吃人，旁白在讲今天的外卖好难吃）。
- 旁白节奏平稳不带情绪，情绪全部交给画面和音乐。

### 2.3 三连升级 + 打破预期

铺垫按"1、2、3"递增到观众以为知道结局（主角终于举枪对准反派——），第 4 拍给完全意料外的落点（——然后递过去一杯奶茶："少冰，三分糖"）。关键：前三次铺垫要一次比一次"更像要发生"，观众预期被拉满，反转才响。

### 2.4 彩蛋结尾

正片结束后 2–3 秒给一个"重新解释全片"的画面或一句台词（反派爬起来擦掉血说"下次换你演"）。作用：拉完播率 + 转发率（观众会拉朋友看彩蛋）。卡点：彩蛋不能削弱正片结尾的情绪，要么反转信息，要么升级世界观。

### 2.5 拟声与音效梗

- 用明显不匹配的卡通音效配真实暴力画面（喜剧缓冲 + 过审双赢）。
- 关键道具出场给一个"标志性音效"（某扇门永远配吱呀声），第三次出现时观众听到声音就笑——声音做成了伏笔。

## 三、炫技纪律与审核清单

1. **一场一技**：同一场戏只炫一个，观众的记忆点需要呼吸空间。
2. **炫技为叙事服务**：每个炫技镜头删掉后如果故事不受影响，就删——它只是漂亮，不是必要。
3. **预算守恒**：炫技镜头失败率是普通镜头 2–3 倍（运动复杂），定量预算留给全片最重要的那一个镜头，其余镜头用稳妥语法。
4. **先学会走**：前三个项目各只练一种炫技（项目 1 练 oner、项目 2 练声画对位、项目 3 练匹配剪辑），跑通再叠加。

- [ ] 全片炫技 ≤3 处，且分布在 20%/50%/80% 附近的节奏位？
- [ ] 每个炫技镜头都能回答"删掉它故事是否受损"？受损才保留。
- [ ] 炫技镜头的时长与失败预算是否已预留重抽余量（见 07 工程化机制 §④成本台账）？
- [ ] **动作类炫技按七段式逐段写齐**（动作目的/起势轨迹/对手响应/接触落空格挡/受力反馈/位移状态结果/下一动作条件）——只有动作名的按"划拉两下"打回？
- [ ] **末帧仍有余波运动**（主体/摄影机/环境至少一项）？停在完全静止姿态上的不通过。
- [ ] **选用具体招式/技法时六检全过**（能掌握/形制肢体距离兼容/姿态可衔接/场景有支点落点/时长装得下/不破坏已锁定顺序胜负）？
- [ ] 无厘头段落的形式与内容反差是否成立（画面越正经，内容越离谱）？
- [ ] 反转点前的前三次铺垫是否一次比一次"更像要发生"？
- [ ] 彩蛋是否独立于正片情绪（可单独剪掉不影响正片）？

## 四、文戏任务定位与三大根因

**负责**：文戏/对白驱动剧场的分镜节奏设计——让长对话场面不闷、有层次、有压迫与呼吸的交替。

**不负责**：台词本身的创作（回 01 编剧引擎）；对白的配音断句与时长（回 05 配音与音效设计）；生成镜头（回 04）。

### 4.1 文戏为什么闷：三大根因

| 根因 | 表现 | 解法 |
|---|---|---|
| **信息单线** | 一镜一句，镜头只是在"换人说"，没有画面信息增量 | 信息分层（§五）：每镜至少同时推进台词信息 + 画面信息（表情/证据/空间变化） |
| **节奏无起伏** | 全程同一个说话-听话-说话的节拍，没有停顿、没有加速 | 压迫-留白交替（§七）：审讯段步步紧逼，转折前留静场 |
| **镜头无角度** | 全程单人正脸，没有正反打、没有轴线、没有景别递进 | 正反打系统（§六）：过肩/单人/反应/证据四类镜头轮换 |

## 五、对白密度与信息分层

### 5.1 三层信息模型

每一场文戏同时承载三层信息，分镜时逐镜标注至少承载两层：

| 层 | 是什么 | 怎么进画面 |
|---|---|---|
| **表层信息** | 说出口的台词 | 说话人的口型镜头 |
| **潜台词层** | 没说出口的真实意图（撒谎/试探/隐瞒/施压） | 眼神、微表情、手部小动作、视线回避 |
| **证据/空间层** | 改变力量对比的事实（文件、通话记录、人物登场、位置移动） | 特写、插入镜头、机位变化 |

**规则**：连续三个镜头都只有"表层信息"（纯说话画面），就是文戏开始闷的信号，必须插入潜台词或证据层镜头。

### 5.2 对白密度分档

按一场戏的信息载荷控制台词密度，密度不等于字数，等于**有效信息量/分钟**：

| 密度档 | 适用 | 特征 | 单镜承载 |
|---|---|---|---|
| 高密度 | 质询、对质、身份揭穿、摊牌 | 每句都推进新信息，几乎无废句 | 一镜一个信息点，可配证据镜头 |
| 中密度 | 谈判、试探、情感交锋 | 部分台词是"话赶话"的情绪层，信息在交锋中推进 | 两三句一个信息点，穿插反应 |
| 低密度 | 静默对峙、决裂前、真相揭晓前 | 台词少而重，靠停顿和反应撑 | 一句顶一段，镜头多给反应和留白 |

**写作纪律**：文戏最忌"每句都是信息"——那是把对白写成说明书；也忌"每句都在绕"——那是注水。中高密度交替使用，低密度留给关键转折。

### 5.3 一场文戏的信息曲线

理想的一场戏（90 秒上下）信息曲线：

```
信息量
  ▲
  │            ★ 转折点（低密度停顿）
  │       ╱╲
  │      ╱  ╲___
  │  ╱══╱        ← 收束（一个重音句收场）
  │ ╱
  │╱
  └─────────────────▶ 时间
   铺垫(中密)  推进(高密)  转折(低密)  收束
```

- **铺垫段**：中密度，建立双方关系与话题，夹一个潜台词暗示。
- **推进段**：高密度，问题层层逼近，每隔 2-3 句插一个反应镜头或证据镜头。
- **转折段**：在揭晓/反转前**主动把节奏放慢**——一个停顿、一句低密度重台词，让观众先意识到"要来了"。
- **收束段**：一句重音句（判决/真相/宣言）收场，后接被打断或离场。

## 六、正反打系统（对话场面的镜头骨架）

### 6.1 四类基础镜头

| 镜头 | 用途 | 文戏用法 |
|---|---|---|
| **过肩镜头**（OTS） | 建立两人对峙关系、力量对比 | 审讯方压迫审讯对象；过肩方向决定谁强势 |
| **单人近景** | 进入某方内心、给重台词 | 说话人说出关键句时推近 |
| **反应镜头** | 承载潜台词层 | 听者听到关键信息时的表情变化（§6.3） |
| **证据/插入镜头** | 承载证据层、打断台词节奏 | 文件、手机、照片、时钟特写 |

### 6.2 轴线规则（文戏第一雷区）

- **对话双方建立一条 180° 轴线**，机位只放在轴线一侧，反打必在同一侧；越轴必须给中性机位（轴线上的正打）或可见的空间穿越。
- **谁强势，给谁低机位或过肩视角**：审讯者略俯视、被审讯者略仰视；反转发生后换边，观众无意识中感知力量转移。
- **画幅特例**：**横屏 16:9（默认）**横向空间足，双人同框、过肩对话是常规主力，不必刻意省用，双人在一个画面里对峙本身就是横屏的语言优势。**竖屏 9:16（备选）**横向空间窄，双人同框难，优先"过肩 + 单人近景 + 反应"三镜轮换；双人同框只用在关系建立和关系破裂两处。

### 6.3 反应镜头经济学

- **反应给谁**：给"信息接收方"——听到关键句的人，不是每句都切。
- **反应切哪里**：只切在"这句话改变了对方状态"的瞬间：震惊、心虚、被识破、动摇、盘算。
- **反应给多久**：文戏反应可以比爽剧给更长——关键反应的停留 0.8-1.5 秒，让观众读到潜台词；但同一情绪不重复给两遍。
- **反应先于台词**：有时先给听者的反应再切说话人（观众先看到"这话有分量"），比说完再切更有张力。

## 七、压迫-留白交替（文戏的节奏呼吸）

### 7.1 压迫手段（加速感）

- 问题越问越短（长问 → 短问 → 一个词逼问）。
- 镜头越切越近（中景 → 近景 → 特写）。
- 说话间隔压缩（对方话音刚落立即追问，不留缝）。
- 证据镜头插入频率加快。

### 7.2 留白手段（呼吸感）

- **静默对峙**：双方都不说话，镜头在两人之间缓慢推近或固定，3-5 秒。
- **停顿重拍**：关键句说完，给 1-2 秒无人说话的"重拍"，再接对方反应。
- **视线转移**：说话人看向别处再转回，替代台词表达犹豫。
- **环境声进入**：钟表声、空调声、窗外车声在沉默中放大，衬托压抑。

**节奏口诀**：压迫三拍、留白一拍。连续压迫不超过 3-4 个信息点，必须给一次留白或插入镜头，否则观众开始疲劳。

## 八、专项场景：听证 / 质询 / 审讯 / 对峙

这类场景是文戏最高频形态，直接给分镜模板：

| 阶段 | 镜头 | 要点 |
|---|---|---|
| **入场建立** | 全景/双人同框 1 个 | 建立空间与双方关系；横屏（默认）直接用双人同框；竖屏改用连续两个单人侧景代替 |
| **规则声明** | 审讯方过肩近景 | 宣读规则/指控，镜头略俯视 |
| **试探** | 单人来反：审讯方问、对象答 | 各给一个单人近景，对象答时镜头不推（保持距离感） |
| **第一次松动** | 对象回答时给手部/眼神特写 | 潜台词层：话没变，身体先变 |
| **步步紧逼** | 过肩 + 单人近景交替，间隔压缩 | 问题变短，切镜变快，审讯方身体前倾入画 |
| **反转时刻** | 全场最慢的一拍：停顿 + 对象反应 1.5 秒 | 力量关系在这一拍换边 |
| **收束** | 换边后的过肩（视角互换）+ 一句重台词 | 收在情绪最高点，不啰嗦 |

## 九、文戏开场：文戏不能慢热

文戏剧最大的坑是"前三分钟两个人在寒暄"。开场钩子处理：

1. **第一镜给结果**：从对峙现场开始，不给铺垫（"模型权重在哪"这种第一句就要有冲突）。
2. **首句即矛盾**：第一句台词就是指控/质疑/摊牌，不是问候。
3. **前 30 秒至少一个反转或身份悬念**：观众不知道"谁是谁"的错位感，比"观众全知道"的推进更抓人。
4. **文戏钩子类型**：从 01 编剧引擎的钩子四型中选"冲突钩/身份钩"，不用"悬念钩"慢启动。

## 十、文戏分镜表演扩展块

文戏不再给已经过宽的主表追加四列。G1 的「潜台词」先进入主表 `备注`，逐镜 `音频与对白轨` 下统一写下列四项，供 04 提示词与 05 配音对齐：

| 字段 | 填什么 | 示例 |
|---|---|---|
| 表演幅度 | 该镜主角的表演档位（静默/微/中/强） | 微（眼神闪躲） |
| 视线 | 说话人看谁/看哪里 | 看向证据文件 |
| 口型要求 | 开口幅度、语速 | 低幅快语 |
| 潜台词 | 从 G1 继承的未说出口信息，不在 G3 临时另编 | 她已起疑，但想让对方先承认 |

> 表演幅度分档的具体控制词表见 `03-角色与视觉资产/写实对白微表演.md`。分镜定表演档位，微表演文件负责把它翻译成提示词。

## 十一、文戏交付前检查清单

- [ ] 每镜是否至少承载两层信息（表层 + 潜台词/证据）？
- [ ] 是否连续 3 镜以上都只是"对着人说话"？是则已补反应/证据/插入镜头。
- [ ] 正反打是否遵守 180° 轴线，力量关系是否随反转换边？
- [ ] 关键信息是否给了听者的反应镜头，反应时长是否够（0.8-1.5 秒）？
- [ ] 压迫段是否 ≤4 个信息点就给了留白/插入？
- [ ] 开场第一镜是否有冲突，前 30 秒是否有反转或身份悬念？
- [ ] 文戏逐镜表演扩展块是否填了表演幅度/视线/口型/潜台词，且潜台词来自 G1？
- [ ] 转折前是否主动放慢（低密度停顿），而不是一路快到底？
- [ ] 收束是否停在情绪最高点，无冗余尾句？

## 十二、两类特则怎么选

| 片型 / 场面 | 用哪一节 |
|---|---|
| 爽剧、逆袭、快节奏短剧（钩子密集、反转快切、动作推进） | `分镜工作流.md` §十三 为主；记忆点段落按 §一–§三 加一处炫技 |
| 文戏、正剧、听证/质询/审讯/谈判/情感对峙/身份揭穿 | §四–§十一（按对白驱动处理，节奏按对白密度分层而非快切） |
| 打斗、异能、末世、预告片式短片、喜剧 | §一–§三（炫技 + 无厘头），并遵守"一场一技"与删掉不损故事才保留 |
| 混合片型 | 主线按 `分镜工作流.md`，进入文戏段切 §四–§十一，进入记忆点段切 §一–§三 |

> **选用纪律**：特则是**追加**不是替换——分镜表的固定列（`刀型`/`本刀新信息`/`时长`/音频与对白轨）、逐秒五要素、空间锚点与 hook 类型在两类特则下都必须填，规则见 `分镜工作流.md` §一/§五/§六。
