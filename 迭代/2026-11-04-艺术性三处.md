# 艺术性三处 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让已经写在体系里的艺术判断，在和闸门冲突时有三处可以做主：种子活到成片回放，全片至多一处不写推断链的决定，生成结果更靠近种子时可以回写分镜且不占质量重抽。

**Architecture:** 判断落在项目 `06-成片/导演证据/导演笔记.md` 的两节里，不新开表。`tools/_art_exception.py` 只读「一处不可解释的决定」。`tools/check_seed_survival.py` 在成片回放时核种子问答，并核发现回写有没有误记成质量重抽。hook、运镜结构、成片帧差、风格锁各自只放行被点名的那一条，其余规则照旧。

**Tech Stack:** 现有 Python 闸、Markdown 模板、`AGENTS.md` 通过条件。不新增依赖。

## Global Constraints

- 不新加平庸签名，不加第十张风格卡，不要求每片必须破例。
- 破例闸只能是 `hook收尾`、`静止比例`、`色彩情绪` 三者之一。用了就必须写至少 12 个汉字的决定，并且「保护的种子」里要出现 G0「具体物件或话语」。
- `hook收尾` 只放开叙事片末镜的强钩。开场强钩、词表、空值照旧失败。
- `静止比例` 只放开叙事片的静止占比和连续静止（分镜表运镜，以及成片帧差）。等距切点、平均时长、装配单未裁照旧失败。
- `色彩情绪` 只把风格锁里的情绪尺度、主色、点缀色从「逐条必须相同」里拿开。渲染、造型、材质仍注入。每条提示词另写 `本镜光色：`，两条以上时这句不能全片相同。风格锁第一句仍是锚句，不要把情绪尺度写在第一句。
- 种子问答只在成片回放时成为硬条件：`06-成片/` 里已有 mp4/mov/webm/mkv，或《项目状态摘要》的当前关卡写成 `G6`。在这之前不挡 G1–G5。
- 答「不在」时，作品状态必须写 `技术已通过，作品未验证`，并且闸不通过。
- 发现回写的错误类型写 `发现`，质量重抽次数写 `0`。身份、场景归属、风格锁里的材质和渲染不动。
- 文档不写环境绝对路径，不写外链。闸表行数与 `tools/run_all_checks.py` 的注册保持一致。
