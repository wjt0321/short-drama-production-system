# 短剧成片体系

给通用 Agent 用的短剧、漫剧和剧情短片生产协议。从一个题材走到可以复盘的成片：先把故事、资产和分镜锁住，再逐镜生成，最后按剪辑刀裁切，而不是把生成段原样接起来。

规则只规定效果、输入输出和质量。模型、软件和参数写在能力登记里，可以换成你自己的实现。

## 三分钟上手

| 你是谁 | 先打开 |
|---|---|
| 人，想做一片 | [`从这里开始.md`](从这里开始.md) |
| Agent，要知道做到哪一关 | [`AGENTS.md`](AGENTS.md) |
| Agent，要知道该读哪一份 | [`SKILL.md`](SKILL.md) 和 [`skill-manifest.json`](skill-manifest.json) |

做片时按这个循环走，不必逐关等人签字：

```mermaid
flowchart LR
  A[理解目标] --> B[立项与风格]
  B --> C[剧本]
  C --> D[视觉资产]
  D --> E[分镜]
  E --> F[小样]
  F --> G[逐镜生产]
  G --> H[完整回放]
  H --> I[修正或交付]
```

只有五类事需要停下来问人：花钱超出授权、外发或发布、上传隐私素材、不可逆操作、方向已经无法兼容。其余由 Agent 自己决定，并把结果写进项目目录。

## 生产阶段

资产先于最终分镜锁定。预拆镜可以用来估计要做哪些资产。

| 阶段 | 在做什么 | 过关时手里有什么 |
|---|---|---|
| G0 立项 | 片型、风格、反向取舍 | 风格提案，方向锁定 |
| G1 剧本 | 因果、变化、钩子 | 读得懂的剧本 |
| G2 资产 | 角色、场景、道具 | 可复用的参考板 |
| G3 分镜 | 刀型、逐秒状态、声音设计 | 分镜表。叙事片静止过多不过关 |
| G4 镜头 | 已验证的实现，同场接上一镜末帧 | 逐镜成片素材 |
| G5 音频 | 配音、音效、一条连续的音乐 | 试听通过的分轨 |
| G6 成片 | 按刀裁切、字幕、回放、复盘 | 成片。整段用满不算剪过 |

同场的下一镜，用上一镜审核过的末帧做图像条件。新的一场才重新锚定。短镜头写在装配单的入点和出点上，不把一条生成段从头接到尾。

## 仓库里有什么

```text
从这里开始.md          人读的总入口
SKILL.md               任务识别和按需加载
AGENTS.md              G0–G6、回退和停问
导演视觉圣经.md        画幅、色彩、风格基线
能力登记.md            当前可用实现，不是广告
技术资产_*.md          选定实现之后才读的档案
01–07                  剧本、分镜、资产、生成、音频、后期、管线
模板/                  一部片子的目录和表格
tools/                 检查闸。退出码 1 就是不过
```

新片子放在 `00-视频项目/《片名》/`。这个目录只留在你自己的机器上，不进版本库。

## 检查

检查脚本只依赖下面两样：

```powershell
pip install -r requirements.txt
python tools/run_all_checks.py --quick
```

机器检查通过，只说明结构和数字对得上，不说明片子好看。跳过检查也不等于通过。

## 这个仓库里没有的东西

对外发布时，下面这些都不在包里：

- 私人项目、成片和素材
- 研究档案、历史快照和归档
- 参考音色的研究样本
- 可选的外部参考数据库

平台和模型的名字只为了说明怎么接，不表示合作或背书。字体、参考音和第三方语料需要你自己取得授权。边界写在 [`声明与许可边界.md`](声明与许可边界.md)。
