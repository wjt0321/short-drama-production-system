# 优秀 AI 短片镜头结构实测 —— G3 分镜门阈值校准依据

> 2026-10-07｜测量对象：seek库 16 条公认优秀 AI 成片（国风 14 + 真人写实 2）
> 测量工具：外部 seek 项目的 `05_工作流与Skills/harvest/shot_metrics_probe.py`（ffmpeg + Python 标准库，零第三方依赖）
> 结论用途：`tools/check_shot_structure.py` 的全部阈值均由本实测推导，不再拍脑袋。

## 一、为什么做这件事

体系此前只有「要求」没有「门」：G3 分镜表要求填写运镜，但没有任何确定性校验。
某早期样片复盘记下的病因（locked/fixed 占主导、静帧轻推变成主体路线）
在某早期失败样片里原样复发——**规则写进文档不等于被执行**。

参照 shuohao-skills 的设计哲学：checklist 交给模型自觉是靠不住的，
必须用脚本确定性校验；且**阈值必须量出来，不是拍出来**——
拍出来的门要么拦不住真问题，要么误伤好片子。

## 二、测量方法（人话版）

把视频缩成 48×27 灰度小帧流（4fps），逐帧与前一帧比对：

- **整幅画面均匀变化** → 摄影机在动（推/拉/摇/移/跟）→ `cam`
- **只有局部小块变化** → 机位没动、主体在动 → `subject`
- **几乎无变化** → 纯静止 → `static`

镜头切点用双支路判据：帧差绝对突变（硬切）+ 局部尖峰（被叠化弱化的切点）。

**已知局限**（读到数据前必读）：
1. 叠化转场若极其平滑，会被判成一个长镜头（《对话敦煌》8 镜、《穿楼敦煌》1 镜
   属此类——穿楼敦煌本身是无缝一镜到底式创意片，此为真实形态而非漏检）；
2. 片头片尾字幕卡会污染首尾镜头（《晚宴》均长被片尾 16s 字幕拉高）；
3. 极慢的静帧轻推（Ken Burns）在 48×27 下与静止不可分（《守护神》全静止含此因素）。

## 四、三种片型 —— 阈值必须先分型再谈

**这是本次实测最重要的发现**：同样"优秀"，结构上分三类，用一把尺子量会误伤。

1. **叙事型**（有角色、有剧情——用户的主赛道）：
   静止 20–43%（中位 29%）、连击 1–7（中位 3）、均长 1.9–4.7s（中位 3.2s）。
   **G3 门的全部阈值以此子集推导。**

2. **画册型**（美术展示，《守护神》为代表）：
   可以 100% 静止 + 34 连击仍是好片——它就是"PPT + 好美术 + 3 秒节奏 + 音乐"。
   **画册式短片对结构门全部豁免。** 人工标注片型后放行。

3. **长运镜/一镜到底型**：静止 0%、全片运镜，靠镜头内部调度。
   结构门天然通过，无需特殊处理。

## 五、阈值推导表（check_shot_structure.py 的依据）

| 指标 | 旧值(拍脑袋) | 新值(实测推导) | 实测依据 |
|---|---|---|---|
| 静止机位占比 | ≤25% 硬门 | **叙事片 >50% 退出码 1**（意象片豁免） | 叙事型上限 43.1%。2026-10-31 起由提醒改为硬失败：提醒没有拦住失败样片 |
| 最长连续静止 | ≤2 镜硬门 | **叙事片 >5 镜退出码 1**（理想 ≤3；意象片豁免） | 短片上限 5。超过 5 曾只是提醒，2026-10-31 改为硬失败；更长连击走豁免登记 |
| 平均镜头时长 | 3.0–4.5s | **2.0–5.5s** | 实测中位 3.2s、范围 1.9–4.7s；旧上限把 4.7s 的蛙僧误判偏长 |
| 运镜配额 | 固定 25% | 固定 30%（软目标） | 实测固定+局部动的真实分布远比配额表宽 |
| 镜头类型配比 | 空镜 12% 等 | 维持（启发式建议） | 视频帧差无法区分镜型，此项只能基于分镜表文本，保持建议性质 |

**没设门的项及理由**（"误拦的门比没有门更糟"）：
- 运镜类型占比：真实分布太宽，设门必然误伤；
- 静帧轻推：《守护神》证明极慢轻推在好片里广泛存在，帧差法分不出轻推与静止，
  不在 G3 拦，由 G4 提示词契约（validate_video_prompt.py）管运镜声明。

## 六、对照：某早期失败样片在优秀片分布里的位置

| 指标 | 失败样片(实测) | 叙事型优秀片范围 | 判定 |
|---|---|---|---|
| 静止占比 | **86%** | 20–43% | 超标近一倍，真问题 |
| 最长静止连击 | **14** | 1–7 | 超标，真问题 |
| 平均时长 | 5.50s | 1.9–4.7s | 边界，可接受 |
| 空镜/插入镜/反应镜 | 0 / 0 / 2 | （无法从成片帧差测量，按配比建议） | 结构缺失 |

结论修正：此前表述「PPT 感第一来源是静止镜头多」不够准确——
实测证明**大量静止不必然 PPT**（山海经 43%、守护神 100%）。
真信号是：**长连击 + 零反应镜/插入镜/空镜（节奏没有呼吸）**。
某早期失败样片两条全中，所以是 PPT；《守护神》连击 34 但每 3 秒换一张高完成度画，
美术与节奏掩盖了静止。

## 七、复现

```bash
# 测量任意成片（或整个目录）
python "<外部 seek 项目>/05_工作流与Skills/harvest/shot_metrics_probe.py" <视频或目录> --json out.json

# 审计任意分镜表（阈值已按本实测校准）
python tools/check_shot_structure.py <项目>/03-分镜/分镜表.md
```

两工具均零第三方依赖；probe 需要 ffmpeg（本机随 ComfyUI 分发，位于
ComfyUI 目录下 `tools/ffmpeg/bin`，加入 PATH 或用 `--ffmpeg` 指定均可）。
