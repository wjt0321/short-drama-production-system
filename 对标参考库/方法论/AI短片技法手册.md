## 零、先记住这一条主线

整条流水线的骨架在 `AI修仙vlog全流程` 里讲得最清楚，四步：

| 步骤 | 做什么 | 谁做 |
|:--|:--|:--|
| **1. 剧本 & 分镜** | AI 产出故事脚本 + 分镜脚本 | GPT / Gemini |
| **2. 静帧画面** | 画出**清洁且有质感**的分镜图 | 即梦 / LiblibAI / Nano Banana |
| **3. 视频转动画** | 让分镜动起来（数字人 / 图生视频） | 即梦 |
| **4. 配音 & 剪辑** | 配音串成故事短片 | 剪映 |

> 原话：**"我们如果想要用 AI 制作这样质量很高的微短剧"** → 关键在第 2 步的静帧质量。
> 成片的质感上限由静帧决定，动画阶段只是让画面动起来。

## 一、核心公式 A：一句话生成分镜的句式

出自 `影视级AI短剧转场`（SansanYe-Vision）画面实录，这是最可直接复用的模板：

```
镜头 01-07
【景别】+【构图】+【光线】+【人物表情、动作】+【场景/互动】+【台词】+【饰品】+【转场】
```

**填充示例**（同一条视频里的真实内容）：

> **镜头 1** 正面中景。英发，少女，从左侧向内走出，固定，对视镜头，光线从侧光打到女生脸上，脚步后移镜头，房内是暖内投设的平面灯前的光。
>
> **镜头 2** 局部特写镜头，侧拍，倒伤，光线打在她脸颊和刀刃，刀刃处及右没有别停动作，地面反折光到桌。
>
> **镜头 3** 分镜构图镜头，案主正面特写。桌面，桌面，桌面与女孩交叉位置。女孩抬头，表情略带迟疑，低头看班某人。

**要点**：景别 → 构图 → 光线 → 人物 → 场景，五项齐全才叫分镜；缺一项生成出来就是"碰瓷图"。

## 二、核心公式 B：画质四段式

同样出自 `影视级AI短剧转场`，这是**图生视频/写实古装剧**的提示词骨架：

```
【画质质词与氛围】+【主体动作】+【人物/特写+服饰】+【画面处理与氛围】+【运镜速度与运镜方式】
```

填充实例：

| 段 | 内容 |
|:--|:--|
| 画质质词与氛围 | 高质量古代女侠剧照风格、真实 HDR 光照质感 |
| 主体动作 | 身姿婀娜、背影婀娜、光影交叠 |
| 人物/特写+服饰 | 俏皮可爱少女、珍珠项链、光感白纱短裙、香肩圆润、黑色眼影、红唇微笑 |
| 画面处理与氛围 | 光影可见、光影线条、不完全遮灰 |
| 运镜速度与方式 | **不要虚焦、聚焦于人物**（负向约束） |

**器材词库**（增强真实感）：`Sony FX3 拍摄 / 85mm f1.4 / 35mm f1.4 定焦`

## 三、核心公式 C：8 要素法（LiblibAI 多角度缩略图）

出自 `图片提示词8要素`（设计师dooo），用 LiblibAI 的「多角度缩略图」功能批量出图。

```
谁  在哪里  什么时间  做什么
景别  机位  视觉风格  （+ 正在做的动作）
```

配套词表：

| 类别 | 取值 |
|:--|:--|
| **景别** | 大远景 / 远景 / 全景 / 中景 / 近景 / 特写 / 超大特写 |
| **机位** | 仰视 / 平视 / 俯视 |
| **光线方向** | 顺光（光从摄影机方向照来）/ 平光 / 侧光 / 逆光 |
| **光线性质** | 烛光 / 屏幕光 / 摄影棚光 / 霓虹灯光 |
| **视觉风格** | 写实类 / 非写实类 |
| **氛围词** | 孤独 / 欢快 |
| **影调** | 伦勃朗光 / 神秘暗调 / 黄金时刻 / 诺兰冷灰 |

> 母语示例：*「一位女性在悲伤，在夜晚，独自走着；特写，平视，诺兰冷灰；正在跑步」*

**批量技巧**：用「文本节点」+ 批量生成，文本节点里写
`根据图片生成结构和中文关键词，包括主体描述、环境、光影、镜头语言、风格关键词`

## 四、分镜板制作：6 条路径（按门槛从低到高）

出自 `6个分镜路径`（辐射星球Jeffrey）。**你不用会画画**——他全程抱猫讲解，做的就是"不会画画的人怎么出分镜"。

| 路径 | 工具 | 门槛 | 适合阶段 |
|:--|:--|:--|:--|
| **方案二 简笔绘图** | 手绘/画图工具 | 极低 | 刚起片，只求把空间关系想清楚 |
| **方案三 改动原图** | 找一张构图接近的原图，叠自己的元素 | 低 | 快速试镜头 |
| — | **Storyboarder**（免费可下载） | 低 | 标准化分镜表 |
| — | BoltAide 表格模板 | 低 | 剧本→分镜表的转换 |
| — | 剪映/任意绘图 | 中 | 已有素材的重组 |
| 路径一 | AI 生成分镜图 | 中高 | 成片前定帧 |

### 风格化滤镜（方案三的关键）
App 内置的 Post Processing Filter，可把素图一键转风格：

```
Unifying(棕褐) / Hitchcock(黑白) / Big Easy(暖) / Fargo(冷) / Brooklyn(复古) / Bamboozle(电光)
```

**对国风志怪特别有用**：黑白 → 敦煌壁画的褪色感；冷调 → 山海经的幽冥感。

### 分镜表该有的列
`镜号 | 时间 | 景别 | 运镜 | 光线 | 画面内容 | 台词 | 备注`

## 五、一致性：AI 短片最大的坑

`影视级AI短剧转场` 专门讲了这个：角色/服装/场景必须**固定绑定**，否则每格画面人物都在变。

**方法**：
1. 先出一张满意的主形象图
2. 把它的**服装、发型、饰品**写成固定字符串
3. 每一格提示词里**原样重复**这段字符串
4. 分镜板排版时把参考图挂在每格旁边做锚点

> 原话：**"方便我们去保持人物的一致性"**

**分辨率/出图数量建议**（同源）：
- 电影级质感 → **2K 高清**起步，预算够上 4K 超清
- 二次元/竖屏 → **3:4** 或 **9:16**
- 每格**出 3 张**选 1 张（不要只出 1 张碰运气）

## 七、零成本路线：Gemini + Nano Banana

出自 `PREVIS分镜故事板`。**完全免费**，适合还没定稿的阶段。

```
Gemini 写分镜文字（含镜号 P1/P2/P3… + 运镜术语）
   ↓
Nano Banana（Gemini 图像模型）逐格生成分镜图
   ↓
拼成故事板 → 逐格喂给视频模型
```

关键是**先让 Gemini 产出格式化的镜号 + 运镜描述**，再逐格生成。

## 八、Skill 类工具清单

| 名称 | 作用 | 获取 |
|:--|:--|:--|
| **人物站位 skill** | 输入"柱"（场景描述）→ 自动出人物站位示意图 → 确认后生成分组景别/运镜/人物动作提示词 | 豆包搜"专业级多场景分镜调度提示词skill" |

人物在空间里的相对位置错了，后面所有景别都是废的。

## 九、执行清单（照着做）

1. **定一句话概念** → 用 Gemini 扩成故事脚本
2. **拆镜号** → 用上面的"句式 A"写每格的五项（景别/构图/光线/人物/场景）
3. **出站位图** → 人物站位 skill，确认空间关系
4. **选路出分镜板** → 零成本走 Gemini+Nano Banana；要本地可控走 ComfyUI 九宫格
5. **逐格精修** → 固定人物字符串 + 画质四段式，3:4 或 2K，每格出 3 张选 1
6. **接视频模型** → 即梦图生视频 / 你本地的 H3
7. **配音剪辑** → 剪映

## 十、给你（国风志怪方向）的三条特别提醒

1. **色彩锚定在成片里**：`蛙僧` 那条之所以成立，是**赭黄沙漠 × 青蓝洞窟**的冷暖硬分离。做之前先把主色卡定死，别让模型自由发挥。
2. **仪式化构图靠重复阵列**：敦煌千佛那种"朱红底 + 对称网格 + 重复头光"是最容易复刻的高级感，成本极低。
3. **光要局部**：蛙僧的提灯、守护神的壁画高光——**大面积均匀打光会立刻掉到"廉价AI片"**，一定要有主光源 + 环境暗部。
