# 对标参考库总览

## 边界

- `seek库` 已迁出体系，作为独立知识采集项目维护；它不是 SOP、生产入口或默认风格参考。
- `对标参考库/` 只保存体系采用的方法、研究与内部适配实现，不再充当第二套素材库。
- 普通制作 Agent 不加载 seek 的目录、采集脚本或登录态；风格由项目需求、视觉圣经和 Agent 自主判断生成。

## 使用边界

本目录只保留体系自有的方法论、研究结论和内部草案生成脚本。它不是风格模板库，也不是普通制作 Agent 的默认检索入口。Agent 应先依据项目需求、剧本、导演视觉圣经和资产自主形成风格；外部参考只能由用户提供或由维护者在独立任务中显式接入。

## 维护者说明

- `对标参考库/提示词库/` 只保留体系内部生成器、审核门和示例，供维护和回归测试；不是 Agent 的风格检索入口。
- 采集媒体、提示词语料、封面、工作流和原始采集脚本已迁出体系，放在体系外的独立数据项目中维护。
- 研究档可以作为方法背景读取，但不得把历史样片、历史参数或外部提示词直接当作本片风格答案。
