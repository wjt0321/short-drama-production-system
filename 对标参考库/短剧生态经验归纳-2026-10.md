# 短剧生态经验归纳（2026-10）

> 目的：把 2026-10 两路调研（魔搭社区扫描 + 开源短剧仓库精读）收敛成一页**最终结论**——
> 只写已吸收的经验与明确拒绝项；过程证据见 `开源短剧提示词与运动合同研究-2026-10.md` 与
> `生视频HUB与ComfyUI官方案例研究-2026-10.md`，不再分别另建长报告。
> 本文档是归纳，不是 SOP；其中的生态数字是扫描快照，复扫会变。

## 一、魔搭社区扫描（快照观察）

2026-10 对魔搭（ModelScope）短剧/AI 制片方向的公开资源做了一次命中扫描，共 808 条命中：

- **形态分布**：781 条为 skill 形态、27 条为 mcp 形态——生态以"提示词包 / 工作流包"为主，
  不是工程框架；几乎没有可复用的runtime。
- **供给集中度**：BainWu 一个作者占 522 条（64.6%）——供给高度集中且质量参差，
  命中只能进候选池，默认可信度低，逐条实证后才可用。
- **模板换皮普遍**：大量资源是同一套分镜/提示词模板替换题材词复用——
  借鉴**结构**可以，照搬**内容**无用，还会把别人的漂移带进本片。

**结论**：魔搭是候选池不是答案。检索命中只进入"待验证方法库"，不进入主 SOP，不默认加载。

## 二、开源仓库精读（ViMax / Agent Skills / ArcReel / Jellyfish / Toonflow）

对五个有代表性的开源短剧/漫剧项目的共同实践做交叉比对（逐个仓库的细节与 commit
见两份研究档，按需复核，不在此复制）：

- 它们的共同骨架都是"**剧本结构化 → 分镜 → 资产 → 逐镜生成 → 装配**"，
  与体系 G0–G6 同构；差异在自动化程度与 UI 形态，不在流程本身。
- 长剧管理普遍采用"画布/节点视图"（整季全局）+ 列表视图（单集细节）的双层形态。
- 部分管线支持把素材与粗剪时间轴导出为剪映草稿——AI 排顺序与字幕，人只调节奏与封面。

## 三、最终吸收的四条经验

1. **自主导演**：Agent 拿到题目后自己立项、自己看真实参考、自己定风格与导演判断，
   自己小样验证、生产、完整回放、自主修正到交付；审核是可选插入点，不是逐关签字。
   已落到 `AGENTS.md`、`从这里开始.md`、`07-端到端管线/生产证据与片型路线.md`。
2. **能力路由**：镜头需求 → 能力登记找候选 → 按质量 / 实测成功率 / 速度 / 成本 / 隐私权衡
   → 选定已验证实现；供应商选择是 Agent 的内部决策，不甩给用户。
   已落到 `AGENTS.md` §二。
3. **渐进加载**：默认只加载轻量入口（SKILL / 从这里开始 / AGENTS / 当前阶段专项）；
   研究档、适配档、历史项目按需引入。已落到 `SKILL.md` §一与 `skill-manifest.json`。
4. **连续性与 animatic**：首尾帧/关键帧接力 + 低清动态草稿（animatic）先于正式生成验证
   节奏、切点与接缝；运动合同 9 字段（屏幕坐标 / 朝向 / 脚步 / 接触 / 车轮耦合 / 视线 / 轴线等）
   作为按需方法库进入提示词层，验证后才算数。
   已落到 `04-视频生成/平台提示词契约.md`、`02-分镜与镜头/分镜工作流.md`、
   `模板/短剧项目模板/04-镜头/镜头提示词.md` 与 `06-成片/成片质检表.md`。

## 四、明确拒绝项（不做）

- **逐关签核 / 哈希审批链**：技术证据与作品判断分开记录即可，不建签字链。
- **把候选池甩给用户**：候选由 Agent 权衡后自主选定，只在方向级冲突时才递候选。
- **模板换皮式量产**：不复制他人模板内容，只借结构；换皮产物不进入素材库。
- **长报告前置阅读**：研究档不进默认加载集，按问题检索查阅。
- **把生态快照数字当承诺**：魔搭命中数、占比均为扫描观察值，引用时标注日期。
