# 首集验证与止损

## 1. 为什么需要首集验证

连载型作品最大的成本风险是"做完全部集数才发现没人看"。行业观察（2026 年）：即使头部作品，上线第一周也可能数据平平，之后才起量；而大量长尾作品止步于百万播放以下。**首集验证把"押注整季"变成"先验证一集"**：用最少资源先测内容是否成立，成立再放量。

适用场景：

- 计划做连载（≥10 集）的短剧/漫剧 → 必做
- 单集独立短片（无续集计划）→ 可不做，直接看复盘
- 广告片/MV/口播 → 不适用

---

## 2. 验证指标（四项，口径沿用 `06-后期与发布/标题钩子与发布.md`）

| 指标 | 反映什么 | 首发集关注点 |
|---|---|---|
| **3 秒跳出率** | 标题/封面/前 3 秒的合力 | 偏高 → 开头没兑现钩子，或标题封面与内容错位 |
| **完播率** | 全片节奏与结尾 | 偏低 → 中段拖沓或结尾没留追更理由 |
| **互动率**（点赞/评论/转发/收藏） | 情绪强度与话题性 | 偏低 → 缺少可站队/可吐槽/可共情的点 |
| **追更转化**（关注/主页访问/下集预约） | 系列黏性 | 偏低 → 人物弧线不成立，看完即走 |

## 3. 验证节奏与判定

### 3.1 时间点

- **首发集发布后 24h**：记第一组数据，看冷启动是否过门槛
- **72h**：记第二组数据，看是否有二次传播与追更迹象
- 数据落在 `06-成片/复盘一页.md`

### 3.2 分级判定（通用参考线，按平台实测校准）

| 等级 | 判定 | 动作 |
|---|---|---|
| **达标** | 四项中完播率与追更转化均达目标平台同期中位水平以上 | 继续连载，回写本集有效钩子到剧本规则 |
| **边缘** | 完播率尚可，但 3 秒跳出率高或互动率低 | 先改标题/封面重测，不改内容；24h 后仍无改善进止损 |
| **不达标** | 完播率明显低于中位，或追更转化接近 0 | 进入止损流程（见下节） |

> 阈值如何定：立项时在 `00-立项/立项决策表.md` 记录"目标平台同期中位参考"（可从 `docs/连载运营/立项对标拆解.md` 拆解对标作品时一并采集），不拍脑袋定标准。

## 4. 止损流程（分级，先低成本后高成本）

```text
首集数据不达标
  ├─ A. 改标题/封面（成本最低，1 次机会）
  │    条件：3 秒跳出率高但完播率尚可 → 标题封面与内容错位
  │    动作：换备用标题（发布时本应备好 2-3 条）+ 换封面帧，24h 复测
  │    结果：达标 → 继续；仍不达标 → 进 B
  ├─ B. 回 G1 改钩子/重剪开头（内容层，1 次机会）
  │    条件：完播率低 → 开头没兑现承诺 / 中段拖沓 / 结尾钩子弱
  │    动作：回 01-创意与剧本/短剧编剧引擎.md 重写开场钩与集尾钩，重剪开头 3 秒与结尾
  │    结果：达标 → 继续；仍不达标 → 进 C
  └─ C. 换题材/换方向（立项层，需用户决策）
       条件：A、B 都无效 → 方向本身没市场
       动作：回 docs/连载运营/立项对标拆解.md 重新对标与选题，另起新项目
       记录：止损原因、投入、结论写入《用户裁决日志.md》与《变更记录.md》
```

**止损纪律**：

- A、B 各只有一次机会，不无限重试（对齐 AGENTS.md 回退链的"最多 2 次质量重抽"精神）。
- 止损不是失败，是省下整季的投入；止损结论要能指导下一部（记"这个题材这个钩子在这个平台没跑通"）。
- 数据好但口碑差（完播高、互动低）→ 不急着止损，先补情感点与站队点，看下一集。
- 数据差但作者强烈认为方向对 → 允许缩小投入再做 2-3 集观察，但必须设第二次验证点，不无限续投。

## 5. 量产/连载模式下的验证变体

当采用量产模式（见 `07-端到端管线/片型全流程.md` §4.0，用户只审首集与里程碑集）时：

- **首集验证 = 里程碑**：首集数据达标，才放行第 2-10 集的批量生产；不达标则整批不产。
- **滚动验证**：每 5-10 集或每季末设一次里程碑验证（对照 `06-后期与发布/标题钩子与发布.md` 的复盘指标），防止"首集过关、后续注水"。
- **批量生产期间若单集质量崩**：暂停放量，回质量归因（`AGENTS.md` 第五节失败回退链 + `04-视频生成/重抽与回退决策.md`），而不是继续灌水——完播率下跌的代价大于断更。

## 6. 交付物与记录

- 首发集《复盘一页.md》：24h/72h 数据、结论、保留/调整项
- 若触发止损：《用户裁决日志.md》记录用户对换方向的裁决
- 有效钩子与失效钩子回写 `01-创意与剧本/短剧编剧引擎.md` 的钩子规则或项目剧本规则，供后续集复用
