# 立项对标拆解

## 立项先落到可拍内容

一般短片不必做商业爆款与回本流程；只在任务需要时使用下文。全权委托由Agent自主定方案。

立项用简短文字交代观众跟随什么、核心看点如何被画面兑现、主要人物/物件与空间、开头和结束有什么变化。补一条视听路线：故事的时间/天气与主光来源，哪些节点改变光线方向、色温、明暗或可见程度，以及这种变化服务什么内容；同时说明镜头距离、构图/视线引导和色彩阶段如何随着内容变化。没有变化理由时保持基准，不为了“丰富”随机换光或换色。列出真正要表现的生活过程、交互或视觉变化，而不是只有题材名与“唯美震撼”。结合实际看过的seek参考写借鉴点，不把参考标签当内容。历史事实、创作假设与艺术改编分别说明，未知不编成事实。

预判影响制作的具体难点（多人接触、文字、空间转移、连续镜头等）并选择可实现呈现，不为了避难把主内容全部删成远景。时长由内容需求初估，不先锁“镜头数×固定秒数”。不新增表格；必要信息沿用立项说明。

## 1. 为什么立项前必须先拆爆款

AI 短剧/漫剧是产能爆炸型赛道。据 2026-08 公开行业统计：单月新增播放量数百亿级、日均新上数百部、单月破亿播放的作品数百部，头部与长尾严重两极分化（约九成作品月播放不足百万）。**题材公式和爆款结构是公开的，新作品的机会不在"发现新赛道"，而在"在热门赛道里做出差异化 + 用首集数据验证"**。

对标拆解的目的不是抄袭，而是把以下问题在花钱之前答清楚：

- 这个方向现在到底有没有人看？（选题验证）
- 头部作品是靠什么留住人的？（钩子与节奏公式）
- 头部作品的视觉规格和单集规格是什么水平？（制作基准）
- 头部作品单集成本/团队/周期大概多少？我能不能复现？（产能与成本可行性）
- 我这部片子凭什么是下一部被看中的？（差异化定位）

**纪律**：拆解结论只做立项输入，不做抄袭模板；任何"参考当前榜单"的结论都标注采集日期，过期即失效。

## 2. 拆什么：六个拆解维度

对每个对标作品（建议 2-4 部：2 部头部 + 1 部同期黑马 + 1 部同类差异化作品），按六个维度拆：

### 2.1 题材与爽点公式

| 拆解项 | 要回答的问题 | 记录方式 |
|---|---|---|
| 题材大类 | 属于哪个高频题材（逆袭/重生/甜宠/悬疑/玄幻/家庭…） | 主题材 + 辅题材 |
| 剧名特征 | 剧名用词模式（身份反转型/数字型/悬念型…） | 记录句式，不抄片名 |
| 核心爽点链 | 观众为什么留下来（打脸/逆袭/团宠/解谜/情感代偿…） | 一句话爽点链 |
| 开场承诺 | 前 3 秒给观众什么"已经出事"的画面 | 记录钩子类型（对照 `01-创意与剧本/短剧编剧引擎.md` 钩子四型） |

### 2.2 钩子与节奏结构

| 拆解项 | 要回答的问题 |
|---|---|
| 开场钩位置 | 第几秒出第一个冲突 |
| 首个爆点 | 前 30 秒内第一个爽点/反转在哪 |
| 集尾钩 | 每集结尾停在什么"未完成"状态 |
| 单集节奏 | 大高潮间隔、小高潮密度（对照 `01-创意与剧本/短剧编剧引擎.md` 节奏曲线） |
| 付费/转化卡点（如适用） | 卡点位于全剧什么位置 |

### 2.3 视觉规格

| 拆解项 | 要回答的问题 | 记录方式 |
|---|---|---|
| 形态 | AI 真人短剧 / 3D 漫剧 / 2D 动态漫 / 特效概念片… | 对照 `题材风格与平台库.md` 形态表 |
| 画风基调 | 写实电影感 / 3D 电影级 CG / 国风厚涂 / 韩漫精修… | 一段风格描述词 |
| 色彩与照明 | 冷暖、反差、主光方向 | 记入后续 G0 色彩脚本输入 |
| 画幅与时长 | 竖屏/横屏、单集时长、集数体量 | 规格基线 |

### 2.4 单集结构与产能

| 拆解项 | 要回答的问题 |
|---|---|
| 单集镜头数 | 一集约多少叙事镜头/剪辑点 |
| 更新节奏 | 日更/隔日更/周更、单次放几集 |
| 总集数与季数 | 连载体量（一次性全集 / 分季续作） |
| 制作周期 | 单集从脚本到成片约多久 |

### 2.5 成本模型（估算）

| 成本项 | 估算依据 | 说明 |
|---|---|---|
| 角色资产收敛 | 每个主要角色出图筛选成本 | 主力角色收敛定稿的抽卡/算力开销 |
| 分镜设计 | 分镜占比（行业经验：分镜最耗精力） | 一部片约六成以上精力在前置设计 |
| 视频生成 | 单镜算力成本 × 镜头数 × 重抽系数 | 行业经验区间：精品单集单分钟算力成本数百到数千元；量产漫剧单集可压到数百元级 |
| 配音/音效/BGM | 配音、配乐、音效成本 | 是否用免费/低成本方案 |
| 后期与交付 | 剪辑、字幕、质检 | 自动化可显著压缩 |

> 行业公开案例（2026 年观察，仅作量级参考，立项时按当期实测更新）：独立精品剧（8 分钟/集）总投入可达十万元级、单分钟算力约千元级；红果/抖音量产漫剧（几十秒-2 分钟/集）单集成本数百元级、单周可产数十集。**不要把这些数字当成固定价格**，它们只是"精品 vs 量产"两条路线的成本量级参照。

### 2.6 变现与合规约束

| 拆解项 | 要回答的问题 |
|---|---|
| 变现模式 | 免费 IAA / 付费 IAP / 平台分账 / 广告植入 / 私域导流 |
| 备案与合规 | 目标平台的备案/资质要求、题材红线 | 对照 `01-创意与剧本/短剧编剧引擎.md` 合规红线 |
| 平台规则 | 上传规格、日更上限、活动标签 | 发布前按当天规则核验 |

|---|---|

| 视觉规格 | |
| 单集结构与产能 | |

## 4. 拆完反推：立项三问

对标表全部填完后，回到项目层面回答三个问题，结论写入《立项决策表》：

### 4.1 这个方向还值不值得做？

- 头部作品是否仍在该题材上持续产出且数据没有下滑 → 值得做
- 榜单已被同质化作品塞满、且你无法提供差异化 → 换题材或换切入点
- 该题材近 30 天没有新爆款 → 可能已过热度周期，谨慎

### 4.2 我的差异化在哪？

至少写出一句"这部片子比对标强在哪"：

- 更强的故事/情感厚度（用户需求已从纯爽转向情感共鸣）
- 更独特的视觉风格
- 更快的产能（量产漫剧路线）
- 更垂直的受众（如银发、特定圈层）

### 4.3 我的成本与回本模型成立吗？

完成回本测算（见下节），结论进《立项决策表》的"预算上限"与"产能模式"。

## 5. 回本测算（立项闸门）

回本测算是立项的硬性闸门之一。算不清账的项目不进 G0。

### 5.1 成本侧

| 项 | 计算方式 | 本片估算 |
|---|---|---|
| 角色资产收敛 | 主要角色数 × 每角色收敛成本 | |
| 分镜设计 | 总镜头数 × 单镜分镜成本 | |
| 视频生成 | 总镜头数 × 单镜算力成本 × (1+重抽系数) | |
| 音频 | 配音+音效+BGM 合计 | |
| 后期交付 | 剪辑/字幕/质检/导出 | |
| 总成本 | 以上合计（按整季或首批集数） | |

### 5.2 收益侧（按目标平台当期政策估算）

| 项 | 估算方式 |
|---|---|
| 平台分账/播放收益 | 预期播放量 × 当期分账单价（按目标平台政策） |
| 广告/付费转化 | 预期完播用户 × 转化率 × 客单价（IAP 或 IAA） |
| 其他收益 | 商单、版权、私域导流、出海 |

### 5.3 判定

- 预期收益 ≥ 成本 × 安全系数（建议至少 1.5）→ 可立项
- 收益不明确但方向值得验证 → 缩小首期投入（只做首批 3-5 集 + 首集验证），用数据换确定性
- 算不平 → 降规格（短时长/少集数/量产化）或换方向，不硬做

**预算纪律**：立项时写死"单集成本上限 + 全片预算上限 + 重抽预算"，写入《立项决策表》；执行中任何超支必须回立项重审，不允许边做边默默加钱。

## 6. 与后续关卡的关系

| 关卡 | 对标拆解如何输入 |
|---|---|
| G0 风格立项 | 对标作品的视觉规格、画风基调、画幅时长 → 风格提案基线 |
| G1 剧本 | 题材公式、钩子类型、节奏曲线、集尾钩模式 → 剧本结构 |
| G2 视觉资产 | 头部作品的资产精度水准 → 角色/场景品质基准 |
| G4 逐镜生成 | 成本模型与产能模式 → 单镜预算与重抽预算 |
| G6 发布与首集验证 | 变现模式、更新节奏 → 发布计划；首集数据验证见 `docs/连载运营/首集验证与止损.md` |

## 7. 数据纪律与更新

1. 榜单、成本、政策数据都有时效：每个数字标注采集日期，立项前重新采集。
2. 行业案例只做量级参照，不写成本片承诺；实测后回写 `00-立项/能力登记.md`。
3. 拆解结论与"本片差异化定位"分开记录：公式可复用，内容不得照搬。
4. 数据来源区分：官方发布 / 行业报告 / 社区观察，引用时标注类型。
