1. README 从历史说明、外部资源和迭代流水账收敛为入口、路线、G0–G6、核心纪律和校验方式。

3. 增加参数化只读源档案核验：`tools/check_source_archive.py --root <目录>`。脚本不写入、不移动、不删除源档案。

6. 增加 G0/G1 叙事决策锁、统一审核包头部、冻结解冻申请、回退原因和重新进入关卡字段。
7. 增加资产冻结版本、三视图验收、关键机位、道具跨镜状态和首帧资产版本字段。
8. 增加 G5 分轨试听与音画粗混试听；补齐配音、音效、BGM、字幕的稳定 ID 和交付映射。

## 仍然保留的使用边界

- 本仓库提供能力层规范与项目模板，不承诺任何具体实现、服务或模型始终可用。
- 源档案只做外部存档核验，不是运行时依赖；调用者必须显式传入源目录。
- “合格 Skill”指体系规范、入口和模板达到可执行标准；实际项目仍需逐关通过用户审核。
