## 三、对目标最直接的两条阻塞

### 阻塞 A：G3 及之后的闸门不认识片型

**现状**：`模板/短剧项目模板/01-剧本/剧本.md:18` 有「片型：叙事 / 意象」字段，`check_script_causality.py:200-232` 也确实有「意象片」分支（改查意象变奏 ≥3 次）。

**但片型信息止步于 G1。** 逐闸清点：

| 闸 | 是否读片型 | 对意象片/文艺片的后果 |
|----|-----------|---------------------|
| `check_script_causality.py` | ✅ 读 | 正常 |
| `check_hook_density.py` | ❌ | 末镜必须是 visual-joke / reversal / reveal / suspense / tender 之一 → 留白、静默、反高潮结尾一律不通过 |

| `check_per_second_coverage.py` | ❌ | 每秒五要素对"静默的一秒"同标准要求 |
| `check_emotion_words.py` | ❌ | 但这条对文艺片反而是助力 |

**结论**：体系允许你声明自己是意象片，但只有 G1 一道闸当真。G3 之后会被当成商业竖屏短剧来量。

### 阻塞 B：G1 有欲望/阻力字段，没有闸验证它们

**现状**：剧本模板 `:76-77` 已有：
```
- 主角当集目标：______
```

`check_script_causality.py` 的检查项是：因果四句、道具翻转/意象变奏、朗读测试、exec 参数黑名单。**它不读「主角当集目标」和「核心阻力」两栏**——grep 全文零命中。

### P0-C：情绪词闸可用通用量词绕过（已实测）

**文件**：`tools/check_emotion_words.py:79-81`

```python
PHYSICAL_MARKERS = (..., "范围", "边界", "走向", "面积", "深浅",
                    "力度", "速度", "角度", "高度", "距离", "方向", ...)
```

**实测结果**（本轮直接调用 `find_violations()`）：

```
'她很愤怒，范围很大，走向是向前。'  -> []          ← 通过
'他很悲伤，角度稍微低。'            -> []          ← 通过
'画面中人物紧张，速度偏慢。'        -> []          ← 通过
'情绪：愤怒。'                     -> [('愤怒', ...)]  ← 被拦
'眉间收紧，下颌前伸，嘴角下压。'    -> []          ← 通过（应当通过）
```

**结论**：在情绪词后面接一个"范围/角度/速度"就能过关，而这些词本身不指向任何可指认的画面事实。§8.1 要求的是"眉间收紧程度、嘴角朝向、下颌角度"，闸接受的是"范围很大"。

**修复方向**：通用量词只有在同小句内出现具体落点时才算数——例如 `范围` 需搭配方位/部位/数值（`范围从锁骨到耳根`），`角度` 需搭配数值（`15°`）。或者引入部位词表（眉/眼/嘴角/下颌/手指/肩/背）作为必要条件。

## 五、必须填补（8 项，按对"作品性"的影响排序）

### 1. G1 成立性闸：把已有的两栏接上闸（最高优先级）

**不做新字段，只接闸。** 模板 `:76-77` 的「主角当集目标」「核心阻力」已经存在，缺的是验证。

**最低可用版本**（不追求语义理解，只拦"填了等于没填"）：

```python
def check_viability(txt):
    issues = []
    for field, reasons in (("主角当集目标", GOAL_ANTI),
                           ("核心阻力", OBSTACLE_ANTI)):
        v = read_field(txt, field)
        if _hollow(v):
            issues.append(f"{field} 未填")
        elif len(v) < 8 or any(v.strip() in a for a in reasons):
            issues.append(f"{field}「{v}」不构成{...}：需要具体到"
                          f"{'他想要什么、为谁、什么时限' if field=='主角当集目标' else '谁/什么在阻止、用什么手段'}")

    # 代价栏（需新增）：失败会失去什么
    if _hollow(read_field(txt, "失败的代价")):
        issues.append("未写「失败的代价」—— 没有代价的追求不构成戏剧")
    return issues
```

配套：
- 剧本模板新增「失败的代价」一栏（现有「核心阻力」只管"被什么挡住"，不管"挡住会怎样"）
- 意象片豁免目标/阻力，改查"意象 ←→ 立意 的对应关系"是否写明

**为什么这是最高优先级**：《离谱日常》六条批评里四条在这个缺口内。补上这道闸，那部片子进不了 G2。

### 3. G3 物理可行性闸：动作量 vs 镜头时长

**依据**：《离谱日常》的"无行动"；分镜工作流 §三 闸 1「状态差五拍齐全」。

**查什么**：`主体动作` 列提取动词短语数，对照 `时长` 列与 `刀型`（短刀 ≤2s / 常规 2–4s / 长刀 4–8s）。

约略经验值：
- 短刀 ≤2s：≤1 个动作阶段
- 常规 2–4s：≤2 个
- 长刀 4–8s：≤3 个

超出则告警"动作量超出镜头容量，需拆镜或延时长"。同时检查 `镜前状态` 与 `主体动作` 不矛盾（如镜前"他坐在椅子上"，动作写"他冲出门"——缺中间状态）。
