# 反PPT建议（针对“短剧成片体系”已启动项目）

> 本文件为仅供参考的建议文档，**不修改体系内任何现有文件**，不作为体系规范的一部分。请在阅读后自行决定是否采纳，采纳时请按你的项目实际情况执行，不必全部照做。

---

## 一、先诊断：你的片子为什么会像 PPT？

AI 短片最容易“PPT 化”的典型症状，按发生频率排列：

| 症状 | 为什么像 PPT |
|------|-------------|
| 所有镜头时长几乎一样（如一串 4–5 秒） | 观众被固定节奏“催眠”，没有信息密度变化 |
| 镜头全是静止人物说话，没有运镜 | 画面像幻灯片翻页，没有“电影感” |
| 缺少空镜、反应镜、细节镜 | 只有主角在念台词，观众没有情绪缓冲点 |
| 每个镜头没有“本刀新信息”，只在重复同一件事 | 推不动剧情，观众失去期待 |
| 提示词里直接出现“愤怒/悲伤/高级感/氛围感” | 模型只能给中庸的“平均脸”，没有张力 |
| 主角跨镜身份漂移（近景换脸） | 观众认不出是同一个人，情感连接断裂 |

**建议先不要改剧本，先用现有工具扫一遍已出片子的分镜表与提示词，找出上面哪条命中了。**

---

## 二、立即可做的“体检”（不需要重新生成，只需跑脚本）

你项目根目录下的 `tools/` 已经内置了一批检查脚本，针对你已有的在制项目目录（在 `00-视频项目/` 下）：

```powershell
# 1. 检查切点节奏（是否全片等时长，像 PPT 的头号元凶）
python tools/check_shot_duration_variance.py <你的项目目录>

# 2. 检查运镜结构（静止占比、连续静止、镜型缺口）
python tools/check_shot_structure.py <你的项目目录>

# 3. 检查逐秒覆盖（每秒是否铺满视觉/声音/动作/表情/环境五要素）
python tools/check_per_second_coverage.py <你的项目目录>

# 4. 检查情绪词是否裸奔入提示词（§8.1 硬闸）
python tools/check_emotion_words.py <你的项目目录>

# 5. 检查风格锁是否注入（避免每镜风格漂移，像拼贴画）
python tools/check_style_lock.py <你的项目目录>
```

**如何看结果：**
- 任何脚本退出码 `1`，就是该环节的“PPT 源头”。
- 如果没有在制项目，脚本会打印 `[未评估]`，说明你需要先把已出片子的分镜表与提示词放进 `00-视频项目/《片名>/03-分镜/` 和 `04-镜头/prompts/`，再跑。

## 三、分阶段补救建议（G0–G6，按你卡住的环节对号入座）

### G1 剧本：先救故事，再救画面

PPT 化往往源于剧本本身就是“场景描述 + 台词”，缺乏因果推动。

**1. 人先给“三要件”，AI 只负责“长出肉”**

不要对 AI 说“写个短剧”，而要先由你锁定三个不能妥协的要件，再让 AI 展开：

| 要件 | 你需要回答的问题 | 示例 |
|------|----------------|------|
| 主角想要什么 | 具体、可量化、眼下就能行动 | “想在三天内卖掉祖母留下的旧手表” |
| 被什么挡住 | 具体的人、物、规则或内心恐惧 | “当铺老板说这表是赝品，不给钱” |
| 一件会变形的道具 | 日常物品，在故事中含义改变 | “那块旧手表：最初是负担→后来是证明身份的钥匙→最后被扔进河里” |

**原则**：AI 只负责把这三要件翻译成场景和台词，**你负责保证“因为/所以/但是/于是”的因果链不断裂**。

**2. 强制每场填“因果四句”，禁止“然后”**

体系 G1 已经要求：每场先填「因为 / 所以 / 但是 / 于是」。把它当作不可协商的模板：

```
因为 [主角已有的状态/目标]
，所以 [行动或选择]
，但是 [意外阻力/反转]
，于是 [新状态，推入下一场]
```

如果某一场填不出“但是”，这场就不该存在，直接删掉或合并到相邻场景。

**3. 道具翻转按需使用，含义要“递进”**

道具不是每集配额。只有它真正参与因果时才使用；再次出现必须改变人物选择或观众理解，不能为了过清单硬加象征物。意象片改用意象变奏 ≥3 次且意思递进。

操作示例：
- 第1次出现：主角用这把折叠伞遮雨，很实在。
- 第2次出现：主角用伞把遮住脸，不想让人看到哭的表情。
- 第3次出现：主角把伞扔进垃圾桶，不再需要躲藏。

AI 容易写“伞出现了三次”，但很难写“伞的含义变了三次”——这个含义变奏，需要你在提示词里**明确要求 AI 按阶段改写道具功能**。

**4. G4 提示词禁用裸情绪词，G1 剧本保留具体心思**

体系 AGENTS.md §8.1 只约束 G4 提示词，不上溯 G1 剧本。剧本应写清人物怕什么、想隐瞒什么，供 G3 设计表演；不要把每个人物都写成“情绪词 + 握拳/低头”的机械动作说明。

> G4 提示词中出现“愤怒/悲伤/紧张/高级感/氛围感”时，必须已经翻译成可指认的动作、表情、光线或声音事实。

**5. 朗读测试（不改文件，只找个人读）**

体系 G1 要求：把剧本交给新上下文读者，不给大纲，让他复述。每完成一个场景，找一个没参与构思的人读，问他：
- 主角想要什么？
- 谁或什么在挡他？
- 最后他卡在哪里？

如果对方说不出，这个场景就是“PPT 胚胎”，必须重写。

---

### G3 分镜：这是反 PPT 的最关键环节

分镜只是“把剧本每句话配一张图”，没有独立的导演判断，必然崩溃。在从剧本走向分镜时，强制加入以下三层过滤：

**1. 每个镜头必须有“本刀新信息”**

体系 G3 要求：分镜表逐刀填 `本刀新信息`。如果一个镜头只能填“主角再说一遍刚才的话”，这个镜头就应该被合并或删除。

**2. 刀型必须混排，禁止等时长**

PPT 化的头号元凶是“所有镜头时长几乎一样”。体系 G3 定义了三档：
- 短刀 ≤2 秒（情绪爆点、信息切换）
- 常规 2–4 秒（承接叙事）
- 长刀 4–8 秒（情绪沉淀、关键动作）

建议：全片至少出现一次短刀和一次长刀，切点绝对不能等距。

**3. 音频与对白轨在 G3 就填好**

不要等到后期才配声音。每个镜头的分镜表里要有：环境声、物声、对白、旁白、表演备注。没有声音设计的画面，天然像无声 PPT。

---

### G4 生成：提示词里不能有“情绪词”

这是体系 §8.1 的核心，也是大多数 AI 片子变中庸的根源。

| 不要写 | 改写成可指认的物理量 |
|--------|---------------------|
| 角色愤怒 | 眉间锁紧，嘴角向下拉，下颌发力 |
| 画面高级感 | 主光从画面左侧 45° 打侧面，光比 4:1，背景虚化 |
| 氛围感十足 | 前景有一束灰尘在光柱里飘动 |

在 G4 批量生成前，必须跑三个零机时预检（体系 AGENTS.md §八）：

```powershell
python tools/validate_video_prompt.py --platform <你的实现> --prompt-file <提示词文件>
python tools/check_emotion_words.py <项目目录>
python tools/check_style_lock.py <项目目录>
```

---

### G5 音频：不要“事后配声音”

PPT 化的另一半是“无声幻灯片”。体系要求：**音频设计在 G3 分镜表就完成**，G5 只负责执行。

- 每个镜头的音频与对白轨要在分镜表里预埋（环境声、物声、对白、旁白）。
- BGM 一条连续轨，不逐镜生成。
- 对白与重要音效处 duck（降重），别让音乐盖过台词。

---

### G2 视觉资产：如果涉及人物，先解决“谁是谁”

如果你的片子有可见主角，近景镜头却每次换一张脸，观众根本没法投入情感，自然像 PPT 拼贴。

- 用 H3 Ref2VA（图像条件节点 `MiniMaxH3ReferenceToVideo`）把 G2 的角色参考板作为图像条件接入生成，**不要纯文生图**。
- G3 批量首帧前，先出同一角色 2–3 个不同机位/表情的图，做**人眼目检**，确认是同一个人后再批量。

## 四、怎么利用 E:\AI\demo视频 这个失败品目录

不要把它当“垃圾场”，而当**反向教材**。建议花半小时，逐个打开里面的视频（或看文件名反映结构），手动记录一张“反面清单”：

| 观察维度 | 建议记录的内容 |
|---------|--------------|
| 平均镜头时长 | 如“13 个镜头，每个 4.5 秒，完全等距” |
| 镜头类型分布 | 如“全是中近景人物对话，没有空镜、没有反应镜、没有细节特写” |
| 运镜 | 如“全部固定机位，没有推拉摇移” |
| 画面重复度 | 如“三个镜头背景一样，人物姿势几乎不变” |
| 与体系闸的对比 | 对照 `check_shot_structure.py`、`check_shot_duration_variance.py` 的检查逻辑，找出哪条会红 |

把这些记录成一张**不要做什么**的清单，下次生成分镜时，把它作为负向检查表。如果新片子的任何一个镜头命中了这张清单上的条目，直接重做。

## 五、一个本周可执行的“最小反 PPT 小样”计划

不要重启整个大项目，只做一个 **5–8 分钟、3–5 个镜头** 的小样：

1. **选一个失败片段**，从 `E:\AI\demo视频` 里挑一个你最不满意的，只保留它的核心冲突。
2. **人写因果四句**，用「因为/所以/但是/于是」写出这一段故事的骨架。
3. **AI 展开场景**，每场不超过 100 字，强制插入：
   - 一件道具，且在三个场景中含义要变；
   - 一个感官细节（声音、气味、温度、触感）。
4. **拆成 3–5 个镜头**，每个镜头标注：刀型（短/常规/长）、本刀新信息、音频与对白轨。
5. **生成前过一遍情绪词禁令**，没有“愤怒/悲伤”，只有物理动作。
6. **生成后**，如果体系内的检查脚本支持扫描外部目录，可以对这个小样跑 `check_shot_structure.py` 和 `check_shot_duration_variance.py`；如果不支持，就肉眼核对：时长有没有短刀？每个镜头有没有新信息？

这个小样做出来，你会立刻感觉到“不同于 PPT 的地方在哪”。验证通过后，再用同样的方法推到全片。

## 六、给你的一句心里话

你体系已经搭得很好了（G0–G6、因果闸、情绪词物理量翻译、身份锚硬闸），这些是很多 AI 短片创作者都没有的。**现在的问题不是体系不行，而是“让 AI 独自写剧本”这个环节，需要你作为导演先注入“具体伤口”和“因果锚”。**

AI 可以帮你长出“皮肤和血肉”，但“骨架”——主角为什么非做不可、会失去什么、道具为什么变了意义——这部分，建议你先亲手定下来。
