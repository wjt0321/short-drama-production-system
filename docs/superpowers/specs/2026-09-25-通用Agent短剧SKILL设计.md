# 通用 Agent 短剧 SKILL 逐步整合设计

**日期：** 2026-09-25

## 目标

从 `短剧导演台/` 中抽取与平台、ComfyUI、供应商、价格和无关办公技能无关的短剧生产方法，融合进现有短剧成片体系，形成通用 Agent 可使用、可渐进加载、遇到不确定性可提供候选项的 SKILL。

## 范围

### 纳入

- 弹性拆镜与镜头因果；
- 真实剪辑镜头与视频生成段的区分；
- 首尾状态快照和跨镜交接；
- 角色、场景、道具资产锁定；
- 分镜到执行提示词的通用转换纪律；
- 失败归因、质量循环和成片质检；
- Agent 阶段编排、预算边界、用户审核和回退；
- 风格候选的抽象分类和案例复盘方法。

### 排除

- ComfyUI 脚本、工作流、目录、运行参数；
- 平台 API、模型价格、供应商线路、登录资料；
- 编程、财务、合同、PPT、电商、学术、邮件等无关技能；
- TokenGo 原始界面、接口和账户数据；
- 不能抽象成通用能力的具体平台语法。

## 设计原则

1. `SKILL.md` 是稳定入口，中文目录和中文内容保留；增加机器可读 manifest，但不制造第二个正文入口。
2. 通用能力层只描述效果、输入、输出、约束和决策条件；具体实现留在项目《能力登记.md》。
3. 任何不可逆或高代价的不确定性，提供 2–4 个候选项，标注推荐项、效果、代价、风险和选择者。
4. Agent 默认自动处理执行细节；只有风格、预算、合规、叙事方向和不可逆变更交给人类决策。
5. 采用渐进加载：入口层 → 当前关卡 → 专项能力 → 项目局部资产；禁止默认读取全量知识库。
6. 原始导入目录在抽取完成、引用检查通过后删除；所有保留内容必须进入当前项目的正式文件或提取记录。

## 产物设计

- 新增 `通用Agent短剧生产规范.md`：通用编排、候选项、渐进加载、状态快照、镜头拆解和质量循环总控。
- 新增 `skill-manifest.json`：ASCII/机器可读入口声明，entry 固定为 `SKILL.md`。
- 新增 `资料提取记录.md`：记录来源、吸收内容、忽略内容和删除时间。
- 修改 `SKILL.md`、`AGENTS.md`、`README.md`、`从这里开始.md` 及相关分镜/连续性/资产文档。
- 模板新增 `项目状态摘要.md`，让后续 Agent 只加载当前项目状态和当前关卡。

## 渐进加载层级

- L0：只读 `SKILL.md`，识别是否命中本体系。
- L1：按任务读取 `从这里开始.md`；端到端任务再读取 `AGENTS.md` 和 `通用Agent短剧生产规范.md`。
- L2：只读取当前 G0–G6 关卡涉及的阶段文档和项目状态摘要。
- L3：出现专项需求时才读取对应的角色、场景、运镜、音频、平台适配文档。
- L4：只有需要查证或解决失败时才读取案例、历史资料和参考附录。

## 验收标准

- 通用 Agent 只读入口即可知道下一步如何路由；
- 不确定性场景出现候选项而不是单一硬编码结论；
- 中文目录仍可被 `SKILL.md` 和 manifest 识别；
- 项目能按摘要文件断点续跑，不需要重新加载全部资料；
- 主体系中不再依赖 `短剧导演台/`；
- 原始 `短剧导演台/` 删除前完成文档引用、结构和内容验收。
