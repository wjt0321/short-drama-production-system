# 短剧 SKILL 全量测评与文档收敛设计

- 日期：2026-09-25
- 目标：校验外部原始素材未被误删；消除环境绑定和绝对路径风险；从导演、摄影、美术、文案、剪辑五个专业视角测评；删除无价值外部引用并收敛 README。

## 范围

1. 只读核验 用户显式提供的外部源档案目录，不修改、不删除。
2. 并行五角色评审，读取入口、总控规范、相关阶段文档和项目模板。
3. 收敛运行文档：删除外链、绝对路径、平台/供应商快照和历史噪音；保留可复用方法、验收标准、回退规则和路由。
4. 通过静态检查验证：绝对路径、外链、源目录误依赖、断引用、manifest、中文路径、文档结构。

## 评审角色

- 导演：故事推进、镜头功能、关卡决策和可执行性。
- 摄影技术：景别、机位、轴线、光线、焦段、首尾状态和运动连续。
- 美术顾问：角色/场景/道具资产合同、风格统一、冻结和可复现性。
- 写文高手：入口可理解性、提示词/剧本表达、冗余、歧义和用户审核负担。
- 剪辑师：镜头边界、节奏、生成段与真实剪辑镜头、声音/字幕/交付闭环。

## 收敛原则

- 运行文档不保留外部 URL；必要来源只写方法归纳，不写链接。
- 不删除阶段能力，只删除重复、历史回顾、平台快照、失效链接和与短剧生产无关的内容。
- README 只保留：如何识别、如何开工、G0–G6、目录、模板、验证命令、断点续跑。
- 所有路径使用相对路径或项目根目录变量；不写本机绝对路径。
- 原始素材路径只允许出现在审计记录/验证脚本的输入参数中，不进入运行文档。

## 验收

- 五角色报告无未处理的阻塞级问题；
- 项目运行文档绝对路径为 0；
- 项目运行文档外部 URL 为 0；
- README 控制在 80 行以内且仍能独立完成路由；
- ComfyUI 原始素材存在且文件数量不变；
- 四个验证入口和 Windows PowerShell 中文包装器退出码为 0；
- 独立终审返回 CLEAN。
