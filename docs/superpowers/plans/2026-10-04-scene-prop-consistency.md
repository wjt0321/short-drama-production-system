# 场景与道具一致性优化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 将场景与道具的参考资产、空间/状态连续性和按镜头投喂规则统一到通用 SOP 与项目模板。

**Architecture:** 场景专项作为空间与状态规则的唯一详细来源：场景采用“空间总览 + 所需机位参考板 + 必要平面示意”；道具采用“身份细节合板 + 按需交互/状态图”。G2 使用预拆镜估计需求，G3 最终分镜核对引用；分镜和视频只引用冻结版本或其可追溯裁图/状态。

**Tech Stack:** Markdown 文档、Python 文本/结构核对、Git 差异检查。

## Global Constraints

- 不绑定具体工具；参考图数量、格式、缩放和标签按项目能力登记与小样验证。
- 不把场景机位九宫格或道具多角度合板当作固定数量门槛。
- 叙事道具、固定地标、接触物件必须明确；背景装饰按场景基准继承，不要求每镜重复堆提示词。
- 道具身份版本与剧情状态编号分开；状态变化写入分镜/执行清单，不把合理状态变化误报为资产漂移。
- 不改 `00-视频项目/`、`archive/`、源资料和用户未跟踪文件；不生成图像/视频。
