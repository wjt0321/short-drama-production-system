# 2026-10-19 体系评审迭代 Implementation Plan

> **For agentic workers:** Execute this plan inline in the current workspace, task by task, with verification after each task.

**Goal:** 根据 `docs/体系评审-2026-10-19_四层审查.md`，把片型路由、成立性检查、跨镜接力和文档契约落到现有工具、模板与协议中，并以负样本与全量自检验证。

**Architecture:** 保持现有“每个检查器自带 `--selftest`、由 `tools/run_all_checks.py` 汇总”的结构。片型统一从项目 `00-立项/风格提案.md` 读取，旧项目无该字段时回退到剧本字段；机器检查只做可判定的硬闸和预警，不把审美判断伪装成正则结论。

**Tech Stack:** Python 3 标准库、Markdown 模板、PowerShell 验证命令。

**Spec:** `docs/体系评审-2026-10-19_四层审查.md`；体系约束：`AGENTS.md`。

## Global Constraints

- 遵循评审文件的分阶段顺序，先修现有闸与片型路由，再补成立性闸，再同步协议文档。
- 不删除已有自检，不覆盖既有项目产物，不把教程原文直接当作现行协议。
- 叙事片保持现行严格检查；意象片只在评审明确指出的 hook 收尾、切点均质度、静止镜头和静默秒块处走分支。
- 新增检查必须有反例 selftest，并接入 `tools/run_all_checks.py`。
- 所有实现完成后运行相关 selftest、真实项目扫描和 `python tools/run_all_checks.py`。
