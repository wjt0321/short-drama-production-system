# 角色双参考板 SOP 修改计划

**Goal:** 将用户已确认的角色双参考板方案落实到通用 SOP 与新项目模板，不修改历史项目和归档。

**Architecture:** `03-角色与视觉资产/角色资产参考板.md` 是布局、表情和投喂规则的唯一详细定义；身份一致性、生产清单、入口和模板引用同一契约，不新增生产审批手续。

**Tech Stack:** Markdown 文档、Python 文本核对、Git 差异检查。

## 已确认约束
- 主要角色默认两张：身份造型板（左约40%正面半身定妆，右约60%正/侧/背全身）及日常表情九宫格。
- 九格从同一身份派生，统一妆造、构图和光线，以日常低到中等幅度表情为主。
- 可直接出板或分图校验后拼板；保留源图与裁图来源，两板共同冻结、统一版本。
- 标准产物不等于固定投喂：按镜头与能力选择整板/裁图；仅支持首帧时先做场景首帧。
- 执行前验证缩放后细节、多人误读和表情混用，不宣称普遍优于旧方案。
- 一次性剪影、远景路人按需减量；额外角度、服装、材质、强表演与互动按需补充。
- 不修改 `00-视频项目/`、`archive/`、源资料及用户已有未跟踪文件。
