# 主动导演判断与前置风险预警 Implementation Plan

**Goal:** 用户提出做片需求后，Agent 主动查阅并选择光照/构图/运镜等方法，在依赖性投入前识别并告知不可适配与未验证风险。

**Architecture:** 细则唯一写在现有简明生产流程；入口和 manifest 路由到该节；已有项目模板记录简短结论，不增加审批包、脚本门禁或供应商依赖。

**Tech Stack:** Markdown、JSON、现有只读检查器。

## 已确认设计与约束

用户要求主动思考并寻找适配，真实情况无法适配时第一时间提出，防止后期投入放大。导演判断与风险验证不可等用户点名；全权委托也不绕过关键风险告知。方法检索不是效果证据，实测结论只对已覆盖条件有效；受影响生产暂停，不无差别停掉全项目。保留已有经验与工作区改动，不调用生成服务、不改变工具代码。
