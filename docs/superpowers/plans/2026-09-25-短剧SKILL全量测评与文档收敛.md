# 短剧 SKILL 全量测评与文档收敛 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to execute this plan task-by-task.

**Goal:** 对 ComfyUI 外部素材做可重复的只读核验，完成五角色专业测评，消除运行文档中的本机路径和外链，收敛 README 与重复说明。

**Architecture:** 专业评审只读并分别给出阻塞项；主 Agent 保持阶段能力不变，只清理重复和环境绑定。源档案校验器通过命令行传入路径，不内嵌本机路径；主入口保持短，详细流程仍按阶段按需加载。

**Tech Stack:** Markdown、Python 标准库、PowerShell。无第三方运行时依赖。

## Global Constraints

- 外部源素材根目录不删除、不修改；路径仅作为校验命令参数，不写入 Skill 运行文档或脚本默认值。
- 运行文档不得包含绝对路径、外部 URL、用户机器路径、账号或密钥。
- 不删除角色、摄影、分镜、连续性、音频、剪辑与交付的独立能力。
- 外部来源的可迁移方法保留；来源链接、行情快照、历史迭代记录与平台宣传材料移除。
- README 不超过 80 行；单一权威文档承载完整加载和审核规则，其他入口只做短路由。
- 不静默改变 AGENTS.md 的 G0–G6 决策边界；必要的统一口令使用“通过 / 修改（指出项） / 暂停”。
