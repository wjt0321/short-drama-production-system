# 短剧成片体系工程化补足 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 保留 `AGENTS.md` 作为正式执行协议文件名，并把体系补足为可复用、可审查、可回退、可验证的短剧成片生产系统。

**Architecture:** 以 `AGENTS.md` 为协议唯一入口；根目录文档负责路由，`模板/`负责每部片的产物结构与审核包，`03-角色与视觉资产/`补足场景与道具资产接口，`tools/`负责静态文档一致性检查。现有方法论正文尽量不重写，只修复冲突、入口、版本和工程接口。

**Tech Stack:** Markdown、PowerShell、Python 标准库；不引入第三方依赖。

## Global Constraints

- 保留 `AGENTS.md` 文件名，不创建或引用 `AGENT-执行协议.md`。
- 端到端生产以 G0–G6 为准；01–07 是知识库目录，不强制等同于生产顺序。
- 同一实现默认最多重试/重抽 2 次；第三次只允许作为不消耗质量预算的瞬态技术重试，并须登记。
- 所有新模板必须支持用户只做“通过 / 修改 / 回退 / 终止”裁决。
- 不记录密钥、密码或个人隐私；能力登记只记录配置位置和可复现信息。
- 当前日期按 2026-09-25 记录。
