# G3 分镜表

> `剪辑镜头 ID` 是成片叙事单位；`生成段 ID` 是一次生成任务。一个剪辑镜头可对应多个生成段，多个剪辑镜头也可从同一生成段取材。

| 剪辑镜头ID | 生成段ID | 剧本段落 | 场次 | 时间线时码 | 本镜叙事功能 | 刀型 | 本刀新信息 | 时长 | 镜前状态 | 镜后状态 | 情绪变化 | 观众新增信息 | 对下一镜约束 | 景别 | 机位/焦段 | 主体动作 | 台词/声音 | 首帧资产 | 尾帧参考 | 锚句版本 | 角色版本 | 场景版本 | 道具版本 | 素材文件/版本 | 状态 | 备注 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| S01 | G001 |  |  | 00:00-00:00 |  | 长刀 |  | 6.0 |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |

> **刀型 只填 长刀 或 短刀**；本刀新信息 填这一刀给观众的新东西（没有新信息就是过渡刀，应填 短刀）。
> **判断标准**：有新信息、情绪重、观众要看清 → 长刀（4–8 秒）；过渡、过场、纯交代位置 → 短刀（1–2 秒）。
> **时长 按内容填，不按模型档位填。** 全片必须长短都有——如果整列时长差不多一样，说明没做判断，必须重做。
> 一刀长过模型单次生成上限时，做成**一个长生成段、段内切多刀**，不要把这一刀砍成两段等长的短刀。

## G3 逐镜通过条件

- [ ] 每个剪辑镜头有明确叙事功能并关联生成段
- [ ] **`刀型` 每行都已填（`长刀` / `短刀`），且整列长刀短刀都有** —— 全列一个值视为未做判断，不通过
- [ ] **`本刀新信息` 每行都已填** —— 填不出新信息的行，应改成 `短刀` 并考虑与邻刀合并
- [ ] **`时长` 按内容填、长短不一** —— 整列时长几乎一样（切点等距）视为节奏失败，不通过
- [ ] 构图、机位、焦段和安全区明确（默认横屏 16:9；竖屏项目查竖屏安全区）
- [ ] 角色、场景、道具锚句可追溯
- [ ] 首帧来自已审核资产；尾帧只作下一段参考并需复审
- [ ] 台词、动作、声音和时间码不冲突
- [ ] 素材文件与版本可追溯
