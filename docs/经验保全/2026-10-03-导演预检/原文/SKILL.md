# 短剧成片体系 · 通用 Agent 入口

本文件只负责识别任务与路由，不复制专项方法或当前工具教程。01–07 是知识库分类；实际生产按 G0–G6：立项、剧本、资产、最终分镜、镜头、音频、成片。资产先于最终分镜锁定，预拆镜可用于估计资产需求。

## 一、渐进式加载（唯一正文加载规则）

1. 初次识别：读 `SKILL.md` 与 `skill-manifest.json`。`README.md` 是人读总览，不另设读取前置。
2. 续跑：先读项目《项目状态摘要.md》《执行清单.md》和当前产物/审核包，仅恢复当前阶段需要的上下文。
3. 单点任务：查 `从这里开始.md` 的路由，只读对应专项；不要要求完整端到端前置材料。
4. 端到端任务：读 `从这里开始.md`、`AGENTS.md`、`通用Agent短剧生产规范.md`、`07-端到端管线/生产证据与片型路线.md`，再读当前阶段资料。
5. 需要执行某项能力时：优先项目 `00-立项/能力登记.md`；无记录再探测，体系《能力登记.md》只是可用实现候选。仅加载已选实现对应的适配资料，历史、源文件、技术档案按需查。

`skill-manifest.json` 对应机器路由。其他入口引用本节，不另外维护读取顺序。

## 二、授权、能力与交接

- 全权委托按简明流程自主制作和质检；只有明确选择阶段审核时，才逐关等待裁决。不自行扩大费用、外发、发布和创作范围的授权。
- 能力获取、重抽预算、回退、冻结/解冻和产物命名统一见 `AGENTS.md`；不要在专项文档另造失败处理顺序。
- 已选方向记入项目状态；项目资产 ID 与版本独立于实现，实际上传编号、标签和字段由执行层映射。
- 通用方法只规定效果、输入输出和质量。具体模型、软件、工作流、路径、参数及失败经验保存在能力登记、技术档案和标注的适配资料中，不能反向成为全体系前提。
- 当前附带的草案生成器是可选辅助，不替代剧本、首帧、视频和成片的实际检查。查其实现时再读 `01-创意与剧本/AI短片全链路流水线.md`。
