# 主动导演判断与前置风险预检：条款覆盖与情景复核

日期：2026-10-03。范围：人工静态条款复核，不是实际生成、真实试拍或 Agent 行为自动化测试。

## 条款对应

唯一执行细则位于 `07-端到端管线/生产证据与片型路线.md` 的“主动导演判断与前置风险预检”。入口、视觉圣经、分镜工作流和模板只引用该节，不维护第二套阈值。

| 用户要求 | 已写入的执行约束 |
|---|---|
| 不等用户点名专业项 | SKILL 默认触发；从需求推导八类导演判断，单点任务及续跑检查受影响范围 |
| 主动寻找方法而不是随意发挥 | 检索已有方法的具体章节，记录采用理由与产物位置；找不到就说明，不假装命中 |
| 不受工具绑架 | 先定内容目的和方法，再核对能力；不绑定任何供应商或实现 |
| 尽早发现现实不适配 | 立项、依赖性批量投入前、关键条件改变时检查；不等正式视频完成才试动作或声音 |
| 第一时间提出 | 识别关键不确定性时即告知；列明证据缺口、影响、停止范围、候选及下一步 |
| 防止后期沉没成本 | 待验证/不适配的关键依赖不放行相关批量投入；只暂停受影响范围 |
| 不退回繁重审批 | 授权内等效技术修正自主执行，核心效果和授权变化才请用户决断；复用现有产物 |
| 保留经验 | 不删除方法库；修改前原文逐字节快照；不改变工具代码 |

## 情景桌面复核（条款推演，未调用生成服务）

| 输入或现实情况 | 按条款应如何执行 | 静态复核 |
|---|---|---|
| 仅说“做一部雨夜悬疑短片” | 主动判断观众重点、光源与反打、构图、运动和声音；查具体方法，不直接把悬疑等同蓝色滤镜 | 有明确触发与方法表 |
| 单人定妆图成功，剧情需要两人拉扯并交接道具 | 同框接触、遮挡与道具转移仍待验证；先告知，再用授权小样验证，不先批量出全套素材 | 明确限制证据适用范围 |
| 一镜到底需要跨生成段，但接缝尚无证据 | 当即说明接缝风险，先试代表性接缝；不能把单段成功说成全片可行 | 有对应试样要求 |
| 接缝连续失败，想改成多镜头 | 暂停相关投入，报告失败范围和替代效果；涉及核心要求变化由用户决断，替代路线仍需验证 | 有告知、停止及恢复条件 |
| 没有适合工具，调用费用也未知 | 说明缺少实现/费用条件，按能力获取协议寻找；不自行付费、采购或上传素材 | 有授权与投入边界 |
| 同一实现、同样输入条件已有实际通过样片 | 说明可比性后复用，继续相关生产与质检，不重复建立审批材料 | 有复用规则 |
| 续跑更换版本、人物数量或夜景灯位 | 只重验受影响部分，不把旧环境结论当新条件保证，也不推倒整片 | 有条件变化规则 |
| 正脸对白很长，但正式音频阶段在视频之后 | 提前试实际台词长度、语种、口型及表演，正式交付顺序不阻碍前置验证 | 有声音前置例外 |
| 无人物的自然景观短片 | 身份、口型等写不适用理由，仍判断光照、构图、运动及声音，不强塞人物或复杂镜头 | 有不适用和简洁选择规则 |

## 验证边界

以上只能确认规则及其连接写入了文档。manifest 为路由与执行要求的描述，不是程序化强制门禁。没有调用实际生图、视频、配音或付费服务，也没有证明每个 Agent 都会稳定遵守、实际成片效果已通过。首个真实项目仍须按规则留下试样和查看/试听记录。完整检查器结果另见本目录“完整校验.txt”；缺少在产项目时，切点均质度检查会跳过实片检查。
