# 平台提示词模板：MiniMax H3 / 即梦 / Seedance

## 细节充分且遵守实际长度

先读当前实现/版本的实际说明，核实必填字段、语言、参考语法与长度单位（字、词、字符或token不可混同）。下文数值有官方/社区与版本差别，不视为全供应商硬限制；未规定长度时不自造统一上限。不要求写满最大长度，若需计数使用工具对应口径，不凭视觉估算宣称合规。

由剧本和分镜转写提示词时保留：引用资产与起始构图、主要行为的触发/过程/结果、人物反应与视线、关键空间和道具变化、摄影机如何观察及结束、必要对白/环境声。按工具字段分别放置，原生不支持的能力另选实现，不一律删除内容。多镜头段按真实节拍组织，时间足够说话和完成动作；生成档位不反过来决定内容秒数。

长度受限时先删重复风格词、万能质量词和无作用装饰，再压缩固定描述（只有工具真正支持引用时才可用引用省字）；保住主动作、关系、关键反应、状态和对白。仍装不下则按内容关系拆技术段，不能截断官方字段、对白或必要因果。细节写具体而有顺序，不让多种表情和动作同时发生。重点不是更长，而是模型知道这一段会发生什么。

最终对照上游：原剧本的关键事件是否还在、提示词里的动作是否真能从首帧开始、末状态能否承接下一段。补查动作的时间顺序与持续性、人物注意力/视线、接触与遮挡、受力与物理反馈，以及必要的同步声音/光影变化。光线提示写主光来源和方向、主体受光、辅光/轮廓/反射层、阴影落点与色温关系；连续镜头沿用光线基准，只有有内容理由才改变。只给首帧加推拉与背景微动不算完成转写；确实需要静止观察的段落则保留，不机械添加眨眼或动作。

## 0. 使用前必读：三条诚实声明

以下结论来自官方文档调研（2026-09），用于防止误信社区传言：

1. **即梦官方未公布 `@` 引用语法**，也没有独立的"提示词指南"页。可用的官方 Prompt 建议散见于火山引擎《即梦 AI 视频生成 3.0 Pro 产品介绍》§4。网上流传的"即梦 @图片1"写法是把 Seedance 语法张冠李戴。
2. **Seedance 和即梦都没有独立的 negative prompt 字段**（官方指南均未列出）。社区在 prompt 末尾内联 `NEGATIVE: ...` 或反向写"不要 XX"的做法**不是官方承诺的参数**，效果因版本而异。MiniMax H3 则通过 `non_diegetic_music: N/A` 这类字段值表达否定。
3. **三家的官方写作语言不同**：H3 官方模板是**英文**（对白/画面文字保留原文语种），即梦和 Seedance 官方模板是**中文**。把 Seedance 的中文段落直接喂给 H3，或把 H3 的英文字段名写给即梦，都是常见翻车点。

## 1. 平台路由决策树

拿到一个镜头/一段分镜后，先决定用哪家生成：

```
这个镜头需要什么？
│
├─ 需要精控对白、口型同步、说话人区分、原生音效与配乐分层？
│    └─ 是 → MiniMax H3（唯一把 diegetic 声效 / 对白 / BGM 分字段控制的）
│
├─ 需要上传图/视频/音频做混合参考、视频编辑、视频延长？
│    └─ 是 → Seedance 2.0/2.5（@ 引用语法 + 任务类型分类最完整）
│
├─ 需要首尾帧精确锚定的物理过渡（A 状态 → B 状态）？
│    └─ 是 → H3 FL2VA 或 Seedance 首尾帧任务（两者都支持，按画面风格偏好选）
│
├─ 需要一段 prompt 直接出多镜头连贯叙事（不切给多个生成请求）？
│    └─ 是 → 即梦 3.0 Pro（"镜头1+主体+动作1+镜头2…"）或 Seedance（"镜头切换"）
│
└─ 只是普通单镜头、三家都能做？
     └─ 按画风偏好与手头账号选；玄幻打斗一镜到底优先走同目录《玄幻动作导演.md》（即梦 2.5 模板）。
```

## 2. 通用槽位模板（本文件核心：一次构思，三端输出）

### 2.1 八槽位通用模板

构思任何镜头时，先填这 8 个槽位，与目标平台无关：

```text
【风格画质】整体媒介与画质基调（写实/3D CG/2D 动画/胶片感；分辨率与流畅度诉求）
【主体】谁/什么：身份、外貌、服装、当前状态（写作纪律：不用代词，见《多镜头角色一致性.md》）
【场景】地点、时间、天气、关键道具与陈设
【动作】按时间顺序的连续动作链（先动后静，动作优先于修饰）
【镜头】景别 + 运镜 + 视角 + 起幅/落幅
【光影】光源性质、方向、色温、时间感
【声音】对白（原文）、环境音、音效、配乐（不需要就标注"无"）
【约束】必须保持不变的东西（面部/服装/logo）+ 明确禁止项
```

### 2.2 通用槽位 → 三家语法映射表

| 通用槽位 | MiniMax H3 | 即梦 3.0 Pro | Seedance 2.0/2.5 |
|---|---|---|---|
| 风格画质 | `integrated_multimodal_description` 首句 `[Shot 1] <style>, a <shot> frames...` | 句首风格关键词（"古风，…"） | 独立一行"风格与画质："或句首 |
| 主体 | 首句内 `frames a <subject>...`，英文详写外观 | "主体 + 外观描述"自然语句 | `主体：` 标签行 |
| 场景 | 同句内环境描写 | "背景"自然语句 | `场景：` 标签行 |
| 动作 | 同段按时序展开；新镜头用 `[Shot N] At MM:SS.mmm` | "动作"自然语句；连续动作用"主体+运动1+运动2" | `动作：` 标签行，按时序分句 |
| 镜头 | 英文运镜三轴：`<Motion Type> with <small/large> amplitude at <slow/fast> speed` | 官方中文词典（"镜头缓慢左移跟随"）+ 程度副词 | `镜头：` 标签行，景别与运镜分开写（先"中景"再"缓慢推镜"） |
| 光影 | 融入 description 的环境描写 | 句尾"光影/氛围"自然语句 | `光影：` 标签行 |
| 声音 | **拆三处**：对白进 `description`（`<d>[语种]…</d>` + `(S1)` 说话人标签）；环境音进 `overall_soundscape`；配乐进 `non_diegetic_music` | 无官方音频字段，写在语义句中或不写（后期配音） | 写在句中（"她说：……"）；或用 `@Audio1` 引用音频 |
| 约束 | Ref2VA 用 `retention_analysis` 声明保留关系；基础模式在句中写"keep ... unchanged" | 句中反复重申主体外观（"你详细描述了什么，什么就能最大限度保持稳定"） | `约束：` 标签行（"面部稳定不变形"等）；多模态任务用 `@` 引用锁定 |
| 参考素材 | 开头对齐指令段 + 空行（如 `For the target video, at 0.00 seconds..., <Picture 1> is fully referenced.`） | 官方未公布引用语法 | `@Image1 作为角色参考，@Video1 提供运镜节奏` 等自然语句 |

### 2.3 翻译工作流

1. 用八槽位把镜头构思完整（这一步与平台无关，可在分镜阶段就填好）；
2. 按 §1 决策树选定平台；
3. 按 §2.2 映射表逐槽翻译，**然后通读一遍目标平台的官方写法章节（§3/§4/§5）做合规检查**——映射表负责"不丢信息"，官方章节负责"不踩语法坑"。

## 3. MiniMax H3 官方模板

> 本节为实现适配示例；执行前必须按《能力登记.md》中已验证的当前规格复核。

### 3.1 五种模式

| 模式 | 入口 | 适用 |
|---|---|---|
| T2VA | 纯文本 | 文生视频（音画一体） |
| I2VA | 文本 + `first_frame` 图 | 图生视频 |
| FL2VA | 文本 + `first_frame` + `last_frame` | 首尾帧过渡 |
| L2VA | 文本 + `last_frame` 图 | 逆向收敛到指定末帧 |
| Ref2VA | 文本 + 图片 ≤9、视频 ≤3、音频 ≤3，且总数 ≤12 | 全参考：角色/动作/镜头/风格/声音 |

通用参数：768P / 2K；时长 4–15 秒整数；宽高比 5:2～2:5；提示词上限 7000 字符。

### 3.2 基础模式三字段结构（T2VA / I2VA / FL2VA / L2VA）

**第一步（仅 I2VA / FL2VA / L2VA 需要）**：整段提示词最前面写对齐指令，**后跟一个空行**：

```text
# I2VA
For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.

# FL2VA
How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot N) aligns with the S.SS-second mark of the target video.
```

> `S.SS` 是有效视频时长，**严格两位小数**；`N` 是实际最后一镜的编号。

**第二步：三大核心字段**（顺序固定）：

```text
integrated_multimodal_description: [Shot 1] ...
overall_soundscape: ...
non_diegetic_music: ...
```

| 字段 | 写什么 | 硬性约束 |
|---|---|---|
| `integrated_multimodal_description` | 画面 + 动作 + 镜头 + 说话人 + 对白 + 字幕 + 与时间轴同步的 diegetic 声效 | 首句 `[Shot 1] <style>, a <shot> frames...`；后续 `[Shot 2] At MM:SS.mmm, ...`，时间戳严格递增 |
| `overall_soundscape` | 全片环境声、物声、非语言人声 | **1–4 句连续英文段落**；完全静音写 `N/A`；不含对白、演唱、BGM |
| `non_diegetic_music` | 角色听不到、观众听到的配乐 | **1–3 句**；写乐器/节奏/动态变化；**不要写"悲伤/欢快"这类情绪词**；无配乐写 `N/A` |

### 3.3 运镜三轴写法（官方词表）

写法 = Motion Type + Amplitude + Speed，作为自然英文动作嵌入句子，**不要堆标签**：

- Motion Type：`Zoom In/Out`、`Push In/Pull Out`、`Pan Left/Right`、`Truck Left/Right`、`Tilt Up/Down`、`Pedestal Up/Down`、`Arc Shot`、`Tracking Shot`、`Static Shot`、`Shake Slightly/Strongly`、`POV`、`Roll Clockwise/Counterclockwise`
- Amplitude：`with small amplitude` / `with large amplitude`
- Speed：`at slow speed` / `at fast speed`

例：`The camera pushes in with small amplitude at slow speed toward the folded letter in her hands.`

### 3.4 对白与画面文字标签

| 语法 | 含义 |
|---|---|
| `(S1)`、`(S2)` | 发声人 ID，全片贯穿稳定；不说话的角色不给 ID |
| `(S1,S2)` | 多人同时说/唱 |
| `<d>[English] ...</d>` | 对白/歌词必须包在此标签内；保留原文语种与标点 |
| `says in an off-screen voiceover` | 旁白；其后必须写 `lips remain completely closed` |
| `<scenetrans>` | 一段对白跨过切镜 |
| `<cutoff>` | 对白被视频末尾截断 |
| 英文双引号原文 | 画面可见文本不翻译：`a sign reading "营业中"` |

### 3.5 Ref2VA 六字段结构（高级）

```text
subject_definitions:
<Subject N> 是 ……（可复用主体）
<Picture N> 是 ……（帧锚点/构图参考）
<Video N> 是 ……（被编辑源/续写源/时间结构）
<Audio N> 是 ……（音频资产）

summary:
[<task type 1> + <task type 2>] 一句话概述目标视频 + 各参考的作用

retention_analysis:
<Subject 1> (appears in [Shot 1], [Shot 3]): fully_preserved — 保留说明
<Video 1> (cut and pacing structure): weak_reference — ……
<Audio 1>: fully_copy — ……

detailed_description:
（全英文；[Shot 1] 起；参考标签标在实际出现处；对白仍 <d> 包裹）

overall_soundscape: ……
non_diegetic_music: ……
```

关键术语：主体保留关系 `fully_preserved | partially_preserved | attribute_transfer | weak_reference`；音频保留关系 `fully_copy | partially_copy | reference | weak_reference`；任务类型前缀 `keyframe completion | reference generation | video editing | video continuation | audio reuse | audio reference`，可用 `+` 组合。**参考标签一旦定义，全文不得变更含义。**

### 3.6 官方六大致命错误

1. 把一切写在一个不分段的大段落里；
2. 上传了参考文件但没声明每个文件的作用；
3. 一句要 BGM、一句又禁 BGM（自相矛盾）；
4. 想一镜到底却写了 `[Shot 1]` / `[Shot 2]`；
5. 想角色一致却没有"character reference (lock face)"作用的参考图；
6. T2VA 提示词过短，缺主体外貌 + 场景 + 动作 + 风格四要素。

### 3.7 官方示例（T2VA，雨中古风女子）

```text
integrated_multimodal_description: [Shot 1] Live-action, cinematic, a medium-wide shot frames a young Hanfu woman walking through a narrow stone-paved lane on a rainy day. She holds a pale-paper oil-paper umbrella above her head, the dark wooden handle steady in her right hand, while rain taps softly on the canopy and droplets run down to pool on the bluestone slabs at her feet. The camera trucks left with small amplitude at slow speed to follow her as she steps forward, her white silk hem brushing the wet stone, the distant glow of a red paper lantern warming the deep background.

overall_soundscape: Steady rain taps on the oil-paper canopy and patters on the stone slabs. Soft fabric rustles as her hem moves, her cloth shoes make light wet steps, and a faint wooden door creaks at the lane's far end.

non_diegetic_music: Sparse guzheng arpeggios at a slow tempo, joined by a low erhu drone that swells gently as the shot progresses.
```

## 4. 即梦（Jimeng）官方模板

> 本节为实现适配示例；执行前必须按《能力登记.md》中已验证的当前规格复核。

### 4.1 官方基础结构

> 1. 基础结构：**主体 / 背景 / 镜头 + 动作**
> 2. 多个镜头连贯叙事：**镜头1 + 主体 + 动作1 + 镜头2 + 主体 + 动作2 ……**
> 3. 多个连续动作：
>    - 时序性的多个连续动作：主体1 + 运动1 + 运动2
>    - 多主体的不同动作：主体1 + 运动1 + 主体2 + 运动2 ……

模式入口：T2V（纯文本）；I2V 首帧（首帧图 + 文本）。

### 4.2 官方运镜词典（中文）

| 类别 | 关键词 |
|---|---|
| 切换 | "镜头切换" |
| 平移 | "镜头向上/下/左/右移动" |
| 推轨 | "镜头拉近 / 拉远" |
| 环形/航拍 | "镜头环绕"、"航拍"、"广角"、"镜头 360 度旋转" |
| 跟随 | "镜头跟随" |
| 固定 | "固定镜头"、"镜头静止不动" |
| 聚焦 | "镜头特写" |
| 手持 | "镜头晃动/抖动"、"手持拍摄"、"动态不稳定" |
| 程度副词 | "快速"、"大幅度"、"高频率"、"剧烈"、"缓缓" |

### 4.3 官方写作五原则

1. **简洁明了**：避免古诗词、抽象描写、长难句；
2. **具体详实**：只写给定时长内能完成的指令；
3. **突出主体**：先确定主体及其运动形态；
4. **自然语言描述**：避免歧义与抽象；
5. **一致性描述**：对同一主角的服装/动作保持前后一致——官方原话的精神是"**你详细描述了什么，什么就能最大限度保持稳定**"，公式：`【主体A】+【外观描述】+【运动】，【主体B】+【外观描述】+【运动】……`

### 4.4 官方受限点

- 1080P 高清；多镜头叙事可保持主体和风格一致；
- **不适用于精准生成文字的场景**——官方建议尽量避免在视频中生成文字；
- 官方未公布 `@` 引用语法、未公布负面提示词字段（见 §0 诚实声明）。

### 4.5 即梦模板（语义顺序版）

```text
[风格关键词], [场景/背景], [时间/天气], [主体外观描写], [运动/动作], [镜头词 + 程度副词], [光影/氛围], [画质词].
镜头1: <主体>+<动作1>.
镜头2: <主体>+<动作2>.
```

## 5. Seedance 官方模板

> 本节为实现适配示例；执行前必须按《能力登记.md》中已验证的当前规格复核。

### 5.1 官方万能公式

```text
提示词 = 主体 + 动作 + 场景 + 镜头语言 + 风格
```

| 部分 | 解决问题 | 要点 |
|---|---|---|
| 主体 | 主角是谁 | 人/动物/物体/角色 |

### 5.4 多镜头叙事（官方机制）

> 支持在同一 prompt 里包含多个切镜，切镜会根据提示词保持主体/风格/场景的延续性。镜头的变化通过"**镜头切换**"连接；切镜之后如果场景和人物发生变化，可以用 prompt 刻画新人物/场景的特征。

官方五镜示例：

> 推到红发女孩惊讶的表情特写，镜头切到废墟中的一个窗台上的花盆，里面种着一个蓝色的多肉植物，镜头切到俯瞰，女孩走向这个多肉植物，切过多肉植物前景女孩双眼特写，摇到女孩的嘴，碎碎念出植物的名字。

### 5.5 `@` 引用语法（官方）

| 用途 | 写法 |
|---|---|
| 设置首帧 | `@Image1 作为第一帧` |
| 参考动作 | `参考 @Video1 的打斗编排` |
| 复制镜头运动 | `跟随 @Video1 的镜头运动和转场方式` |
| 加入音乐 | `使用 @Audio1 作为背景音乐` |
| 视频延伸 | `将 @Video1 延伸 5 秒` |
| 替换角色 | `用 @Image1 替换 @Video1 中的女性` |

API 侧对应 `content.role`：`first_frame` / `last_frame` / `reference_image` / `reference_video` / `reference_audio` / `base_video`。文件上限：图片 ≤9、视频 ≤3、音频 ≤3，且总数 ≤12（视频/音频单段 ≤15s；2.5 单次最多 50 个素材）。

### 5.6 任务类型分类（2.5 官方，含锁定项）

| 类别 | 任务 | 锁定项 | 触发条件 |
|---|---|---|---|

## 6. 同一镜头三端对照示例

**统一例题**：古风女子在雨中撑伞走过青石板巷（5 秒单镜头）。

**八槽位通用构思**（与平台无关）：

```text
【风格画质】古风写实电影感，高清流畅
【主体】年轻女子，白色交领汉服，墨色长发低髻，持米白色油纸伞
【场景】青瓦白墙中式窄巷，青石板路，中雨，远处一盏暖红纸灯笼
【动作】持伞缓步前行，裙摆微湿，回眸一笑
【镜头】中景，缓慢左移跟随，浅景深
【光影】傍晚，雨雾，软光，暖色高光 + 青灰阴影
【声音】雨声、布料摩擦声；古筝配乐（无对白）
【约束】面部稳定不变形，雨丝连贯
```

### 6.1 MiniMax H3 版（英文三字段）

见 §3.7 官方示例——该例正是本题按 H3 官方范式的成品。注意：动作与画面全英文，运镜用三轴写法（`trucks left with small amplitude at slow speed`），环境音与配乐拆进两个独立字段。

### 6.2 即梦版（中文语义顺序）

```text
古风，青瓦白墙的中式老巷，湿润的青石板路，
中雨，
```

### 6.3 Seedance 版（中文分段标签）

```text
古风写实电影感，5 秒。
```

## 7. 提示词英文定稿（可选环节）

**什么时候需要翻译**：不是所有平台都要英文，先按下表判断——

| 情况 | 要不要英译 |
|---|---|
| MiniMax H3 | **必须**。官方写作语言就是英文（仅对白/画面文字保留原文），直接按 §3 用英文成稿 |
| 即梦 / Seedance | **不要**。两家官方都是中文原生，翻成英文反而丢精度 |
| 可灵 / Runway / Pika / Veo / Sora 等国际模型 | **建议**。这类模型英文训练语料占比高，英文提示词普遍更稳定 |
| 实测发现中文版效果漂移 | **可以试**。同镜头中英各跑一版对比，哪个稳用哪个 |

**翻译纪律（翻译不是改写）**：

1. **先中文定稿，再翻译**。中文稿是唯一事实源；翻译中发现内容要改，回中文稿改完再重译，不要在英文版上直接改。
2. **术语一次选定、全程不变**：运镜/景别词从 §2.2 映射表和 §3 运镜词表取，同一个镜头动作在全片只用一个英文词（比如定了 `push in` 就不要下一镜又写 `dolly in`）。
3. **这些原样不动**：`@Image1` 等引用语法、文件名、专有名词、画面中的可见文字、对白原文（H3 里 `<d>` 标签内保留原文语种）。
4. **译后逐槽核对**：对照 §2 的八个槽位逐个问"英文版有没有丢信息、有没有多写"，丢了的补，多了的删。
5. **中英两版都存档**，文件名加 `_zh` / `_en` 后缀，便于返修时对照。

> 这不是一个新阶段，只是第 4 阶段交付前的最后一步：中文稿（即梦/Seedance 直接可用）→ 需要时 → 英文定稿。

## 8. 常见错误对照表

| 平台 | 致命错误 | 正确做法 |
|---|---|---|
| H3 | 一段不分段的大段落 | 按 `[Shot N]` 时间戳分段 |

| 即梦 | 堆古诗词、抽象形容词 | 官方五原则：简洁、具体、自然语言 |

## 9. 国际模型公式速览（Sora 2 / Veo 3 / Runway Gen-4 / Kling 3.0）

> 按需查阅：只有当目标平台换成国际模型（或用户明确要求对比）时读本节。本体系主力仍是 H3/即梦/Seedance，§2 的八槽位模板和翻译工作流不变。

### 9.1 各模型官方/社区公式的要点

| 模型 | 核心公式 | 记忆点 |
|---|---|---|
| **Veo 3.x**（Google） | `[镜头弧线] + [主体调度] + [声音提示]`，例：*Camera arcs 180° around the artisan; footsteps on stone synced to the beat* | 原生音画一体，对白写引号并归属到人；物理与写实度是当前标杆 |
| **Runway Gen-4** | 参考矩阵（reference matrix）/ look bible：一组定调静帧（色板、服装、光比）喂 I2V | 品牌色/指定画风必须不走样的项目首选 |
| **Kling 3.0**（备选位） | 五层公式，按顺序写：**场景 → 角色 → 动作 → 镜头 → 声音**；多镜头用时间码 `Shot 1 (0-3s)`，台词归属写 `[Character A: 名称, 语气]` | 物理重动作强；动作写"起→中→止"时序 |

> ⚠️ **Sora 已退市，勿再引用**：OpenAI 于 2026 年 3 月 24 日宣布关停 Sora，4 月 26 日 App/网页下线，**API 于 2026 年 9 月 24 日停止服务**，且无继任型号。旧教程里的 Sora 提示词公式（Shot Stacks 等）只作历史参考。这也给体系一条铁律：**任何平台的深度功能都可能一夜消失，导演决策层（01–03 阶段）必须与单一平台解耦**，执行方言层（本文件）要能整章替换——本文件按此原则维护。

### 9.2 国际社区四条铁律（与 §2 通用槽位互补）

1. **逐镜提示，不整段提示**：别写"a 30-second sequence of X, Y, Z"——模型只会前 3 秒合格、后面漂移。长片 = 分镜 + 剪辑问题，不是提示词问题。
2. **片段时长是硬约束**：模型一档几秒就按几秒设计节拍，超容量的叙事必翻车。
3. **I2V 优于 T2V**：先锁首帧（见 `02-分镜与镜头/分镜叙事工作流.md` 首尾帧分镜法），视频模型只负责动。
4. **按镜头选模型，不按项目选模型**：对白密度高的镜头给 H3/Veo 3.x，物理动作镜头给 Kling/Seedance，风格锁定镜头给 Gen-4。单一模型打全场 = 每类镜头都留遗憾。

## 10. 跨平台通用进阶：连续性锁表 · 微动作词库

### 10.1 连续性锁表（continuity lock sheet）

同一场戏的所有镜头，开拍前把六项锁死，逐镜原样重贴（与本体系锚句机制同源，此处补全国际社区惯用项）：

| 锁定项 | 示例 | 漂移症状 |
|---|---|---|
| 时间/天气 | 雨夜，霓虹反光 | 相邻镜头一个晴一个雨 |
| 服装 | 灰色风衣，左胸口袋巾 | 配饰凭空出现/消失 |
| 主光源方位 | 顶光偏左 45° | 影子方向前后相反 |
| 180° 轴线 | 镜头永远在两人连线的同侧 | 越轴导致人物左右互换 |
| 色彩基调 | 青橙对比，低饱和 | 剪辑点"跳质感" |
| 种子/参考 | 同种子或同组参考图 | 同提示词两次生成两张脸 |

### 10.2 微动作词库（micro-motions）——"纹理=可信度"

画面"塑料感"的解药是给静止主体加一层真实世界的微运动，每镜挑 1-2 个，不要全堆：

`呼吸起伏` · `眨眼` · `发丝被风掀动` · `布料轻微摆动` · `蒸汽/热气升腾` · `尘埃在光柱里浮动` · `水面反光晃动` · `霓虹/烛光闪烁` · `呵出的白气` · `手指无意识摩挲物件`

同理，**光源要写真**：不写"dramatic lighting"，写"闪烁的日光灯管""雨夜便利店霓虹""烛光+窗外闪电"——具名光源才生成可信光影。

### 10.3 运动动词专业化

模糊动词（moves / goes around）等于放弃运镜控制。用专业词：

| 想要的效果 | 写法 |
|---|---|
| 缓推近 | dolly push / slow push-in |
| 拉远揭示 | pull-out / crane up revealing |
| 快速横摇 | whip-pan |
| 急速变焦 | crash zoom |
| 瞬间合焦 | snap focus |
| 环绕主体 | orbit / arc around |
| 手持晃动 | handheld drift / shoulder-cam shake |

> 本节参考：Kling 3.0 Prompt Guide（atlabs.ai 整理）；AI Video Prompting: The Complete 2026 Guide（sureprompts.com）；Cinematic AI Video Prompts 2026 Playbook（truefan.ai）。

## 12. 已批准分镜的转换边界

本文件负责把已批准的生成段翻译为当前实现可执行的表达，不负责重新拆镜或改变叙事。转换必须继承：资产版本、风格锚、首状态、变化过程、尾状态和镜头主要观看重点。

当当前实现无法同时满足要求时，输出 2–4 个候选：拆段、降低运动复杂度、改用更稳妥机位、或经用户同意更换方案。不得静默省略角色身份、关键道具、动作结果或连续性字段。

## 镜头语言、画面语言与色彩路线

视频提示词在动作链之外补齐三项即可：

- 镜头语言：机位/视角、景别和运动目的；必要时写焦点如何从人物转到道具或环境。对话与移动写轴线、视线和屏幕方向，不用无理由越轴。
- 画面语言：第一视觉焦点、前中后景、引导线/留白/前景遮挡、主体层次和遮挡关系。提示词限制长度时优先保留主动作、焦点和空间关系。
- 色彩路线：当前阶段主色/材质、光线色温、对比/饱和度，以及与前后段的继承或变化理由。不能每镜换滤镜；相邻镜头同一时空优先统一白平衡和肤色。

这些是可执行事实，不是“电影感、唯美、高级”等评价词。详情用`影视视听语言速查.md`，光源层次用`对标参考库/方法论/光线设计库.md`；不绑定平台。
