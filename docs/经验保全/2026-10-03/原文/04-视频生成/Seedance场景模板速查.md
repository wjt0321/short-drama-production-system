## 一、快速上手

### 1.1 三阶段工作流

遇到用户只给一句话或粗略想法时，不要一次性长篇提问，按阶段推进。

**阶段一：意图与素材澄清（轻量访谈）**

快速确认核心三要素：

1. **故事 / 核心画面**：想讲什么故事，或展示什么产品、场景？
2. **时长与画幅**：默认 15 秒（可自选 4-15 秒）；横屏 16:9、竖屏 9:16 或宽银幕 2.35:1。
3. **可用素材**：手里是否有现成角色图、场景图、运镜参考视频或卡点配乐。

**阶段二：构建分镜时间轴（以 15 秒为例）**

- **0–3 秒（建立）**：开场镜头建立空间与主体亮相，确定光影色调。
- **3–7 秒（展开）**：引入冲突或核心动作，镜头推进/环绕。
- **7–11 秒（高潮）**：核心动作爆发、关键特写或情绪顶点。
- **11–13 秒（转折/过渡）**：动作收尾、视角切换或悬念落版。
- **13–15 秒（结尾）**：落幕、定格或品牌标语渐出。

**阶段三：规范交付**

按"八、交付检查清单"的四件套输出，不省略任何一项。

### 1.2 标准通用公式

```text
【风格】[艺术风格]，[时长]秒，[画幅比例]，[色彩与光影氛围]

【时间轴】
0-X秒：[景别与运镜] + [主体与环境] + [关键动作/表情] + [光影/特效]
X-Y秒：[景别与运镜] + [主体动作推进] + [细节特写]
...
Y-Z秒：[收尾运镜] + [情绪定格/落版]

【声音】[配乐风格] + [关键动作音效/环境音] + [对白/旁白台词与语气]
【参考】@图片1 作为首帧/角色参考，@视频1 参考运镜/动作节奏
```

四条硬约束：

- 时间轴必须**连续覆盖**，从 0 到总时长无空档，末段结束时刻等于总时长。
- 每一段都要有**新的可见变化**，不能只换景别或只换运镜节奏。
- 一个片段只承担**一个核心节拍**（见 2.4）。
- 声音与参考素材必须与时间轴上的动作/时刻**对齐指认**。

## 二、13 类场景配方库

> 配方是起跑线，不是模具。先按用户的**结果**选族，再替换主体、动作、运镜、光线、声音与约束。用户一旦感觉自己被套进模板，即使成片合格也算失败。

### 2.1 配方族速查表

| 配方族 | 最佳场景 | 核心模式 |
|---|---|---|
| Product（产品） | 广告、电商、英雄镜头、材质揭示 | 产品锚点 + 单一材质变化 + 受控运镜 + Logo 完整保留 |
| Lifestyle（生活） | 人物使用、美食、旅行、社交短片 | 简单动作 + 真实生活环境 + 手持或自然光 + 环境声 |
| Drama（剧情） | 情绪、对白、短叙事节拍 | 角色标签 + 手势动作 + 有动机的运镜 + 静默或稀疏声音 |
| Music video（音乐） | 卡点、舞蹈、风格化剪辑 | 节奏参考 + 可见节拍变化 + 光脉冲 + 清晰人物走位 |
| Landscape（风景） | 建立镜头、自然、氛围 | 缓慢运镜 + 天气运动 + 层次纵深 + 自然声 |
| Commercial（商业片） | 品牌安全质感与功能演示 | 问题 / 使用 / 结果三拍 + 精确产品约束 + 干净光线 |
| Animation（动画） | 原创角色与风格化动作 | 媒介 + 造型语言 + 色板 + 弹性或重量感动效 |
| VFX（特效） | 变形、粒子、天气、能量 | 源起点 + 材质行为 + 交互 + 消散终点 |
| First/last frame（首尾帧） | 首尾帧之间的过渡、产品状态变化、角色姿态目标 | 首帧 + 末帧 + 连续过渡 + 身份锁定 |
| Commercial campaign（系列广告） | 6/10/15/30 秒多版本、竖屏与社交剪辑版、无字版与本地化版 | 钩子 + 产品证明 + 结束状态 + 多尺寸削减矩阵 + 交付说明 |
| Short drama（短剧） | 快切竖屏迷你剧节拍：铺垫、反转、悬念 | 两三个标注镜头 + 一次情绪反转 + 停留反应近景 + 在钩子上切走 |
| Talking head（口播） | 主持人、讲解、直播式对镜推荐 | 锁定中近景 + 短引用台词 + 极小头部动作 + 字幕安全构图 + 房间底噪 |
| Home / space tour（空间导览） | 房间、场地、房源导览 | 单条连续长镜头 + 匀速前进路径 + 分区光线变化 + 仅环境声 |

### 2.2 Prompt Skeleton 字面模板

以下五个骨架为可直接填入的字面模板（参数位用 `[...]` 标注），照抄后替换方括号内容即可。

**Product I2V（产品图生视频）**

```text
@Image1 is the product reference; preserve logo, label, shape, and materials exactly. [One material or light change]. Camera: [single move]. Lighting: [physical source]. Sound: [ambient/SFX].
```

> @图片1 为产品参考，严格保留 Logo、标签、外形与材质；只给一次材质或光线变化；运镜只给一种；光线写物理来源；声音写环境声/音效。

**Drama T2V（剧情文生视频）**

```text
Character A [visible emotional action] in [specific setting]. Camera: [motivated framing]. Lighting: [motivated source]. Sound: [ambient or short dialogue]. End state: [changed expression/action].
```

> 角色 A 在具体场景中做出可见的情绪动作；机位、光线都要有叙事动机；声音写环境声或短台词；结尾给出变化后的表情或动作。

**Reference Motion（动作参考迁移）**

```text
@Video1 provides only [camera/action/timing] reference; do not transfer identity, costume, logo, or environment. New subject: [authorized/original subject]. [Action and endpoint].
```

> @视频1 只提供运镜/动作/时机参考，**不得迁移身份、服装、Logo、环境**；新主体用已授权或原创对象；写清动作与终点。

**First/Last Frame（首尾帧）**

```text
@Image1 is the first frame. @Image2 is the last frame. Preserve [identity/product/scene anchors]. Generate a continuous transition from [start state] to [end state]. Camera: [locked or one controlled move]. Sound: [ambient/SFX].
```

> @图片1 为首帧、@图片2 为末帧；锁定身份、产品或场景锚点；生成从起始状态到结束状态的连续过渡；运镜只用锁定或一次受控运动。

**Animation（动画）**

```text
Original [character archetype] [action] in [environment]. Style: [medium, line quality, texture, palette]. Motion: [rhythm]. Camera and sound: [simple support].
```

> 原创角色原型 + 动作 + 环境；风格写媒介、线条质感、材质与色板；动效写节奏；运镜与声音只做简单支撑，不抢主体。

### 2.3 优先级铁律

用户给出多个目标时，选**最能保护最脆弱需求**的那一个配方：

```
产品身份 > 运镜奇观
口型同步 > 大幅头部动作
角色一致性 > 复杂编排
首尾帧目标精度 > 额外风格变化
安全与授权 > 风格模仿
```

### 2.4 One-beat discipline（单拍纪律）

一个短片段只承载**一个核心节拍**：一次材质变化、一次情绪反转、一次动作命中、一次状态切换。配方可以铺开画面，但不能在一个片段里塞入两个终点。想要更多节拍，就多给一个片段，而不是把一个片段写长写满。

## 三、常见场景定制

- **叙事与剧情类**：突出眼神与微表情变化，拆解动作连贯性，明确标注情绪推进（如从疲惫到释然、从平静到爆发）。
- **产品与商业广告类**：采用"0-2s 悬念/特写吸睛 → 2-5s 环绕展示全貌 → 5-8s 材质与工艺微距 → 8-12s 实际使用场景 → 12-15s 品牌 Logo/标语落版"结构。
- **角色对战/动作类**：用中性词代指对阵双方（`Figure 1` 对战 `Figure 2`），标注击打节奏、受击反馈及武器特效，建议挂接 `@视频1 动作节奏参考`。玄幻打斗一镜到底另见同目录 `玄幻动作导演.md`。
- **口播与虚拟人**：指定 `@图片1` 为人物形象，`@音频1` 为语音源，在提示词中加入"自动对齐口型、神态自然生动并带微表情变化"。
- **视频延长与剧情改写**：见"五、视频延长与改写语法"。

## 四、多模态引用边界（硬性）

- **文件上限**：最多 **12 个**参考文件（图片 ≤ 9、视频 ≤ 3、音频 ≤ 3）。
- **时长限制**：参考视频与参考音频的总时长**各自 ≤ 15 秒**。
- **引用语法**：严格使用 `@素材名` 标记素材用途，例如 `@图片1 作为首帧`、`@视频1 参考运镜`、`@音频1 作为配乐`。素材与用途必须一一对应，不留歧义。
- **红线限制**：
  - 不支持写实真人脸部素材。真人需求须提示用户改用虚拟人、插画或非写实风格。
  - 涉及已有知名 IP / 明星须转换为中性代称（如 `Figure 1`、`Figure 2`）以防拒审。
- **唯一性原则**：同一素材只承担它被声明的那一项用途；参考了动作，就明确写"不迁移身份、服装、Logo、环境"。

## 五、视频延长与改写语法

### 5.1 视频延长（续拍）

开头明确声明，时间轴从 0 起按**新增**时间编写：

```text
将@视频1延长 X 秒（生成长度选择 X 秒）

【时间轴】
0-X秒：……
```

强调与已产出的前段在色调、人物动作、运镜惯性上无缝衔接；不要重复上一段已经发生过的动作。

### 5.2 视频剧情改写 / 颠覆

采用结构化标记，逐项指认保留与改动范围：

```text
【保留】原视频的场景布局与运镜轨迹
【修改】0-3秒角色的动作与表情
【颠覆】3-8秒突发剧情反转
```

范围必须写成时间区间，避免"整体调整"这类无法执行的表述。

## 六、镜头语言速查

### 6.1 镜头运动

- **推镜头 / 急推**：强调主体心理状态，制造紧张感。
- **拉镜头 / 渐拉远**：交代环境全貌，营造孤独或浩瀚氛围。
- **环绕运镜 (360° Orbit)**：展示产品全貌或高光时刻。
- **跟随镜头 (Tracking Shot)**：跟随角色跑动或飞行动态，增强临场感。
- **希区柯克变焦 (Dolly Zoom)**：背景压缩/拉伸，表达震惊或空间异化。
- **手持晃动 (Handheld Shake)**：纪实感、战争临场感或伪纪录片 Vlog。

### 6.2 景别标准词

| 中文 | 标准词 |
|---|---|
| 大特写 | Extreme Close-up (ECU) |
| 特写 | Close-up (CU) |
| 中景 | Medium Shot (MS) |
| 全景 | Full Shot (FS) |
| 远景 | Wide Shot (WS) |
| 大远景 | Extreme Wide Shot (EWS) |

### 6.3 运镜标准词

| 中文 | 标准词 |
|---|---|
| 固定镜头 | Static Shot |
| 左右平摇 | Pan Left/Right |
| 俯仰 | Tilt Up/Down |
| 推拉 | Dolly In/Out |
| 跟拍 | Tracking Shot |
| 环绕 / 弧形 | Orbit / Arc |
| 升降 | Crane/Boom Shot |
| 低角度仰拍 | Low Angle |
| 高角度俯拍 | High Angle |

### 6.4 光影与质感

- **光影**：丁达尔效应/体积光、伦勃朗光、逆光剪影、霓虹冷暖对比、自然晨光。
- **色调与质感**：电影级胶片质感、高动态范围、35mm 镜头虚化、低饱和青橙色调、水墨晕染。

## 七、负向提示词

标准负向提示词列表，按需增删但不要留空：

```text
blurry, distorted face, low quality, morphing limbs, static pose, text, watermark
```

含义对照：`blurry` 模糊、`distorted face` 面部畸变、`low quality` 低质量、`morphing limbs` 肢体变形、`static pose` 姿态僵死、`text` 画面文字、`watermark` 水印。

类型片可追加：多手指或手指粘连、面部漂移、背景跳变、镜面反射错乱。

### 8.2 出片前自查

- 时长、画幅、风格三项参数与用户确认一致，未擅自默认。
- 时间轴 0 到总时长连续无空档，末段结束时刻等于总时长。
- 每段都有新的可见变化；整片只有一个核心节拍。
- `@素材名` 与实际上传顺序一致；总文件数 ≤ 12，视频/音频各自 ≤ 15 秒。
- 未使用写实真人脸部素材；涉及知名 IP/明星已改中性代称。
- 负向提示词已附。
- 延长的片段只写新增时间；改写/颠覆用 `【保留】【修改】【颠覆】` 标出范围。
- 若首次生成出现主体变形：拆分为首尾帧（图生视频）或精简动作复杂度后重试。

## 附：序列状态与输出契约（多镜头项目）

- 处于序列状态时，配方必须继承：故事主线、当前片段范围、连续性锁定项、精确的参考素材标签、已完成的节拍、预留的后续节拍。
- 配方可以提出片段地图，但**只最终确定当前这一个尚未解决的提示词**；后续提示词保持临时状态，直到验收过的成片被复核。
- 输出契约：给出所选配方、为什么合适、定制后的骨架、精简后的最终提示词，以及在适用时给出系列/交付说明。
