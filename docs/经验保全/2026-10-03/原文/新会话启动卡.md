# 新会话启动卡

> **体系定位**：本文件是【短剧成片体系】的**跨会话接续入口**，纯能力层。体系遵循"渐进加载"协议（见 `AGENTS.md` 第九节）：新会话的 Agent 不需要知道上一次对话，只需要按本卡三步读齐该读的文件，即可从任意关卡接续。**适用于**：用户说"新开会话接着做""之前那套体系怎么在新会话里用"。本卡**不写任何工具/工作流/路径**——执行层对接一律按项目《能力登记.md》运行时发现。

## 〇、一句话

新会话里，让 Agent 按下面顺序读三个入口，然后从当前关卡继续推进。**不用复述历史对话**——文件里都有。

## 一、三步接续法

### 第 1 步：读体系入口（能力层）

Agent 按序读取：

1. `AGENTS.md`（项目根，若工作目录已选则自动加载）——关卡制协议 G0–G6、回退链、产物规范
2. `从这里开始.md`——总入口：先问五件事、全流程路线、单点直达表
3. 当前要做的关卡对应专项文件（按 `从这里开始.md` 的路线图找）

### 第 2 步：确认当前进度（断点）

- 项目文件夹存在？→ 读《项目状态摘要.md》《执行清单.md》，从上次停下的关卡继续，不重新加载全量知识库。
- 新项目？→ 从 G0 立项开始；新建项目优先复制 `模板/短剧项目模板/`（对齐 `AGENTS.md` §六）。

### 第 3 步：按授权继续实际制作

先读`07-端到端管线/生产证据与片型路线.md`。用户全权委托时自行判断和继续，先看相关seek参考，再定内容；不等逐关签核、不要求审批文件。以下审核包步骤仅适用于用户明确要求阶段审核时。

按关卡标准动作执行：**产出审核包 → 等用户裁决（通过/修改/暂停）→ 通过后登记产物 → 进入下一关**。涉及生成类动作（出图/出视频/出声音）时，执行层用哪个工具、怎么对接，由 Agent 查项目《能力登记.md》运行时决定——本体系不预设。

## 二、用户第一句话模板（复制即可）

```
读《新会话启动卡.md》（体系根目录），然后按它接续。
我想做一部 [题材] 的 [短剧/漫剧/对话片/视觉片]，[时长/平台/画幅（默认横屏16:9）]，
请按体系 G0-G6 走，先给我分镜 JSON 和图片生产清单。
```

也可以更具体：直接说"上次做到第几关"让 Agent 读项目《项目状态摘要.md》《执行清单.md》断点续跑；或说"要整理图片/音频生产清单"让 Agent 直接产出清单文件（清单整理不依赖任何工具）。

## 三、本卡不写什么（解耦自检）

- 不写任何具体工具、工作流文件名、模型名、节点名、目录路径。
- 不写执行层脚本命令（如"跑清单""填参""合成"）——那是执行层的事，登记在《能力登记.md》与技术档案。
- 清单类产物（分镜、图片生产清单、音频生产清单、剪辑装配单）**全部在能力层完成**，与任何工具无关；工具只在"拿清单去执行"时才出现。

## 四、红线（新会话同样生效）

1. **尊重本次授权**：用户全权委托时Agent自主制作和质检；只有用户要求逐阶段审核时才等待裁决。外发、发布、费用和范围扩展仍遵守本次授权，不因自主制作取得额外权限。
2. **不扫/不读/不调用/不回显 env 文件**：也不硬编码其中任何值。
3. **skill 与工具解耦**：能力层文件不写任何工具/工作流/节点名/路径；执行层细节只登记在《能力登记.md》与执行层文档。
4. **通用型**：体系不绑定平台/工具/账号；平台差异查体系内对应文件。
5. **拿不准就问**：风格、预算、合规取舍问用户；执行细节（参数、重试）不问。
