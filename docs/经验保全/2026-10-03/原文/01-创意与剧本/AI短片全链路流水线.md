> **体系定位**：本 skill 是【短剧成片体系】的**自动化主控**。
> 上游是 `01-创意与剧本`（人工定调），下游是 `02-分镜与镜头` / `04-视频生成`（实际出片）。
> 它把中间的**取材 → 结构化 → 规格化**三段自动化，人只做判断不做搬运。
>
> **工具**：`对标参考库/提示词库/shortfilm_pipeline.py`
> **配套**：`对标参考库/提示词库/auto_select_cards.py`（只要卡片不要全流程时用）

# AI 短片全链路流水线

## 零、它解决什么

从「我想拍一条国风 AI 短片」到「手里有能开工的完整材料」，中间有 6 步是重复劳动：

| 步骤 | 人工要做的事 | 本流水线 |
|---|---|---|
| ① 选卡 | 翻 4 万条提示词找参考 | 自动按题材打分，输出 top-N 锚点卡 |
| ② 剧情 | 想 logline、想三幕、想钩子 | 自动生成，按情绪套结构 |
| ③ 脚本 | 逐场拆景别/画面/台词/时长 | 自动拆，台词可直接念 |
| ④ 分镜 | 把画面写成能出图的提示词 | 自动套九段骨架出首帧提示词 |
| ⑤ 技巧 | 配光影/构图/调色 | 从技法库匹配，不编造 |
| ⑥ 清单 | 汇总素材需求与工作量 | 自动出执行清单 + 5 个审核点 |

**人保留的权力**：审核 5 个节点、决定风格情绪、改台词。搬运工作全部交出去。

## 一、怎么用

### 最常用：一条命令出全套

```bash
cd 对标参考库/提示词库
python run_all.py "敦煌飞天 复仇" --style 工笔 --mood 肃杀 --duration 60
```

产出 5 份材料（详见第三节）：

```
制作包.md      人看：执行摘要 + 六节详版 + 审核签核
制作包.json    机器读：后续三个导出器的输入
G3分镜表.md     分镜：24 字段，机位焦段/时码/叙事功能/下一镜约束
G4生成段.md     出图到视频：运镜三段式/焦点策略/轴线/拆分理由
G6剪辑装配单.md 剪辑：稳定 ID + 逐帧时码 + 转场 + 声音字幕计划
```

**批量**（每题材一个独立子目录）：
```bash
python run_all.py "深山道士" "水墨剑客" "非遗皮影" --style 水墨 --out ./项目
python run_all.py --batch topics.txt --out ./批量
```

### 审核：用 `review_gate.py`，机器可读

制作包里的 5 个审核点不是纸质方框——`review_gate.py` 把裁决存成 JSON，
带时间戳与备注，机器能读、工具能消费、门禁能卡。

```bash
python review_gate.py 制作包_xxx.md --checklist                 # 先看每关该审什么
python review_gate.py 制作包_xxx.md --status                    # 看进度
python review_gate.py 制作包_xxx.md --sign ① --verdict 通过      # 签一关
python review_gate.py 制作包_xxx.md --sign ③ --verdict 修改 --note "环境栏混入非本题元素"
python review_gate.py 制作包_xxx.md --gate G3                    # 5 关没过完 → 拒绝放行
python review_gate.py 制作包_xxx.md --reset
```

**状态存哪**：制作包同目录 `_<名称>_审核状态.json`——不污染制作包本身，拷走即带走。
裁决三态：`通过` / `修改`（带备注）/ `暂停`。

**审核要点清单**（`--checklist`）：每关到底该看什么，全部取自本项目实战踩过的坑，
不是通用套话。`--status` 遇到没过的关卡会**直接把要点摊开**，且只显示未过的那些。

> 为什么要单独一份清单：只报「未通过：①剧情审核」等于让人凭感觉点头——
> 闸拦住了流程，却没告诉人这一关在考什么。清单让「人类只负责审核」真正可执行。

清单的唯一真源是 `review_gate.py` 里的 `GATES`，`shortfilm_pipeline.py` 直接 import 它
来生成制作包里的摘要行——不抄第二份（抄两份必然漂移，实测已经漂过）。

### 已拦下的不适用词

制作包里有一节列出「素材库给过、但本片没用」的词及原因。**这节不能跳**：

- **画风冲突**：语料按「跨作品共识度」挖词，挖到的是**高赞词**，不是**合拍风词**。
  工笔/水墨/国漫片里会混进 `INS风`、`纯欲风`、`胶片摄影`、`上海中心大厦`——
  两条画风信号打架，出图模型只能二选一，抽卡率直接起飞。
- **主体错位**：全库挖词会带出描述**别人**的词（主体是书生，服饰却写
  `孩童头戴草帽`），出图会多画一个人。

被拦下的词**仍列在制作包里**，因为静默丢弃会让人误以为素材库里本来就没有。

**内容变了会自动作废**：改了风格/时长/情绪重跑，文件名往往不变但内容全换。
`review_gate.py` 对**实质内容**（分镜提示词 + 台词 + 声音计划）取指纹，
发现变了就把旧的「通过」降为「**需重审**」并注明原因，门禁重新拦住。

> 这一条比「防止状态丢失」更重要：**旧裁决还显示「通过」比丢失更危险**——
> 人会以为已经审过，实际审的是上一版内容。

**为什么要有门禁**：目标写的是「人类只负责审核」。没有门禁，人会跳过审核
直接开工，审核退化成走过场。`--gate` 让「没审」变成**技术上的不可能**，
而不是「应该做但会忘」。退出码 2 = 拒绝放行。

### 单独用某个脚本

```bash
python shortfilm_pipeline.py "题材" --until 分镜        # 只跑到分镜
python export_g3_storyboard.py 制作包.json --out G3.md  # 只导 G3
python export_g4_generation.py  制作包.json --out G4.md
python export_g6_assembly.py    制作包.json --out G6.md
```

| 参数 | 说明 | 默认 |
|---|---|---|

| `--style` | 水墨/国漫/工笔/写实/赛博 | 写实 |
| `--mood` | 肃杀/空灵/热血/凄美/诡谲/温情 | 空灵 |

## 二、输出长什么样

一份 Markdown 制作包 = **执行摘要** + 六节详版：

```
# AI 短片制作包：敦煌飞天 复仇

## 执行摘要          ← 先扫这段
   · 一句话表格（题材/规格/故事/工作量/声音基调）
   · 开场 3 秒钩子
   · 分镜速查表（照这个顺序出图，提示词可直接粘）
   · 库内实词清单（不贴题的可自行替换）
   · 审核签核勾选框（5 条，打勾再开工）

## ① 选卡        6 张参考锚点（含封面路径 + 来源 uuid）
## ② 剧情        logline + 开场钩子 + 三幕时长表
## ③ 脚本        6 场：景别/画面/台词/时长/技法标注
## ④ 分镜        每场一段首帧提示词（九段骨架）+ 运镜意图
## ⑤ 技法匹配    光影/构图/调色/镜头/氛围 五个维度的库内覆盖
## ⑥ 制作清单    素材需求 + 工作量 + 负向词 + 5 个审核点
```

**现成样例**：`对标参考库/提示词库/示例/制作包_敦煌飞天 复仇.md`——不跑命令也能看成品长什么样。

**分镜速查表里的提示词长这样**（纯词序，可直接贴进出图工具）：

> 敦煌飞天，东方古典·工笔重彩语境设定，纱罗，手持琵琶，仿佛无垠的云端，
> 中景，腰部以上，视线平齐，背景虚化，首饰轮廓与身体线条，冷／对比高，
> 刺绣等材质，工笔，石青石绿层层罩染

注意每一段都来自**库内真实作品**（纱罗 / 仿佛无垠的云端 / 首饰轮廓与身体线条），
不是模板占位符。

## 三、接回体系：G3 分镜表 + G4 生成段 + G6 剪辑装配单

制作包是**给人看的**；要真正进入体系流水线，需要体系自己 G3/G4/G6 三张表。
三个导出器做格式对齐（`run_all.py` 会自动依次调用）：

```bash
# 单步（也可单独用）
python export_g3_storyboard.py 制作包.json --out G3.md
python export_g4_generation.py  制作包.json --out G4.md
python export_g6_assembly.py    制作包.json --out G6.md
```

### G3 分镜表：自动填好 15 字段
剪辑镜头ID / 生成段ID / 剧本段落 / 场次 / 时间线时码 / 本镜叙事功能 / 镜前状态 /
情绪变化 / 观众新增信息 / 对下一镜约束 / 景别 / 机位·焦段 / 主体动作 / 台词 / 首帧资产。

### G4 生成段：补齐「首帧→视频」的中间依据
| 字段 | 怎么来的 |
|---|---|
| 运镜起点/过程/终点 | 运镜意图拆成三段可执行描述（如「正轴反打 → 对话视线平齐 → 台词完停住」）|
| 焦点与焦点变化 | 按景别给（特写=极浅景深锁面部；大远景=全景深）|
| 屏幕方向/轴线 | 按幕给正轴/守轴提醒，防跳轴 |
| 生成段拆分理由 | 时长≥12s / 特写 / 冲突段自动说明为何独立成段 |
| 时间码节拍 | 按镜头累加 |

### G6 剪辑装配单：ID 体系 + 时码
- **画面轨 V1**：`S01/G001` 稳定 ID + 逐帧时码（`00:00:00.000 → 00:00:08.000`）
- **声音与字幕**：`A001` / `FX001` / `BGM001` / `SUB001`，按镜头分配
- **转场自动判断**：景别切换 → 6 帧叠化；同景别连续 → 硬切

**三张表里标 `待人工填` / `待填` 的**：资产版本、锚句版本、能力登记 ID、
实际输出文件、镜后状态。这些要真出图/录音后才有——**流水线不编造，缺什么一目了然。**

### 设计原则
三个导出器都**零 import 体系模块**，只按字段名对齐。换个项目的模板，
改 `G3_FIELDS` / `SHOT_FIELDS` / `FIELDS` 与 `build_rows` 即可——不破坏「不绑项目」。

## 四、分镜提示词是「库内实词」不是「编的」


这是本流水线与普通模板脚本最大的区别：**九段骨架里的实词全部来自素材库**。

### 打分靠「跨作品共识度」，不是出现次数

这是关键区别：**一个作者在同一篇提示词里重复 5 次的词说明不了什么；
10 个不同作者各写 1 次，才说明这是通行写法。**

```
score(词) = Σ over 命中作品( log(1+点赞) × 命中强度 )   ← 单次贡献
          + 2.0 × log(1 + 独立作品数)                  ← 共识奖励
```

同一作品内去重（重复 5 次不额外加分），共识度单独加成。
被越多**不同创作者**用过，越靠前——这正是「借鉴 + 减少抽卡率」的依据。

### 匹配分三级，整词压过 2-gram

中文复合词库里往往不原样出现（「深山道士」查不到），所以要切 2-gram 提召回；
但泛字会带偏，所以权重必须分层：

| 命中方式 | 权重 | 例子 |
|---|---:|---|
| 整词命中 name/tags | **3.0** | `深山道士` |
| 题材别名 | 2.0 | TOPIC_HINT 命中的词 |
| 2-gram 命中 | **1.0** | `深山`、`山道` |
| 只在 prompt 里命中 | ×0.45 | 降权 |

不这样分级，「深山道士」会被 `山` 捞进一堆山水/山景作品，
真正相关的 `道士` 语料被稀释——实测修正后，
「深山道士」能挖出 **宽袍大袖 / 蓝色道袍 / 袖子上绣着太极图 / 背景终南山道观**。

| 维度 | 库内实词（示例：敦煌飞天） |
|---|---|
| 服饰 | 纱罗、缎面、刺绣纹样、披帛、裙摆 |
| 环境 | 中国山水背景、仿佛无垠的云端、亭台楼阁、高山流水 |
| 光影 | 轮廓光沿肩颈、叠加对应色调环境光、层次分明 |
| 材质 | 石青、金箔为主调、金箔质感、朱砂 |
| 动作 | 飞檐翘角、手持琵琶、披帛飞扬、裙摆飘逸 |

**为什么重要**：这些词是别人**验证过能出好图**的，不是我们自己想的。
这就是「借鉴 + 减少抽卡率」的落点——同一个题材，别人踩过坑的写法直接复用。

**词用尽时**：该维度退回内置描述（风格/情绪知识库），不会出现「6 场反复用同一个词」。
**库内语料稀薄时**（如某些小众题材）会混入次优词，此时人工在审核节点替换即可——
脚本不假装每个题材都有好语料。

**输出两版提示词**：
- `首帧提示词（中文·带段标）`：`主体：敦煌飞天，时代/身份：东方古典·工笔重彩语境设定，…` —— 人看，方便改
- `首帧提示词（纯词序·直接粘贴）`：`敦煌飞天, 东方古典·工笔重彩语境设定, 纱罗, …` —— 机器用，直接贴进出图工具

**运镜按「幕 × 景别」分配**，不是全片一个机位：

| 幕 | 大远景 | 中景 | 特写 |
|---|---|---|---|
| 建置 | 拉远揭示规模 | 固定承载对话 | 固定特写埋伏笔 |
| 对抗 | 升降拉开战场 | 环绕对峙双方 | 手持特写爆发点 |
| 解决 | 拉远收束留余韵 | 固定情绪平复 | 固定特写尘埃落定 |

## 五、通用性保证（重要）

| 维度 | 做法 |
|---|---|
| **零本地路径** | 全部 `os.path.dirname(__file__)` 推算，`--prompts`/`--covers` 可覆盖 |
| **不绑厂商** | 输出是**中性制作规格**，不写任何平台专属语法；换平台只微调首帧提示词 |
| **素材库可缺** | 没有 prompts.jsonl 时用内置模板降级，仍产出完整制作包（提示"需补素材"） |
| **纯本地** | 不连网，不调任何 API |
| **可移植** | 单文件拷到任何机器、任何目录都能跑 |

已实测：把脚本单独复制到任意临时目录、且不带素材库，运行正常产出全套制作包（仅提示"需补素材"）。

## 六、内置创作知识库

脚本自带这些通用工艺知识，不依赖素材库：

- **风格库** 5 种（水墨/国漫/工笔/写实/赛博）：各配光线/色彩/运镜/质感方案
- **情绪库** 6 种（肃杀/空灵/热血/凄美/诡谲/温情）：各配色温/对比/节奏/配乐倾向
- **三幕结构**：建置 25% / 对抗 50% / 解决 25%
- **景别表** 7 档：大远景→大特写，各带使用说明
- **构图要点表**：每种景别对应的构图规则（人物占比/景深/留白）
- **时代设定表**：每种风格对应的世界观语境
- **运镜表** 8 种 + **幕×景别运镜计划**（21 组，见第三节）
- **台词库**：按「幕 × 景别」给可直接念的国风对白，变量按题材自动替换
- **九段提示词骨架**：主体/时代/服饰/动作/环境/构图/光影/材质/风格
- **负向词基线**：中英各一套

## 七、5 个人工审核节点

流水线会在输出末尾列明，人只需逐条签字或打回：

1. **剧情审核** — logline / 三幕 / 钩子是否成立
2. **脚本审核** — 逐场景别/台词/时长是否合理
3. **分镜审核** — 首帧提示词能否直接出图（**重点看实词是否合题材**）
4. **技法审核** — 光影/构图/调色是否匹配情绪
5. **清单审核** — 素材与工作量是否可执行

打回后改参数重跑即可，不必手工改文件。

## 八、扩展方式

- **加风格**：往 `STYLES` 字典加一项（光线/色彩/运镜/质感四个键）
- **加情绪**：往 `MOODS` 加一项（色温/对比/节奏/音四个键）
- **加台词**：往 `DIALOGUE_BANK` 加 `(幕, 景别) → [台词]` 条目
- **加题材提示**：往 `TOPIC_HINT` 加 `(题材关键词 → 检索正则)`
- **加技法维度**：往 `TECHNIQUE_MAP` 加一项
- **加运镜计划**：往 `_CAMERA_PLAN` 加 `(幕, 景别) → 运镜说明` 条目
- **调语料清洗**：改 `_JUNK` / `_CLAUSE` / `_CAT_EXCLUDE` / `_CAT_MAXLEN` 四个正则

都是纯字典/常量，主逻辑不用动。

## 九、注意事项

1. **台词是模板生成的初稿**，节奏对但内容泛。正式剧本建议在此基础上改写，不要直接用。
2. **分镜提示词的实词来自库内高赞作品**，题材冷门时可能混入次优词——审核节点③重点看这个，替换掉不贴题的即可。
3. **语料挖掘是纯规则**（正则 + 跨作品共识度），不联网、不调模型，所以快且零依赖；代价是无法理解语义，个别词可能不贴题。宁可人改一眼，也不要脚本假装完美。
4. **冷门题材是数据限制，不是算法能补的**：规则再严也只能从现有素材里挑。当某个题材库里几乎没货（比如某个具体角色职业），挖出来的词质量必然下降。
   **怎么办**：先看这个题材库里有几条，够不够：
   ```bash
   python auto_select_cards.py "深山道士" --top 5    # 先确认有货
   ```
   货不够就补采（采集在素材库侧，见《能力登记.md》「外部工具链」）：
   ```bash
   # 素材库 harvest 目录下
   python liblib_probe_keywords.py 道士 山鬼 书生     # 先探测站上有没有
   python liblib_collect.py --keywords 道士 山鬼 书生 --pages 3
   ```
   探测返回 0 条的词，说明站上也没有，换近义词再试。
5. **出图后大概率要调词序**——不同模型对提示词权重处理不同，规格对了顺序未必对。
6. **时长分配是按三幕比例算的**，不是节奏大师作品，需要人按情绪微调。
7. **配套选卡**：只要卡片不要全流程时，用 `auto_select_cards.py`（支持 `--tech` 按技法挑）。
