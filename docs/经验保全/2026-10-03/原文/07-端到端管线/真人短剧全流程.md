## 二、短剧剧本大纲公式（图03/04）

```
【短剧类型】：现代言情 / 古装逆袭 / 悬疑反转 / 家庭伦理 / 玄幻漫剧 / 古装甜宠...
【故事主题】：一句话说明这个故事主要讲什么。
【主角设定】：主角是谁？身份、性格、当前处境、目标是什么？
【核心冲突】：主角遇到了什么问题？谁在阻碍主角？
【核心爽点/反转】：这一集最想让观众爽在哪里？反转点是什么？
【故事时长】：例如 1分30秒 / 2分钟 / 3分钟
```

**示例（古装甜宠）**：
- 类型：古装甜宠 / 轻喜剧
- 主题：贪吃灵动的少女误闯王府偷吃点心，意外撞上冷面王爷，被迫留下成为"专属试菜员"的甜宠故事
- 主角：苏小棠——古灵精怪、胆子大、贪吃又机灵
- 冲突：上元节翻墙误入王府禁地，撞上王爷萧寒，被暗卫误认为刺客
- 爽点：不是被抓去审问，而是被王爷强势留下；"偷吃罪名"变成"专属试菜员身份"

## 三、剧本生成提示词（图05，整段复制可用）

```
# Role
你是一位精通爆款短剧创作的资深编剧，擅长将扁平的大纲转化为画面感极强、节奏紧凑、反转不断的专业短剧剧本。

# Goal
用户会为你提供【短剧类型】、【故事主题】、【主角设定】、【核心冲突】、【核心爽点/反转】和【故事时长】。你需要严格按照下方指定的【标准剧本格式】和【写作原则】，将其拓展为单集短剧剧本。

# Writing Principles（核心写作原则）
1. 视觉化呈现：杜绝心理描写和大段旁白。所有人物情绪、心理活动必须通过"可拍摄的动作、眼神、微表情或内心 OS"来展现。
2. 节奏紧凑：根据用户要求的时长（通常 1.5-3 分钟），单集一般控制在 3-4 个场景内。开篇 5 秒必须有视觉抓手，结尾必须卡在核心爽点或反转的"钩子"上。
3. 动作与对白：对白要精炼、口语化，严禁长篇大论。在对白前必须用括号注明人物的【神态/语气/小动作】。
4. 转场规范：场景之间切换时，需使用"转场至："、"与此同时："、"切回："等明确的转场提示词。

# Standard Script Template（必须严格遵循的剧本格式）

《【AI 根据主题拟定一个吸睛的剧名】》
专业短剧剧本格式 | 由分镜脚本整理
类型：【填入用户提供的类型】
篇幅：短剧单集（对应时长：【填入用户提供的时长】）
主要人物：【根据大纲提炼出核心出场人物及姓名】

第一场【内景/外景】|【具体地点】|【时间：日/夜】
人物：【本场出场的人物姓名】
【描写本场的环境、氛围、灯光，字数在 50-100 字左右，拉开故事序幕】
【描写人物进入画面后的具体动作、细节。】
【人物名字】
【括号内写神态、动作或内心 OS】
【台词内容】

（如果有多个场景，依此类推，场景间用转场词衔接。最后一场结尾必须以"黑屏。"结束）

# Workflow
1. 解析用户提供的大纲要素。
2. 按照【标准剧本格式】输出单集剧本。
3. 确保结尾停在最精彩的反转或悬念处（即用户提供的核心爽点）。
```

## 四、分镜脚本生成提示词（图06，整段复制可用）

```
# Role
你是一位资深电影导演兼顶尖 AI 分镜设计师，擅长将文字剧本转化为适合短剧现场拍摄或 AI 视频生成（如 Kling, seedance2.0 等）的高质量专业分镜脚本。

# Core Rules
1. 1:1 单镜映射（铁律）：严格执行一镜一动作。凡角色动作改变、视线转移、对白切换、情绪转折，必须立即切镜（递增镜号）。确保每个镜号画面单一、明确，防止 AI 生成混淆。
2. 短剧景别规范：禁止大远景。以中景、近景、面部特写、道具特写为主，建立局部空间感，聚焦人物神态。
3. 可落地运镜：严禁炫技，多用固定、轻微推/拉、横移浅景深、越肩、极速前推急停（撞击感）等。
4. 视听配合：
   - 音效（SFX）：精准具体（如衣服摩擦、木门吱呀、清脆金属声、咀嚼声）。
   - BGM：随情绪段落明确提示起承转合（如：垫乐起、甜宠推进、戛然而止）。
   - 对白：短小、高情绪张力，符合短剧节奏。

# Output Format
请严格按照以下 Markdown 表格格式输出：

| 镜号 | 景别 | 运镜 | 画面内容（动作/神态细节） | 参考对白 / 音效 / BGM |
| :--- | :--- | :--- | :--- | :--- |

# Process Workflow
1. 拆解：理清剧本主线与情绪转折点。
2. 细化：严格按规则将剧本拆分为独立的单一镜号。
3. 对齐：为每镜填充景别、运镜、画面细节与精准音效 BGM。
4. 输出：渲染为 Markdown 表格。

# Example
| 镜号 | 景别 | 运镜 | 画面内容 | 参考对白 / 音效 / BGM |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 全景 / 背影 | 固定，轻微推进 | 上元节夜景，花灯如昼，高墙森严。 | BGM：悬疑垫乐起；音效：夜风、石阶轻脚步。 |
| 2 | 近景 / 特写 | 固定，极轻缓推 | 苏小棠趴在墙头，古灵精怪的大眼睛四处张望。 | 音效：轻呼吸；BGM 压低。 |
| 3 | 胸口近景 | 极速前推，撞击急停 | 苏小棠往前走，头狠狠撞上了王爷的胸膛。 | 音效：沉闷撞击"咚"；BGM 戛然而止。 |
```

## 五、人物资产公式（定妆照 / 三视图 / 肖像特写）

### 5.1 人物定妆照提示词公式（图07）

**【人物信息】**：年龄 / 性别 / 外貌特征 / 发型 / 妆容 / 服装 / 配饰

**【定妆照提示词公式】**：
```
写实真人短剧定妆照，{年龄}，{性别}，{外貌特征}，{发型}，{妆容}，{服装}，{配饰}，正面站立，半身构图或全身构图，背景为纯白色背景，无任何多余光线，真实皮肤质感，五官自然稳定，服装材质清晰，角色造型统一，高清细节，适合真人短剧人物资产图。
```

### 5.2 人物三视图提示词公式（图08）

```
角色一致性约束：保持参考图中人物的五官、脸型、年龄感、发型、妆容、服装、配饰、身材比例和人物气质一致。

视图规格：生成一张完整的人物三视图资产图，在同一画面中同时展示角色的标准正面全身、标准90度侧面全身和标准背面全身。

姿态规范：人物均为自然站立姿态，双手自然下垂，双脚自然站立，头部与身体朝向一致，无夸张动作。

造型细节规范：发型结构清晰，发饰位置准确，服装廓形、颜色、材质和层次关系清楚，配饰位置固定，服装前后结构展示完整。

画面规范：纯白色背景，光线均匀柔和，无多余场景干扰，三视图从左到右整齐排列，人物高度一致，身体比例统一，整体构图清晰规范。

输出要求：写实真人短剧人物资产图，高清细节，适合作为后续分镜设计、角色一致性控制和视频创作参考。
```

### 5.3 三视图生成后检验规则 Check（图09）

```
① 角色一致
② 发型是否变化
③ 服装颜色款式长度是否一致
④ 配饰是否丢失/更换位置
⑤ 身高比例是否统一
```

### 5.4 人物肖像特写的作用（图10）

固定人物面部细节：**脸型 / 五官 / 妆容 / 整体气质**（用于后续近景、特写镜头的一致性控制）

### 5.5 人物肖像特写提示词公式（图11）

```
角色一致性约束：保持参考图中人物的脸型、五官比例、年龄感、发型、妆容、人物气质和角色神态基调一致。

视图规格：生成角色正面肖像特写，采用头部与肩部构图，人物位于画面中心，面部完整清晰展示。

表情规范：人物表情自然克制，眼神清晰稳定，正视镜头或平视前方，无夸张表情和过强情绪变化。

皮肤细节规范：保留真实皮肤纹理和自然面部细节，五官边缘清晰，发际线自然，妆容稳定，不做过度磨皮，无明显AI塑料感。

画面规范：纯白色背景，光线均匀柔和，面部受光清晰，无多余干扰元素，整体构图规范整洁。

输出要求：写实真人短剧人物肖像资产图，高清细节，适合作为后续近景、特写镜头和角色一致性控制参考。
```

### 5.6 肖像特写生成图检验规则（图12）

```
① 脸型五官是否一致
② 发型妆容是否变化
③ 年龄气质是否跑偏
④ 面部皮肤是否自然
```

## 八、分镜关键帧生成公式

### 8.1 分镜图核心作用（图24）

把剧本里的某一个镜头，转化成一张清楚、明确、可用于后续视频制作的画面。
**一张分镜图，最好只表现一个时间点、一个核心动作。**

### 8.2 分镜画面信息拆解公式（图25）

```
什么时间 + 谁 + 在哪里 + 做什么 + 什么情绪
```

示例：夜晚，苏小棠来到王府膳房外，侧身靠近木门，环顾四周，神情紧张的偷看
→ 什么时间：夜晚 / 谁：苏小棠 / 在哪里：王府膳房外 / 做什么：靠近木门，环顾四周偷看 / 什么情绪：神情紧张

### 8.3 分镜关键帧生成提示词公式（图26）

**三段式结构：资产约束 + 画面描述 + 构图机位角度**

```
【资产一致性约束】
保持参考图中{角色名}的五官、脸型、发型、妆容、服装、配饰和人物气质一致。
保持参考图中{场景名}的{木质建筑结构/空间布局结构}一致。

【画面内容】
{什么时间}，{谁}来到{哪里}，{做什么}，{什么情绪}
人物表情{具体表情描述}

【构图机位角度】
采用{景别}构图，摄像机位于{位置}，以{平视/微仰/俯视}角度{斜拍/正拍}，画面同时展示{人物}、{场景元素1}、{场景元素2}。
```

### 8.4 分镜关键帧生成流程总结（图27）

```
① 多图参考搭配资产逐帧生成
② 分镜脚本拆解关键信息
③ 锁定人物场景一致性再描述
```

## 使用说明（执行顺序）

1. **大纲**：用【短剧剧本大纲公式】确定类型/主题/主角/冲突/爽点/时长
2. **剧本**：把大纲喂给【剧本生成提示词】→ 得到标准格式剧本（结尾"黑屏。"）
3. **分镜脚本**：把剧本喂给【分镜脚本生成提示词】→ 得到Markdown表格分镜
4. **角色资产**：按【定妆照公式】→【三视图公式】→【肖像特写公式】批量生成，逐个过检验规则
5. **场景资产**：按【场景提示词公式】用专家模式生成，需多机位时用【九宫格公式】，过检验规则
6. **道具资产**：按【道具提示词公式】生成，过检验规则
7. **分镜关键帧**：用【资产约束+画面描述+构图机位】三段式，逐镜生成
8. **图生视频**：用【主体动作+动作顺序+表情视线+镜头运动+环境动态】公式生成视频片段
9. **配音剪辑**：按分镜表配音配乐、剪辑成片（配音语速180-220字/分，1分钟15-25个镜头）

## 十一、工程化生产机制（向开源流水线借鉴的六条理念）

> 本节管"多集连做、批量交付时不乱套"。单集试片可忽略；一旦开连载，建议逐条落实。来源为 2025-2026 年开源端到端管线的共性实践。

### ① 资产锁定先于生成（反"抽卡式"）

开源工业管线（BigBanana 的 Script-to-Asset-to-Keyframe）的共同结论：**先把角色/场景/道具资产锁死冻结，再进关键帧与视频生成**，生成期不返工改资产。对应本 SOP：第五~七节的资产检验规则（图09/12/17）是硬闸口，没过检的资产不许流入第八节的逐镜关键帧。靠提示词碰运气 = 无限重抽 = 成本黑洞。

### ② 断点续跑与失败重试

- 每个生成步骤默认进行**最多 2 次质量重抽**；限流、排队超时等瞬态错误可额外进行 1 次技术重试。质量重抽 2 次仍败就跳过打标并进入回退链，最后统一处理，不让单镜卡死整集。
- 已有产物**智能跳过**：重跑流水线时只补缺口，不覆盖已通过检验的旧资产。
- 每集结束把整集工程打包归档（分镜表/资产图/提示词/成片），可整体搬家、可回溯。

### ③ 长任务队列化

视频生成是长任务（单镜数十秒到数分钟）。批量生产时把所有生成任务入队异步执行，失败单任务重试不阻塞队列；不要在对话里逐镜同步傻等。人工/Agent 只负责把任务排进去和验收结果。

### ④ 算力成本台账

逐镜记录所用模型与单次花费，一集一汇总。作用：发现"哪个环节烧钱最多"（通常是视频重抽），用数据决定是改提示词还是改流程；超预算的集数在立项时就能预警。

### ⑤ 多供应商 fallback（应急专用）

图/视频/文本三类模型独立配置，单一供应商限流或故障时切换。**注意**：切换供应商 = 画风断裂风险，仅限同类别素材应急使用，主角戏不中途换。

### ⑥ 画布工作流管理长剧

整季项目用"画布视图"管全局（每镜一个节点、流水线竖排、整组重跑），单集用"列表视图"抠细节。LibTV 式画布已被多个开源工具（LocalMiniDrama、Toonflow）验证为长剧管理的最佳形态。

### 本地部署选项（数据不出本机）

Wan 2.x、HunyuanVideo、LTX-Video 等开源视频模型可在本地跑通"剧本→分镜→视频"闭环：素材与剧本不出本机、零 API 费。代价是画质与可控性目前仍低于商用 API——推荐用于草稿预览、敏感题材和断网场景，正片量产仍走商用模型。
