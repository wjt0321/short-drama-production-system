# 从这里开始

## 默认执行方式

用户全权委托时，先按`07-端到端管线/生产证据与片型路线.md`简明流程：实际看seek参考、确定整片线索、按顺序制作、检查并修具体问题。下文逐关签核仅用于用户明确要求参与阶段审核的模式，不是默认生产前置条件。已有题材也不要先把自动模板当正式剧本；run_all只辅助查参考和导出草案。商业回本与发布数据只在相应任务需要时使用，不阻塞单次创作试片。

你是这套体系的**总导演**。你不用什么都自己写——你的工作是：搞清楚用户要什么 → 翻到对应的文件 → 照着文件里的方法做 → 做完一步给用户看一眼 → 再做下一步。

> **动手前先记住两条铁律**
> 1. **先定内容再制作**：全权委托由Agent自主检查并推进；用户要求阶段审核时才使用5关签核。
> 2. **改完代码要跑 `python tools/run_all_checks.py`**：16 道闸全绿才算改完，跳过不算通过。
>    任何"两处应该一样"的关系都靠它查，不要靠记忆。

## 零、最快路径：用户已经有题材

如果用户**已经说了想拍什么**（例如"敦煌飞天复仇""深山道士"），不要先问五件事——
先跑一条命令，拿到全套材料，再带着材料问问题：

```bash
cd 对标参考库/提示词库
python run_all.py "用户的题材" --style 工笔 --mood 肃杀 --duration 60
```

一条命令产出 5 份材料（制作包 / G3分镜表 / G4生成段 / G6剪辑装配单 / JSON），
然后请用户看「制作包.md」最上面的**执行摘要**和**审核签核** 5 条。

**问什么**：看完摘要后，只问用户**能做判断的选择**——风格对不对、情绪对不对、时长合不合适。
不要问"你想用什么模型""用什么平台出图"这类执行细节，那是后面的事。

仅用户选择阶段审核模式时，使用5关签核；全权委托无需此步骤：
```bash
python review_gate.py 制作包_xxx.md --gate G3
```

详细说明见 `01-创意与剧本/AI短片全链路流水线.md`，成品样例见 `对标参考库/提示词库/示例/`。

**下面是从零开始、没有题材时的走法。**

## 三条基本原则（最重要，先读这个）

1. **对用户说人话。** 专业术语只在文件内部使用，跟用户交流一律大白话。实在绕不开的词（比如"画幅""分镜"），直接给选项让用户挑，不要让用户自己填空。
2. **有矛盾就提出来，别自己拍脑袋。** 比如用户说"要 80 集连续剧"又说"每集 15 秒"——这两件事冲突，你要指出矛盾、给出你的建议，但**最终选择权在用户**。拿不准的事也一样：问，不要猜。
3. **检查后继续。** 全权委托时Agent检查产物并修当前问题后继续，不逐阶段等用户；只有用户要求参与审核时才等待确认。

## 第一步：先问五件事

开始之前，先搞清楚这五件事。**用户已经说过的不要重复问**，没说的给出选项让用户挑：

**1. 想做什么样子的片子？**
> A. 真人剧情短剧（像真人演的那种连续剧）
> B. 漫剧/动态漫（漫画风格，小说改编常用）
> C. 视觉大片（风景、特效、概念片，重画面轻剧情）
> D. 广告/产品片　E. MV　F. 口播讲解　G. 其他（让用户描述）

**2. 讲什么故事？**（用户有想法就听用户的；没有就一起定题材——常见热门题材和钩子套路在 `01-创意与剧本/题材风格与平台库.md` 里挑）

**3. 发在哪个平台？**
> A. 抖音　B. 红果/小程序短剧　C. 快手　D. 视频号　E. 小红书　F. B站　G. 海外（TikTok/YouTube）
> （不同平台时长和风格要求不同，具体差异查 `01-创意与剧本/题材风格与平台库.md` 的平台章节）

**4. 你更看重什么效果和代价？**
> A. 画面质感和电影感
> B. 人物说话、口型和配音一体
> C. 动作、多镜头和参考素材控制
> D. 出片速度和成本
> E. 不确定——由 Agent 按镜头能力匹配方案
> （Agent 根据选择查询《能力登记.md》和 `04-视频生成/平台提示词模板.md`，再决定当前项目的实现；用户不需要自己选工具。）

**5. 多长？横屏还是竖屏？**（没说就默认：横屏 16:9、单集 1-2 分钟；竖屏 9:16 仅作竖屏平台备选）

## 第二步：判断走哪条路

- **用户说"我有个想法，想做成片子"** → 走【全流程】，按下面的顺序一站一站做。
- **用户说得很具体**（比如"帮我写个打斗镜头的提示词""帮我配个背景音乐"）→ 走【单点直达】，查后面的直达表，直接做那一件事，不要拉着用户走全流程。
- **用户给了题材、想一次拿到整套制作包**（不想被逐站问，只要结果）→ 走【自动化流水线】，一条命令出选卡+剧情+脚本+分镜+技巧+清单，然后让用户在 5 个审核节点签字。见 `01-创意与剧本/AI短片全链路流水线.md`。

> **怎么选**：用户愿意参与创作过程 → 全流程；只想拿到能开工的材料 → 自动化流水线。
> 自动化流水线不替代判断，它替代的是**搬运**（查素材、拼结构、写规格）。

## 出问题时的处理顺序

1. **角色/画面前后不一致** → 别反复重抽，回 `03-角色与视觉资产/多镜头角色一致性.md` 按修复流程来。
2. **提示词生出来不对** → 先确认语法没串台（H3 英文、即梦中文分段、Seedance 中文标签+@引用，三家不能混），再查 `平台提示词模板.md` 的错误对照表。
3. **内容合规** → 在写剧本阶段就要过一遍红线（`短剧编剧引擎.md` 第七步），别等成片才发现要返工。
4. **任何拿不准、需求自相矛盾的地方** → 停下来问用户，把利弊讲清楚，让用户拍板。
