## 一、ComfyUI 出图（Qwen-Image2.1）

| 事实 | 说明 |
|---|---|
| **默认出 1024×1024 方图** | 即使提示词写 16:9。必须用 `EmptyLatentImage(width, height)` 显式钉 `1344×768` |
| **`resolution` 不是尺寸开关** | API 模式下 `resolution` 是**必填**（GUI 有默认值，API 没有），但**填它不改变输出尺寸**。省掉会报 `prompt_outputs_failed_validation: Required input is missing: resolution` |
| **API 模式下 `images` 是 autogrow 字典** | 必须传 `{"image_1": ["8", 0]}`；传 list 或 `["节点", 0]` 都不被接受 |
| **验收不能信参数** | 每张出图后立刻 `Image.Width/Height` 打印实测值 |
| 现役权重 | UNET `qwen_image_2.1_int8_convrot.safetensors` / TE `qwen3vl_8b_int8_convrot.safetensors` / VAE `qwen_image_2.1_vae_bf16.safetensors`；KSampler 25 步 / cfg 1 / euler / simple |

### 伪汉字：否定式约束**完全无效**（最重要的一条）

Qwen-Image2.1 对"宋代街市"有**必挂招牌的强先验**。实测**连续 5 张**在门柱/店面出清晰汉字，
而提示词里**已经**写了 `readable characters` / `kanji signage` / `any lettering on banners or signs`，
常量里**已经**写了 `no signboard` —— **一条都没压住**。

**唯一有效的解法是正面改构图（三件套）**：
1. `BARE`：`bare plain weathered grey brick and bare unpainted dark timber` +
   `the surfaces are completely blank, smooth and unmarked` + `nothing at all hangs on the walls`
2. 背景**大光圈虚化**：`thrown far out of focus by a wide aperture so no detail is sharp back there`
3. `BLANK`：`completely blank, completely unmarked, no writing, no characters, no symbols`

**绝对禁止后期 gblur 遮字** —— 实测糊出明显矩形方块边，比有字更假，ffmpeg rc=0 零报错。

**判定尺度**：招牌 ≤20×35 像素且不可辨认 = 可接受；≥40 像素或可辨认字形 = 判废重搓。

## 二、ComfyUI 图生视频（MiniMax H3）

| 项 | 值 |
|---|---|
| UNET | `minimax_h3_fused_refdelta_r1024_turbo8_mystic07_int8_convrot.safetensors` |
| TE | `qwen3vl_32b_heretic_minimax_h3_nvfp4.safetensors` |
| VAE | `minimax_h3_video_vae_int8_convrot.safetensors` |
| 采样 | 1344×768 / 124 帧(5.17s@24fps) / 4 步 turbo8 / SLA 0.9 block64 / res_multistep / MiniMaxChunkFeedForward chunks=4 / SigmaShift video 12.0 audio 3.0 |
| **像素红线** | 帧数 × MP ≤ 1.3 亿（1344×768 时最多 124 帧） |
| 机时 | ~207s/镜，9 镜 ≈ 31 分钟 |
| 显存 | 8GB；低显存启动脚本见 `能力登记.md` 的「配置位置」列 |

### H3 的三个行为特征（都会毁掉素材）

**1. 否定式约束提到某个动作，等于把那个动作请进画面**

实测两轮：v1 写 `Nobody raises their arms above their head` → 第 3 帧起高举手臂；
v2 加写 `never lifts it, never waves, never gestures, never touches his head`
→ **举得更高，而且真的把手按到了头上**。
第三轮改用**结构性解法**才通过：两只手都占用来牵绳 + 只写正面状态 + 运镜改 `static`。

> **正解**：让动作在结构上不成立——占住空闲手、减少可动部位、一个字不提被禁止的动作。

**2. 视频会自己加人和加招牌（首帧干净 ≠ 视频干净）**

- 首帧墙面素面无字 → 视频里 H3 **自己长出一块蓝色竖招牌**（20×35px，带白色字样）
- 首帧只有 6 个人 → 视频里**长到 10 多个人**，还多出一块带汉字招牌 + 底部彩色条纹 artifact

> **必看 `<shot>_sheet.jpg`（5 帧横排，自动生成）**。这类问题通常在**第 3 帧之后**才出现。

**3. 运镜要选 `static` 才安全**
`push` / `pull` / `track` 暴露新区域，模型就有"新地方"可以往上加人加招牌。
**镜头不动，模型就没有发挥空间。**

### 触发"动作暗示"的词（都要删）
`as if` / `appears to be` / `seems to be` / `gesturing` / `waving` / `calling out` / `shouting` / `reaching up`

> 注意 `overall_soundscape` 里写 `a merchant's call` 同样会推着画面做呼喊动作。

### 人数约束要**相对首帧**，不能写绝对数字
写 `Exactly five people` 而首帧有 6–8 个时，模型会**往"更满"的方向**调和。
正确写法：`the line is exactly as long as it is in the first frame and it stays that way for the whole shot`。

## 三、BGM（YuE2）

| 项 | 值 |
|---|---|
| 权重 | `yue2_3b_int8_convrot.safetensors` + `ar_lora_inst_v3abc_comfyui.safetensors` + `nar_lora_joint_v4_comfyui.safetensors` |
| 歌词 | **必须锁 `[instrumental]`**，改了就出人声 |
| 采样 | 32 步 / cfg 1 / dpm_2 / sgm_uniform（官方配方，不动） |
| 潜空间 | `EmptyYuE2LatentAudio.seconds` 接 `YuE2GenerateMusic` 的 **1 号输出** |
| `top_p` | 最大 1.0（GUI 里的 1.2 是旧值，越界报错） |
| 时长 | 只改 `YuE2GenerateMusic.max_duration` |
| 机时 | 80s 音乐 ≈ 55s 生成 |

### 调性判定（`bh_key.py`，Krumhansl-Schmuckler + Chroma）
**光写 `MAJOR KEY` 不足**，必须写全这四句：
```
MAJOR KEY ONLY, C MAJOR, simple diatonic major harmony,
no modulation, no borrowed chords, definitely NOT minor, no minor tonality
+ "the melody stays clearly in C major"
```
且**先删小调触发器**：`serene / intimate / dusk / quiet / sparse / slow / gentle / mellow / dreamy`

> 实测：只写 `BRIGHT MAJOR KEY, D major` → 仍出 E 小调 r=0.903。
> 写全四句 → C 大调 r=0.951。**不验调性不算完成**，门槛 r > 0.85。

## 四、ffmpeg 装配

| 坑 | 症状 | 解法 |
|---|---|---|
| **concat 接 xfade 时基不匹配** | 报 `libx264` 崩，真因是 `First input link main timebase (1/1000000) do not match ... xfade (1/24)` | 每个 `concat`/`xfade` 后加 **`settb=1/24`** |
| `color` 源是 RGB | 同上报 libx264 起不来 | concat 前显式 `format=yuv420p` |
| **烧 ASS 字幕路径** | 反斜杠被当转义吃掉；含中文/《》时 libass 解析 `original_size` 失败 | 复制到纯 ASCII 路径，用 `ass=<name>.ass` + `cwd=<纯ASCII目录>` |
| ffmpeg 9.x | `-vsync` 已移除，报 `Unrecognized option` | 改用 `-fps_mode passthrough` |
| **`-ss` 在 `-i` 之前** | **关键帧级跳转**，会回退到最近关键帧（41s 片子能差好几秒），抽出的"中点帧"其实是上一镜 | 用输出端跳转 `-i file -ss T`（帧级准确） |
| `metadata=print` | 是 **INFO 级**输出，`-v error` 会**静默丢掉**，导致切点检测返回 0 而闸显示"通过" | 用 `-v info` |
| 字体 | libass 找不到字体**静默回退**，rc=0 但字全没了 | 字体名用 `PIL.ImageFont.truetype().getname()` 读真名；烧完**抽帧看图** |
| 可用中文字体 | — | msyh.ttc / simhei.ttf / simkai.ttf / simsun.ttc / Deng.ttf |
| 艺术字（已验收） | — | **FZShuTi**（方正舒体）128px 暖金 `&H007ACCF2` + **FZYaoTi**（方正姚体）44px `&H00C4A882` |
| 色值格式 | `&HAABBGGRR`（BB蓝 GG绿 RR红） | 暖金 = RR:F2 CC:CC 7A:7A → `&H007ACCF2` |

## 五、质检闸的三条元规则

**1. 闸只能验"可机器判"的，语义/听感/节奏必须人脑过**
客观闸全绿 ≠ 成片能看。第一次生产中客观闸 9/9 通过，用户一次性指出 6 处问题，全部落在"人要判断"的维度。

**2. 阈值必须来自"已知合格旧片"的同口径实测**
当场编的阈值会给出与事实相反的结论。实例：
- 编"齿音带 < 1.5%" → 已验收成片实测 9.62% / 11.72%，**错 6 倍**
- 把测语音音节的"独立能量团 ≥ 12"套到纯器乐上 → **范畴错误**
- 用均值考核节奏 → **制度化均分**

**3. 闸要反向验证过才可信**
把被检查的性质**主动破坏掉**（等长 → 抓标准差不足；单镜 9.9s → 抓超上限；叠化七处 → 抓转场滥用），
确认闸真的报红，再还原。**"平时都过"不能证明检查有效。**

**4. 抽帧类闸必须先验采样有效性**
抽帧失效会让相邻差值恒为 0 而**静默通过所有阈值**。先断言 `len(抽到的帧) == 期望帧数`，不等就判废非 0 退出。

## 六、脚本派生的两个转义陷阱

**陷阱一：`\v` 被当转义。** 只要替换串里含有目录名的第二个字母是 `v` 的路径段
（例如 `output\video\TUOLING` 这种），Python 就把 `\v` 解析成**垂直制表符(0x0B)**，
搜索串永远匹配不上，`replace` **静默返回原串、不报错**。
同类还有 `\t \n \r \f \b \0`。
→ **凡含路径的替换串，一律用 raw string `r"..."`；改完 `assert 命中次数 == 1`。**

**陷阱二：多行精确串匹配不可靠。** 拿注释+赋值拼成长块去 `replace`，换行符或任一行改动就不命中，同样静默失败。
→ **改多行区块用行锚定正则** + **`assert` 命中次数 == 1**。
→ 收尾必须有残留守卫：`assert "TUOLING" not in s and "EP03" not in s`。
**守卫必须真的会因为漏改而失败，否则就是装饰品。**

## 八、配音（indexTTS）

| 项 | 值 |
|---|---|
| 部署 | 独立项目，uv 管理，自带 `.venv`（Python 3.11） |
| 权重 | IndexTTS-2.5（`gpt.pth` / `s2mel.pth` / `codec.pth`）；webui 必须 `--version 2.5` |
| 推理入口 | `from indextts.infer_v2_5 import IndexTTS2`（**不是 infer_v2**） |
| 调用 | 参数是 `use_bf16`（不是 use_fp16）；`infer()` 必传 `lang="zh"`（ZH/EN/JA/AR/ES） |
| 音色 | 零样本克隆，参考音语种必须与目标一致（中文配音用 ZH 参考音） |
| 定位 | 本机实测 indexTTS 情绪表达优于 VoxCPM，作为**首选配音**；VoxCPM 为备用 |

**铁律**
1. 构造过程出现任何 `missing keys` / `skipping unexpected keys`，一律当加载失败立刻停（v2.0 入口 + v2.5 权重会出电流音，且**不报错、声学指标全正常**）。
2. 官方 CLI（`cli_v2`）和仓库测试走的是 v2.0 入口，不能照抄；只有 `webui.py --version 2.5` 走对。
3. 判定"念全了没有"用**有效语音 + 语速**（有效语音 <0.45s、字/秒 >9、总长越界等四项检查），不用绝对时长；同一句出 N 个候选再筛。
4. 真人声 vs 电流音必须看频谱（谐波堆叠/音节断点/基频轮廓），不能只看 LUFS。
