# 导演视觉圣经

## 〇、为什么需要这份文件

AI 出片最常见的死法不是单镜不行，而是**每镜都"还可以"，整片没有气质**——第三镜是冷青、第五镜是暖黄，特写和长焦乱用，光一会儿顶一会儿侧。真人剧组解决这个问题靠**摄影指导（DP）与导演在开拍前定下的视觉圣经**：全片一套统一的色彩、光线、镜头、质感决策，所有镜头服从它。

本文件把这套决策压缩成四张表 + 三张风格基线卡。使用顺序：**定基线卡 → 填色彩脚本 → 填照明方案 → 每镜按焦段语法选镜头 → 表演说戏 → 用检查清单收口**。

## 一、风格基线卡（先选一张，允许按 7:3 混合）

### 1.0 开工先过两件事：AI 套路黑名单 + 风格探针

**① AI 套路黑名单（真实剧质感的天敌，默认全禁）**

这些是 AI 最容易"自动生成"的画面，越"漂亮"越假，做出来就是廉价古风 MV：

- **光**：黄金时刻逆光、丁达尔光、晨雾、光晕、镜头眩光、大光比
- **色**：高饱和、浓艳、过曝、死黑、全片统一套滤镜
- **脸**：网红脸、大眼、磨皮塑料感、浓妆、满头珠翠、五官一个模板
- **衣**：白衣飘飘、影楼仙气化、无布料质感
- **动作**：摆 pose、空泛意境、"站着看风景"
- **景别**：纯大远景堆砌、人物不做事

（追求真实剧质感的卡 D 必须全禁；卡 A/B 仅在有明确内容理由时少量使用，不得全片依赖。）

**② 风格来源：先自动检索本地库，再做探针验证（纯离线，不依赖任何外部厂商）**

拿到题材后，不要凭空想象风格，按三步走：

1. **自动检索本地库**：在本地 seek 库 / 对标参考库里检索，给出 **2–4 个风格候选**（带本地抽帧 / 封面与借鉴点），由用户挑。检索走体系自带的离线选卡能力（默认用 `对标参考库/提示词库/auto_select_cards.py`，题材 → 本地候选 + 封面；视觉素材在 `seek库/02_视觉素材/`），**全程不联网、不调任何厂商接口**。
2. **风格探针**：选定后先做 **1–2 个探针关键帧**（一个生活场景、一个人物中近景），与参考画面并排比对。
3. **过闸才量产**：探针在光线 / 色彩 / 脸 / 布料质感上对味，才允许批量生产；不对就改 prompt 直到对齐。**不做探针就批量做，等于拿整片段时长赌方向。**

### 卡 A · 繁花系（光影叙事 / 情绪向）

**一句话**：光在讲故事，人在光里走；观众先感到情绪，后知道情节。

| 维度 | 决策 |
|---|---|
| 标志视觉 | 前景遮挡窥视感（门框/珠帘/车窗把画面切成层）、镜中像与玻璃反射、霓虹与暗部青绿对撞 |
| 光线 | 侧逆轮廓光为主，人脸常半明半暗（伦勃朗光变体）；光源必须具名（霓虹招牌、路灯、橱窗、烛光） |
| 色彩 | 高饱和点缀色（红/金/霓虹粉青）+ 大面积暗部；单场景不超过一个点缀色 |
| 镜头 | 长焦压缩（等效 85–135mm）为主，浅景深；慢门抽帧拖影用在情绪峰值 |
| 运动 | 缓推、缓摇；手持只用于混乱情绪段落 |
| 表演 | 少台词多停顿；情绪靠眼神与呼吸，不靠喊 |
| 声音 | 年代感金曲或慵懒爵士；环境声做厚（雨声、电台、市声） |

**适合**：都市情感、悬疑、人物内心戏。**风险**：节奏慢，前 3 秒钩子必须另外加力（用 01 编剧引擎的钩子四型补）。

### 卡 B · 好莱坞炫技系（奇观向）

**一句话**：每 10–15 秒给观众一个"这镜头怎么拍的"的瞬间。

| 维度 | 决策 |
|---|---|
| 标志视觉 | 一镜到底跟随长镜头、FPV 穿越机穿窗穿廊、体积光剪影、爆炸/碎裂慢镜、英雄低机位 |
| 光线 | 强方向光 + 大光比；逆光剪影与顶光压迫交替；戏剧化而非自然化 |
| 色彩 | 青橙对比为底，按场景换对撞色（沙漠金/毒雾绿/冰蓝） |
| 镜头 | 广角沉浸（等效 16–35mm）拍动作与奇观；长焦只用于压缩人群/追车 |
| 运动 | 运动是主角：环绕、升降、FPV 冲刺、速度斜坡；静止镜头只出现在爆发前的蓄力拍 |
| 表演 | 动作先于表情；反应镜头（瞪眼/后退/攥拳）要足帧给 |
| 声音 | 低频轰鸣垫全程，重音点给音效；音乐在爆点处才进 |

**适合**：玄幻打斗、末世、动作、预告片式短片。**风险**：炫技堆过头会疲，遵循 02 新增《炫技镜头与非常规叙事》的"一场一技"纪律。

### 卡 C · 丧尸清道夫系（强镜头语言 + 无厘头构思）

**一句话**：用拍大片的认真劲儿，拍一个正经不起来的故事——反差就是笑点。

| 维度 | 决策 |
|---|---|
| 标志视觉 | 电影级开场（异常冷开场第一秒就出事）、强跟随长镜头建立"大片幻觉"、突然打破预期 |
| 光线 | 真实感优先：自然光/现场光质感，恐怖或紧张段落才上戏剧光 |
| 色彩 | 写实灰绿/冷调为主，让"无厘头内容"发生在"严肃画面"里——反差来自不调色 |
| 镜头 | 前半用大片语法（斯坦尼康跟、航拍升起、浅景深特写），反转点之后可以突然变糙（监控视角、手持、竖屏自拍） |
| 运动 | 一个片子至少一个"炫耀镜头"（跟/穿/升），放在 40%–60% 处 |
| 表演 | 内容越荒诞，表演越正经；旁白/独白用极度生活化的语气讲离谱的事 |
| 声音 | 声画对位是核心武器：画面越紧张，配乐/旁白越日常（详见 02 新增文件） |

**适合**：丧尸/末世喜剧、反差短剧、彩蛋向品牌片。**风险**：无厘头需要剧本层配合，只调镜头不调叙事会"尬"。

### 卡 D · 真实剧集系（自然主义写实 / 生活流）

**一句话**：像真人剧组真的去那里拍了一段生活——真实，就是最高级的精致。

| 维度 | 决策 |
|---|---|
| 标志视觉 | 自然的生活场景（屋内 / 院 / 廊 / 街市 / 楼阁），人物在做具体的事；不刻意炫技，克制、真实 |
| 光线 | 柔和均匀的自然散射光（阴天 / 窗边 / 日间），无硬阴影、无逆光轮廓、无丁达尔；光比小（约 2:1） |
| 色彩 | 低饱和、真实灰度、自然 / 莫兰迪色系；不套滤镜、不强行调色 |
| 镜头 | 35–50mm 自然平视视角，中近景为主；靠内外景与空间调度，少用大远景 |
| 服饰 | 真实棉麻 / 布料质感，素雅层叠、淡妆；发型简洁、不满头珠翠 |
| 面部 | 真实演员脸：自然肤质与细微纹理、五官比例真实、有辨识度；去美颜、去网红脸 |
| 动作 | 人物始终在"做事"：扶栏、整理、缝补、端茶、下楼、开门、回头、收拾包袱 |
| 声音 | 真实环境声（脚步 / 门 / 布 / 水）＋自然的器乐铺底 |

**适合**：生活流古偶、真实质感剧情、仿真人短片（对标《梦华录》《清平乐》等真实古装剧的摄影质感）。**风险**：不靠"第一眼惊艳"取胜，必须把道具、场景、陈设等资产做全（细节拉满，见 §三补），否则会显空。

> **混合规则**：主卡决定光影与色彩（占 70%），副卡只借镜头语言（占 30%）。例如"繁花色彩 + 清道夫结构"= 严肃画面讲荒诞故事，是反差感最强的混法；写实生活片（卡 D）可在关键节点借卡 B 的一个炫技镜头，但不要把卡 D 的自然光改成戏剧光。

## 二、色彩脚本（Color Script）

一场戏一行，开拍前填完。它回答"观众的情绪温度应该从哪里变到哪里"。

| 场次 | 情绪 | 主色 | 点缀色 | 明度走向 | 参考质感 |
|---|---|---|---|---|---|
| 例：雨夜对峙 | 压抑→爆发 | 暗青 | 霓虹红 | 前暗后炸 | 《繁花》雨夜霓虹 |
| 例：清晨和解 | 松弛 | 暖白 | 金 | 均匀柔和 | 日系胶片 |

**规则**：
1. 相邻两场的主色必须有区分（观众靠颜色感知转场，哪怕硬切）。
2. 全片点缀色不超过两种，且同一点缀色只在同一角色的戏里出现（色彩归属角色）。
3. 爽点/爆点场次的明度走向必须"先压后炸"，不允许平铺。

## 三、照明设计三件套（每场景一张照明卡）

提示词里写"柔和光线"是许愿；照明设计是决策。每个场景开工前填：

| 项 | 决策内容 | 示例 |
|---|---|---|
| **主光** | 方位 + 高度 + 性质（硬/柔）+ 具名光源 | 左前 45° 高位，硬光，破碎的霓虹招牌 |
| **光比** | 亮部:暗部 | 8:1（戏剧）/ 2:1（日常）/ 16:1（恐怖） |
| **色温对撞** | 两个对撞光源的色温 | 室内 3200K 暖台灯 vs 窗外 6500K 冷月光 |

**三条铁律**：
1. 同一场戏内主光方位**死锁**（跨镜头复制进锚句，与 03 一致性文件的连续性锁表对齐）。
2. 光比决定类型：不知道打什么光时，先定这场是"日常 2:1 / 戏剧 8:1 / 恐怖 16:1"。
3. 恐怖/悬疑段落的暗部必须有细节（深灰而非死黑），否则竖屏压缩后糊成一团。

## 四、焦段与画幅语法

**焦段即情绪**，每镜按语义选，不按习惯选：

| 等效焦段 | 空间感 | 典型用途 |
|---|---|---|
| 16–24mm | 扩张、变形、沉浸 | 炫技动作、FPV、逼仄空间里的无助感 |
| 35mm | 自然叙事 | 对话跟拍、场景交代（最"隐形"的焦段） |
| 50mm | 标准、平视 | 日常戏、过肩对话 |
| 85–135mm | 压缩、剥离背景 | 情绪特写、窥视感、繁花系主力 |
| 200mm+ | 极压缩、窥视 | 跟踪、人群中的孤独感 |

**画幅默认（全体系权威，各文件以此为准）**
- **默认横屏 16:9**（成片 1920×1080；现役工作流 1344×768）：电影感、环境调度、横向场面、艺术短片的默认画幅。
- **备选竖屏 9:16**（成片 1080×1920；现役工作流 768×1344）：仅当面向抖音/快手/红果等竖屏平台、或用户明确要求时启用。
- 未指定画幅时一律按**横屏 16:9**，不询问、不默认竖屏。

**横屏 16:9 的大片语法（默认）**：
1. **横向调度**：善用左右纵深，人物走位、跟随、横向运动是横屏的气势来源。
2. **环境与人同框**：大远景/全景先交代空间，再切人物，环境是叙事的一部分。
3. **多人同框**：横向空间足，双人对峙、过肩对话比竖屏自然。
4. **浅景深与焦段推拉**：景深分离层次，配合焦段和运镜做节奏。

**竖屏 9:16 备选四招**（仅竖屏项目，横屏思维直接搬会翻车）：
1. **浅景深优先**：竖屏画幅窄，靠虚化分离层次，不靠横向调度。
2. **纵向构图**：主体偏上 1/3，顶部留白给字幕和钩子文案。
3. **上下运动代替横向**：升降镜头、起身/蹲下的垂直动作在竖屏里比横移有气势。
4. **特写比例提高**：竖屏天然适合脸，情绪戏直接 85mm+，不要再退。

## 五、表演调度：说戏四步（给 Agent 的表演话术）

AI 没有演员，"说戏"要翻译进提示词。每个表演镜头按四步构造：

1. **动机**：这个角色此刻想要什么？（写进动作描述：`desperately trying to hide the letter`）
2. **动作**：用一个可见动作表达动机，禁写"很伤心"这类结论（`her thumb keeps rubbing the envelope edge`）。
3. **障碍**：给动作一个对抗物（手抖、雨声、对方逼近的脚步）。
4. **反应**：给视线一个落点（`glances toward the door, then back`）——没有落点的眼神就是 AI 空洞脸的主要来源。

**视线铁律**：角色看画外时，方向必须跟轴线一致（延续 04 号文件的 180° 锁）；对白镜头"看对方"还是"看镜头"全片统一，不混用。

**停顿**：情绪重拍前给 0.5–1 秒的无台词动作帧（整理袖口、咽口水），比任何形容词都更像"演技"。

## 六、全片视觉一致性检查清单（交剪前必过）

- [ ] 开工前已做风格探针并通过（与参考并排比对）？
- [ ] 全片无 AI 套路黑名单元素（逆光 / 晨雾 / 网红脸 / 摆拍 / 大远景堆砌）？
- [ ] 每个镜头都能说出自己属于哪张基线卡？混用处的比例是否符合 7:3？
- [ ] 色彩脚本的点缀色全片 ≤2 种，且与角色绑定关系未被破坏？
- [ ] 同场景所有镜头的主光方位一致？影子方向无矛盾？
- [ ] 焦段选择符合语义表，没有"顺手用了长焦"的交代镜头？
- [ ] 横屏片每镜检查横向构图与安全区？竖屏片额外检查字幕安全区与顶部留白？
- [ ] 表演镜头都过了"说戏四步"：有动机、有动作、有障碍、有视线落点？
- [ ] 颗粒/锐化/景深基准全片统一（后期的"跳质感"在调色前拦截）？
