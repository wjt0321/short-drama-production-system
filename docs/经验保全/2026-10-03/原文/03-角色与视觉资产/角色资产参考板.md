# 角色资产参考板

## 一、为什么一张定妆照不够

专业 AI 片的角色在几十个镜头里始终是同一张脸，靠的不是运气，而是**前期把角色"看全"了**——正面、侧面、背面、四分之三角度、全身服装、材质、典型表情都做成参考图。后续每个镜头不是"凭一句描述重新抽一个人"，而是"从这套参考板里，按当前镜头的视角选对应的参考图，让模型照着画"。

只给一张正脸定妆，会出现三个必然问题：

1. **镜头一换视角就变脸**：剧本要侧脸、背影、低头，模型只见过正脸，只能"猜"，猜错就换人。
2. **全身/远景比例和服装丢失**：胸像定妆没有身体、服装背面和材质信息，一拉全身就崩。
3. **多人同框脸互相融合**：没有清晰的多角度身份基准，模型在多个人之间"分脸预算"，每张都画不好（见 §五像素预算）。

一句话：**定妆照解决"长什么样"，参考板解决"从任何角度都还是这个人"。**

## 二、完整角色资产包（按需，不凑数量）

一个反复出现、需要换视角的**主要角色**，资产包按以下组件准备；一次性、剪影、远景路人不必做全套（对齐 `多镜头角色一致性.md` 三件套纪律）。

| 组件 | 内容 | 什么时候必须做 |
|---|---|---|
| **① 正脸定妆** | 素颜/淡妆正脸，锁脸型、三庭五眼、五官主辅（做法见 `人物定妆设计.md`） | 所有有正脸的角色 |
| **② 多视图转身图** | 同一角色的**正面 / 四分之三侧 / 正侧 / 背面**全身，等高、中性站姿、同套服装 | 会换视角、走位、走动的主角 |
| **③ 服装/造型板** | 每套会出场的服装：正/背面全身，层次、配色、鞋、配饰；古装多为常服/礼服分开 | 换装、服装有展示镜头的角色 |
| **④ 材质与色板** | 棉麻/丝绸/皮革/铠甲等织纹、光泽、厚薄；主色 + 辅色色板 | 材质易漂移（棉布变亮面是高发塌方） |
| **⑤ 表情参考** | 剧本需要的明显情绪（哭、笑、怒、惊）近照，同一妆造派生 | 情绪重头戏、微表情特写 |
| **⑥ 手持/互动参考** | 关键道具手持状态、多人接触关系（站位、谁碰谁） | 道具特写、双人/多人互动镜头 |

**纪律**：
- 资产包是**按需清单**，不是固定张数门槛。先看分镜表：这个角色会出现在哪些视角、景别、服装、情绪里，就做到哪一层。
- 组件之间先互相核对：定妆、转身图、表情图必须已经是同一张脸，否则先修静态锚，再往下走。
- 一经确认即冻结；要改脸/改服装 = 重开一版，不在原版上"顺手微调"。

## 三、多视图参考板怎么做（两条路径，已实测）

多视图（turnaround sheet）是整套资产的核心。生产时有两条路径，按可用能力选择：

### 路径 A：文生图"一板出"

用一条提示词，让模型在**一张横向宽图**里直接排出同一角色的多个视角。适合从无到有、快速立板。

关键（缺一不可，已验证）：
1. 明确写"**这是同一个角色的多个视角，不是多个人物**"；
2. 写清**角度顺序和数量**："正面、四分之三侧、正侧、背面，角度各不相同，不重复"；
3. **中性站姿**：双臂自然下垂、微微张开呈 A 字站姿，背脊挺直，不做动作、不摆姿势；
4. **影棚中性灰/白底、均匀布光、无场景道具**；
5. 把要保持的**脸型、发型、服装、配饰、材质**写全。

### 路径 B：图生图/编辑"从定妆派生"（推荐，一致性最好）

以已定稿的正脸定妆照为**参考图**，让模型"保持这个角色、只换视角"，扩出多视图板。因为脸直接来自定妆，一致性最高，也不用在提示词里重复写完整外貌。

- 参考图给身份（定妆照）；若有服装/材质参考，作为第 2、3 张参考并**在提示词里写明各自管什么**（见 §六）。
- 提示词写明"保持 `<image1>` 角色的脸型、发型、服装、配饰与体型，只把视角换成正/四分之三侧/正侧/背"。
- 输出尺寸由参考图与当前设置决定；需要横板时按能力调整，或单视图逐张生成再拼版。

### 路径 C：逐视图生成再拼版（最稳，适合高要求）

像标准动画/建模 turnaround 那样，**每个视角单独出一张**（正面一张、侧面一张、背面一张），以同一张定妆为参考、用同一组保持项，最后横向拼成参考板。
- 单张图只承担一个视角，不会出现"一图多脸互相抢"，最稳。
- 每张出完并排核对，不一致的重抽；拼版便于检查，**实际投喂视频时可拆回单视图**，避免模型把多视图误当成多个人。

> 三条路径都可在**完全离线**的本地出图能力上完成，不依赖任何在线服务；具体用哪个工作流由 Agent 按《能力登记.md》运行时选择，本文件只规定"要产出什么、提示词必须写清什么"。

## 五、像素预算铁律（崩脸的根因与规避）

**官方与社区 2026 年共识：远景/多人脸崩，本质是"像素预算（pixel / face budget）"问题，不是单纯的提示词写错。**

- 一张脸只有在**占画面足够比例**时，模型才有足够像素解析五官几何。当人脸占比过小（约低于 15%；多人场景每张脸常只有 5–8%），模型把有限的"脸预算"分给多张脸，每张都画不好——五官糊化、融合、扭曲。
- **多人同框是当前所有模型的共同弱项**；远景小脸、纯侧脸、极端俯仰角、脸被遮挡（手/发/道具）也都容易崩。
- 结论：这既是模型能力上限、也可通过**构图与资产方法规避**。把规则写死如下：

| 场景 | 规则 |
|---|---|
| **近景/特写要保脸** | 情绪与反应戏用近景/特写，让主演的脸占画面足够大（≥15%），脸才有细节 |
| **远景/大远景不塞正脸** | 环境板里的人物**远景化、背影化、侧影化**，不要求出现清晰正脸；环境归环境板，正脸归角色镜头 |
| **多人同框逐人分述** | 不写"三个人""众人"，按**空间位置**逐个描述（"左侧人物脸…，右侧人物脸…，中间人物脸…"），赋予不同特征，建立个体语义边界 |
| **人群弱脸** | 背景人群用背影、虚化、遮挡、过曝处理，避免观众数到"突然多了一张生脸" |
| **高风险角度** | 纯侧脸、低头、极端俯仰尽量用对应视角的参考图；无参考就改机位，不让模型硬猜 |
| **小脸后期修复** | 确有必要的远景小脸，可用专门的人脸修复（只在远景小脸时启用，中近景不必） |

**环境板与人物分离铁律**：场景/环境底图里不要混入陌生正脸（会污染角色参考）。先做无人物的环境板，再把角色按正确站位单独放进画面或交给人物镜头。做法与 `场景与道具资产.md` §"场景图怎样实际准备"一致。

## 六、多参考图分工（一张图管一件事）

当一次生成能吃多张参考图时，**每张图应回答不同的问题，并在提示词里写明各自角色**；三个无标签参考会互相拉扯。

| 参考 | 锁定什么 |
|---|---|
| 参考 1（角色） | 身份、脸型、五官、发型 |
| 参考 2（构图/姿势） | 本镜的机位、姿态、构图 |
| 参考 3（材质/环境） | 布料材质、色板、环境 |

提示词里要具名引用，例如 `<image1>` 定角色、`<image2>` 定姿势、`<image3>` 定服装材质，并写清"保持什么、只改什么"。面部、发型、服装、材质最好分别有对应锁定图，不要指望一张图同时锁全部。

## 七、与分镜 / 视频生成的前后联动

参考板不是做完就归档，它要和分镜表逐镜对应，解决"图片与镜头前后有联系"：

1. **分镜表标注每个镜头的"视角 / 景别 / 服装 / 情绪"**，并列出该镜应引用参考板的哪一张：
   - 正面镜 → 正脸定妆 / 正面视图；侧脸镜 → 四分之三或正侧视图；背影镜 → 背面视图；
   - 换服装的镜 → 对应服装板；情绪特写 → 对应表情参考；道具戏 → 手持/互动参考。
2. **首帧由参考板 + 分镜构图生成**，不是凭空重抽；视频模型只负责"让这张构图动起来"，不承担重新设计脸、服装、场景（对齐 `分镜叙事工作流.md` 首尾帧分镜法）。
3. **构图从导演构图库里选**：分镜的"怎么摆、什么视角、情绪如何外化"从 `影视视听语言速查.md` 与 `导演构图库.md` 中按情节选取，再落到参考板与首帧。
4. 复杂互动（多人、拥抱、递物）先做**站位/接触关系的同框关键图**，而不是把两张独立肖像堆进提示词。

## 八、参考板审核清单（G2 资产）

**完整性**
- [ ] 每个主角按分镜需要的视角、景别、服装、情绪备齐了对应组件？
- [ ] 多视图覆盖正/四分之三侧/正侧/背，角度不重复、不缺？

**一致性**
- [ ] 定妆、转身图、表情图并排核对为同一张脸（脸型、五官、发际线、发型、配饰、体型）？
- [ ] 服装的颜色、领型、纹样、材质、鞋在各视图一致，无凭空换装？

**像素预算**
- [ ] 近景/特写主演的脸占比足够、细节清晰？
- [ ] 环境板人物已远景/背影化，没有崩掉的小正脸？
- [ ] 多人镜头逐人分述、无串脸融合？

**可用性**
- [ ] 各视图与分镜表逐镜对应，侧脸/背影/换装镜都有对应参考？
- [ ] 资产已冻结、版本号与文件路径登记，可被后续镜头按名读取？

## 九、公开实践依据与边界

- 多视图 turnaround（正/侧/背或正/四分之三/侧/背，3–5 视图）、中性 A/T 站姿、纯色背景、专业项目用更多参考（不同表情/姿势/光照），是角色一致性的通行做法；多角度参考能显著提升跨镜头稳定。
- 出图模型官方实操明确：改变视角/姿势推荐用 character sheet，且提示词必须说清"**这是同一人物的多个视角，不是多个人**"；多参考图应分别锁定角色、构图、材质。
- 崩脸根因（像素预算、脸占比过小、多人为当前共同弱项）有官方与社区公开说明。
- 以上为供应商中立的公开方法；本文不绑定任何具体模型或平台，具体张数按镜头需要确定，不冒充某位作者的固定配方。
