# 国风提示词库取材

## 零、这个库是什么

- **来源**：liblib.art 登录态批量采集，2026-09-30 起 6 轮扩充
- **规模**：6227 作品记录 / **50642 条真实提示词**
- **筛选标准**：中国元素优先（国风、敦煌、志怪、非遗、水墨、仙侠、侠客、武侠、神话、汉服、故宫、玄学、道教、文物），欧美猎奇向不入库
- **封面**：1234 张唯一封面已下载到 `封面/`（4.34 GB），按 URL md5 命名，本地文件名即唯一键

## 一、核心原则：借结构，不抄句子

**整段复制别人的提示词 = 出片和别人一模一样。**

正确用法是三步：

1. **搜**——按题材找到相关条目（用编辑器 Ctrl+F 搜关键词，如"敦煌""留白""三视图"）
2. **拆**——把提示词按语义切成块，看它由哪几段组成
3. **换**——保留结构骨架，把内容换成你自己剧本里的人物与情节

## 二、拆解模板：国风人物提示词的通用骨架

从库内高频结构归纳出的骨架（按顺序）：

```
[主体描述] + [时代/身份] + [服饰细节] + [动作/神态] +
[环境背景] + [构图安排] + [光影氛围] + [材质肌理] + [风格声明] + [画质词]
```

**实例**（库内「敦煌合璧飞天图」条目）：

| 块 | 原文片段 |
|---|---|
| 主体 | 飞仙自石窟壁面间凌空而出 |
| 动作 | 衣带长帛环绕成优雅动势，姿态轻盈灵动 |
| 道具 | 手持琵琶、莲花与仙乐器具 |
| 环境 | 背景融合赭红岩壁、石青藻井、鎏金祥云与斑驳壁画肌理 |
| 构图 | 飞仙居于视觉中心偏上，飘带向四周延展形成平衡的圆形动线 |
| 色彩 | 朱砂红、孔雀绿、石青与金色交织 |
| 材质 | 岩彩颗粒细腻，古壁画剥落痕迹自然 |
| 风格 | 尽显敦煌艺术空灵浪漫的东方气韵 |

**换成自己的**：把「飞仙/琵琶/石窟」换成「你的角色/你的关键道具/你的场景」，八个块的顺序和详略照抄。

## 四、按阶段怎么用这个库

### 第 1 步：定题材（第 1 阶段）
在库里搜你的题材词，看别人怎么定义这类画面，**校准你的描述词汇**。

### 第 2 步：出角色定妆（第 3 阶段）
搜「人物角色」或「三视图」，找同类型角色的提示词结构 → 套 `人物定妆设计.md` 的流程。

### 第 3 步：出分镜首帧（第 2 阶段）
搜你的场景词（敦煌/园林/宫殿），拿场景描述块，配 `分镜故事板与批量出图.md` 的九宫格流程。

### 第 4 步：视频生成（第 4 阶段）
出图提示词的**首帧描述部分**可以直接扩写成视频提示词，方法见 `平台提示词模板.md`。

## 八、自动选卡（auto_select_cards.py）

**单行命令就能按题材挑出 top-N 候选卡片**。工作方式：

1. 题材描述 → 拆出关键词（先查内置题材别名表，再简单分词兜底）
2. 用关键词在 `name / tags / prompt` 里匹配打分（命中权重：name×5 / tags×3 / prompt×1）
3. 命中为 0 的记录直接淘汰（防止"高赞 ≠ 主题"刷掉相关性）
4. 质量加分：likeCount / 100
5. 输出 top-N 卡片：类型 / 名字 / 标签 / 提示词节选 / 封面本地路径 / 来源 uuid

### 用法

```bash
cd 对标参考库/提示词库

# 基础：单题材，top 8
python auto_select_cards.py "敦煌飞天"

# 多题材：一次查询多个主题
python auto_select_cards.py "国风女角色" "三视图" --top 5

# 限定资源类型与题材维度
python auto_select_cards.py "逆光" --type 图片模板 --topic-type 光影
python auto_select_cards.py "青橙色调" --topic-type 调色 --top 5

# 按短片制作技巧限定（不锁题材）
python auto_select_cards.py "逆光剪影" --tech 光影 --top 8
python auto_select_cards.py "航拍俯瞰" --tech 镜头语言 --top 8

# 诊断：看库里各技法维度覆盖量
python auto_select_cards.py --list-tech

# 批量查询（每行一条）
echo "敦煌\n水墨\n山海经" > query.txt
python auto_select_cards.py --query-file query.txt --out cards.md

# JSON 输出（给其他脚本消费）
python auto_select_cards.py "敦煌" --format json --top 5

# 写在任意目录都能跑（路径参数覆盖）
python auto_select_cards.py "茶道" \
  --prompts /some/other/place/prompts.jsonl \
  --covers /tmp/covers
```

### 通用型保证

- **零本地路径耦合**：脚本放进任何目录都能跑。默认从 `os.path.dirname(__file__)` 推算素材库位置，可被 `--prompts` / `--covers` 参数覆盖。
- **纯本地零网络**：不连 liblib，不发任何外网请求，所有匹配基于已采集的素材。
- **两套筛选维度**：题材维度（`--topic-type`：人物/场景/光影/镜头/调色/氛围/构图/动作/国风元素）+ 技法维度（`--tech`：镜头语言/光影/调色/构图/场景氛围/剪辑节奏）。前者答"画什么"，后者答"怎么拍"。
- **维度可扩展**：`TOPIC_DIMENSIONS` / `TECHNIQUE_DIMENSIONS` 字典里加新维度即可，无须改主逻辑。
- **输出格式可选**：Markdown 表格（人读）或 JSON（脚本消费）。
- **失败降级**：关键词为空时返回空 + 提示建议换个说法；不崩溃。

## 九、注意事项

1. **合规**：库内提示词来自公开作品，**学习其结构可以，直接照搬出图商用需自行判断授权风险**。建议只取结构、换内容。
2. **参数别盲抄**：`steps/cfg/seed` 是原作者的模型和分辨率下的值，你换模型后要重调。
3. **模型依赖**：部分提示词依赖特定 LoRA/Checkpoint，换模型效果会崩，先看条目里的模型引用。
4. **多语言混用**：中文提示词与英文提示词各有优势——中文适合意境与文化专有名词，英文适合精确控制构图与光照。**同一镜头不要中英混写**，参见 `平台提示词模板.md` 的语法对照。
