## 一、这是什么

一个通用 Agent 的短剧/漫剧生产体系 + 素材库，**一个项目**（2026-10 起 `seek库/` 已并入）。
目标：把「想拍一条国风 AI 短片」到「拿到手就能开工」之间的 6 步自动化，人只负责审核。

**不绑厂商、不绑本机路径、整体可搬走**——这三条由第 3、4、8、9 道闸守着。

## 三、四条命令

```powershell
# 四段各自先 cd 到注释里那个目录，再跑命令。

# ① 做片子 —— 先 cd 到  对标参考库\提示词库
python run_all.py "江南 书生 夜雨" --style 水墨 --mood 凄美 --duration 90 --out "<你的输出目录>"

# ② 审核 —— 同上，仍在对标参考库\提示词库 里
python review_gate.py 制作包_xxx.md --checklist    # 先看每关该审什么
python review_gate.py 制作包_xxx.md --sign-all 通过
python review_gate.py 制作包_xxx.md --gate G3      # 没审完不放行（退出码 2）

# ③ 补素材 —— 先 cd 到  seek库\05_工作流与Skills\harvest
python pipeline_collect.py --probe 将军 宫廷 --then-collect --apply   # 默认 dry-run

# ④ 改完代码验一遍 —— 先 cd 到 项目根。必跑，跳过不算通过
python tools\run_all_checks.py
```

素材库挪盘：设 `AI_SEEK_ROOT`。想知道它解析到哪：在 `对标参考库\提示词库` 里跑
`python lib_locator.py`

## 四、15 道闸

| # | 闸 | 查什么 |
|---|---|---|
| 1 | 结构校验 | frontmatter / 外链 / 绝对路径 / 断链 |
| 2 | 数字一致 | 文档写的数字 == 磁盘实况（含**闸数**、技法条数） |
| 3 | 体系可移植 | 清空 `AI_*` 后 skill 仍能跑（8 项） |
| 4 | 素材库可移植 | 同上，采集侧（8 项） |
| 5 | 流水线边界 | 极端参数 / 非法输入 / **时长守恒** / **景别曲线**（10 组） |
| 6 | 样例新鲜度 | `示例/` 与当前代码一致 |
| 7 | 闸的自检 | 独立复算磁盘，不信子进程自述 |
| 8 | 搬家验证 | 整项目复制到临时位置后仍完整、无写死路径 |
| 9 | 闸完整性 | 检查器没被改坏/被删（指纹比对） |
| 10 | 语料质量 | 36 镜抽样：占位符/画风冲突/主体错位/情绪冲突/选卡/技法方案 |
| 11 | 安全性能 | XSS / 路径穿越 / 非法协议；耗时与体积 |
| 12 | 素材对齐 | 封面与候选表匹配，孤儿 < 1% |
| 13 | 未提交提醒 | **只提醒不失败** |
| 14 | 闸集合完备性 | 关键维度有没有闸漏掉（代码里 `REQUIRED` 声明） |
| 15 | 产物自洽 | 制作包/G3/G4/G6 的镜头、时长、时间线、ID、景别互相对得上 |
| 16 | 切点均质度 | 刀长有长有短吗（std<0.2s 判为节拍器）+ 提示词里有没有生成内多刀 |

改了 `tools/` 里的检查器后，闸 9 会报「已改动」——确认是有意的再跑
`python tools\check_gate_integrity.py --fix` 同步指纹。

## 六、最近做过什么（2026-10-01 一轮实战审查）

以「资深制作者视角重跑新题材、逐份读产物」的方式，修了这些：

**产物缺陷**
- 字幕把表演提示当台词显示（`对白字幕：（转身）后会无期。`）；`（闭眼）` 那镜整条字幕只有括号
- 18 字台词被静默截掉最后一个字
- 总时长 60 秒给成 62 秒（逐个 `round()` 各自进位）
- G6 缺抽卡失败回退链 → 补 R1–R5 五级
- 语料污染：工笔/水墨片里混进 `INS风` `纯欲风` `上海中心大厦` `胶片摄影`
- 主体被取成地名（`江南 书生 夜雨` → 主体「江南」）
- 镜头里多出第二个人（主体书生，服饰 `孩童头戴草帽`）
- 情绪不匹配（诡谲恐怖片里 `面带笑意`）
- 景别机械轮转 → `大远景→中景→远景→近景→全景→特写` 的锯齿 → 改成叙事曲线 `0→1→2→3→4→5`
- 选卡选中小红书男模 LoRA，且同一张重复占两个名额
- 第 5 步只给「正则 + 命中数」这种**检索索引**，不是技法方案

**闸失效（更严重）**
- 编排器把子进程闸的 status 写死成 `OK` → 失败被吞，报「✓ 全绿」+ 退出码 0
- `test_pipeline_edge.py` 只 print 不 `sys.exit(1)` → **这道闸从上线起就是装饰性的**
- 新规则在固定抽样里一次没触发，却一直显示「✓ 达标」

**合并**
- `seek库/` 并入，去掉 4.31GB 副本 + 1.5GB 嵌套 `.git`，13.46GB → 7.68GB

## 八、几条别再踩的（都栽过）

1. **检查器必须可证伪**：写完注入一个已知故障，确认它的**退出码真的会变**。不验 = 不知道它是活的还是摆设。
2. **豁免即后门**：任何 `if 某文件: continue` 都要问「它有没有可能正是违规来源」。答不上来就摘掉。
3. **泛化规则后先测误报**：把「N 道闸」泛化成「任意数字+闸」时，先后误伤了比喻义「第一道闸」和量词「任一闸」。
4. **篡改实验本身要先自证**：写 `if False or X` 过滤器根本没被关掉（优先级），差点误判成「闸不敏感」。要写 `False and`。
5. **不解析原数字**：中文数字转换要另写一套还会写错；一律匹配到位置就重写成真值，天然幂等。
6. **gitignore 用 `**` 不用 `*`**：`*` 不跨目录，28 个 mp4（1.17GB）差点入库，靠 `git add -n` 拦下来的。
7. **先查证再下结论**：两个「视觉素材」看着像重复，其实一边是静帧一边是视频；`comfy工作流` 25 个文件内容不同（清洗过）。直接删就是丢数据。
