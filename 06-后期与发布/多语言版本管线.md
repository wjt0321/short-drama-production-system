# 多语言版本管线

## 1. 版本策略选择（先决策，再动手）

开做前先定版本策略，三种策略成本与效果差异极大：

| 策略 | 做法 | 效果 | 成本 | 适用 |
|---|---|---|---|---|
| **A 同画面 + 多音轨** | 画面共用，各语言单独配音轨 + 字幕轨，打包为多音轨文件或分版本导出 | 口型与原语言基本吻合（仅同语系近似），不同语言口型明显不匹配 | 低（只多做配音与封装） | 口型特写少、以中远景/OS 为主的片 |
| **B 同画面 + 配音 + 口型适配生成** | 画面共用，但对口型特写镜头按目标语言重新生成局部口型（图生视频局部重做） | 口型基本匹配 | 中 | 对白以近景/特写为主的短剧（最常用） |
| **C 全片重新生成** | 按目标语言重写台词、重画分镜、全片重新生成 | 完全匹配（语言、口型、文化梗都重做） | 高 | 目标市场文化差异极大，或原片语言梗无法翻译 |

**决策规则**：
- 目标语言与原语言**语系相同**（中↔日韩、英↔西法）→ A 或 B。
- **语系不同**（中↔英）且近景对白多 → B（口型适配是刚需）。
- 全片 70% 以上是画外音/旁白/中远景 → A 即可。
- 想认真做出海品牌 → 至少 B，重点集 C。
- 拿不准就问用户预算与目标市场，给出 A/B/C 的价差。

## 2. 双语台词表（全管线的唯一事实源）

建立《双语台词表》，逐句对齐，作为配音、字幕、口型适配、质检的共同依据：

| 列 | 内容 | 示例 |
|---|---|---|
| 编号 | 集-镜-序号（与分镜表一致） | 01-03-a |
| 原语言台词 | 定稿台词（不带翻译腔） | "你把模型权重给了她？" |
| 目标语言台词 | 本地化翻译（不是逐字直译） | "You gave her the model weights?" |
| 类型 | 口型台词 / OS / VO | 口型台词 |
| 原语言时长 | 配音预估时长（按语速基准算） | 3.2s |
| 目标语言时长 | 翻译后预估时长 | 2.8s |
| 口型适配等级 | 无需 / 局部重做 / 全重做 | 局部重做 |
| 备注 | 文化梗、专有名词处理 | 人名保留原拼写 |

**台词本地化纪律**：
- 翻译目标是**表演可说的口语**，不是书面翻译——台词翻译后必须重新按 `配音与音效设计.md` §1.4 断句，单条 ≤30 字（目标语言字数按目标语速算）。
- 人名、机构名、专有名词按目标市场习惯处理（保留原拼写或音译），全片统一，写入备注列。
- 文化梗/双关语：直译会死梗就换等效表达，并在备注说明"原梗是什么、换成了什么"。
- **翻译不等于重写**：信息量与情绪强度保持，允许语序调整，不允许加戏减戏。

## 3. 多语言配音轨

### 3.1 配音轨结构

按语言分轨生产，保持与画面时间的绝对对齐（同一时间轴，各语言轨只替换人声）：

```
主画面轨（共用）
├─ 配音轨 L1（原语言）
├─ 配音轨 L2（目标语言）  ← 多语言版切换此轨
├─ 音效轨（共用，不随语言变）
└─ BGM 轨（共用，不随语言变）
```

- 人声、音效、BGM 严格分轨，多语言版只替换人声轨，音效与 BGM 复用——这是多语言版成本最低的做法。
- 若目标语言配音后时长与原语言差 >10%，**不要变速硬拉**（音调会变），优先：删冗余尾白、压缩句间空隙、或回 §2 台词表微调译句长度。

### 3.2 配音演员与音色

- 每个角色一个音色（按 `05-音频/配音与音效设计.md` 建档：§2 选音色、§8 平台专属音色定制），多语言版**同角色尽量保持同年龄段/同气质音色**，不同语言由不同配音者完成但音色定位一致。
- 语气要按台词表"类型"列执行：OS 的配音可跨镜连续，口型台词的配音必须与画面口型起止对齐。

## 4. 双语字幕排布

### 4.1 单语版（按语言分版本导出）

每个语言版本的字幕独立按 `成片与字幕.md` §4 字幕规范制作（位置、字号、描边、断行），**不要做双语混排**——竖屏空间不够，双语混排必糊。

### 4.2 双语混排（仅当用户明确要"中英同屏"时）

| 项目 | 规范 |
|---|---|
| 排布 | 主语言一行在上，副语言一行在下，两行同屏；或主语言居中、副语言顶部，不得两行都挤底部 |
| 行数 | 总行数 ≤2 行，每行 ≤15 字符（英文按词断行，同屏行数不足时只保留主语言） |
| 时间对齐 | 两种语言以台词表编号为锚点同时出现/消失，偏差 ≤0.1 秒 |
| 强调 | 每屏最多 1 个变色词，两种语言各自独立强调会太花，只强调主语言 |
| 遮挡 | 任一行遮挡关键画面（表情、证据、字幕区）时，两行一起上移或隐藏 |

### 4.3 字幕文件规范

- 每语言版本独立 SRT/ASS 文件，命名 `片名-EP01-zh.srt` / `片名-EP01-en.srt`。
- 烧录硬字幕按语言分版本导出；不烧录时封装为多字幕轨（用户可切换）。

## 5. 口型适配

### 5.1 适配等级判定（回 §2 台词表）

| 条件 | 等级 |
|---|---|
| 该镜头为 OS/VO，或人物背对/侧面/远景 | 无需适配 |
| 口型特写但目标语言发音与原语言近似（同语系） | 可仅调时间轴 |
| 口型特写且语系差异大（中↔英典型） | 局部重做口型 |
| 口型特写 + 台词长度/音节数差异过大（如原句 6 音节 → 译句 18 音节） | 全重做该镜或降级为 OS |

### 5.2 局部口型重做流程

1. 从《双语台词表》筛出"局部重做"镜头清单。
2. 用该镜画面做图生视频/口型驱动生成：只换嘴部与下颌动作，保持脸、发型、光、背景不变（输入原帧 + 目标语言音频）。
3. 重做后逐镜核验：脸不漂（对照锚句表）、口型幅度与语速匹配（对照 `写实对白微表演.md` §5）、音画同步。
4. 重做镜与原画面的衔接按 `跨镜连续性与帧链法.md` 检查（首尾帧状态一致）。

### 5.3 适配失败回退

口型重做失败（脸漂/口型仍对不上）时按序回退：
1. 该镜降级为 OS 画外音（画面切听者反应或侧脸），配音轨不变。
2. 调整台词表：把译句改短，使音节数逼近原句（在目标语言允许范围内换同义短句）。
3. 全片该角色场景改策略 B→A（放弃口型特写，改中远景），并在成本台账登记损失。

## 6. 多语言版本质检清单

- [ ] **台词表完整**：编号与分镜表一致，无漏句、无加戏减戏。
- [ ] **本地化正确**：专有名词统一、文化梗有等效处理且有备注。
- [ ] **配音轨独立**：人声/音效/BGM 分轨，多语言只换人声轨，音效 BGM 未重做。
- [ ] **时长偏差**：目标语言配音时长与原语言差 ≤10%，未变速硬拉。
- [ ] **音色一致**：同角色多语言版音色定位一致（年龄/气质），无串角色。
- [ ] **字幕对齐**：各语言字幕按台词表编号对齐，双语混排时同屏偏差 ≤0.1 秒。
- [ ] **口型匹配**：局部重做镜脸不漂、口型幅度与语速匹配、音画同步。
- [ ] **回退已登记**：任何降级 OS/改短句/换策略的镜头已在台词表与成本台账登记。
- [ ] **文件规范**：各语言字幕、配音轨、成片命名统一（片名-EP01-语言）。
- [ ] **整片回放**：每个语言版本完整回放一遍，抽查必漏。

## 7. 与发布策略的衔接

- 多语言版本的分发渠道与节奏（同步发 vs 原版先发再跟译版、各市场标题钩子）见 `标题钩子与发布.md`。
- 出海版本的合规（目标市场分级、数据、内容审核）按 `短剧编剧引擎.md` 的合规审查 + 目标市场规则执行，台词表翻译阶段就要过一遍目标市场红线，别等成片返工。
